想找个实习生，欢迎大学生进来瞅瞅

大家好，我想招一个实习生，以下是我的需求：

  • 本科生或研究生在读，

金融/经济/英语专业优先

。

  • 无需坐班，但

最好在北京

，我希望每周能和你见上一次面。

  • 我非常在乎你的

态度

，因为我让你做的事，只需要普通的智商+认真的态度就能干好。

  • 如果你

对具体的财经、研究、当理财博主感兴趣

，我想我们会非常需要彼此。

  • 如果我们彼此适合的话，我希望这种配合以年为单位，而不是3个月，这点对我尤其重要。
  • 我没有名校情节，也不介意你具体是大

(研)

几

，我不需要以美化简历为目的来我这刷实习经验的同学，我不太喜欢总有后路拿我当备选之一的优越感尖子生，我希望你是个能沉下心来的普通学生，没什么选择，拿我当个很珍惜的机会。

  • 我想找的是

踏实、稳定的长期伙伴

。

以下是我能为你提供的：

  • 带你上手慧博、choice、推特等资源的使用，你需要大量阅读文章、研报、海外博主的帖子、书籍。
  • 让你接触到非常具体的泛理财内容的日常生产，包括：公众号、播客、知识星球、知乎、小红书。
  • 我不会让你做简单的重复性的工作，而是直接参与选题生产。
  • 总的来说，就是我付费带你学习，你要汇报分享你的学习成果。
  • 按天计费、工资周结，有具体工作和产出算1天，每天100元，偶尔要来找我一次。

你可以通过「阅读原文」了解我。

如果你觉得自己合适，可以准备好简历或Cover Letter以及你日常的随笔作品，直接加我的微信972319151（备注：实习）。

我评判你的标准已经标黄加粗，合适的同学，我会安排一次电话面试，以及一天工作量的任务。如果我们彼此认可，就正式开始合作。

也欢迎把本文转给你认为合适的同学，谢了。
