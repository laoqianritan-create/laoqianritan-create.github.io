去重庆收房的一些见闻

趁着清明假期，去了趟重庆，办理收房手续拿钥匙。抱歉周二拖更了，现在人在候机室，一会儿回北京。

聊聊这一路的所见所感，时间有限写得急，没什么逻辑：

1去年年初拜托老妈去重庆买了套房子，位置比较偏，所以入手价非常便宜，很棒的江景也只有5千多。

房子的大区位以本地人自住为主，炒性不强。但周边配套优质，交通方便。虽有上涨，但幅度比不上热门区域。

2重庆的新房和二手房供应充足，是一座随时都可以买入上车的4D城市。

楼非常非常多，鳞次栉比。同样人也是真的多，感觉哪里都是人满为患的样子。

尽管如此，现在并不适合投资性买入。甚至本地的刚需买入，都可以再等等。

我们来说说目前的买入成本：

投资性买入，基本上都算“外地三无人员”，很多新盘是不卖给你的。

当然，还有新盘可以接受，还有大量二手房可选。

但买入成本如下：

  • 首付40%起步；
  • 贷款利率上浮20%～30%；
  • 每年0.5%的房产税；
  • 购买后2年不可交易；
  • 如果买楼龄<2年的二手房，再加5.6%的营业税；

如果有重庆户口，是本地居民，利率上浮15%—这是伴随整个还贷周期的，成本太高了。

所以，即便是本地的刚需、改善，我都建议不妨等等。

3 相比窗外景色，感觉重庆并不太在意朝向。这点和北方不同，在北方朝南一定是首选。

在重庆的街头走一走，经常有种身在香港的错觉—复杂、热闹，需要极力仰头，才能看到楼的全貌。

重庆楼都太高了，所以每层相差不大，基本上每高一层，平米单价贵10块。
