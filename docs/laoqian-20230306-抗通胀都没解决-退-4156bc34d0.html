抗通胀都没解决，退哪门子休？

***1***万万妹想到，上海300万退休小夫妻能让财务自由这种烂大街概念又火一把。放心，咱们今天不聊退休躺平，也不聊因人而异的自由。而是想和大家唠唠通胀，因为我发现，大家讨论养老、养娃、财务自由时，总会遇到一个拦路虎——通胀，好像只要有它在，准备多少钱都会有不安感——不够吧？300万也行？

***2 当我们合理地想象未来时，必须考虑到「货币的时间价值」，因为通胀，所以今*年的钱比明年的钱更值钱，想维持同样的购买力，明年的钱必须更多。这就是我们的恐惧之源。

***3*** 首先很多人忽略了极其重要的一点：不同消费结构和生活方式的真实体感通胀天差地别！什么意思？

你有娃还是没娃？养车还是共同交通？油车还是电车？做饭还是外面吃？有房还是租房？常去医院还是不去医院？

通胀（CPI）只是一个数字，一视同仁，但体感通胀，千人千面。

***4*** 货币如水。

物价是一个蓄水池。股市也是蓄水池，楼市也是，黄金也是，茅台也是，汇率也是，文玩字画也是... 我们有大大小小各种各样的货币蓄水池。

什么是通胀？物价蓄水池的水位上涨速度——CPI。

***5*** 什么是通胀？国家的价值观会深刻影响各个蓄水池，以美国为例：

生命（医疗）和阶层通道的入场券（教育）最贵；房子和食品基本与CPI持平；汽车、服饰、3C产品，越来越便宜。

***7*** 所以，重要的不是通胀本身，而是你的生活方式和支出结构要面对的通胀。

比这些都更重要的，是找到能高效跑赢「货币印钞机」的那个蓄水池！

如果连印钞机都能跑赢，通胀又算哪根葱呢？它也只是印钞机的一个低效蓄水池罢了。

举个现实中的例子：

我在沈阳老家有个二代同学，家学深厚，同学成了家族公司里最善于搞关系的销售，特别会满足大哥的多样化需求，投其所好。他跟我说：生意虽然挣钱，但账期能拖死你。搞关系的支出又高，但多年下来，搞关系反倒成了非常舒服的赚钱业务，因为每次给客户买茅台，都会顺道多买一些囤起来。

茅台就是个横截面很窄的蓄水池，水稍微多点儿，水位上升得极快！

***8*** 黄金是另一个观察印钞机的有效蓄水池，这是金价走势图：

你会发现，1971年以前，黄金价格一直非常稳定。

为啥？因为那之前是金本位时代，黄金是地球共识度最高的流通和储备货币，金矿就是全球的央妈。这套体系彻底终止于「布雷顿森林体系瓦解」，此后，人类彻底放弃了金本位，转向更容易扩张的信用本位。

于是，我们看到黄金作为货币体系的镜像，其价格在1971年以后随着轰鸣的印钞机一路狂飙！这是一场长达半个多世纪的赛跑，而美元相对黄金贬值了接近97%。

通胀和美元指数，都和黄金价格没有太大联系，纸币的随意印刷和滥发，才是推动黄金价格大幅飙涨的主因。

***9*** 现在，我们再来梳理一遍整个逻辑：

1971年，人类打开潘多拉魔盒，发现里面装着一台印钞机，从此进入信用本位时代。

只要印钞机还放水，通胀就会一直存在，各个蓄水池的水位会越来越高。这样的时代，蓄水池为王！

那些共识度高、供给有限、稀缺属性强、可以流通交易的蓄水池可以跑赢印钞机。

哈，这场不可言说的分配游戏哟~

***10所以，印钞机时代，你该首先放弃的，就是对货币的信仰。*

黄金、商品、房子等实物资产可以对抗通胀。

农业股、能源股、消费股可以涨价对抗通胀。

医药股、科技股可以靠成长和拉估值对抗通胀。

金融地产股可以靠杠杆对抗通胀。

所以，再看那对网络热议的300万退休上海小夫妻——300万不重要！300万的XX资产，很重要！

***11*** 最后升华一下：

人生的意义是自我寻觅的，家庭财务责任是不可逃避的，躺平心态是不值得鼓励的，自由的标准是因人而异的，你的财富是靠资产定义的。

祝兄弟们发财！且幸福！
