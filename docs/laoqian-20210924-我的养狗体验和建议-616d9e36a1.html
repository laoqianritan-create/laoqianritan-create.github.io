我的养狗体验和建议

‍‍

聊狗之前，必须开门见山地亮一个观点：

如果你想亲自养个宠物的话，我建议优先选猫，它更好养。现实也是如此，养猫的人就是比养狗的多。在网络上，与猫相关的流量更是碾压狗狗。

原因多种多样：比如养狗需要更大的空间，对很多人来说这就是个老大难。养狗需要更多的时间，一天最少两次带出户外活动，风雨无阻。捡屎官最烦的，就是下雨。养狗也更费钱，狗狗消耗的财力肯定比猫多很多。

总结来说，养宠物需要你有钱、有房、有时间。而养狗尤甚。

如果以上都不是问题，你还在猫和狗之间纠结怎么选，也好办。

养宠物本质是一种精神文明消费，绝大部分人的需求都是陪伴，而养宠物是一种最低成本的陪伴消费。

把养宠物换成找对象，如果倾向于选择找你爱的人，那就养猫。反之，倾向选爱你的，养狗。

... ...

我的第一次养狗体验比较失败，因为没有任何经验和准备，直接从朋友那接手了一只金毛，然后种种问题就来了。那时我还没买房，租的一居室，我们和狗子的地方都很有限。它的体型又大，80多斤，钱嫂遛他时经常拉不住。加上我还没全职做公众号，还在上班，白天把它关在笼子里，非常不落忍。

最后开车把它送到了我上大学时当家教带的小朋友那，他们家条件很好，有大院子，本身也养了一条狗，而且三代同堂，家里常年都有人。

这次经历让我意识到，养宠一定要做好十足准备，不要相当然地将就克服，因为开始的任何一点勉强都会在日后无限放大。

... ...

之后我买了房子，也彻底成为自由职业者，我意识到自己还是非常需要陪伴的，坚定了还是要养狗的决心。

吸取上次的经验教训，经过一番深思熟虑后，我制定了几条硬性标准，如果不符合条件，坚决不养。

第一，我要领养。

第二，必须是小型土狗。

第三，必须有流浪经历。

第四，必须是成年狗。

上面每条标准背后都有巨大好处，我详细解释下：

只有领养，我才有足够多的选择，可以在领养平台上筛选符合条件的狗。

小型犬不占地，遇上急事比如和别的狗打架、生病，抱起来就走，方便。

小型犬更容易办狗证，路人对它的反感和恐惧也会小很多。

土狗是领养平台的主流犬种，普遍短毛，毛发重，会落在地上，对呼吸道影响小。

土狗肠胃好，不挑食，不易生病，好养活。

土狗有看家护院的基因，非常习惯独处，性格独立，很少会主动招惹路人。

有流浪经历的成年狗狗被收养后一般会极其懂事，珍惜当下的生活状态，主动迎合适应主人的生活习惯，不拆家，坚决不在家里拉屎撒尿。

简单的四条标准基本能保证我找到一条几乎挑不出毛病的天使狗狗，而且每条都不过分，相对容易实现。

2019年8月，我真的领养到了完全符合所有标准的理想狗狗，她叫福袋，是一只两岁多的流浪土狗，长这样：

福袋到家后的表现挑不出任何毛病——地上的拖鞋袜子一律不碰，可粘可飒，家里没人时从不焦虑，喜欢自己晒太阳，而且我最担心的流浪狗护食的毛病也没有。

教会她yes、no、停、坐下、不许动这五个最基本的口令后再没鸡过娃。

我之前经常因为焦虑晚睡，养了福袋以后，抱着她躺在瑜伽垫上很快就能睡死过去...她也从来不吵我。经常后半夜醒来，用滚毛器滚掉身上的狗毛，再爬上床睡觉。

... ...

最后，提醒所有养狗人士一句：

其实养狗和抽二手烟很像，是一个充满了负外部性的行为。

除了你自己，其他人都不会把你的狗当作心肝宝贝。

尤其是小区里带小朋友的家长、上了年纪的老头老太太，这些人群天然对狗狗排斥、恐惧、更有甚者欲除之而后快。

所以狗主人没有任何理由让社区和路人承担你养狗行为的负外部性。

一定牵绳！捡屎！
