早早躺平的上海夫妻

‍‍

‍‍●

躺平是今年突然流行的一个网络热词，对此我没什么看法，任何一种思潮能够流行起来，背后一定有与之对应的社会环境和经济基础。

最近有个7年前的网络旧帖被刨了出来，主人公是一对上海本地夫妻，早早就过上了躺平的生活。

基本情况如下（注意下文都是2014年原贴的表述）：

上海本地人，男43岁，女39岁，没孩子。

三套房子市值500万，现金150万，股市50万，其中10万是股票，无贷无车。

1994年就已经在上海外企工作了（有收入优势，相当于早期互联网行业），后来2008年外企倒闭，题主夫妻双双辞职，彻底躺平。

2014年两人花了2万元，大概生活状态是这样的：

社保已经交够15年，不再交纳。

平时只去菜市场买菜，水果牛奶零食都不怎么吃，就喝茶买点西瓜。两人共用一部手机，步行或者骑车，一个月吃一次120元/人的自助餐。不买衣服，不买化妆品。

不孝敬父母，也不问爹妈要钱，就靠上班时的积蓄过日子。

天天躲在家里看电影和电视剧，住的房子90平，两个人住很宽敞。

●

原贴下面也有一堆网友各种指手画脚，题主都有回复，从中也大概能看出来他躺平的想法，依然引用原话：

之前享受过（好日子），用两年时间游了全国100多城市，现在这样不觉得没面子。

房子是2002年上班时买的，2500每平，也就这点运气了。

超市东西贵还有毒，不敢吃，但买肉要来超市。

不跟朋友来往，不花钱也没人跟你交际，现在的社会多个朋友多份危险。

上海基本物价不涨反跌，09年时一年要花3万多，2014年只花了2万。

不上班了身体好，健康最要紧。

我很舒服，不用看人脸色，这就是有尊严。

在中国凭借自己的劳动就只能温饱，我已经温饱了，为啥还劳动？

听说要延迟退休、延长社保缴费年限就想通了，不如先退休。

每天起床最先想到的是股市，睡觉都梦见K线图。

小孩子可爱，但长大了都是坏蛋，你老了打诈骗电话的就是现在的小孩子。

一个人可以没本事，但要有自知之明。

我引用的都是他的原话，就是想让大家看看一个心安理得躺平的人，他到底是怎么想的。

说实话题主的一些观点我个人非常不喜欢，但是必须承认他还是挺诚恳的。

有网友劝他把上海的房子卖了，去个环境优美的小县城住别墅，能活得更好。还有人劝他去二线城市，那边成本更低。

但是题主全都怼了回去，坚决不卖，就呆在上海。在这种大是大非的问题上看得还是很清楚的。2014年至今上海大涨了两轮，一轮是2016-2017年，第二轮是2020-2021年，我估计他那三套房子最保守估计也有1200万市值了。

相当于2008-2021真躺着赚了至少700万——这何尝不是现在很多小年轻躺平的一大原因啊！有人躺赢，就有人躺平。反正靠打工房子一辈子也攀不起了，还不如取悦自己。

包括欧美流行的YOLO（you only live once）思潮也是类似的思路，正经路子都没戏，人生这样也没啥可输的了。风险有限，收益无限，那就索性梭哈干两把。

另外你说题主不上班这些年错过哪些时代红利了吗？想想好像也没有，2011年初代互联网时代那会儿男主都40岁了，真想再扒上一辆时代高铁似乎也不太可能了。

每个人一生中最精彩的部分也就是身上那点时代性。

像题主抓住了外企职场红利+上海楼市红利，也就有资本心安理得地躺平了。

最搞笑的是他说每天早上起来最先想到的是股市，其实也就10万的本，做梦都放不下，还是这玩意磨人呐！躺平了都淡定不了...
