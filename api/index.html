Static JSON API

先看懂接口做什么，再点进去取数据。

不要把整页 JSON 粗暴堆给人看。先给 4 个接口卡片，再给示例响应与引用要求。

Index

/api/documents.json

全站索引，用来搜索、筛选、做目录页。

Document

/api/documents/<id>.json

单篇全文、元数据、attribution_text 都在这里。

Sources

/api/sources.json

拿到来源统计和引用协议。适合先判断站点结构与引用要求。

OpenAPI

/api/openapi.json

给程序和 AI agent 用的机器可读接口描述。

How To Use

API 说明

本站是纯静态 API。你可以直接抓取 JSON 文件，不需要鉴权。

  • 先读 /api/documents.json，拿到所有文章和播客的索引。
  • 再用某个文档的 id 去请求单篇详情。
  • 展示或引用内容时，必须同时保留 attribution_text。

示例链接

  • /api/documents.json
  • /api/sources.json
  • /api/documents/laoqian-20260227-余生-roi-你余-2166886e30.json
  • /api/openapi.json
