# 萧条中的生存智慧

给大家推荐一本书吧，书名就是标题，作者是个日本企业家，叫「长谷川广和」，在尼康、家乐氏、强生等7家跨国企业担任过高管或董事长。  
  
在日本的「失去时代」，作者作为企业重整顾问，帮助2千多家企业扭亏为盈。  
  
我是真心被书名吸引了，但稍微翻了几分钟就直皱眉毛，全书爹味满满，其中的很多话放到今天的中文互联网上都足以引发数起无可挽回的「哪李贵了」式的公关危机。  
  
不过这本书在日本很畅销，重印过24次，也足见中日在很多层面是有很大差异的。  
  
比如我自己的一个感慨就是：日本的集体主义氛围要远胜我国，否则这种书也不会如此受欢迎。  
  
本书更像是那种鸡汤汇总，它最神奇之处是，你甚至只看一遍目录，就能大概把本书看个七七八八，非常快。  
  
P.S. 目录给大家截下来了，放到了✅图4. 有微信读书会员的可以自己去搜来看。  
  
我带着两个目的把本书快速扫了一遍：  
  
其一，我好奇日本倡导的职场文化，一个强调员工对企业忠诚的环境里，需要给「企业战士」灌输怎样的观念。  
  
其二，90年代经济泡沫破裂后，加了最多杠杆的企业部门，从追求「利润最大化」转而追求「债务最小化」。  
  
这种转变过程中，如何自我税负，如何改变企业经营？  
  
比如：「哪怕多1日元也要赚，成本哪怕少1日元也要压缩，无论做什么都要创造利润，要有这样的干劲才可以。」  
  
总之还是推荐大家一看，感受下，反正半小时左右就能看完，也不费事儿，说不定会有点启发，万一呢~
