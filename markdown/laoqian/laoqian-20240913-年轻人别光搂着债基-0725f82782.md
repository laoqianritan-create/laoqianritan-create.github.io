# 年轻人别光搂着债基下蛋，多少也投资下自己

这两年的一个显学是过苦日子，然后买债基下蛋，别管收益高低，起码大部分日子里都是红的。  
  
但✅图 3. 给我们提了个醒，推荐大家仔细看下全文，它告诉我们：  
  
自己的人力资本效用高的阶段，应该多投资自己，这有点类似企业的研发费用。很多支出，表面看起来是消费，其实是一种投资——  
  
一本书，一节课的价值，拉长看，其效益可以换台车也说不定，真的！  
  
老话讲得好，穷则独善其身（人力资本），达则兼济天下（四处交换优质企业的长期现金流）。  
  
什么阶段干什么事儿，就像我最后悔的事之一，就是大学期间追求什么经济独立，四处走穴当家教找实习。大二到大四那 3 年，累死累活折腾那点儿钱，还没现在一个月赚得多... 搭进去的却是最美好的青春。  
  
有那功夫，多谈恋爱多看书，多好！  
  
想当年，哥这张脸啊，去吃软饭都能硬吃。算了，不说了...
