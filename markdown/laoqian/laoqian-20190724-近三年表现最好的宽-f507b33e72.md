# 近三年表现最好的宽基指数

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MtYY6DwPeUXqfqgXDKoQRQeA9lxVSd9HTSxerpf9Kfab3NIHynuD1vvdRfyy5R85thF4htRUm9uw/640?wx_fmt=png#imgIndex=0)

你们先猜猜，近三年表现最好的宽基指数是谁？

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PU8yicyqFOxN1pQSSEnuqaoBTTYJzpZVq7KdcDQbg7tOHCx8ER1vS2cjEmMrhFWvI9bQeehSEJNuQ/640?wx_fmt=png#imgIndex=1)

其实是很少被提起的那个，中证100指数。

用数据说话，这4个指数近三年走势是这样的：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PU8yicyqFOxN1pQSSEnuqao31S2AXv3ZyW2hVA4TDqhC7HMbrVsU8zjVSKp6gSgMgDnEo6a7kibqFg/640?wx_fmt=png#imgIndex=2)

收益排序是100>50>300>500。

中证100能这么厉害，我觉得有几个原因：

从行业集中度看，100比300更集中，又比50更分散，这不废话么...

我来详细解释下：

50的缺点是只覆盖了沪市，深市最好的好股票并不在篮子里。

300的缺点是它的成份股中「周期性行业个股」有一定的占比，而这几年周期性股票的表现并不好。

100则同时避免了这两个问题，比300马太效应更强，比50更全面。

今年行情的特点是，谁超配白酒谁牛逼，100确实比两位哥哥在家电和白酒行业上的仓位更多。

100还有个外号叫「北上资金聚宝盆」，因为估值优势，[外资一直在A股买买买](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649613065&idx=1&sn=1171000da02d6266044269b089ffab72&chksm=881c27d5bf6baec3beb0252ccbf522b42721dcd913cfcfd7a4d4d6c29e245f266f1ae30d3d32&scene=21#wechat_redirect)，成天进进出出的北上资金一直被看作市场风向标，他们重仓的行业排序依次是：

食品饮料、非银金融、银行、家用电器、医药生物。

跟100的重仓股行业是一样的：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PU8yicyqFOxN1pQSSEnuqaopiaIE2B8yFo70ZDzCg0lxYvTjjKraiaCtGvyPuC5zqcHlPb1Tia83HRNg/640?wx_fmt=png#imgIndex=3)

这5个行业，不光北向资金在超配，也是所有公募基金最重仓的行业，所有机构一起抬轿子。

估值呢，高不成低不就，因为白马抱团，确实不便宜。

现在PE-TTM是11.4，2015年高点是15，2018年高点是14.6，你们感受下：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PU8yicyqFOxN1pQSSEnuqao1GneqTCgX5M63ZesjQmsHJSQVNVIiayUl49wA6gycibHrFmUSUeGBibDg/640?wx_fmt=png#imgIndex=4)

P.S. 指数基金呢，没有多大差别，大家都是完全复制中证指数公司提供的权重文件，不用纠结买哪个好。

同一个指数，选择哪个基金主要看两方面：规模别太小，尽量选C类的，费率最便宜。

又，搜基金，我觉得数据最全的是「天天基金网」。
