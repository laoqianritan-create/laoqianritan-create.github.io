# 买基金喂饭指南

![图片](https://mmbiz.qpic.cn/mmbiz_gif/ibw8b04QVx2M7PTAr8JHoc98wCJlkDyXxsA0LtNpBgqhicVxmxOENpDia40416PMnQfU6BgCLN0bVtwGJS9LMhIJQ/640#imgIndex=0)

被昨晚的留言气到了，带着小情绪写下这篇文章，用了半个小时左右。

我把基金投资的所有知识点写了一遍，包括用什么软件买、如何定投等等，方便大家查阅：

***1*** 场内和场外没啥区别，场内无法自动定投而已，需要手动来。

所以我个人一般都是推荐场外，自动定投能帮你省很多事儿。

人为定投是有变数的，比如定投的基金跌很多，该加仓的时候你反倒犹豫了，机器不会出现这种问题。

***2***我只建议购买「指数基金」，核心原因是，不用考虑「基金经理」这个变量。

牛逼的基金经理更适合私募，因为赚得更多，盘子小难度也小。

***3***指数基金有两种：「宽基指数」和「行业指数」。买入策略如下：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2ONMVsS6BgpL8M0TWWHtPM76cibjicZ2zkumKnO7ongmzHpY2ZMIklrNZdGrq5icqVgvrOeSoH8vdWtg/640?wx_fmt=png#imgIndex=1)

***4***长赢是我个人最推荐的指数基金买入策略，他的核心逻辑就是低估买入。

消息回复：**长赢**  可以收到。

长赢最大的好处是逻辑靠谱，实盘运行10年以上，有买卖建议，非常省心。

好策略从来都是简单有效。

***5***但是长赢有个缺点，就是它的频率不固定，可能突然会让你买入好几份。

如果你更喜欢固定频率的定投，回复：**估值**  有另一个相似的低估买入策略，每月定投。

***6***跟踪同一个指数的指数基金们差别非常小，大家的目标都是牢牢跟紧指数，尽量减少跟踪误差而已。

所以在选择上不必纠结。

***7***其实基金定投偏左侧交易，越差越买。

基金不好的时候，你能找到各种缺点，它唯一的好处就是便宜，这就够了！

***8***基金定投的意义是**降低持仓和犯傻成本**，不要抱着买了就涨的预期。

什么时候涨，市场说了算。

不要预测市场走势，不要预测市场走势，不要预测市场走势。

***9***目前市场上最常见的基金定投APP是「蚂蚁财富」和「天天基金」，安全的，别怀疑了。费率都是最低的一折。且慢的费率也是一折。

***10***不同基金之间做比较，我一般用天天基金网，数据是最全的。

如果是看指数基金的基本面（注意是指数基金），我一般用「理杏仁」这个网站，没有APP，需要付费，不贵。

***11***基金不是股票，别指望大幅盈利，能超过15%就该知足，也要开始考虑止盈了。

***12***低位的时候肯定一次性多买点儿更合适，前提是，你真的确定它在低估区间。

一次性买入的钱和定投的钱，还真就不太一样。

***13***定投更像一种生活方式。

定投资金最好的来源是工资，因为每个月都有，它是小钱、闲钱、长期不用的钱。

***14***公众号对话框里回复：**定投**  建议把收到的文章都看一遍。

***15***基金定投，亏损时卖出，浪费时间浪费金钱。亏损时卖出，浪费时间浪费金钱。亏损时卖出，浪费时间浪费金钱。

***16***定投频率无所谓，长期看对最终收益影响微乎其微。

定投日期无所谓，建议在发薪日之后。
