# 74岁老股民的幸福晚年生活

2019年我写过一位特别可爱的日本老头，叫「桐谷广人」。

👉《[带着600支股票退休的老头](http://mp.weixin.qq.com/s?__biz=Mzg2MDc2MjM3NA==&mid=2247493358&idx=1&sn=883f5ee81ba544cc18b65952a9667659&chksm=ce23de87f954579136123475ddbae9e6eab14ab79c189b5bd9c6a405473517b56fdef26030fd&scene=21#wechat_redirect)》

给还不了解的读者快速介绍下这位：

70岁的退役职业象棋手，因综艺而火的知名IP，日股多年老股民，持仓近千支股票，目前持仓创新高身价5亿日元，长期投资践行者，不买房人士，每天为消耗掉股东福利券而努力，不花现金，东京街头单车传说，还在追女生的纯爱战士...

这位老哥非常有喜感，人也很欢乐，给我留下了深刻印象。

哦对了，这里稍微回顾下前情提要：

桐谷大叔年轻时以前是职业象棋手，总去证券公司教人下象棋，所以也成了股民，炒股5年把账户做到了2亿多。

2006年1月23日下午收盘，账户迎来新高，3个亿，结果遇到08年经济危机，资产变成了原来的1/6。

生活困难后，桐谷决心利用好收到的股东福利券生活，往后余生只有两件事：

**继续炒股！非交易时间努力用掉每一张股东优惠券！**

通过桐谷使用福利券的场景可知，他的持仓中有相当部分的必选+可选消费股，这是日股第一大权重板块，而且在失去的30年期间，消费板块长期表现非常好，稳定跑赢大盘。

尤其在08年次贷危机之后，消费板块走出了一波大牛市行情，这很大程度上受益于「安倍经济学」。

日本消费板块内部有两条主线——一是个性化消费，二是出海成功的公司，两条线索共同指向了「增量」。

撤回来，今天的主题是八卦！

兄弟们我就不硬上价值了，老哥很讨喜，能感觉出来他在日本的群众基础也很高，是老年人中的一抹亮色。

1989年12月29日，日经225指数达到了历史最高38957点，就在市场普遍认为4万点不是梦时，泡沫开始破灭了。

回顾这30多年的历史，日本股市整体的表现不好**（还未创新高）**，但也没那么差，因为日经225指数中并不包含股息红利收益——30多年的维度看，这部分收益影响很大。

其次，拖累日股这么多年的罪魁祸首主要是金融地产股。在现实经济中，房地产泡沫破灭后，以银行为主体的间接融资系统无法找到合适的信用扩张渠道，M2始终起不来，货币乘数不断下降。

**P.S. 08年次贷危机后美股金融板块持续跑输大盘。2010年之后我国M2增速持续下台阶，银行板块估值也持续创新低，股价持续跑输大盘。**

而日股中的科技、消费、医疗保健板块都实现了结构性牛市，大幅超越了1989年历史高点。

而日股特色的「股东优待计划」，相当于在股息之外，又多了一层股民福利——这也成了桐谷大叔晚年生活的根基。
