# 好好搭个股票池

![图片](https://mmbiz.qpic.cn/mmbiz_gif/ibw8b04QVx2M7PTAr8JHoc98wCJlkDyXxsA0LtNpBgqhicVxmxOENpDia40416PMnQfU6BgCLN0bVtwGJS9LMhIJQ/640#imgIndex=0)

什么是股票池呢？

我理解，股票APP里的「自选股」板块就是你的股票池。

写《5分钟看懂一家公司》系列后，我开始给股票池做减法，剔除了很多票。

因为我发现，池子里的大部分股票，自己都没有无法做到心中有数，知根知底：

既然如此，关注那么多股票有啥用呢？只会带来更多噪音。

更何况正常情况下，根本不会持有很多支股票。

看了下自己的账户：除了用来当[打新门票的银行股](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649609374&idx=1&sn=8e121c6e00c318146684c3b756d635f3&chksm=881c1042bf6b9954a95c098f0c9ffca154e702713ee32c444c6eb323719067e4fb3c8e044866&scene=21#wechat_redirect)外，只有2支个股，剩下都是场内基金。

现在池子里留下的票，我给自己定了几个要求：

***1*** 看过研报和财报（理杏仁上有「自定义财报」功能，很好用）；

***2***熟悉公司所在行业的格局，知道竞品是谁；

***3***对公司基本面，低估高估有个大概判断；

***4***知道要关注的「核心指标」是什么；

***5***有心理价位，有设置价格提醒；

前4条不就是《5分钟看懂一家公司》系列要做的事儿嘛～

推荐几个工具：

理杏仁（网站）—多次提到过的，在基本面和财报展示方面做得特别好；

通联数据（网站）—非常好用的金融搜索引擎，可以用来找数据和研报；

雪球（网站）—关注的公司，可以去雪球里关注下，可以看到很多讨论。但是噪音很多，建议多看大v少看韭菜，多看文章少看观点；

总结起来就一句话：对于真感兴趣的公司要去研究，不然干脆就别看。

真正了解一家公司很难，其复杂程度远远大于了解自己。
