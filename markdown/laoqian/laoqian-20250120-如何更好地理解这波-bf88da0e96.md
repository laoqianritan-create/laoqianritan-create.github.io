# 如何更好地理解这波中美对账？

这两天热衷于在小红书的#中美对账单#标签里吃瓜——

全款买菜、付费坐牢、雨水税、午餐贷、救灾贷款、修电线杆子的账单、496、抱婴费...等等，闻所未闻，非常开眼。

此中细枝末节所呈现出的个体悲欢的真实写照，与我喜欢逛水木社区的理由如出一辙。

但是，在诸多细节之上，应该如何理解这一整套的运行逻辑呢？

我能想到的最好诠释，还得是去年推荐给大家的那幅名画：

[**《金钱世界是怎样运行的？》**](https://mp.weixin.qq.com/s?__biz=Mzg2MDc2MjM3NA==&mid=2247498365&idx=1&sn=24ef956cbd64e77fa6fef07eceb75683&scene=21#wechat_redirect)

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/M7fHtGOlzVaEWfs7tuY6m18NJicMDITb8btlpkbzjiaxryKmKseLEcDibgJOibhnCQaiczhHH8QlsoqK1z9oN5OM3Ug/640?wx_fmt=other&tp=webp&wxfrom=5&wx_lazy=1&wx_co=1#imgIndex=0)

实际上，这幅画还有两个配套的英文视频，我的朋友@很帅的投资客 取得了原作者的官方授权，给视频配上了中文字幕，这里强烈安利给大家。

看完你能具体感受到这个体系从分工→生产→收入→分配→分层各环节的运营逻辑。
