# 做个思想实验：卖不？

我觉得大家今天可以在脑子里做一个思想实验：   
  
如果你这些天有过「要是之前卖了就好了」、「牛没了」等等想法，今天确实是个很不错的反弹，那么！  
  
你会卖吗？   
  
会忠于自己前几天得出的无比正确的想法吗？   
  
重要的其实不是别人（或者大v）的观点，而是你自己的决策。   
  
市场（和世界）从来也不在乎你是怎么想的，只会（阶段性地）奖励你做没做对。  
  
人得为自己的决策承担后果。  
  
⚠️胡思乱想，胡言乱语，不构成任何参考或建议。
