# 房贷滞销，帮帮我们！

今天颁布的楼市新政：**首套房**贷款利率较LPR降低**0.2%**，可以理解为房贷利率打折。

上一次这样**（求着你贷款）**是在2016年。

大家可以数一数，能切实有效刺激楼市的几个大招，**你所在的城市用了几个？**

以四大一线城市为例：

* 放开限购🚫
* 房贷利率打折✅
* 首套、二套首付比例降低🚫
* 认贷不认房🚫

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2M97m69NgBS5323aYlUSjkU1kRqR3Jes7IrzoJwj3c5dQ4u8W3sYicZicfIjOy7Qg1WFLkdXlXYlFyQ/640?wx_fmt=png#imgIndex=0)

另外，**一线楼市的核心动能在于放宽二套**，从而释放置换需求，卖小买大才能给刚需输送更多房源，同时激活两个市场。

再，本轮周期的另一大特点是因城施策，具体的决策和执行都看地方，因此目前并没有太统一的政策，这又考验大家搜集信息的能力。

但框架我是给大家准好了的，见下图。
