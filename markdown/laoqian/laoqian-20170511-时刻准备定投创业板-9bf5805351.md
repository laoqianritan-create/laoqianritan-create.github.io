# 时刻准备定投创业板，摩拳擦掌中...

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02qCgMvYKH34MxWobzPkRicErYCnJAM2HX32tJ2v7qzrH2kuNv18iaGNcQ/0?wx_fmt=png#imgIndex=1)

今天的文章不长，核心观点就一个：我觉得***创业板差不多可以买入了***，甚至可以建底仓买入。

来看下目前创业板的位置：

![图片](http://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PQDibW0cOXE9SAkjQTeVsrXibicbtBeGlJpKroUiayuQA287mor6A902zYQF5v9tOWWBhtgiaoz8B7t8w/0?wx_fmt=png#imgIndex=2)

1772点，已经很低了。当然，跟历史数据比，比如2012年底，也就是创业板开始上涨的位置，也不算很低。

再来看一张新做的图：

![图片](http://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PQDibW0cOXE9SAkjQTeVsrX7Op7lOjCUofjFcBye3amiaGnFDtgWH4NRvIxsTQANyic1zXriah7dsMrA/0?wx_fmt=png#imgIndex=3)

如上图，我用创业板的市盈率/沪深300的市盈率，红线是目前的估值水平，从这样图我们能得出一个结论就是：***创业板目前的估值，处于历史低位***。

但你说创业板就是铁底了么？*（突然想到了李大霄哈哈哈哈...）*

我说不好，乐视复牌了肯定会补跌，而且它在创业板的权重还很高，所以未来再往下跌一点儿，还是有可能的。

之前都说创业板的估值贵得离谱，今天创业板的市盈率在37.2左右，可以说，绝对不算贵了。

我们在👉[大跌是赚钱的前奏](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649608945&idx=1&sn=6ef6da3947428c9bdb3421946f5884e3&chksm=881c162dbf6b9f3bcde7aa4bb469ddeef8b2178f3377b9368cd86c12a646d1e6e2abacaf9720&scene=21#wechat_redirect)这篇中说过，如果知道哪里是底，千万不要定投，一定要建底仓，越大越好。但闹心的是，我们不知道哪里是底。

所以，开始定投，分批买入吧。

定投买入的最大好处就是，熬得起，等得起。分仓买入，波澜不惊地，一点点低价吸筹，建立成本很低的仓位。然后静静地，等待微笑曲线的上扬。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02b6ic60tUu5mmkiaW840DDlQZbpDx6FrKZw80myPXshlIiamrskPzvYEwg/0?wx_fmt=png#imgIndex=4)

老规矩，推荐几个具体标的。

偷个懒不做图了：

![图片](http://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PQDibW0cOXE9SAkjQTeVsrX7D5Lic7hciaicg574MibOMvhDFXp2RhTURjf5uAAkA2rOcQcltk3X5jibTQ/0?wx_fmt=png#imgIndex=5)

绿油油的... 大底宝贵，但买入需要勇气。

5支基金差别不大，都是指数基金，之前说过，指数基金看的是跟踪精准度。前两支是场内基金，需要用股票账户购买。个人比较推荐001593，费率低。

用蚂蚁聚宝或者天天基金这两个app都可以买，申购费都是一折。
