# 省会们的历史机遇：1亿人进省城

![图片](https://mmbiz.qpic.cn/mmbiz_gif/ibw8b04QVx2M7PTAr8JHoc98wCJlkDyXxsA0LtNpBgqhicVxmxOENpDia40416PMnQfU6BgCLN0bVtwGJS9LMhIJQ/640#imgIndex=0)

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2OrYk01tQRV43lotIicQheu5H3kEeicrIfKPqqicroPCYxtPKcrHIGay2GdL3TpAp9ol7bF7dpTyic2ZA/640?wx_fmt=png#imgIndex=1)

直到昨天我才知道，原来省会城市们玩命欢迎你来落户，背后是带着任务的。

2016年国务院发布了《推动1亿非户籍人口在城市落户方案》，文件核心内容是促进几类人在城市里安家落户。这些人包括：

> 以升学、参军形式进入城镇的人、在城镇居住就业5年以上的人、举家迁徙的农业转移人口、新生代农民工。

前两天发改委下发文件说，我要开始检查大家的落实情况了。

2016年我国户籍人口城镇化率为41.2%，2017年为42.35%。「十三五规划」要求每年至少提高1个百分点，2020年实现45%的城镇化率。

我们的城镇化正以这样的速度推进着。

如果按照发达国家70%左右的城市化率来参考，未来要进城的人口远不止1个亿。

作为一名漂龄5年的人，我深刻理解******落户******的真正含义：

户口我倒不奢望，但是必须得有工作，养得起家人，买得上房子，孩子上学、老人养老努努力都可以兼顾。

以上需求，但凡有一样解决不了，很可能都留不下。

你不用赶，我自己走。

当然，北京上海确实也不缺我。

这两个城市的任务是，分别把常住人口控制在2300万和2500万，并长期稳定在这一水平。

不同城市实现落户的难度系数有差别，在其他强二线省会城市的落户难度要小很多。

比如在长沙，哪怕是二胎家庭，存款加负债有200万就能实现一百多平的房子加七座商务车，月供不会超过8千，幸福感非常之高。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2OrYk01tQRV43lotIicQheu5ibeRsMa6Xzt4FWQFvhkgwpwFZhN5P7sBEdakdggBKINJlANiakAP5utw/640?wx_fmt=png#imgIndex=2)

发改委的文件揭示了省会城市在城镇化过程里的巨大历史机会。

> 文件要求省会及以下城市要****全面放开****对大专院校毕业生、技术工人的限制，户籍人口占比较低的超大城市和特大城市，要****进一步放宽****外来人口落户限制。

这意味着，除了京沪这样存量人口近饱和的特大城市以外，其他人口规模不太大且硬件和产业都有吸引力的省会城市将成为1亿增量人口的主要吸收地。

我们的城市格局还远没有定格，相信未来还会有多个城市变成如今的「杭州」。

**人口才是城市房地产的长期驱动力。**

要吸纳如此多的人口，省会本身也要跟上变化，它会以「城市圈」的形态变得更加集中。

比如最近比较火的济南合并莱芜，省会扩容合并代管其他城市未来还会发生。

这种变化具体来说就是，楼往高了盖（容积率变高），地铁往远建（地段平权）。

谁有资格修地铁，谁就有能力吸纳更多人口。

不用多想，能接纳至少1亿人口红利的城市，只有土地供应充足、硬件和产业基础良好、存量人口不多、背靠人口大省的省会。

这是一个人口从大几百万到两千万的变化过程。

省会吃肉！其他城市可能连上桌喝口汤的机会都没有。
