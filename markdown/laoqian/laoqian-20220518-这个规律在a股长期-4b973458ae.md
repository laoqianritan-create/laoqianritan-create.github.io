# 这个规律在A股长期有效

逆向是我今年琢磨比较多的一个命题。

可能跟现在的行情也比较匹配，最近聊的次数也挺多。

诚然，逆向只是一种「方法」而已。

投资中的方法太多了，但没办法拿来就用。

**因为了解方法有效的前提条件，甚至比了解方法本身还重要。**

那么，逆向投资有效的前提是啥？

为啥逆向投资在A股就容易奏效呢？

我觉得主要是市场特征决定的。比如：

**①**四轮脉冲牛市沉淀下来的经验和惯性

**②**散户主导，换手率高

**③**舆论和讨论戾气重

**④**没有做空机制

**⑤**1.9亿股民+7.2亿基民（含货币基金），基民数量确保股票和股基有源源不断的新韭菜

**⑥**公募市场，基民→基金经理→市场的正反馈循环

还有最有趣的一点：**短视频的兴盛会进一步强化以上特征**。

因此，我对逆向在A股的有效性很乐观。
