# 全是朴素的真理

感谢@小投顾·神原老师的推荐，下午看了一份非常棒的报告——

景顺长城、富国、交银三家基金公司一起统计了旗下4682万主动权益类客户的账户，分析了5.65亿笔基金买卖记录，想通过这些真实的交易数据全面分析基民的真实盈利情况。

说白了，看看大家到底是咋赚钱的。

一般报告会采取抽样统计的方法，这么做讨巧但精准度有限。

这份报告不一样，三家头部基金公司把家底都搬出来了，**覆盖了历史全部个人客户的样本量**还是极其罕见的！诚意满满

但得出的结论却并无新意——这里并非贬义，真相就是如此，**基金投资的圣杯从来都是公开的，康庄大道，却少有人愿意在路上走太远。**

借着这份报告，我们再来复习遍基金投资的奥义。

**··· ···**

买基金的盈利水平和持仓时间的长短正相关，持有时间越长，越容易获得正收益。

**慢慢来，更容易赚钱！**像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PPUlAicotG16rlAWdicyQvu4QpIySxkgicObFWnrm1ZDLuPlYhY4QCOHibu1hicgs7hgp8KoMCVjGzRKw/640?wx_fmt=png#imgIndex=0)

道理都懂，但现实就是45%的基民持仓坚持不了3个月，60%的人坚持不了半年，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PPUlAicotG16rlAWdicyQvu4NtuHYAPJ3eicjXTv6475P22a5OGmCv7sRD2OyWJ6DXBTMyJOnT87l5A/640?wx_fmt=png#imgIndex=1)

而且基金不是股票，短买短卖会带来巨大的摩擦成本。

我们**持有基金的收益=产品损益+基民行为损益**，后者在绝大部分情况下贡献的都是亏损。

**交易越多，赚的越少**——

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PPUlAicotG16rlAWdicyQvu4KO85ZLF0BeLrEMcpkIjHuC292ibOt9b2QDR1DyT56F90yG9xUpoUKnw/640?wx_fmt=png#imgIndex=2)

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PPUlAicotG16rlAWdicyQvu4UZ8ibgwsybSIdibNAHcFGsOWOKfrqDHBmib8tYjLrHshVeZqsyKeSarCg/640?wx_fmt=png#imgIndex=3)

之所以这样，是因为市场时刻在变化。

你越关注市场，对涨跌就越敏感，就越想主导投资，也越容易被情绪左右，越可能在情绪不稳定时做出错误决策，越容易高买低卖，过早止盈止损。像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PPUlAicotG16rlAWdicyQvu4ricarzibyha6dSCCmH0rpfVuDwWlshxdzD0VTghiaKu0SsQQviaicZHzNxw/640?wx_fmt=png#imgIndex=4)

越高越买，越亏越装死，最后在跌妈不认的绝望时刻卖出，然后在反弹时进一步绝望。

**翻倍的基金很多，翻倍的客户很少。**

大部分人对波动的忍耐阈值都不高：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PPUlAicotG16rlAWdicyQvu47RvHE3bymPUbAf3qjm7xgANnwBhxzybFvvUYuaKLouQYqErsmCUOWg/640?wx_fmt=png#imgIndex=5)

网上很多人都说「定投收益不如一次性买入高」。

他们的理由是大涨的基金，持续买入会拉高成本。说的对！

这些人懂理论，但不懂客户。

现实是，选择定投的人完胜不定投的人，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PPUlAicotG16rlAWdicyQvu4Kqw6zCY4hW7D9Q10U5UU7LIicdiaVd8NMKmV10Z70cjLeQk7rGqlsenA/640?wx_fmt=png#imgIndex=6)

定投人群的盈利比例更高，平均收益率也更高。

除了大于100%的超高收益这一种情况，定投在各个区间段的表现都好过非定投。像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PPUlAicotG16rlAWdicyQvu4CeClFSyVxM6U3kcUjZ23Q8KDmiaIh2AeXKedib4d6xZ8v13VPr71byqw/640?wx_fmt=png#imgIndex=7)

我再加一条，因为定投会持续买入，持仓体量更大，所以收益的绝对值也会更高。

对于普通投资者而言，**定投是一种兼顾强制储蓄和对市场波动保持顿感的明智之举。**

持有时间越长，越容易拿到高收益的另一个原因是，基金收益的「二八效应」非常明显，大部分的收益都集中在为数不多的上涨阶段内获得，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PPUlAicotG16rlAWdicyQvu4QbPo3r1rBY75L41JibbKGYkj6Vay83dB6S5CqUzhpVcNhOAKGuKUBZQ/640?wx_fmt=png#imgIndex=8)

这也提醒我们，基金需要长期持有，而持有过程中绝大部分时间都百无聊赖，收益平平。不仅如此，如果你关注市场和媒体报道，还要忍受其它基金在暴涨的高光时刻的诱惑——这是基金投资的最大陷阱。

**只有熬得住，掉馅饼时才能用盆接。**

**··· ···**

以上就是报告揭示的基金投资的奥义，没啥新意，更没难度，但执行起来真的不易做到。

**根据我的经验，在持有过程中，越关注价格，越容易把这些朴素的真理抛诸脑后。**

时间一长，连前十大持仓股都懒得看了，养基的初心也忘了，每次打开账户，只剩对这场价格游戏的骂骂咧咧。

**投资最有意思的地方在于，强大的内心往往和智商无关。**
