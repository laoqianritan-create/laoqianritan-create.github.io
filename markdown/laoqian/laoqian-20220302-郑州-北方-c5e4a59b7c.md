# 郑州！北方！

郑州发布了19条政策松绑楼市，这件事引起了很大关注。

因为用的都是真大招——

**①** 限购，完全破了。不仅如此，还可以通过亲友投靠的方式增加一套名额。

**②** 限贷，破了，还清贷款算首套。

**③** 鼓励加大个人住房按揭贷款投放，鼓励下调住房贷款利率。

**④** 推进货币化安置。

我们再复习一遍过去三轮房地产宽松周期时的刺激政策：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MMg3pkVV8bWrPmxEueIqaGdDnPRhUA76yhh3Ab2Fus8k2hibDWtibHH5NAcSxPcNNGQOZXIKBGkNcA/640?wx_fmt=png#imgIndex=0)

你会发现，郑州这次出手除了「房贷利率相比基准利率打折」这条以外，全中！

这是郑州房价的历史走势，2019年房价见顶后阴跌至今。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MMg3pkVV8bWrPmxEueIqaGLkibgAUISApPlgIfSrQODzIHBKkMiblZIicFMzwFeKjNWibhz9gURoG4zw/640?wx_fmt=png#imgIndex=1)

本次郑州松绑楼市值得重视的第二层逻辑是：

哦，你房价跌了就敢用这么狠的招！

**那其它北方核心城市会怎么做？**

天津已经阴跌五年。

沪深房价均超越2017年巅峰，只有北京卧倒不动。

环京楼市房价直接真·腰斩。

济南、青岛、石家庄已经跌去30%。

沈阳大连还好但土拍市场颗粒无收...

自家楼市，冷暖自知。

**··· ···**

房地产长期看人口，中期看土地，短期看金融和政策。

**如果现在你对未来一二线楼市还没有明确观点，说真的，宏观水平堪忧。**
