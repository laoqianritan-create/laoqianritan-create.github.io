# 保命

‍‍

‍‍刚和家里的女搬砖工商量了一下钱的问题。

事情是这样的，她有点积蓄，加上去年的年终奖，以及最近带血割肉的公司股票，手里多出来一笔可支配的钱。 

我们就商量了下怎么处理。 

我问，最近互联网这德行，你会被优化吗？ 

她说真被裁了也能找到工作。 

我问，你还搬得动吗？ 

她说还行，还能卷。 

我说，那有三个选择—— 

第一，咱买点基金，我给你代码。 

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2NDpKW13mAWvD1MwBZ0BqbwbnCWZeoiaZicl2OPmibhFrib54ibsiarZqda7d34u09tiawlmKImpHFbnarQA/640?wx_fmt=png#imgIndex=0)啪！她说闭嘴，不许我再多说一个字，不然还抽我。 

第二，咱找中介看看长沙的法拍房，有漏的话可以买一套收租。 

她说待议。 

第三，咱家继续去杠杆，把组合贷里的商贷部分还掉，这样你还的那套，公积金就能覆盖剩余月供了。 

她说待议。 

总的来说，我们友好地初步实现了求同存异，会谈很成功！

**··· ···**

我之前写过，房贷不提前还更划算。

怕有人误会，这里再解释一下：

**理论上，数学意义上，不提前还贷是划算的。**

等额本息的月供不会变，但生活并不是理想公式，有各种变数和财务需求。

就像复利在实际投资中极难找到适用场景一样。

**现实中，人的年龄在变，收入曲线会变，对未来的预期也会变**——比如行业巨震。

如果你的月供压力大，或者预感自己未来现金流状况比较糟糕，或者干脆年纪大拼不动了就想躺平，那么卸掉一部分负债当然可以。

**··· ···**

关于杠杆和人生的安全边际，再和你们分享两段我在网上看到的话，都深以为然。

这段是某网友对近期互联网裁员传闻的感慨——

积蓄方面，很多从业者因为上了高杠杆买股票损失惨重。

收入方面，因为股票跌得太狠了，工资package也被腰斩。

但是支出方面，比如养孩子房贷车贷都多了很多...

真的是一场财富一场梦，梦醒一地鸡毛。

**所以不要根据浮盈来做影响人生的真实决策。**

**上坡路虽辛苦，下坡路它痛苦啊！**

**··· ···**

这段来自我很敬佩的一位媒体前辈「bian斯基」的微博，简直人间清醒：

我至今认为，自己如果去打工，只值一年30W。  
  
一年下来，如果多挣了，我肯定一次性花完。  
  
房贷车贷，永远按照老婆20我30来计划，加杠杆是不可能加杠杆的。  
  
如果有孩子的话，养娃开支也只能按照这个水平计划。  
  
跟无产阶级资产阶级没有什么关系。我有一家公司，包括我自己，大家离开这个公司都会挣更多，但是在一起工作大家更快乐。  
  
这种生活方式的原因，纯粹是不相信我能比很多自己见过的更优秀的人挣更多。  
  
然后是不相信钱，不相信超额的钱能够解决人的困境。  
  
**人们想要自由地生活，首先得相信人可以自由地生活，然后是坚持自己必须自由地生活。**  
  
跟我同时代的很多人，一边说着要自由，别人多给一级工资就奔过去，这种人是不配自由的。  
  
如今更多年轻人，被教育得更好，自由让他们无所适从，给他们他们都不要。
