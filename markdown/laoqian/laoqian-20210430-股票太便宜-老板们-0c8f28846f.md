# 股票太便宜，老板们自己买了

**●**

4月最后一天，所有上市公司的2020年报已经全部披露完毕。

吸引我注意的是万科，倒不是业绩，而是一则举牌公告——

万科管理层持股平台持有的股票超过5%，根据监管规定，首次触碰到这个持股比例时要发布举牌公告。

这很自然地就让人联想到了6年前宝能的那次举牌，姚老板作为门口的野蛮人连续增持，想夺取万科的控制权。结果被王石极力抵抗，最后老王退位，深圳地铁接受华润成为万科大股东。

我对万科的主要印象有这么几点：

公司稳健有余，激进不足。这让万科错失2017年的地产股大爆发，成为期间表现最差的地产股之一，没赔钱，但让股东蒙羞。

财务方面，净利润增速一直在趋势性走低，如下图：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PauOkX769IibDMVSHVutbk7v5x3CfShMNCLQVgYZsLA01DAStRUdy5CG3B27gdiaibdicAicuHiaeLF1jg/640?wx_fmt=png#imgIndex=0)

不过这跟行业有关，17年开始土地越来越贵，成本项越来越高。

但是别忘了，万科的融资成本是业内最低的几家。

本来你借钱既便宜又容易，大家都趁着地便宜、钱也便宜的时候高杠杆突飞猛进，万科却因「房地产进入白银时代」的口号磨磨蹭蹭。

说道这里，必须提一下定位成职业经理人的万科管理层，王石和郁亮，因为企业利益和自身相关性不大，明明在一个高杠杆+高周转的行业里，非得玩稳健，这是最大的决策失误。

然后他俩人模狗样的，泡妞跑步，搞个人包装，当青年导师。发明的口号坑了多少人——白银时代、活下去、年轻人别着急买房。

不过三道红线确实利好万科，谁都别想猛加杠杆了，以后拼资金成本、一二线城市土地储备、利润空间，万科在这些方面做得都很不错。

**好公司+估值合理=好股票**，万科那时就是好股票，但人家就是不涨，多亏了宝能。

所有万科股东都应该感谢姚老板，没有他的举牌，万科可能至今无法迎来价值发现。

本次内部管理层举牌的估值跟当初姚老板买入时的估值差不多。

在多元化方面，万科一直以来的特点也是稳健有余，非常专注。

商业地产做得还不如龙湖，万科物业是最争气的好大儿，不出意外今年就能推到港股去上市，目测市值0.5个万科打底。

之前我妈的深市打新门票就是万科，后来我建议她换成了京东方A。

一季报+上年年报披露时间是每年的3、4月份；半年报在7、8月份披露；三季报是10月份。

相当于每年有三个时间点帮大家用业绩**（内含价值）**去锚定股价。

业绩是实的，估值是虚的。

看财报和公司数据的话，推荐大家用「萝卜投研」网页版，我一直都用这个，主要是完全免费又好用。本文的前三张图片都来自萝卜投研。
