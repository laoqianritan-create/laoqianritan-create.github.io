# 猪事不顺

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MtYY6DwPeUXqfqgXDKoQRQeA9lxVSd9HTSxerpf9Kfab3NIHynuD1vvdRfyy5R85thF4htRUm9uw/640?wx_fmt=png#imgIndex=0)

目前全国平均生猪价格是32.4/公斤，处于什么水平呢？

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2M7cCiaByhAJgWMQVuo01cnIgqxfS27VwJUXG3ib5AiaCB0sD3alHdn49icyicVeOiaLHW4iaMKN466Hw8Og/640?wx_fmt=png#imgIndex=1)

根据历史经验，这个价格放到之前的猪周期里已经是最高点了。

其实6月份时价格还好，只有26块多，但是7、8月飙得太狠。仅7月份，猪肉价格环比涨了7.8%、同比涨了27%。

如果把2018年5月算做本轮猪周期起点的话，8月份非洲猪瘟进入中国，今年4月份所有省份均查出疫情，全国范围的扑杀使得供给快速减少。

上行周期加上疫情，这一轮价格涨得确实太快，只用了15个月就飙到历史高点。

关键是，它还有可能继续涨，因为供给端真的不容乐观。

猪肉真正的供给端是「能繁母猪的存栏量」，说白了就是能下仔的母猪有多少？

能繁母猪存栏数 X 产仔率=1年后有多少能吃的猪肉

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2M7cCiaByhAJgWMQVuo01cnIY32ScKOzM56d3ppc4xstAYxlpXIKXDPW8jJxicunybd3EhegKIfepxg/640?wx_fmt=png#imgIndex=2)

7月份只有2287万头，同比减少超过30%，还没有任何见底趋势，每个月都是新低。

猪肉价格和咱们老百姓生活息息相关，生猪生产、猪价稳定和猪肉供应最近频繁被国务院提到，出台了很多措施比如：扑杀补贴、支持扩产、养殖企业贷款贴息等等。

在CPI的构成中，价格波动最大的就是肉类和蔬菜水果。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2Pibp2w8lp7eJPWEv3ks0FU2udP7vbxEdZcNXMIxe6P6lICKR9pE3jmmQzun3vib73KECTP9JkNP74w/640?wx_fmt=png#imgIndex=3)

肉类有养殖周期、水果蔬菜有种植周期，同时灾害疫情又对这两个行业有巨大影响。

其中养猪行业因为集中化程度不高，周期性又尤为明显。

秋冬季又是猪肉需求的旺季，贴完秋膘就要过冬了，猪肉这么贵能咋办，多吃鸡...吧~

话说回来，猪肉股也算为数不多确定性强，认知门槛很低的周期股了。

合肥发明了一个狠招，直接停贷！

券商中国在合肥摸底了18家银行，情况如下：

大部分银行把首套按揭利率上浮了20%，二套上浮30%；

12家银行停止了对二手房放贷，还有的干脆连新房贷款也停了。

行行行，知道了，不买不买！

很多人都觉得宏观经济没啥用，其实不然，认清形势，别对着干。

2016年房贷利率打折的时候不买也就算了，现在二线全部完成上涨，房贷利率上浮比例高到发指，还想硬上就是犯傻。

我还是那个建议：

所有三线及以下城市一律不碰；房贷上浮比例超过10%的城市，刚需再等等，现在真的不划算；一线城市，首套刚需，遇到合适的不用犹豫。

值得下手的原因，一定是合适，肯定不能因为你钱够、焦虑就胡来。
