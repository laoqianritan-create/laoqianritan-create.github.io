# 婚姻经济学

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MtYY6DwPeUXqfqgXDKoQRQeA9lxVSd9HTSxerpf9Kfab3NIHynuD1vvdRfyy5R85thF4htRUm9uw/640?wx_fmt=png#imgIndex=0)

感觉今年参加了好多场同学和朋友的婚礼。

从毕业算起，五六年的时间了，大家经营的感情都到了收获期。

我一直觉得婚姻是件充满挑战又足够美好的事儿，你想啊：

两个独立的公司经过各种业务往来的磨合，最终选择在各自ROE最高的阶段选择合并，共享各自的收入、资产、负债、背后的家庭。

接着再用二十几年的时间培养下一代的CEO，让接班人带着公司一以贯之的文化和经营理念继续走下去。

有没有很酷？！

结婚表面上是在选人，其实选的是自己未来想要的生活方式。

你想过什么样的生活就得有与之匹配的财富。

诶？怎么又回到钱上了...

嗯，婚姻确实也很现实。

刚说了，结婚就是两家公司合并重组，同时为了新公司走得长远，男方家出彩礼，女方家出嫁妆，一起支持下。

**「丈母娘经济学」**的本质就是：本次重组，双方各注入多少资产？

还有与之对抗的**「婆婆经济学」**：婚姻不会产生任何增量财富。

什么意思呢？

说白了就是零和博弈，如果婚姻让一方的财富增加了，那另一方的财富必然减少。

这就牵扯出一个问题，**对于经济地位有优势的一方，结婚实际上是一种冒险行为。**

比如婚前女方有房有贷，男方没房，女方天然地会担心自己的房产归属权问题。

婚前女方没房，男方有房，那么加名字和彩礼大家就得商量商量了。

婚前男女双方两家人一起支持新人买房，大家都会去搜出买房钱和出装修钱的区别啥的。

最常规操作就是签署婚前协议，但是你懂的，很多时候大家碍于面子也不好意思开口。

面对这种问题最好的办法就是谈，但我们总爱回避，搪塞，装不在乎，嘴上说三观不合，心里骂你个抠逼。

时代变了，婚姻也在变。

以前婚姻就是两个人的感情和两个家庭之间的笼络，现在大家都变富了，要考虑的事情远比之前复杂得多。

所以婚姻法也在跟着变，**现在的婚姻法基本上就是一部财产法**。

感情甚至性别在婚姻法中都被很大程度地淡化了，结婚双方最大的差别是财富的多寡。
