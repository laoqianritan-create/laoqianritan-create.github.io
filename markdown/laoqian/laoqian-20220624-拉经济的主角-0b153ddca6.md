# 拉经济的主角

每次刺激经济，汽车都是主角之一。  
  
不仅因为汽车是居民最大的消费项目**（家电同理）**，更因为汽车还有不间断的后续消费——贡献车险保费，贡献高速费，贡献汽油消费。

其中汽油最有意思，你加100元的汽油，国家可以拿到48元左右的税收。

像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVaMOcsRZ1Pb3oqD0xNHeJCuA5ibTTMq54clcTGymruX0upF8x8rtySib3430ibczltjNeibSxKbzSGVsQ/640?wx_fmt=png#imgIndex=0)

从这个角度看，**车主、烟民、父母、中产、房东都是为国做贡献的人。**

就比如买房吧，房东永远赢，但拿走房价大头的是...

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVaMOcsRZ1Pb3oqD0xNHeJCuzdnN93Rt3WVIzOhibbLyIPzsVkNUoWI6xdLdocAibacL3oaDpgwhl0lQ/640?wx_fmt=png#imgIndex=1)

再比如缴纳个税，说出来你可能不信，我国够资格缴纳个税的人数也就***6000***多万人，同期全国就业人员7.5亿人，其中城镇就业4.6亿人，农民工2.8亿人——以上数据来自《2020年度人力资源和社会保障事业发展统计公报》。

保护市场主体，也是保护税基。

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVaMOcsRZ1Pb3oqD0xNHeJCuJ9EkTVa8Yn1zEWwrsDueeuA3KyuFic5dicHJenicDdWaMqoHutW2iaoyyQ/640?wx_fmt=png#imgIndex=2)

政府部门并不创造财富，财政的本质是「取之于民，用之于民」，这句话反过来也是成立的。

最后弱弱地建议下：**这次拉经济，少拉点房价吧！**当然我怎么想不重要...
