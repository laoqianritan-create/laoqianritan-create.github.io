# 现在无需智商，只问信仰

沪深300又一次来到长期轨道的下沿附近，像这样：

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/M7fHtGOlzVYFYvNGnpqfgyxF0DJ9eq8teMnicwhoBYvz9NtyT6jr76lZyISwFhK86nVFo3atA7LGREpqCatd2HQ/640?wx_fmt=png#imgIndex=0)

如上图，我做了个简单回测，结论是：

沪深300的下沿轨道（市场底部）的长期年化增速是**6%**——这是市场再烂也能给到你的收益。 

当然还有几个非常重要的事实需要大家重视： 

✔️ **下沿增速的本质是经济增长**。

因为经济在发展，所以市场的底越来越高。

但经济发展也只能决定下沿轨道这6%，仅此而已。

✔️ 那下沿轨道以上的波动都是哪来的？ 

如果是沪深300的话，波动源于市场对经济的预期，这种预期受很多因素影响——情绪、内外资、基本面、热点事件、政策信号等等。 

✔️ 预期的力量很强，所以沪深300的波动很大。 

沪深300最近一轮顶部是2021年2月份的5930点。

今天的点位是3800点。 

从顶部跌到今天，用时2年3个月。

在这个过程中，2021年中国GDP增速8.4%，2022年增速3%。

然而顶部至今的跌幅是**-35%**。如果未来能从底部回到顶部，涨幅**56%**。 

实际的经济增长贡献的力量微乎其微，但预期的力量相当骇人。 

✔️ 既然沪深300下沿轨道都能提供6%的年化收益，为啥你的收益这么差？ 

因为经济增长只能决定6%的增长，但市场波动却能带来-35%~+56%的波动区间。 

**这个区间里你是怎么想的，怎么做的，市场就回应怎样的结果。每一次决策都会被定价。**

如果下沿区间买入，至少能拿到年化6%的收益——这是个极大概率事件。

✔️ 今时今日，有大量估值工具和方法都能告诉你市场的状态，择时根本不是难事。

当前无需智商，只问信仰。
