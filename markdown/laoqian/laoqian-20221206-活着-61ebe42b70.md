# 活着

「风险敞口」是理解反脆弱的一个有效抓手。

脆弱的反义词，是反脆弱。

我在哪里脆弱呢？风险会怎样暴击我呢？

答案是：**风险敞口就是脆弱之源**。

举几个例子：

我的房贷月供占现金流过高，这就是风险敞口，疫情或者失业会暴击我。

我在投资时加了杠杆，这就是风险敞口，大波动会暴击我。

我的消费习惯和消费水平已经隐隐超越了现在的收入水平，这就是风险敞口，未来收入不稳定会暴击我。

我的资产结构过于集中了，比如全押了股票，我的命运和金融周期挂钩了。比如全压了房子，未来流动性可能就是我的梦魇。

我单押了，我把所有资金都买了某个标的，错误判断就会暴击我。

...

既然如此，难道大家在日常生活中对风险敞口就没有一丝警惕吗？

确实很难，打开风险敞口的好处是进攻性强，可以很快赚很多钱。

盈亏同源，相应的，只要你不下牌桌，随着时间推移，当专属你的黑天鹅来临时，脆弱性也就暴露无遗。

我们是不是只重视短期收益，是不是要求某只基金必须超越业绩比较基准？

那么，你清楚代价吗？不太可能大上涨让你遇上了，大下跌你就躲过了吧？

所以某种程度而言，反脆弱也是一种比较中庸的哲学。

它的思路是：朋友，先别想那么多，淹死会水的，何况你根本也不厉害，咱们还是研究研究会怎么死？

因此反脆弱意味着要**重视对抗冲击，避免破产，确保生存。**

实践反脆弱，**始终留一份安全边际**是很有效的思路——

背房贷时算好月供，行业悲观时准备跳船，给自己和家人买好保险，用资产配置的思路给自己留点儿现金或者可卖的债券...

主观上讲，保持乐观是一种难能可贵的品质，因为我们始终让情绪起到积极作用而非相反。

客观上讲，保持乐观的一大前提是人还活着。活着，一切才有意义。
