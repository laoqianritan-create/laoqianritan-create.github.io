# 你是我的朱大哥！

昨天的文章，有读者反馈说下图中的「主动股基指数」「偏股基金指数」表现是不错，逻辑也通畅，但存在一个硬伤！

没有跟踪这两个指数的基金呀！再好用啥用？买不了。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PjyYLbLzssTIkY32X2W3G3Vatt0VAcxjVYiaHmrcaPA8Rnky01JneicK1hS9VWDFeEdBpFWIibt23bw/640?wx_fmt=png#imgIndex=0)

其实是有的，虽然与两个股基指数并不完全一致，但也算个不错的替代。

给大家介绍下：

工商银行为了拉客户，和中证指数公司独家合作编制了一个工银股混指数（030994），具体编制方案大家去中指官网搜代码就能找到。

我大概说下它的选基思路：

根据基金公司、基金产品、基金经理三个维度构建综合打分体系。从股票型、混合型公募基金中选取综合得分最高的作为指数样本。

最后选出了24支基金，基本覆盖了各大知名基金公司，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MMgiaVjDqCKoeotKJHyn184EKAibnOW54g7cxDqUSUZOsorib6TX2aKhpafpia5ibPbqBk0jENGpPeFxQ/640?wx_fmt=png#imgIndex=1)

市场上唯一跟踪工银股混指数的基金由富国基金推出，名叫「富国智诚精选FOF」。

目前只能在工商银行APP才能买到。在天天基金、蚂蚁财富甚至富国基金自己的官方渠道都无法购买。

因为独家，工商银行定的费率也不是很不友好：0.6%管理费+申购费1.2%（目前打8折）。

**··· ···**

说说我喜欢这个指数的原因：

第一，它的逻辑是很出彩的，通过量化+人工的方式，在足够分散的前提下选出一批优秀的主动型基金经理。

在主动型基金中一直缺少有足够逻辑支撑的指数，工银股混既做到了足够覆盖、足够分散，又没有过度分散。

而且它还是可实操的，有跟踪的基金可以买到。

第二，我对它的喜欢和对「Wind全A指数」的喜欢很像。

这里需要花点时间解释下其中的逻辑——

**①** 市场环境年年巨变，我们都是必须要适应巨变的生物，适应得好，当年投资收益就高。

那么有没有一个指标能反映出市场整体的变化呢？

有的。就是「Wind全A」指数。它不做任何判断，就是简单囊括了几乎所有的A股股票。

所以我把这个指数看成A股市场真正的「锚」。

**②** 进一步的，投资中的进攻和防守、激进和保守的正确定义应该都是围绕着「Wind全A」指数这个锚来描述的。

总结来说：越像Wind全A指数**（即市场本身）**，越是防守。

越有自己的判断，相对市场本身越偏离，越是进攻。

这就是锚的价值。

必须理解这点，才会懂得这种锚指数的好。

「工银股混」指数就给我们提供了一个新的锚，一个描述中国优秀股票型主动型基金经理们的「锚」。
