# 很难不对北方房价悲观

如题，对此很多北方人应该都不愿承认，但这就是事实。

北方核心城市房价已经连续多年处于下跌周期，意味着每年房价都不如上一年，买完即亏。

当然，房子不是股票，因此价格方面的小幅调整感受并不强烈。

注意，除了哈尔滨，以上城市几乎都保持人口净流入，「GDP」和「人均可支配收入」等关键指标也都保证着正增长。

但房价如你所见...

其实我不太敢多说，说多了容易开地图炮。

疫情确实是一面镜子，比如刚一放开，浙江、江苏、广东等省份立刻组织包机带小老板们出国拉单子。

本以为今年小老板们都死气沉沉的，结果人家撒腿就冲出去了，真心佩服。

这几年我始终没有卖掉沈阳的房子，其实打心底也对下一个国家中心城市有所期待，但是看到的种种差距真的消磨耐心。

无论振兴东北老工业基地，还是一厢情愿地喊下一个国中城市，似乎东北做事老是透着一股等、靠、要的味道，总希望政策倾斜拉一把，否则靠自己起不来...

我知道很多人对房子很纠结，如果不涨了还要不要买？

这个问题我没法回答，但我有个建议——

不如完全把房子看成**「使用品」**或者**「****投资标的」**，不要兼而有之，既要还要。

如果认为房子是使用品，有需要，买喜欢的。

如果认为房子是投资品，这里没有升值潜力，可不可以不买了？或者换个有升值潜力的地方买？反正可以租房嘛，房住又没说必须自己住...

其实很多问题我们心里都有答案，只不过不愿承认或者先麻烦罢了。
