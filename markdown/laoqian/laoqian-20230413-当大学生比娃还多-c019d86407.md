# 当大学生比娃还多...

**************1**************今天做了张让人五味杂陈的图，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVbvQAwUmTPzuOUBe5cjJoFIsOg12lg38w1YzOghJ3zNsbC1eXeFWNae1TWkYqH6f0icbwpEsLPddzg/640?wx_fmt=png#imgIndex=0)

**************2************** 和兄弟们唠唠我的真实想法——

你看上图中新生儿的拐点发生在哪年？

2016年我国全面放开二胎政策，当年新生儿数量见顶。

同年，一线楼市启动了史上最猛的地产牛市，随后伴随涨价去库存政策，地产牛向二三四线城市传导。

次年，新生儿数量掉头向下。

**************3************** 高房价的代价无法否认，它不光是新生儿的问题。

还有房地产相对其它商品和资产的价格扭曲，从而影响资源配置效率的问题。

对实业的挤出问题。

负债约束对消费的压制问题。

财富分化问题——

城乡之间分化：宅基地VS城市房产

地区之间分化：鹤岗们VS一二线城市

家庭之间分化：本地多房家庭VS外地进城家庭

代际之间分化：老哔登房东VS大学生

年轻人的希望问题... 等等。

**************4************** 当然，大城市的房价，该看好还得看好。

因为有**供需错配+人口流入+货币效应**这些因素做支撑。

大城市的好房子作为家庭财富的压舱石肯定是没问题的。

**************5************** 但总量呢？

现在的购房主力是**等着结婚的90后**和**等着退休的60后**，那以后呢？

毕竟接盘侠越来越少，也越来越不满，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVbvQAwUmTPzuOUBe5cjJoFITyb9qJpuGshQvb30NuAWzibZfuM3x0FcZHSbuKAmdy8cYD3hZ8lEgHA/640?wx_fmt=png#imgIndex=1)

**************6**************我只能说，在网络系统中，天然地由马太效应主导——

**大城市虹吸各种资源，大公司占据宽基指数的主要权重，财富向少数人集中... 都是客观规律。**

**************7************** 以上也是我越来越不太愿意聊房子的原因。

一方面，每次聊房子，很多读者都默认是在喊多，其实我对总量和低线城市的看空程度可能比绝大多数读者都更狠更坚决。

另一方面，第五轮楼市宽松周期已经开启，这点从利率和宽松政策上都很明显，已无需多言。

该说的，也重复过很多次了。说多了，又刺激大家情绪。

反正都有代价，要能自洽。

希望大家都能认识自己，识别时代性，和谐共处。
