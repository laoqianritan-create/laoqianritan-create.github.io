# 幸福≈低回撤+好收益

‍‍

‍‍●

最近很多财经话题都不敢碰，稍微了解情况的读者也都知道是什么原因。

我自己也每天都在琢磨接下来应该写啥，抓耳挠腮地想，斑秃都变严重了![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2NVYyo4prTz8gia1ic3WmJ1dRysKzQuwND5Xmcia24HFp2iaqib2O6qiaMib6S4dwnhCmIVw1zTGz9fMCmmg/640?wx_fmt=png#imgIndex=0)。反正你们容我再过渡一段时间。

●

今天继续老老实实地写理财话题，聊聊固收+。

这类产品我应该会重复写很多次，希望引起大家的重视和认识。

**和房产投资转向股票基金一样，固收+也是理财领域非常重要的新变化和新趋势。**

任何趋势都有时代背景，房子不能再投的背景是房住不炒，居民财富搬家。

而固收+应该投的背景是无风险利率趋势性下降，导致所有债券类资产的回报都很平淡。

举个例子，2018年银行理财和利率债的收益都还能涨过5%，现在基本都已跌破4%。

同时呢，所有理财产品都必须转向净值化，没人敢承诺保本，风险再低你也得承受波动。

这两大前提让固收+产品一下子脱颖而出，反正波动无法避免，它还有望在收益率上PK掉「银行理财」和「纯债基金」。

所以，如果你有以下几种理财需求：

**争取比银行存款/理财更高的收益**

**分散投资风险**

**低风险的养老/教育储备**

固收+产品一定是几个首选之一。

●

那它是怎么赚钱的呢？

收益来源于三个方面：

① 债券票息，稳定，年化4%左右。

② 债券投资收益，主要是在纯债利率上做波段，时正时负，依赖管理债券部分的基金经理的水平。

③ 股票投资收益，年度差异也较大，既依赖当年行情，又依赖管理股票部分的基金经理。

三个收益来源的历年表现如下：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2NVYyo4prTz8gia1ic3WmJ1dRfMh7GFNeQRNw7ib7g06j4jYzof4Hamicpa52smUFiap84111f7iaxb94Jw/640?wx_fmt=png#imgIndex=1)

你们注意看图中的灰色柱子，它代表股票投资收益。

除了2018年这种超级熊市外，其实股票每年都很稳定地给固收+贡献了超额收益，而且越是牛市越猛，平淡行情至少也没拉胯。

粗暴点说，**所谓「固收+」就是「票息+股票收益」**。

●

那什么样的固收+产品拿着最爽呢？

必须满足两个条件：

第一，**低回撤**。大家买它的第一诉求还是低风险，因此最好别亏损，哪怕亏了，幅度越小越好。

尤其那些没啥事，每天都开打账户看一眼的长辈们，不亏或者短时小亏对他们来说是非常好的体验。

第二，**能做出绝对收益**。毕竟跑赢银行理财和纯债基金才能体现出固收+的价值。

根据上面两个标准，招商证券做过一次筛选，看看市场上哪些固收+产品真正拥有良好的持有体验。

筛选条件是这样的：必须成立5年以上，每年必须做到正收益，复合年化回报超过5%，单一年份最大回撤小于10%。

最后发现真正满足条件的固收+产品非常稀缺，能入得了法眼的只有12个产品，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2NVYyo4prTz8gia1ic3WmJ1dRl8xcJooo3lo4XZthkF6RskZ9PwyG2GNuBohVqiayX0LsChqKbOBbbMA/640?wx_fmt=png#imgIndex=2)

能排进这份名单中的，每个都是固收+领域的佼佼者。

●

从图中我发现天弘姜晓丽居然独占两个产品，相当厉害。

于是我着重看了下这个人和她管理的产品——

姜晓丽有12年的从业经验，9年多基金管理经验，4次获得金牛奖，现任天弘固定收益部老大，一直深耕债券投资。

而且她非常专注，只研究债券，管理固收+类产品时会和另一名专门负责股票的基金经理合作。

姜晓丽管理的三支产品近一年收益如下：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2NVYyo4prTz8gia1ic3WmJ1dRprrUhF4UI50RRVpfCSvIJqCExYHIwwHhDNcIZGdicZ9VquGvqo7cU5w/640?wx_fmt=png#imgIndex=3)

数据截至2021.6.30

其中两个老牌产品「天弘安康颐养A」和「天弘永利债券B」已经运行了9年，每年都是正收益，持有体验非常好。

「天弘增强回报」比较新，成立于2019年，成立以来总收益37.8%，年化回报13.5%，受益于行情，股票部分一直在持续贡献超额收益。

9月13日，由天弘永利、天弘增强回报同班人马打造的天弘永利优佳（A：013569/C：013570）将正式开售，基金经理还是姜晓丽和张寓，感兴趣的朋友到时可在北京银行及各大线上平台、线下渠道了解认购。
