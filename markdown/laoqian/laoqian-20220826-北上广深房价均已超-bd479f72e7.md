# 北上广深房价均已超越2017年高点

‍‍

‍‍2017年的317大顶是四大一线城市的前高，如今已被超越。

当然，北京才超越不久，深圳老早就超越了。

第五轮楼市宽松周期已经开启，这一波过去，不知多少80后、90后又被挡在车门外，第一批00后今年今年开始陆续变成社会人。

但在我国，似乎在一线城市没房在很多人心中仍是一种亏欠。

二线楼市也有周期的，只不过滞后于一线城市。
