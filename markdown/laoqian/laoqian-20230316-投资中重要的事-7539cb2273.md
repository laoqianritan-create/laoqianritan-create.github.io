# 投资中重要的事

继续讨论[昨天文章中的图1](http://mp.weixin.qq.com/s?__biz=Mzg2MDc2MjM3NA==&mid=2247496577&idx=1&sn=034b2d756c896584b5465c0dea292343&chksm=ce23cbe8f95442fe89c97ee805d4a391b8cd2abd96a810d71a2ce91a44234a808c4557491834&scene=142#wechat_redirect)，所以，短期看，没谁是时间的朋友。  
  
每逢年关、年度策略会、年中策略会...这些场景下，我们考虑的是：  
  
今年啥涨得好？  
你看好哪个板块？  
我怎么投能回报更高？  
  
但以上问题都不怎么重要...  
  
什么才是重要的？  
  
我今年32 岁。35岁时我想摆脱负债约束，没有生存焦虑后，做点有意义或者有意思的事。40岁时我想和女搬砖工回二线定居。50岁时我想把老妈安排在身边方便照顾她。  
  
那么，回到投资上，我该问的重要问题是：  
  
35岁时我能获得的最佳回报是什么？通过什么标的实现？  
40岁时呢？50岁时呢？  
  
我不该对今年什么涨得好感到焦虑，因为就算我抓住了今年的TOP1行业，后年仍得投资，仍要面对同样的问题...  
  
所以咱们偷个懒，粗暴点，直接思考最重要的那个议题。
