# 先洪水，后猛兽

这三张图放到一起看，我觉得还挺有意思的，分别解读下：  
  
图一，长期看放十收一，哪有什么缩表，放水是唯一的选择。  
  
更有趣的来了，每一轮洪水，都被猛兽很好地吸收消化了！  
  
本轮缩表始于2022年第二季度，缩到现在，才回收了5000亿左右，然而这种体量的边际收缩已经让整个金融体系感受到了压力，紧平衡到了如此程度。  
  
这提醒我们：信用本位下，印钞机不会停也没法停，此招无国界。  
  
现在市场盼着啥呢？赶紧出现衰退迹象，然后启动QE5，接着奏乐接着舞。  
  
图二，统计了美国各州房价涨跌，比较震撼我的是08年房地产金融泡沫破裂后，房价足足跌了4年！  
  
图三，次贷危机后，美股正式成为好大儿，美股涨跌和美联储的放水相关性非常明显。  
  
从QE1开始，房股完成了资产切换——美房埋葬了一批房东，而美股成就了一批股民。
