# 装修款都快够首付了...

![图片](https://mmbiz.qpic.cn/mmbiz_gif/ibw8b04QVx2M7PTAr8JHoc98wCJlkDyXxsA0LtNpBgqhicVxmxOENpDia40416PMnQfU6BgCLN0bVtwGJS9LMhIJQ/640#imgIndex=0)

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2OrYk01tQRV43lotIicQheu5H3kEeicrIfKPqqicroPCYxtPKcrHIGay2GdL3TpAp9ol7bF7dpTyic2ZA/640?wx_fmt=png#imgIndex=1)

今天心情非常差，原因是有两件事刺激了我。

这几年和女朋友一起过得可谓节衣缩食，我们在朋友和同事圈里是出了名的节省。

比如我女朋友的同事会和她说，你怎么老是这几身衣服啊，让你老公多买几件！

我买的，我和她有好几款情侣环保袋呢...

今年我们在北京上了车，说以后不要再太过节省，还是要潇洒一点，不然熬成中年大叔和妇女，心气儿都没了。

装修也是，我们俩都比较忙，谁也没空盯着，直接找了链家旗下的家装公司，平时根本不管，有时周末犯懒也干脆不去看。

我硬装大概十一万（需要恢复毛胚状态从头装），想到以后都是自己住，这钱不能省，也没心疼。

快到双11了，这两天要把家具、电器都列出来一起买了便宜，一算账，还得花7万多...

问了同事们，都说不贵不贵。

那就买！都说了要对自己好点儿，不能抠！

结果前几天我高中同学给我打电话，说她工作这几年攒了些钱，想在嫁出去之前给爸妈买一套改善户型的二手房，首付预算20万左右。

听说我辞职了，问能不能回沈阳帮忙一起看看房，出点儿主意。

我放下手机，满脑子都是首付20万还改善户型，我的装修预算是不是太多了？！![图片](https://res.wx.qq.com/mpres/htmledition/images/icon/common/emotion_panel/emoji_wx/2_05.png#imgIndex=2)![图片](https://res.wx.qq.com/mpres/htmledition/images/icon/common/emotion_panel/emoji_wx/2_05.png#imgIndex=3)

瞬间开始心疼，出血那种疼...

钱真的是毛了，首付通胀成了装修款。

**M2大水漫灌，不找个资产上船把财富锚定住，下场就是泥牛入海，冲着冲着就成牛犊子了。**

熟悉理财后，我最大的恐惧就是货币恐惧，害怕手里有现金。

当然，这两年还是渴望现金的，所以这个装修费用越想越嫌贵。

合计跟女朋友商量一下，不知道咋说，就是开不了口让她知道....

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2OrYk01tQRV43lotIicQheu5ibeRsMa6Xzt4FWQFvhkgwpwFZhN5P7sBEdakdggBKINJlANiakAP5utw/640?wx_fmt=png#imgIndex=4)

第二件事是一直想找本关于日本消费升级方面的书，应该对当下很有参照意义。

如果真有的话，我就当选题好好写个推送。心心念念搜了一下，还真被我找到了，书名叫《第四消费时代》。

这本书我收录到了书单里。回复：**书单**  可看

昨天寄到了家里，本来打算这个周末啥也不干，快速地书看完，下周就把稿子发了。

结果上午赴了一个必须去的约...那就下午抓紧看会儿吧！

装修师傅打电话说地板装好了要过来验收。

妈的！不去！没空！

不行，明天还得装柜子，你今天必须验收。

什么？那明天又得盯一天啊，这书是别想看了。

终于把地板验收完了，嗯？

今天不是周六么？是不是要更新？是不是稿子还没写？![图片](https://res.wx.qq.com/mpres/htmledition/images/icon/common/emotion_panel/smiley/smiley_0.png#imgIndex=5)

真是想死的心都有，因为还有点儿发烧。

打车回家！一开门，28斤的小奶狗尿了一地。

我刚刚就该去死的...

说好的辞职以后要岁月静好地过小日子呢？

我奉劝大家，你们最好在春节、十一、毕业以前，把要考的证，要看的书都搞定！

否则，你要面临谈恋爱、吵架、租房、买房、装修、上班工作、同事关系、投资决策、照顾孩子、照顾老人等一系列费心费力的事情。

你根本没有没有大段可以专注的时间。

生活分分钟教你做人。闹心...
