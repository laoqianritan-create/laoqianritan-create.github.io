# 哎呀妈，沈阳鸡架意外走红了

‍

‍‍

‍●

本来今天想偷懒的，结果看到沈阳疫情对确诊病例的流调结果一下子把鸡架带火了。作为沈阳人，忍不住蹭个热点。

之前北京确诊病例的流调结果个个拼搏奋斗——

40多岁一天跑十几个小时的滴滴；

30多岁北漂女生，白天上班，晚上在顺丰兼职；

每天100多公里燕郊→望京通勤的北漂；

一家四口挤在70平房子里，男主人边上班边备战清华考研...

然而沈阳确诊病例的流调结果画风突变，不是干面条就是啃鸡架，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MLzwkYY2LIDNKzcuJa4E4Vn5CibYFvAuENk1LwrVHMTlwicxUiczUXKbQEB2IBgR130hibPrQNCiaiacBg/640?wx_fmt=png#imgIndex=0)

上图也提到了沈阳鸡架这一块的几个王者，正好给大伙儿安利下：

熏鸡架，**「老迟家」**挺有名，大爷第一家选的就是它，用糖熏。

拌鸡架，**「玖福记」**很有名，熏鸡架的基础上再用各种调料拌一下，酸甜口，还有点麻，必须放香菜，不然就失去灵魂了。它家外卖做得好，我回沈阳了有时候大晚上都点，推荐单加点海带和鸡脆骨，更好吃。

烀鸡架，这个领域**「老四季」**是王者，其实没啥味，所以必须二次加工下，榨菜、香菜、辣椒油、陈醋四样混合在一起吃，相当重口。

还有一个铁板鸡架，我私藏的店叫**「大富鸡架」**，一般配老式麻辣烫。

炭烤鸡架也不错，味道和铁板鸡架大差不差。

另外我个人非常瞧不上油炸鸡架和炒鸡架，这两做法多少有点倒反天罡了，不推荐。

沈阳人为啥这么爱鸡架？

说说我个人的观察，不一定对：

沈阳和青岛很像，啤酒文化很流行，大家普遍都挺好喝。

九十年代国企下岗潮，大批原来经济条件还行的人丢了铁饭碗，失去经济来源。

经济基础决定消费行为，在喝酒和下酒菜方面只能被迫消费降级。

鸡是最便宜的肉食，鸡架又是其中最便宜的边角料，完美满足了大家的需求。

直到现在，想在沈阳买个醉，成本还是很低的——

两瓶酒精度12°的老雪花，你酒量再好，喝完也至少保证微醺，2个鸡架足够啃半个小时，当然这是吃不饱的，最后再来一碗抻面填肚子，一般用不了25块。

所以鸡架一直是沈阳本地认可度最高的食物之一，属于小吃范畴。不同于东北菜，这东西一般拿不上台面，尤其沈阳人又普遍好面子，不太可能拿这东西招待不熟的客人，所以全国层面知名度一般。

这把也算一炮而红了，等疫情结束了，欢迎大家来沈阳尝尝![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MLzwkYY2LIDNKzcuJa4E4ViaViccB0GgiaEKTy6JpXN0r7GPM6gYicvAyTv2mOKjEW0xoh0WgvuePJbA/640?wx_fmt=png#imgIndex=1)。
