# 我最喜欢的一期

兄弟们，新一期的《面基》来了。

嘉宾是首位坐客《面基》的私募基金投资经理@南添，又是一位好大哥。

坦率讲，**目前为止这是我个人最喜欢的一期**，节目时长也创下了纪录，3小时。

而在此之前，我听老南的分享时长妥妥超过了100小时——包括线下的青训营分享，线上的B站直播，我常在洗澡时听。

老南是金融行业的异类，他中专毕业后开着一辆捷达车在长三角地区跑了多年的化工销售，后来又因为看了一本写巴菲特的书，转行进入金融行业，从一家券商地方营业部的柜员一路干到副总，再到券商资管公司的投资主办人，最后回到南京，创办「望岳投资」这家私募。

望岳所在的城市、投资观、方法论、甚至销售模式，都区别于金融行业的主流。

对我来说，这又是一期注定会听很多遍的节目。

其实我今年常常在想一个问题：

**三观都没稳固的情况下，能做好投资吗？**

别说面对财富了，我连面对自己、他人、世界都有很多困惑。

如果自己的三观都弱不禁风，又怎敢说在此基础上建立的财富观、市场观、投资观完备且稳固呢？

但是涉及三观这种神叨叨的问题总是难以开口，能问谁呢？

借着这期节目，我向老南问了几个心中的困惑。

事实证明，好大哥们从不让人失望，也总是真心为你好。

我应该给《面基》单独开个小专辑，就叫#好大哥系列#，哈哈哈。

这期节目里，我们讨论了很多事——

✔️ 如何在一个聪明人无数且超级内卷的行业里自洽地走自己的路？好在聪明并不是投资中最重要的事。

✔️ 除了那100万的起投门槛，私募和公募到底有啥区别？

✔️ 像我这种矫情的小弱鸡，怎么更好地面对生活中的种种负反馈？

✔️ 还有我今年最大的收获之一，**引入了「现金流」这个新视角**，用它去看消费、储蓄、投资、理财、商业，有一种从未感受过的新奇体验。

✔️ **实事求是，真的对自己、对世界诚实，这是投资中最重要的事。**

而我之前从未意识到这点的重要性。

✔️ 我还拷问了老南作为一名投资经理的市场观和投资观——

* A股是什么样的市场？
* 美股又是怎样的世界？
* 在两个市场有哪些心得和教训？
* 你凭什么跑赢指数？
* 你的正面清单和负面清单是什么？

✔️ 再比如，我深刻意识到：什么基金经理、分析师、研究员，都只是title而已，关键是把决策做对。

✔️ 还有我最想做的事：怎么才能拉成久期，活成一家慢公司？

我保证，本期节目能给你带来很多启发。
