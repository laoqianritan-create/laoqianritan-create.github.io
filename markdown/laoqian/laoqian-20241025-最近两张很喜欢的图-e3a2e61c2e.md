# 最近两张很喜欢的图

✅图 1. 其实这张图给我造成了不小的困扰。   
  
因为 9.30 和 10.8、10.9 做了一些止盈，但内心其实相当困惑和迷茫，就是因为我对配图印象深刻，于是不禁怀疑——   
  
啊？这轮... 这么短？这么矮？现在卖一些，是不是早了点？   
  
但谁说这轮它就必然是牛市呢？ 就算是，又为啥必然复刻之前几轮呢？   
  
首先，未来是一种概率分布，最终走向哪个平行宇宙，都说不定的。   
  
其次，周期从来不是时间和空间上的复刻，周期只是因果律层面的反复——盛极而衰，否极泰来。  
  
最后，这张图以沪深 300 的涨跌来统计牛市和熊市，但沪深 300 并不能代表A股。事实上，如果去复盘中证 500 或者中证 2000的话，会看到差别相当大的牛熊周期。  
  
✅图 2. 最近A500的密集宣传看得我有点审美疲劳。  
  
客观讲，这确实是替换掉沪深 300 的好选择。  
  
但性格使然，我看到抱团就闹心。  
  
做了张图，直观展示下各个「规模指数」在A股市场里的生态位。  
  
✅图 3. 是我近期最爱的一期节目，感谢@张翼轸 老师的心理按摩，听完舒服了！
