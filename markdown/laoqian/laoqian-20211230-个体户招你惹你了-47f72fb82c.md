# 个体户招你惹你了？

本周写了两篇税务文章，从[薇娅事件](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649619333&idx=1&sn=4832a8ba2969683664a4b94ed67c5f62&chksm=881c3f59bf6bb64f8720b1b5146a8ca449716936ba2a9670407b4b4b07fe54000d89cb612a74&scene=21#wechat_redirect)写到[我国税收体系](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649619347&idx=1&sn=ac55fcb1f143a1448a6a06c2f77b94e4&chksm=881c3f4fbf6bb659e2f38bf24d5b558fb503fc9629091bda8328485544fb4c75b3c740625c33&scene=21#wechat_redirect)，本想到此结束。

但两篇文章下面不断有新增评论提醒我——

> **那些摆摊的小商贩，农民工的工资，还有一些农村类似微商的个体户，他们的收入并不低还不用交税。**

我实在气不过，想为他们说几句话：

首先，媒体在这件事上有很大责任，热衷于写生产类似《XX摊主/小店月赚三五万，一天只卖8小时，不少人开着大奔宝马过来买！》这种带有反差感的博眼球新闻。都多少年了？还玩不够。

长期以往，给大家造成了一种错觉——个体户收入颇高，吊打白领。

稍微分析下就会发现这里面有多少误会。

为啥一天只卖8小时？没铺子的话，小摊贩敢白天出来卖吗？

个体户不比白领，没有五险一金，尤其是公积金，别忘了公司交的那份可不用白领出钱，月薪1万的话，按照下限交，每月也白拿500元的。

白领的医保是城镇职工医保，好点的公司还有体检和补充医疗。

个体户呢？他们撑死买个报销比例更低的城镇居民医保。

**白领还不用承担任何风险**——这里肯定有人怼，白领就没有失业风险吗？

呵呵，幸福是比较出来的。

白领还真没风险，市场风险由雇主承担，还是上班摸鱼带薪拉屎，失业了只要企业有点良心还给至少N的补偿，实在找不到工作了可以申请失业保险和公积金取现。

你告诉我，这叫风险吗？

个体户可不敢摸鱼，手停口停，任何一丝懈怠都会直接体现在收入中。**如果经营失败，个体户要承担债务的无限连带责任。**

当下就是最好的例子。疫情至今，你说是被迫在家办公的白领痛苦，还是个体户痛苦？

还有人会说，个体户比普通白领赚得多呀！

首先普通白领的收入如何定义？真实利润能跑赢当地社平工资的个体户占比又有多少？这些是没有准确数据的。

大家分析问题有点最基本的商业常识——

白领的工资是净收入。

个体户的收入是净利润吗？他卖的东西没成本吗？那些依托于平台的灵活就业群体的劳务报酬，平台没代扣个税吗？

双职工白领家庭创造的是双份收入。个体户很多都是夫妻店甚至家族店，他们的收入是要平摊到人头的。

白领的工资由老板定价。个体户的收入由市场定价，他还承担了更多的经营风险，收入更多有什么奇怪的吗？

最后，谁说个体户不交税？有店面的话，你觉得他们可能不被「核定征收」覆盖到吗？

白领们真觉得个体户好，不用那么酸，随时可以把自己市场化，个体户和灵活就业群体都欢迎你。

**··· ···**

这篇文章是带着情绪写的，我很生气。

第一，我真的非常喜欢「个体户」群体以及这个词本身。

**个体户是一种精神——勇于把自己市场化，脚踩在泥里赚钱，不寒碜！**

白领也应该把自己当做个体户，本质上我们都是自己的老板，给自己干活。

第二，全职做自媒体以后，这些年我的自我定位也是个体户或者说小老板。亲戚朋友问起我时，我都尽量避免用创业这个词，俺就是内容领域的个体户，属于服务行业，开门迎客，磨炼手艺，伺候好公众号知识星球的衣食父母，还有金主。

所以我对这个群体非常共情，**知道其中的不易，也见不得他们承受不该有的恶意。**

**··· ···**

给大家看下主流个体户的样子，我吃晚饭时刚拍的：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2OnuXTKbYTH6PL0ntMVn58ZOlCoUSZcwkCXVWP2O71cDnibbiahRUoz9Wzia9r1SCycd9YbmGc3VNRPA/640?wx_fmt=png#imgIndex=0)

我经常来照片里的大食堂吃饭，它位于北京某soho商圈，是周围餐饮消费中最便宜的一档，来这里吃饭的都是周围的普通白领、个体户、外卖小哥等灵活就业人员。

我就说几个细节吧：

soho底商基本半年到一年更新淘汰一遍，但这个食堂在此屹立不倒多年，包括疫情。因为客源极其稳定，当然大家来这肯定不是因为好吃，而是真没其他便宜吃饱选择多的地方了。

食堂内档口也会偶尔淘汰，但大部分都坚持了多年。能长期留下的，个个都是做碳水的好手，而且都做了外卖。

我印象中倒闭速度最快的一家档口是做隆江猪肘饭的，味道不错，但就是在这个食堂里水土不服，很快死掉。因为蛋白质占比高，太贵了，小碗卖22元，连半颗卤蛋都不送。这价格在食堂生态里根本活不下去，其他档口都在15～20元的价格区间里厮杀。

而且真正的灵活就业群体来这吃饭更便宜——外卖小哥基本都在非就餐时段过来，个体户老板要么给他们便宜个一两块，要么多盛点饭菜。

食堂很缓和，小哥们哪怕什么都不买也能在这里歇脚。吃饭基本都是一大碗碳水，夏天时还会喝一瓶绿棒子。

这就是他们的画像。

**个体户+灵活就业+农民工能占我国整体就业人口的半壁江山，从他们身上薅不出啥油水的。**

个别网友，我劝你有点脑子和同理心。
