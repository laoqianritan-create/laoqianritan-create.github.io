# 当父辈遭遇「大环境不好」

‍

‍我问过我妈，90年代大下岗，她也是其中的一朵小浪花，那时看到的，听到的，大家接下来都干了什么？

我觉得这是个很有价值的问题，往大了说，是时代逆境下的个人盲目选择**（彼时彼刻没人能看清未来，都是盲目的）**。

得到的答复是，干啥的都有：

接零活干的，干餐饮的**（特别多）**，去南方打工的，做小买卖的**（比较厉害的会去五爱街，那时候可乱了，有黑社会）**。

我妈下岗后找了份查水表的工作，一边考了会计职称。属于子承父业了，我姥爷40岁在夜大学了会计，他的两个女儿后来都当了会计。

后来我妈一直在民企开发商做会计，干了20多年，公司送了套房子，她自己又便宜买了一套小的养老。其实当初的想法是，如果我回沈阳娶媳妇，买不起房子就把大的给我当婚房。

还有很多人考进了体制内，当时看来平平无奇，不曾想踩上了可能是他们人生中最大的红利。

我爸就是其中一员，但他最后从体制内出来了，去了一家热力公司，俗称烧锅炉，我也不知道他咋想的！可能那时候体制内外的差别真的不大吧...

再之后他出来自己做小买卖，专挑没市场还需要技术含量的冷门领域，就是自信！一生碌碌无为。

爹妈下岗时，跟我现在的年纪差不多，那绝对是巨大的人生挫折，甚至有点儿信仰崩塌的味道，铁饭碗没了，内心的社会地位和身份认同荡然无存。

用现在的话说——大环境不好，大通胀，高失业率。

好在养娃成本不算高，也没买房压力，那时的房子连商品都不算。

这种逆境下，**是躲进穷鬼乐园里当个酒蒙子？**

**还是不服输，不要脸地自救，能干点啥干点啥，死劲折腾？**

**不管时代背景如何变，这个剧本是不会变的，很多人都会遭遇。**

真不知道他们是怎么扛过来的，那时候他们没有自己的房子，还带着我，很多时候真的要为基础生活费发愁的，我甚至还记得我爸带着我去爷爷家借钱。

我丈母娘当年也苦极了，一个人拉扯大了3个女娃。

最有趣的是，每当我和两位老妈谈起这些往事，她们都云淡风轻，不当回事。

我经常惊诧于父辈对于苦难经历的心理免疫，其实就是一种麻木。

我爸至今没能那场时代的酩酊中醒酒。

但我妈知足又幸福，她日复一日练了12年瑜伽，有着清晰的马甲线，退休后每周爬两次山，乐此不疲地和我讨论股票代码。

她满足于2千多块的退休工资，前几天特别开心地告诉我国家又给涨了4%。

我丈母娘也岁月静好、游刃有余地照顾着两个孙辈，她调教出的小朋友爱吃饭又懂礼貌。

在苦难中，女人总是要比老爷们儿更坚韧一些，真的！
