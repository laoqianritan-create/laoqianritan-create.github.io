# 开门迎客，每年一次

**●**

留京过年好无聊，所谓的囤年货就是在拼多多上买了个零食大礼包，下单时还想着会不会太少了？到货才发现根本吃不完...

年夜饭都懒得做了。

在超市买了手工饺子，一手店的熟食。

又去家附近的饭店打包一大锅羊蝎子留着明天晚上吃，老板说没必要，除夕正常营业，欢迎随时来。

因为疫情，去年是回家了不能走，今年是有家不能回。

以前主要大城市的经济运转会在春节假期陷入几天轻宕机的状态。没办法，大家都回老家了，今年则完全没这感觉。

一季度的经济数据一定不错！

虽然1月份的CPI数据已经第二个月同比负增长，而且剔除了食品能源价格的「核心CPI」也是负的。

初一的电影票已经买好了，下手太晚，《唐探3》已经没座了，只抢到了《刺杀小说家》。不过没关系，反正六部电影一个也不会落下。

假期还安排了逛公园和泡温泉等娱乐活动。

今天是A股最后一个交易日，本周红包三连。

港股明天上午还有半天的交易时间。

写到这突然想起来，去年除夕上午突然爆出徐峥把《囧妈》版权卖给字节跳动的消息，我还趁着最后的交易时间投机了一把欢喜传媒。

时间过得真快啊~

**#中产八卦**

各种职场、养娃、婆媳、夫妻、相亲、加名字等中产家庭八卦，还有球友们的提问。

**#城市战争**

选择城市就是选择了人生，包含一二线核心城市基本面、地段分析、楼市政策解读。以及乐此不疲地忽悠大家去二线城市，投住分离。

**#买房攻略**

房产类帖子数量特别多，基本上你能想到的有关买房的各种问题都能搜到相关帖子。

**#人生安全边际**

通过大量案例来回重复「人生负面清单」里的各种坑，以及如何应对。
