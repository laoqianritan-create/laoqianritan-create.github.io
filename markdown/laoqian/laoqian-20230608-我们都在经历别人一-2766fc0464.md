# 我们都在经历别人一无所知的战争

想想挺有趣的，对我们来说，今天不过是一个再普通不过的工作日。 

而对那些高三学子和家长而言，今天是他们一生中极其重要的「路口选择日」。

我们说关键节点，关键决策，人生要选对。

但说到底，高考也不过是人生众多分岔路口之一，而已。

短期看，这里分了高下。

长期看，胜负未定，你还真不知道它将引你走向何方。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/M7fHtGOlzVbozD6I99L0rEXP3PFEgouHrAaF4gmlzibnJib4NrmficoFiak0mKhd4T3lIHLgIP153jOCdAsNU3cSRw/640?wx_fmt=png#imgIndex=0)

未来的日子里，我们还可以给自己开拓出很多个平行宇宙。

每个人都在经历一场他人不了解的战争。 

我最近看很多人在转发下面这段话：

「我非常喜欢的一个东西，是一个人十三四岁的夏天，在路上捡到一支真枪。因为年少无知，天不怕地不怕，他扣下了扳机。没有人死，没有人受伤。他认为自己开了空枪。后来三十岁或者更老，走在路上时听到背后隐约有风声，他停下来转过身，子弹正中眉心。」 

这种时间加持下冥冥中的宿命感，也隐喻了我们在一些重要时刻所做决策对未来的影响——让子弹飞一会儿，交给时间，它总会击中什么的。
