# 富途老虎，说下看法

既然已经被定性为「非法金融活动」，那就别心存侥幸了。

我搜了下财联社的电报快讯板块，从15号开始就有相关消息被模糊地表达出来，可能市场还是有些侥幸心理吧，反应比较弱**（这期间也有10%+的跌幅）**。

没想到今天被一锤定音，据说财新网昨天就在首页挂出来了，俺没看到![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2P8S23hbM0TIFSouBibv9jG6UcpcgVNN6JbEBoYhyszkUPruz9QoRgibAYg1Z8AdPE1giao12leFB4PQ/640?wx_fmt=png#imgIndex=0)！不过消息确实是在今天下午才开始大面积发酵。

现在的情况是富途在香港、新加坡、美国当地持牌并展业是符合监管的，业务还会继续。但在大陆并不持牌，所以国内市场肯定不能做了。老虎和其它券商也一样。

**我会把相关券商里的钱先提现到香港银行卡里，慢慢转回来。**

听政策的话，事实变了，思路跟着变即可。

**以后还想投资港美股，只有「港股通」和「QDII基金」这两个合法合规的途径。**

**··· ···**

这样一来，港股打新的红利也没了，纪念一下，2018~2021。

A股打新的红利不知道还能持续多久，今天上市的两支新股全部破发，过去一周还有4支新股破发。这在以前是无法想象的！

A股打新是制度红利，虽然很难中签，但中了一定躺着数钱，根据之前的数据，平均中签收益在2万元左右，9月份降到1.5W，这个月就只有0.6W了。

如果破发常态化，再加上无比鸡肋中签率，没搞头。@A股打新，@可转债打新你们要挺住啊！

哦，可转债破发不碍事的。

**··· ···**

互联网和新经济股今年太惨了，跌幅超越2018年，好公司挨个被政策定点爆破。

我昨天发文章点了下贝壳和房地产中介收费不合理，评论区的负反馈声音也很多。不过还好啦，没出圈，这要是在中介圈里传开，我非得被骂死不可。

这么说吧，只要公司/行业有负外部性，对潜在风险还是要堤防的，尤其为不合理买单的还是老百姓。

**··· ···**

今天看了下河南本地超市胖东来的故事，深刻感受到了啥叫企业ESG，**核心就是持续地资本支出。**

你是干高科技的，就像华为一样砸钱做研发，提供高薪岗位，让上下游都跟着赚钱，最后换来技术领先优势和市场美誉度。

你是做消费/服务行业的，就真材实料别搞猫腻，对员工好，对顾客好。

怎么算好？合理有效的资本支出就是好。

有魄力改变自己的ROE，主动降低净利润率，看起来傻，其实换来的是更长的经营久期和更高的美誉度。

就像周二[《我悟了》](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649618844&idx=1&sn=c3e9227161ca6e131abed1fb66f55a07&chksm=881c3d40bf6bb45648ec684cb1ad941c6b922351ecf1d3f22839ec201ac06ebfc79992af5562&scene=21#wechat_redirect)说的那样——只有时代的企业，能跑出来的龙头，也都是时代的馈赠。

**··· ···**

今年心态变化挺大的，很佛系，很躺平，不是负面意义的破罐破摔哈。

**就是对生活的随机性和周期波动更坦然了，心理阈值噌噌扩宽，啥都能接受。**

号炸了我都不怕，大不了回去上班搬砖咯~

什么阅读量涨粉，通通去他娘的，可别拿这些绑架我。

当然，也时常反思，当个对社会有意的人，至少别成为那个摩擦成本。

共勉！
