# 雨中猫片

骑车骑一半下雨了，正好离中山公园不远，买了张票进去避雨。  
  
看到很多小猫，不怕人，只要不突破安全距离，随便拍，根本懒得搭理你。  
  
雨停后继续骑，又路过宝瑞门钉肉饼，硬吃了三个，现在战斗力不行了，以前我能硬吃四个…
