# 我昨天有些反应过度了

‍‍

‍‍今早跟富途等各家券商沟通了一下，打听了情况，还不算正式定性，其实一切跟之前没啥区别。希望不会给大家带来困扰。

这是富途CEO在社区里的声明：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2O1H0p7jg2TpxZnQDuJ1OnwSDCfTibicGRZOJPVlicTlZB5tB1hMBFXBSIjJLwBEFsPAEcibJiapVHz8rg/640?wx_fmt=png#imgIndex=0)

不好意思各位，昨天的文章我有些反应过度了。

主要是一直非常在意合规，之前屁凸屁，比特币啥的，只要被点名定性了，我都听话不碰。

另外，昨天很多有一些读者反馈是大陆银行卡入金的，这种情况最好还是努力办张香港银行卡，以后出入金也方便。大陆银行卡出金很容易被**（银行）**拒。

**··· ···**

FACEBOOK公司改名了，新名字叫META，有点all in元宇宙的意思。 

这种变动就类似今日头条公司改名为字节跳动一样，APP的名字不变，公司名改了。 

可以理解为，这家公司原来所有的业务都围绕社交媒体展开，但以后公司的头号项目是元宇宙，不是Facebook。 

Facebook、Instagram、WhatsApp、Oculus等这些软件都是META公司旗下的产品。

有个小感慨，回顾一下过去几十年，所有历史级别的科技创新产品，总是美国公司先all in，然后抢下行业头把交椅—— 

电脑和操作系统-微软 

智能手机-苹果 

新能源汽车-特斯拉 

虚拟现实-META？

关于啥是元宇宙，我之前写过一篇小科普👉 《[他们说这是互联网的救命稻草](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649618444&idx=1&sn=982cda4df477caafe044a69f6b8055bd&chksm=881c3cd0bf6bb5c6a3871e6a6bdd90e7c4c8bae61425d8fb6c62747d3e1f92a81e148b747474&scene=21#wechat_redirect)》

**··· ···**

昨天的文章还有一个错误：本月A股新股破发潮并非历史首次。

原来自1991年A股开市至今，出现了七轮新股破发潮，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2O1H0p7jg2TpxZnQDuJ1Onwd1tyb7VTT53rlxaYOZSNu9HlQYhT8fRcpe70ibdx8OcL6H68kSHearQ/640?wx_fmt=png#imgIndex=1)

上图统计了2010年至今的数据，这之前还有2004年6-8月、2007年10月、2008年10月。

这些罕见破发均出现在市场情绪不佳、流动性趋紧时，包括本次。

关键是，上个月A股还在连续创造单日成交破万亿的新记录呢～

不过根据历史经验，这种破发状态也不会长期持续，淡定对待就好了，毕竟中签率在那摆着呢，想当倒霉蛋还真不容易。

**··· ···**

最近看到一句废话，是这么说的：

**赚钱了，一定要知道自己赚的是什么钱！**

你们细品，是不是太有哲理了，发人深思，越琢磨越是内味儿。

甭管公司还是个人，一定要知道自己赚的是什么钱——

是运气的钱，还是时代的钱，是能力的钱，还是趋势的钱，反正最好别是亏心钱...
