# 现在买房，首付和月供谁是真正的问题？

买600万总价的，20%首付，贷款总额480w，房贷利率3.5%，30年等额本息，月供2.15万。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/M7fHtGOlzVYrUcoAfNv55lucEUvOr8J26WiaQ09MKWaicRI0pRCW9OeTAzwxYEEPC22PgvI04vqQezRyaJecShVw/640?wx_fmt=png&from=appmsg#imgIndex=0)

根据银行的风控要求，对应税前收入4.3万。

400万总价的，20%首付，贷款总额320w，房贷利率3.5%，30年等额本息，月供1.43万。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/M7fHtGOlzVYrUcoAfNv55lucEUvOr8J2ZyG7xKiaAeVSWey8DBj5MibvlznY1VX45XaichmiaGhrKXDTvIhaIWQUFg/640?wx_fmt=png&from=appmsg#imgIndex=1)

根据银行的风控要求，对应税前收入2.9万。

4.3万和2.9万，我们假设是对一个家庭总收入的要求——即便如此，估计很多人看了还是没底。

这就是楼市的变化：

以前买房，都觉得月供不是问题，对收入有信心。

问题是首付不太够，一线城市二手房的真实首付比例，最低也要4成。

现在买房，首付问题不大，毕竟卡得不严了。

问题是对收入**（的久期）**没啥信心了，一线城市的房地产支柱型行业，哪个不是鬼哭狼嚎的？

以前老吐槽二套房的八成首付，现在风偏低了，觉得八成首付好像也挺好...

综上，现在的买房问题，看微观也许比看宏观的效果更好。

以及，要想减轻月供压力，核心还是多交点首付。

那么首付何来？

置换来。

置换链条的启动，仍是重点。
