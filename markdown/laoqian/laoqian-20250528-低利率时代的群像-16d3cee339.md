# 低利率时代的群像

2020-2021年，大部分人都认为未来将长期处于低利率甚至负利率的未来，然后2022年的加息让大伙儿都蒙了...   
  
那么，现在再看中国呢？  
  
考虑到老龄化、企业和家庭部门均无意也无力加杠杆、自然利率下行、发钱和补贴可以直接触达到有手机的个人等等背景...  
  
中国是易通缩还是易胀体质呢？
