# 所谓投资风格

![图片](https://mmbiz.qpic.cn/mmbiz_gif/ibw8b04QVx2M7PTAr8JHoc98wCJlkDyXxsA0LtNpBgqhicVxmxOENpDia40416PMnQfU6BgCLN0bVtwGJS9LMhIJQ/640#imgIndex=0)

交易一支股票，总共分三步：买入—持有—卖出，每个环节都有失误的可能：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PzQaoreXWicdodQDyzmUNMHjfeJcl5N0Ppz1eKicI7vdtkgPVoYmIgArEKtJCGH7v725AfL2LU3vAQ/640?wx_fmt=png#imgIndex=1)

买入环节可能脑袋犯错，在错误的时间买了错误的股票；

持有环节可能屁股犯错，该长期持有的股票，早早就跑了，要么卖在腰部，要么低位出局；

卖出环节也可能犯错，对收益和亏损过度贪婪，无法及时止盈止损；

所以啊，炒股是善败者的游戏，太容易赔钱了。而且交易越频繁，在三个环节上犯错的概率也就越大。

同时市场上永远存在获利机会，一直在诱惑你。

慢慢地，有人总结出了一些赚钱的套路，逐渐形成了所谓的「投资风格」：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PvIRlAD4oCBnZ44PD1273PJezVaRAKUMEISxB8Qj4nRMibaWuV9GADb6iaN0cOAcLnDo6UOHzYsIwA/640?wx_fmt=png#imgIndex=2)

所谓「胜率」，就是不亏钱的概率。

对于任何一个股票投资者来说，没必要也不可能在每一种投资风格中都取得不错的「胜率」。

在我看来，能在任何一种风格中做到良好，都算得上投资家。

妄图尝试多种风格，可以说是很合格的韭菜了。

以上六种风格，一种也做不好的大有人在。

比如赚企业成长的钱，看起来很美好，但在A股实践起来，长线收益还真就未必有短线好；

比如靠股市低风险工具赚钱，收益低，看起来一点儿也不高级。而且需要延迟满足，长期见效，很多人都瞧不上也没那个耐心。

但我依然觉得「靠股市低风险工具赚钱」风格适合所有股票投资者，只要有正确的收益预期和足够的耐心，完全可以获得稳稳的幸福。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PzQaoreXWicdodQDyzmUNMHgceWHzNF2xbiaz7sibHMzuwVOP6BMm2jT8kcNo0S3JTd0l7icOrF0r64Q/640?wx_fmt=png#imgIndex=3)
