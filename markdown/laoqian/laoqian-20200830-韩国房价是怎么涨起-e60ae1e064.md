# 韩国房价是怎么涨起来的？

先介绍下背景：

2017年至今首尔房价一路走高，幅度远超其它国际大型城市，¥580万的公寓在首尔差不多是平均水平。 

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2O7u73U1Yic6T5fFEJ5eOu4Yj6PyTCB8GrzkTNia5sDS3XdDKbIVePDRVEZqyjSwf44gcI4OCJZou7w/640?wx_fmt=png#imgIndex=0)

大涨的原因有很多，比如供需失衡、超级宽松的货币环境、外资买入、信贷政策等等。 

复盘后大家发现，以上因素都不是最主要的原因。

真正推手居然是韩国奇葩的租房制度——首尔60%的家庭都是租户，这一比例在国际化大都市属于比较正常的范畴，哪都差不多。 

其实这六成租户很多完全能买得起房子。

但他们为啥不买呢？原因就在于租房制度。 

接下来请用普通老百姓视野有限、爱从众、厌恶贷款、喜欢占便宜的角度思考以下问题。 

现在你要租房子，有两种选择： 

第一种，月付季付都可以，但必须押十。是的，你没看错，押十！既然是制度，就不要去质疑。 

第二种，房租不要钱，水电费自理即可。但是，押金要总房价的50%以上，押金越多，免租期越长。到期后还退还全部押金。 

为了帮你选择，再介绍几个背景： 

**①** 首尔房价长期相对稳定，没啥捞头。 

**②**欧巴那么帅，欧尼那么靓，人生不该一辈子绑在砖头上不是么？ 

**③**月供会吃下很大现金流，影响生活和消费水平，而发达经济体的首都一定是「高收入高消费低结余」的社会。 

**④**韩国是发达经济体，低GDP增速决定了低利率环境，把押金拿去买固收的收益是比不上房租的。 

**⑤**韩国公司有个福利，每个员工在租住楼房时都可以向公司申请1.5亿韩元**（¥87万）**以下的贷款，优惠利率为2％。比普通银行贷款要低得多。 

好吧，不管你怎么选，基于以上原因，很多韩国人选择了第二种租房方式。

于是，这些租客和房东形成了各取所需的共生关系，租客免费住了房子，享受了生活。房东通过租客管理了现金流和贷款，并且拿到了资产。 

此时有人能看出来，这玩法简直是房产无尽阵啊！

房东拿一笔首付贷款买房，从租客手里套出80%的押金变成首付，再次贷款买房，再套押金，再买，再套... 

如果还有贷票配合，完全可以通过层层杠杆买入大量房产。

而且今年之前，韩国房子可以2成首付。 

因为房价平稳，这一切本是静水深流地运行着。

但是，房价开始慢慢涨了，越来越多租客合计过味来，发现自己的财富通过押金转移给了房东。 

于是，买房情绪被引爆了。

加上开头说的，供需失衡、货币宽松+低利率、限购，首尔房价开始冲刺。 

哈~又是似曾相识的配方。
