# 呃...难道又要打卡300的腾讯了？

腾讯股价再次逼近300元大关，我3月15日挂单300元整抄底，当天最低跌到295元，成交了。

这次抄底收益高点在3月17日，腾讯股价摸到了400元，随后一路震荡阴跌，如今几乎又回到了原点。

3月份我同样抄底了一些恒科、专注港股的徐成，同样有不错的β行情反弹。

同样地，这次回撤亦是β行情的下跌。

这种下跌我认为投资者是不必过分在意的，β行情不以个人意志和能力为转移。

如果投资收益是个金字塔的话，最底层一定是β收益，顶层是α收益。

具体而言，我们的投资收益由三部分构成：

个人行为主要看个人情绪的控制和下注多少。
