# 一个技术派买房者的自白

Nick是我去年偶然发现的「异类」，他是个很专业的房产投资客，把房子当成「资产」或「标的」人很多，但我从未见过像他这样的框架——其基础是**代码、趋势、低杠杆、快进快出**。

完全理性，对房子没有任何感情，所有决策都构建在不同城市的房价周期之上，而且有一套完整且自洽的操作准则。

于是我邀请Nick来《面基》做客，聊聊自成一派的他，**到底经历过什么？有何种思想钢印？以及这套框架的逻辑何在？怎么玩？**
