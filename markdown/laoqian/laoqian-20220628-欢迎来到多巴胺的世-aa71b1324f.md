# 欢迎来到多巴胺的世界

**本文字数较多，如果没时间或耐心阅读长文，建议使用微信读书APP的听书功能。**

今年对我来说是比较特殊的一年，我开启一个新的母题：**研究如何幸福**。

说真的以前从来不在乎这事，但30岁以后我清楚地感受到新陈代谢在变慢，意识到了时代性，知道很多事是我力所不能及的。

另一方面，如果说**投资成功**的评判标准是**长期回报**，**理财成就**的评判标准一定是**人生幸福**，财富只是幸福的构成要素之一。

以上种种让我对幸福产生了极大兴趣，我开始探索，去书本里找答案，**第一站便是多巴胺**。

我想要幸福，想要不错的投资收益。

事实上，驱动「我想要」这个想法的源头正是多巴胺。它让我不光想要，还想要更多。

本文和大家分享下**多巴胺的运行原理，以及它如何影响我们的想法和行为。**

**··· ···**

首先让我简单介绍下原理：

我们的大脑在处理**「当下」**和**「未来」**这两个概念时，其实调用了两套完全不同的工作机制——

**一套用来处理当下，你拥有的，触手可及的东西。**当这套机制运行时，调用的是一系列神经递质，比如血清素、催产素、内啡肽**（自产吗啡）**、内源性大麻素**（自产大麻）**，这些化学物质给我们输送源于感受和情感的幸福。

**另一套用来处理未来，你没有的，想要但需要费点功夫的东西。**当这套机制运行时，本文的主角多巴胺在起作用。一开始人们以为多巴胺是快乐之源，后来发现并非如此，多巴胺式快乐的源头其实是**预期**。

举个例子：

没有→拥有，多巴胺快乐。

我拥有了，没有多巴胺。

拥有→拥有更多，多巴胺又回来了。

发现没？**多巴胺的本质是想要更多，是二阶导，是同比增速加快**，一旦变缓就难受。

所以这东西哪里是快乐啊，根本就是**预期满足**。

当下和未来两套机制在大部分时间里都是此消彼长的对抗状态——

当下机制占优时，你会关注和体验周围的真实世界，更容易幸福，我觉得佛学就是**研究如何让当下机制主导大脑的方法**。

而未来机制占有时，我们更被多巴胺主导，畅想未来和可能性，充满欲望。

多巴胺的运行机制又分为两条回路，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVaKR9EriazovbQZ8PcEeiaMGzX7g2ia1glrhTHIVrftJh18QdGUMR3Z0B2trGEqN9ianQjparDibG5FCqQ/640?wx_fmt=png#imgIndex=0)

多巴胺从腹侧被盖区出发，分成两条岔路：

**①****欲望回路**的终点是伏隔核，它让你充满动力，不管不顾，我想要，想要更多！

**②****控制回路**的终点是前额叶，它与欲望回路互补，避免前者带来的失控，它帮我们识别哪些东西值得，以及计算和规划如何得到它们。

打个比方：

**欲望回路激活时，非理性地猛踩油门；控制回路被激活时，管好方向盘和刹车。**

**··· ···**

至此我们识别了多巴胺的本质——预期满足，以及能激活多巴胺的两条回路。

欲望回路看起来是很不好的东西，它让人充满欲望，丧失理智。

但它也有好处，人生总有逆境，当我们处于因失败而失落的情绪中，如果能有效地激活欲望回路，就会振作起来。**进一步地，能不能将其称为「坚韧不拔」「乐观主义」？**

与此同时，我确实想提醒各位警惕欲望回路！

一旦它赋能了某些错误行为，往往也是我们人生悲剧的开始。

举几个例子：

前面提到，多巴胺并非快乐，而是预期满足。

那么仔细想想：你每次打开股票基金账户之前是不是有所期待？

**看账户，啪！赚了！再涨点！啪！亏了！下午能不能V回来？再看！还没涨！再看！收跌！淦！明日再战！**

发现没？你可能从来没意识到看账户这个行为成了激活欲望回路的靶点，看一次就会释放点儿多巴胺，你上瘾了，欲望回路让你兴奋。

再比如：

**你短炒一支股票，果然涨了！爽！再押！这次亏了！没关系！少亏多赚是短线圣经！XXX有利好，押！出金叉了！游资在扫货！券商给的一致预期非常乐观，明天就出半年报了！**

你看起来真的非常努力！几年如一日看账户，盯盘，看XX社电报快讯，不想错过一条财经信息，你给交易找了很多支撑理由...

**但你没意识到，以上动作都与理性和专业无关，不过是一个个能激活欲望回路的隐秘靶点罢了。**

赌→预期满足→多巴胺→爽→失落→早知道多买点

赌→没满足→赶快再来一次

为什么看账户和短炒非常普遍？这套动作真的又爽又快。

长期持有并不会刺激多巴胺回路，而一旦看到别的股神晒交割单，多巴胺又会在脑海低吟：我也想要！我也能做到！

如果手边有个能释放多巴胺的按钮：

按1次爽1下，你会索然无味。

按5次爽1下，你会加快速度。

按n次随机爽1下，你会无脑又疯狂地按按按！

这个按钮叫抖音，学名奶头乐，整个过程很像机器学习，反复训练，再刷一个，下一个会释放多巴胺。

那我能不能把钱交给基金经理？当然可以！

但很不幸，这个行为不会激活控制回路——**得亲身参与、掌控，控制回路才会让你爽。没有参与感，就会有失落感。**

**··· ···**

不仅动作能激活激活多巴胺回路，很多想法也会成为靶点。

**而一旦某个想法被多巴胺加持，它会变成思想钢印，大脑会找出各种证据将其合理化：**

**「价值投资就是牛逼」**

**「某某机构的作业值得抄」**

你很难分辨出某个路径依赖究竟是基于经验和逻辑，还是伪装的多巴胺，因为它们看起来都很合理——

**「StepN未必是庞氏，我看朱啸虎都入局了，年化500%呢！新技术的导入期不就是这种高赔率嘛！」**

时代性也很容易制造「思想钢印」：

1929年大萧条开始时格雷厄姆34岁，人到中年，几乎破产，对此形成了深深的恐惧，他擅长于用低PB捡烟蒂，底色是破产清算也不赔，金本位时代没有货币超发，市场也给他这样的机会。

大萧条的第二年巴菲特出生，二战后美国开启国运，在这样的时代性下开启投资生涯，美国梦成了巴菲特的思想钢印，投资哲学的底色是乐观。而科技浪潮的康波周期开启之前，尤其是80年代，美国的无风险收益率高达两位数，市场没人着急拉股价，价值确定+低价买入仍有机会。

可后来动则零利率，疫情一波QE顶过去几十年放水量的总和，市场才不给好资产定低价的机会。

扯远了，**我只是想提醒大家保持一份清醒，对多巴胺偷摸加持过的行为和想法的自省和反思。**

**··· ···**

本文并没有给出明确的解决办法，但我想，解题思路大概是：

第一，调用「当下机制」来抑制多巴胺，少一些欲望和ego，让自己小一点，世界大一点，学习如何幸福。

第二，**产生「我想要」的念头时，想象是不是多巴胺在作祟？**有意识地识别并阻断「欲望回路」激活，尽可能避免在其主导下做决策。

第三，有意识地利用两种回路构建一些正循环，对有益行为上瘾。调用多巴胺帮我们克服复杂情况、逆境、痛苦。

第四，谨慎地用多巴胺把一些想法变成「思想钢印」，比如对国运和A股的信仰——如果自己都不信，那别人说啥也白扯。当然这个观点是我个人想法，你可以不同意。

以及这绝不是自干五的小粉红思维，如果生在很多其它国家，把所有资产换成比特币然后润走会是我的不二选择。赌国运是大国国民的专属福利，环境才是储蓄财富的最终容器。

一些个人想法，和大家共勉。
