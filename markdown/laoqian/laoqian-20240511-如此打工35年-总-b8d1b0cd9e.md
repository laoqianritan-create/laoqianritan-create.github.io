# 如此打工35年，总共能赚多少钱？

昨天在播客里听到我很喜欢的抖音博主@史黛拉算了笔账：

顶级天选打工人，职场生涯总共能赚多少钱？

这太有意思了！我也给兄弟们算算！

咱是算收入上限，所以一切按照乐观的来，假设如下：

**25岁研究生毕业，第一年月薪1万，一辈子没失业过，而且工资年年涨。更绝的是，60岁退休那年年薪百万！**

这是一个极度理想化的假设，美好到不真实。

算出来35年的总收入并不复杂，都2024年了，让AI算！

N1=12，N35=100，等比数列求和：

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/M7fHtGOlzVZqOK7X30QHZ1Ew4IT32AqwvNJQYP6WiaztNetR6BMaqMX9Ke2KxoFKM8YsreIctuDDWeEGwSHgMBQ/640?wx_fmt=png&from=appmsg#imgIndex=0)

最终结果是**1467.6万**。

我也可以反过来假设另一个天选打工人：

出道即巅峰，年薪百万，此后收入递减，退休时仍能月薪1万。

N1=100，N35=12，等比数列求和。

两者殊途同归，结果还是1467.6万。

**注意，这还是税前名义收入，而且绝大部分打工人都不可能赚到这个数的。**

所以...这个逼班...

反正大家在评论区说说吧。
