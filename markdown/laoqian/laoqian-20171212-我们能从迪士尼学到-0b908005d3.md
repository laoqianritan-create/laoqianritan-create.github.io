# 我们能从迪士尼学到太多

![图片](http://mmbiz.qpic.cn/mmbiz_gif/ibw8b04QVx2M7PTAr8JHoc98wCJlkDyXxsA0LtNpBgqhicVxmxOENpDia40416PMnQfU6BgCLN0bVtwGJS9LMhIJQ/0.gif#imgIndex=0)

今日更新了4本书。在菜单栏—💡财商—【📚杂书单】可以找到。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02qCgMvYKH34MxWobzPkRicErYCnJAM2HX32tJ2v7qzrH2kuNv18iaGNcQ/0.png#imgIndex=1)

在说迪士尼之前，先来扯个闲篇。

我是漫威的脑残粉，苦苦等待的《复仇者联盟3》终于...出预告片了。

不出意外的话，复联3的票房会再创记录。

从2008年的第一部电影《钢铁侠》到前不久的《雷神3》，再到后年上映的《复仇者联盟4》。漫威说，这盘大旗还没下完。复联4将是剧情分水岭，这之后，将会是新的故事。

这告诉我们一个道理，好IP是用之不竭的。

截止最近的《雷神3》，复仇者联盟系列一共推出了17部电影，总票房超过131亿美元。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PsQLiaO5g06obKqHfHYKLxcZ0WRTxba5X196yLxvunSMibmLR0pUgvUKZkEeDqIQLYia447QhalS4xg/0?wx_fmt=png#imgIndex=2)

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PsQLiaO5g06obKqHfHYKLxc5NRfGMA4XsiaGcyIdIWFPlNqG3xkrcyOCZYTFfIchQaNKxu4M4hLC1A/0?wx_fmt=png#imgIndex=3)

而2009年迪士尼收购**漫威**，只用了42亿美元！可以说，漫威宇宙系列近10年的爆发，主要推手就是迪士尼。

2012年迪士尼有收购了**卢卡斯**，后者旗下最有名的IP是【星球大战】和【夺宝奇兵】系列：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PsQLiaO5g06obKqHfHYKLxc4tVb4qmMO1qo0DPy5vIA0lvV0ESuotugrx8BrP1HUg4sSEsl2GdaYA/0?wx_fmt=png#imgIndex=4)

这两笔收购至关重要，迪士尼成功拓展了IP资源库，切入男孩市场和成人市场。

在这之前，迪士尼的主要IP是动画人物—其价值越来越小了。现在，这些动画IP都由皮克斯接班。

迪士尼于2006年收购了乔布斯创办的**皮克斯动画**，几乎包揽了所有优质动画IP。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PsQLiaO5g06obKqHfHYKLxcpuJjvzF8dmjZplzSJ6Fpm2ibzyNEZvQyPDs15APNYtXhU2YEuxxbgbA/0?wx_fmt=png#imgIndex=5)

上面这几张图，我看完的第一感觉是恐怖，原来这么多耳熟能详的优质IP都属于迪士尼。

第二感觉是划算—买下这些IP，迪士尼才花了157亿美元：

* 皮克斯动画：74亿
* 漫威工作室：42亿
* 卢卡斯电影公司：41亿

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PsQLiaO5g06obKqHfHYKLxcVdVvnf4icAQ1hyZnibs8NTUKRbneU9p44vricAtCDV5MJibp8XeVdsrkzw/0?wx_fmt=png#imgIndex=6)

都取得了十几倍的回报。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02b6ic60tUu5mmkiaW840DDlQZbpDx6FrKZw80myPXshlIiamrskPzvYEwg/0.png#imgIndex=7)

迪士尼在IP变现方面也相当牛逼，形成了一条完整的产业链：

* 通过影视作品不断开发IP
* **收购整合媒体网络，线上传播**
* **主题公园和消费品，线下传播**
* 手机游戏等互动娱乐，继续开发

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PsQLiaO5g06obKqHfHYKLxcVy7jcBQSbvEC2cNNTQ50ZXqzmYYKUa1OmOs9l5ltzSU3483O0DMKZA/0?wx_fmt=png#imgIndex=8)

【媒体网络】和【乐园】两方面一直是迪士尼的营收大头来源。

其中，在媒体网络方面，迪士尼也近乎垄断地控制了主要渠道。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PsQLiaO5g06obKqHfHYKLxcTcDMxkQvHsDfFxxicJq5zzECntqpgUypuO4pcwhHexzo7WNWZ4XrqibQ/0?wx_fmt=png#imgIndex=9)

这部分收入包括广告收入、合作电视台的播放费。

主题乐园方面是迪士尼第二大收入来源，包括12家主题乐园+4艘巨型游轮：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PsQLiaO5g06obKqHfHYKLxcjrLOgUajibQ8yFgN0NP18wfnciaiaKWuBQtSWic36Xl2sTJdKyFvKe1CaA/0?wx_fmt=png#imgIndex=10)

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PsQLiaO5g06obKqHfHYKLxcKyRmv5uUH7QFASKGYU2PuLNBwHtYXGhmjXvqlmjwSMl6PyVmGpWHDw/0?wx_fmt=png#imgIndex=11)

迪士尼目前市值1613亿美金，PE不到19倍。

它太大，涉足太广，以至于难以被定义。但，迪士尼可以说是所有文学、游戏、影视、传媒、商业地产公司的终局。

这其中包含了太多标的：阅文集团、开心麻花、华谊兄弟、宋城演艺、华强方特...

另一方面，**IP最大的风险，就是不再受欢****迎，这几乎是必然的**。随着时代的推移，代际的成长，观众口味会变。

很难想象，如果没有皮克斯、漫威、卢卡斯这三笔收购，现在的迪士尼会怎样。就像很难想象，如果没有微信，现在的腾讯会怎样。

从米老鼠唐老鸭到日本动漫、从喜洋洋灰太狼到二次元。这个过程潜移默化，残忍又无奈。

就像曾经的贺岁片教父冯小刚，费尽心力拍着《我不是潘金莲》、《芳华》，我们却用脚投票选择了《羞羞的铁拳》。
