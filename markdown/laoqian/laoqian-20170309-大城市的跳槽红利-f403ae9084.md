# 大城市的跳槽红利

![图片](http://mmbiz.qpic.cn/mmbiz_gif/ibw8b04QVx2M7PTAr8JHoc98wCJlkDyXxsA0LtNpBgqhicVxmxOENpDia40416PMnQfU6BgCLN0bVtwGJS9LMhIJQ/0?wx_fmt=gif#imgIndex=0)

在上海跟大伙儿问好～上海给人感觉比北京软，晚上想吃点儿宵夜，选择太多。不像北京，只有711。好喜欢这里的小洋楼，看见就走不动步了。

最近身边很多朋友都换了工作，大家在北京越来越好。似乎除了买房，北京还是能时刻让人看到希望的。

跳槽季一般发生在春节后，公司发完年终奖，算是对自己过去一年卖命的交代。然后，很多人就开始考虑换个地方，把自己卖个好价钱了。

说说最近我身边这几个换工作的朋友。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02qCgMvYKH34MxWobzPkRicErYCnJAM2HX32tJ2v7qzrH2kuNv18iaGNcQ/0?wx_fmt=png#imgIndex=1)

朋友A，毕业前在某细分领域排名靠前的公司实习。毕业后顺利转正，一直干到现在，快两年了。

当初部门里的老同事基本都走光了，A反倒成了部门里资历最老的，但公司把工资压得很低。于是有一直在追赶的竞品公司，直接开出了三倍工资来挖A。他还在纠结中…

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02b6ic60tUu5mmkiaW840DDlQZbpDx6FrKZw80myPXshlIiamrskPzvYEwg/0?wx_fmt=png#imgIndex=2)

朋友B，在媒体里跑金融口，干了一年半左右，见证了互联网金融的爆发。遂去了一家互联网金融公司做公关品牌方面的工作，干了两年多。最近鼓足勇气下海创业，很多客户都是之前在行业里积累的朋友，连销售都不用做；

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02SKtRicicWjqyGd1G1CXibXVdldbmBCbPIwYRwr3etQhdBp2A37X2Nl4OQ/0?wx_fmt=png#imgIndex=3)

朋友C，我大学铁磁，学霸型选手。河北人安土重迁，他又是家中独子，父母很想把他留住。

毕业时我曾劝他，别去读研了，你回县城里当个老师多好，还能照顾家里。我先去北京工作，等你稳定了，咱俩在你们县办个补课班儿。再在学校门口盘个门市多好。

C是学霸，坚持读研。今年来北京找工作，于是成了第七个被我拉进互联网金融行业的同学...

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk025pDtF6Iibat2Nbl4lRtsCwDCmVxgzMbHS0my1mRT5NG6wy0y3OyHvsA/0?wx_fmt=png#imgIndex=4)

朋友D，女生，之前从事农业领域的工作。但内心却想做时尚行业，她说她很早之前就给一本时尚女性杂志投简历，石沉大海。毕竟农业和时尚之间，差得可不止一个T台的距离。

但，北京最大的魅力就在于，它充满了可能性。兜兜转转了几年之后，D前几天去一本时尚杂志面试了总监级别的岗位。据说可能性很大...

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02KZyicRyn2wibGjNJFtAxZ5nSeSSKNpTDJL3j4pFocmc6yicxzEsnTmBqw/0?wx_fmt=png#imgIndex=5)

朋友E，毕业之后在x投和x氪当投资经理做FA业务。对，就是那种特别烦人的，在中关村的星巴克里张嘴闭嘴几千万“神棍”。

“神棍”是E对投资经理的评价。她觉得投资经理太虚了，没几句真话，投行圈也太虚了。其实基金都没几个钱，却跟创业者聊得天花乱坠。

年后，E辞职去了上海，在一家做电动按摩椅的上市公司独当一面。她觉得传统行业让人踏实，而且公司里有很多年龄比较大的人。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02MEAq1HYe2hdawUsgkPw6icFhrqCpajoEPwxhjQicbsgcKEjIxmohluCA/0?wx_fmt=png#imgIndex=6)

我曾看过一份90后职场报告，里面说90后工作的有个特点，不爽就辞职。我也有这毛病，虽然没辞，但一度很爱抱怨。

那时我还在一家互联网金融公司上班，带我入行的前辈离职创业。走前我们一起聊天，我问：你有什么建议给我么？前辈说，职场里都有那么一阵子，要能耐得住寂寞。

这话我一直谨记，每次对当下不满时，脑子里总能冒出这句话。

后台偶尔会收到一些还未毕业的朋友的留言，说自己正在纠结是否考研，问该怎么选择。

我一直坚定地反对考研，理科生还情有可原，文科生十分不建议考研。不然容易处境尴尬，比如前文说的朋友C。凭他的能力，如果毕业就工作，现在肯定过得蛮好，说不定我们的补课班都办起来了。

大家已经跳槽，还是在跳槽的路上？最幸福的或许就是找到了自己的奋斗方向，最不幸的大概就是这个方向还很模糊。你的方向找到了吗？欢迎在留言中回复。

今天，我们是一档深夜广播节目。难得来上海，在外滩闲逛一会儿，回酒店再回留言~
