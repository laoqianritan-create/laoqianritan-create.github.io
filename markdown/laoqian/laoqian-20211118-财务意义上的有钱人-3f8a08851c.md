# 财务意义上的有钱人

知识星球里回答了一个小问题，感觉还挺有用的。

提问：

创业初期，工作室和公司，注册哪个更能享受税收优惠政策，合理避税呢？

回答：

首先避税的事就不要谈了。

共同富裕，二次三次分配都要积极，纳税光荣。

简单科普下税务筹划。 

我国市场主体分三种：个人独资、个人合伙、有限责任。 

纳税主体分两种：小规模纳税人、一般纳税人。 

注册工作室就是个人独资企业，也可以理解为个体户——我非常喜欢这个词！

注册公司一般指的就是有限责任企业。 

现实来说，如果你有成为市场主体打算，一般都是出于三种需求： 

①方便签合同

②方便对公走账

③方便做事情（经营范围）

如果是像个体户那样，个人自己搞搞，我推荐注册个人独资企业，好处是不用交企业所得税。 

你收款100万，交3%的增值税+3%~6%的个人经营所得税，就完成纳税义务了，剩下九十多万块可以自己支配。

税务局之所以直接按照收入直接收个人所得税，而不去核算你的利润，再按照利润收企业所得税，很大原因是因为个体户一般公私不分，个人和公司的钱混在一起，支出也混在一起。

再加上个体户本身规模就小，也没条件把成本核算清晰，所以直接按收入乘以一个比率收个人所得税，财务支配也更自由。

如果是几个股东一起搞搞，那就注册公司。

这样可以把大家的股份比例确定下来，但是要交企业所得税，要记账申报税务啥的，可选的经营范围也更大。 

你根据自己情况看着来就行。

积累财富是有顺序的，往往是：

**有收入→收入>支出→有结余→用结余购买资产→形成财富。**

如果更激进一些，还可以加杠杆负债购买更多资产。代价则是负债会要求你按月来偿还本息，形成新的刚性支出。

总结，变有钱的财务过程是：

《现金流量表》有结余进入《利润表》，再购买资产进入《资产负债表》。

**··· ···**

当我们说一个人存不下钱，其实是在说《利润表》没有结余流入。问题的症结在上一环节，《现金流量表》出问题了——

要么收入不够多，要么支出太多。

要想解决这个问题，开源相对慢一些，节流则能立竿见影。

进一步倒推，必要的刚性支出省无可省，唯一可以着手改变的只有自己的消费观和生活方式。

那么具体如何改善呢？

需要通过一段时间的记账才能发现消费问题所在：看看刚性支出以外的钱都花哪了？

好在，现在大家花钱基本都通过微信和支付宝来实现——这俩货一直暗戳戳地记录着我们的每一笔消费。

你需要做的，就是找到账单入口，接着分析出哪里的消费不合理。
