# 优秀指数基金的自我修养

![图片](https://mmbiz.qpic.cn/mmbiz_gif/ibw8b04QVx2M7PTAr8JHoc98wCJlkDyXxsA0LtNpBgqhicVxmxOENpDia40416PMnQfU6BgCLN0bVtwGJS9LMhIJQ/640#imgIndex=0)

如何评价一支指数基金的好坏？

除了最常见的，对指数跟踪精准度，还有其它的评判指标么？

我又找了两个，和大伙儿分享下：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2OrYk01tQRV43lotIicQheu5H3kEeicrIfKPqqicroPCYxtPKcrHIGay2GdL3TpAp9ol7bF7dpTyic2ZA/640?wx_fmt=png#imgIndex=1)

第一个指标是指数基金的「收益构成」，它由企业盈利和估值两部分组成：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MPRg3ARt235xlZwjzibaEPlyjtllcp96xo25QicTunm57M4zkkaOhBbhvkFeYuqGiaPW4pOlOoibo8Hg/640?wx_fmt=png#imgIndex=2)

上证50和沪深300代表大公司，中证500和中证1000代表中小公司。

从上面这张表中可以看到：

过去十几年里，中证500、中证1000的年化收益＞上证50、沪深300的年化收益。

也就是说投资「中小公司」指数比投大公司指数赚的多。

投资上证50、沪深300这样的大公司指数之所以不赚钱，不是因为这些大公司盈利能力差，相反这些大公司盈利能力好得很，主要是被估值拉低了年化收益。

相反，投资中小公司指数的收益，大部分来自估值，而非企业盈利贡献。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2OrYk01tQRV43lotIicQheu5ibeRsMa6Xzt4FWQFvhkgwpwFZhN5P7sBEdakdggBKINJlANiakAP5utw/640?wx_fmt=png#imgIndex=3)

第二个指标是夏普比率—承担单位风险获得的「超额回报」。

也可以简单理解成这个指数比当下无风险收益率多赚了多少？

做了一张图：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MPRg3ARt235xlZwjzibaEPlVbUTeIhUGCic36DH1LVdD1UZQlF7MrCSQ18LRcWUSL13OnfzPL9WI8Q/640?wx_fmt=png#imgIndex=4)

横轴：期间平均收益率

纵轴：夏普比率

横轴—收益率，越往右收益越高；

纵轴—夏普比率当然也是越往上越好。夏普值越高，说明基金承担单位风险所获得的风险回报也就越高。

综合来看，这张表右上角的那部分指数在过去十几年里的收益是最好的。

但中证1000指数仅成立3年，时间过短，参考意义不大。

放这张图的主要目的是给在定投中证500指数的小伙伴打打气，不可否认这是个很优秀的指数：

* 过去十几年的回报率名列前茅；
* 风险回报比也可不错；
* 目前非常便宜，百分位低于1%；

结论很简单—要坚持下去鸭！

基金定投，亏损时卖出，浪费时间浪费金钱。
