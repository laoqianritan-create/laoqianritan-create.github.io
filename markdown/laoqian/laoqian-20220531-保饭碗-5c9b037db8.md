# 保饭碗

招商证券做了个有趣的统计，它发现今年《新闻联播》中农业新闻与去年同期相比有显著的增长，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVZCucEDPYqq9PlFUCvrDtyEHTiazDuGPOiaH0ib9ZsibFYL4xuGCIquOib2Nk7Frzib6CKvp1N8CqB3EILg/640?wx_fmt=png#imgIndex=0)

这反映出国家对农业生产的高度关注。

为啥这个夏天要关注粮食和蔬菜？

因为粮食在大涨价，而且其涨幅已经领先于金属、能源、工业原料等大宗商品，势必也会向CPI传导。

不太一样的是，2020年二师兄凭一己之力拉高了CPI，而今年又因猪价低迷掩盖了粮价上涨对CPI的影响。

由于我国主粮自给自足率很高，饭碗端在自己手里，可能大家对价格的体感并不明显**（上海人回避下）**。

其实单论涨幅，本次粮食危机已经能在战后排第二了，再这么继续下去，搞不好能排第一。

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVZCucEDPYqq9PlFUCvrDtyEgibznkwdv4f0OEINwTukt4MO49umXkyrdOzfj1upvY1GEwPMSicCzVBA/640?wx_fmt=png#imgIndex=1)

历史上最高的一次发生在1972~1974年，粮价被几个因素合力推高：

**①**规律性的厄尔尼诺现象让美苏等主要产量国减产。

**②**第四次中东战争，OPEC石油禁运让油价涨了4倍多，大宗商品的运费和化肥等农资价格飙涨。

**③**恰逢布雷顿森林体系崩溃后美元持续贬值，西方国家大通胀+经济停滞，大宗商品价格暴涨。

本轮粮价暴涨也是几个因素的合力：

**①**2020年西亚和东非蝗灾，2021年罕见双拉尼娜，2022年汤加火山爆发，印度遭遇百年来最高气温，疫情这些天灾都导致小麦减产。

**②**美联储带着全球央行大放水，推高了全球大宗商品通胀。

**③**俄乌冲突导致乌克兰小麦生产腰斩，俄罗斯是全球最大化肥出口国，重要石油出口国。

总结一下粮食危机背后的原因：

粮食供需一旦出现缺口，粮价就会有所反应。

缺口往往来自供给端，在减产原因中，气候因素对粮价的影响相对有限，政治因素**（争端、战争、保护主义、油价）**是每次极端波动的主要推手。

那么粮价上涨有啥影响呢？

对我国还好，因为我们的口粮都能保证自给自足，对外依存度很低，且粮食储备充足。

依赖进口的农产品主要是以下几类：

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVZCucEDPYqq9PlFUCvrDtyE3I9qYzFMgJuWD2IwEyT9qsM3Jj0GUHjtUwzvDuapoFEPg4FslsYzkA/640?wx_fmt=png#imgIndex=3)

但小国就遭殃了。

其实历次粮食危机中，世界总体上也有足够的食物，危机只集中在某些国家，而不是按比例地各国一起紧缺涨价。

粮仓库存充足的国家可以动用现有储备，以此避免支付高涨的粮价，但余粮少的国家民众就难免要受到价格上涨之苦。 

所以，真正遭殃的是一些欠发达国家和低收入家庭。

第一产业是用来保命的，却很难赚钱。

有些第三世界农业国的土地里种满了经济作物——烟草、咖啡、橡胶... 它们的经济回报远比便宜的粮食高，能出口创汇。

但代价也是巨大的——口粮严重依赖进口，饭碗不在自己手里。 

一旦粮食供给出现缺口，国际粮价飞涨，对那些经济严重依赖出口，吃饭严重依赖进口的非洲和拉美国家来说，就是**极端短缺和灾难**。

而且很多小国的麻烦还不止粮食危机，我们来梳理下：

**· 疫情→全球供应链问题→供给短缺→生产资料的通胀**

**· 疫情→本国发债扩表放水→债务高企→应对危机能力下降→美国加息，本国外债的压力加大**

**· 能源通胀、粮食短缺→生产资料的通胀**

感兴趣的读者，可以去搜搜与斯里兰卡有关的新闻。
