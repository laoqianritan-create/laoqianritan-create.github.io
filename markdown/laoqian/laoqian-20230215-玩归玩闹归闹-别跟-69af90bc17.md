# 玩归玩闹归闹，别跟央妈开玩笑

继续跟踪美国通胀和加息进程：

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVaIUCuqps5nkibIwTJVN3IuqutLFr14UxMNxdJkIQXPJibDm1icaicfUXQjaJq0xsuiae1RF9XU8jMqxWA/640?wx_fmt=png#imgIndex=0)

其实现在看总量已经没啥额外认知了，我们重点关注「结构」和「边际变化」。

**结构是啥？**

商品已经不通胀了，支撑通胀的是房租。

美国自有住房率才60%多，所以租房市场占比相当重要，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVaIUCuqps5nkibIwTJVN3IuqUfpYO4sXibFuhSA4LO7uolVg7iaUdBLcPuAD0tvt5vEuIicNx8ct2ryFw/640?wx_fmt=png#imgIndex=1)

支撑房租的是90%中低收入群体的工资增速和就业率。 

因此，鲍威尔在演讲中一再强调对「工资通胀螺旋」严防死守。

**边际变化是啥？**

房租价格依然坚挺，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVaIUCuqps5nkibIwTJVN3Iuqic1hRQ8ibIIbHYAsHcjpt45hwyD64BAm4Hrp9D7hqRWd712N5KPibUI5Q/640?wx_fmt=png#imgIndex=2)

通胀越坚挺，美联储加息的终点也就越高，维持高利率区间的时间也就越长。

但是呢，大家平时看到的观点又会很分裂。

原因在于，美联储和市场的立场完全不一样！

**美联储看待通胀问题像女人高潮**，一波过去还要持续很久，所以加息要highe，防止通胀longer；

**股票市场看待通胀问题就像男人高潮**，一波过去，立马消退，宝贝你快睡吧！
