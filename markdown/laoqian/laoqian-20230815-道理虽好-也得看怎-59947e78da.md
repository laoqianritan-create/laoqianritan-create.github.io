# 道理虽好，也得看怎么表达

最近很爱刷有知有行APP里的一个系列，叫**一图流**——简单的小漫画，捅破窗户纸，直入人心。

我最开始是在小蓝鸟上看到这类内容的，很有个人特色。

接着我意识到中文互联网在这个小品类上还是空白的，很想自己搞，可我不会画画...

而且要把文字层面的道理恰到好处地转化成画面，又兼具信达雅，非常不容易。

这个系列仍在有知有行APP里更新，而且几乎日更！

设计师小姐姐好卷！好厉害！瑞斯拜！
