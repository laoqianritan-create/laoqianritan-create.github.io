# 差钱儿，差事儿

消费偏弱（咱这胆子也只能用这种话术了），京沪社零增速双双成了负的。  
  
原因嘛，不说大家也能猜个七七八八。  
  
其一，之前很多人讨论房价和消费的相关性——到底是房价挤压消费，还是房价支撑消费信心？  
  
现在结论也比较明确了：房价下跌损害资产负债表，居民对此的反应是，通过增加储蓄来自行修复资产负债表，从而导致消费不足。  
  
居民的储蓄倾向和二手房的房价走势是高度负相关的。  
  
其二，很多产业、行业的调整优化（这词儿用的应该抽自己嘴巴），收入的增速和久期进一步影响消费预期。  
  
✅图2~8. 是以上现象在数据层面的一些投影。  
  
总结：储蓄不差钱儿，消费很差钱儿，主要还是差事儿。  
  
有人说，你个穷逼去SKP看看，就知道消费有多火了。  
  
不好意思，高端消费旺盛本身是财富不平等的一种映射，它与一般消费背离，甚至于收入增速背离，但是与贫富分化程度正相关。
