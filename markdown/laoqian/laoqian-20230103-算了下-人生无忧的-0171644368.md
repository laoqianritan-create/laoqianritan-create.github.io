# 算了下，人生无忧的标价大概是700万

哈哈，刚看到一个保险公司的朋友吐槽，说他算了笔账——

过去七年，养娃总共花掉了60多万人民币。

一度怀疑算错了，仔细盘了一遍：

* 兴趣班3年20万
* 育儿嫂3年18万
* 奶粉2年5万
* 生活费每年2万

算完又觉得好像也没多奢侈...

这朋友人在深圳，5千块的月嫂已经非常便宜了。

P.S. 我现在觉得在月子中心一个月砸大几万真心不值，性价比不如多请几个月的育儿嫂。

然后他又算了笔账，如果不生孩子呢？

7年省下60万，相当于每月多7千块现金流。

这钱要是拿去买保险呢？

又算了笔账，如果买年金险，每月交7千，连续交20年。

20年后每月可以领1.4W+，只要活着就领钱。要是人提前没了，保险公司也保证给20年的钱。

好像养老也绰绰有余了。

emmm...

我一直对自己的评价就是「把养娃的钱都拿去供房了」。

所以我也照着他的水平算了笔账：

每月7000块的月供，相当于30年等额本息背140万的房贷，买了套210万的房子。

最后，我们再算一个“**豪华版”的人生套餐**：

7000块生活费，温饱无忧

7000块年金险，养老无忧

7000块月供，住房改善**（一线城市别杠）**

7000块养娃，传宗接代

7000块杂费，养车孝敬爹妈旅游医美看病...

综上！

中产无忧的价格是**700万**！

家庭月收入3.5W\*连续撑20年——

届时孩子上大学可以自己打工了，保费缴费期结束了，房贷所剩不多了，人生担子也卸掉了。

当然以上算法漏洞百出，比如首付的钱没算进去，每个月一点结余也没有... 大家权当简单感受下。
