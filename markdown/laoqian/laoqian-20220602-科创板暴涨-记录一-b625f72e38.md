# 科创板暴涨，记录一下

我们上一次记录科创板是在4月15日，👉[《科创板的首次大屠杀》](http://mp.weixin.qq.com/s?__biz=Mzg2MDc2MjM3NA==&mid=2247493988&idx=1&sn=b6aaec8a8a44b7c3f4d2aab415411981&chksm=ce23d10df954581b285220ff5cc1d7d7c15ff34ca4f5a3a7bebb8b3ee4190e32088d900f7f0f&scene=21#wechat_redirect)。

正好昨天浙商证券也出了一篇有关科创板的研报，跟大家分享下其中的重点：

**①**科创板进入筑底期，底部区域看长做长——非常同意！

**②**科创板叠加了其产业分布的鲜明时代感，映射了当前的先进制造业崛起，覆盖了半导体、新能源、云计算、国防和医药等代表性板块。
