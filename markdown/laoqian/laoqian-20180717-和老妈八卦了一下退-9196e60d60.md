# 和老妈八卦了一下退休

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2OrYk01tQRV43lotIicQheu5H3kEeicrIfKPqqicroPCYxtPKcrHIGay2GdL3TpAp9ol7bF7dpTyic2ZA/640?wx_fmt=png#imgIndex=1)

我下班通勤基本靠走，溜达期间会和老妈煲电话粥，家长里短地唠嗑。

昨天说到了退休金，我觉得还挺有意思的，和大伙儿分享下：

在东北，人们管公司叫「单位」，隐含意思是，单位是公家的，更稳定更有保障。

有个特别有趣的现象就是，企事业单位职工是抢着退休的，能早退尽量早退，没条件创造条件也要退。

企业职工想的是退休了继续工作，能拿双份工资；

事业单位国企职工早退的动力就更足了，很可能退休后的工资比上班还要高，而且每年都会有一定比例的涨幅；

现实情况就是这样，很多民企工资都不一定发的出来，国企上班不如退休赚得多，谁不想早点退呢？

在我老家辽宁乃至东三省，老龄化问题非常严重，老龄人口占比超过20%，三个省的养老金缺口超过300亿。

雪上加霜的是大量年轻人都在逃离，官方口径是，过去5年东三升净流出24万人。

这也是为什么我旗帜鲜明地看空东三省刚需以外的房地产投资—省会城市房价确实洼地，但也确实没增速啊...

房产是城市的股票，可这家城市公司，营收不行，员工没动力盼退休。这种股票谁敢买？

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2OrYk01tQRV43lotIicQheu5ibeRsMa6Xzt4FWQFvhkgwpwFZhN5P7sBEdakdggBKINJlANiakAP5utw/640?wx_fmt=png#imgIndex=2)

退休工资的计算公式我不了解，据说非常复杂，和个人养老金账户金额、工龄和缴费年限、当年的社会平均工资等因素挂钩；

但最终结果就是，不同企业类型、不同行业、不同公司的职工，退休工资相差巨大。

比较颠覆我认知的是一家国企（具体哪家就不写了），在职工资2千多，退休工资8千多，典型的后期收割，老来享福。

享受退休工资的关键，用我妈总结的话说：一定得多活两年儿，多拿几年钱...

东北在很多方面已经开始显现「经济低增长」地区的种种特点：

老年人享受到了更多的社会资源和福利，收入高于年轻人，话语权也更高。

不是说这种环境不好，但对年轻人而言，肯定会因为看不到希望而选择逃离。

年轻人需要[高增速的环境](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649609618&idx=1&sn=1c2266ba11c030cd6f556d387f26e843&chksm=881c114ebf6b9858e891a546cc01f3c97be4eac034fab3be5c67b00c1b214f40b81a1241210c&scene=21#wechat_redirect)，因为这意味着上升通道更宽一些。
