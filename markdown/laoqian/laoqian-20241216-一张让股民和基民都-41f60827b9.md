# 一张让股民和基民都破防的图

最近我在各种群里都看过大家对下图的讨论，它统计了 2009 年到今年 930 期间，各大类资产的**「年化回报率」**和**「波动率」**。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/M7fHtGOlzVaHkk1l1TibBuI5MZ92m0F2iaaThSoRvTGLuf708BZZBEj9Rsac5icp15ibNRMibQUGIltaSLiaBkSDdAPA/640?wx_fmt=png&from=appmsg#imgIndex=0)

大家热议，主要是还是破防。

因为这张图赤裸裸地展示了这样一个A股真相：

**在熊市期间，**A** 股的长期回报和债券差不多，但承担了几乎最高的波动。**

有人甚至因此总结出一个神奇指标——

**每当沪深 300 与 偏债指数的长期回报相遇时，总是A股的触底时刻。**

韭圈儿更是直接把它做成了某种温度计：

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/M7fHtGOlzVaHkk1l1TibBuI5MZ92m0F2ia8zLpCMYKU0eDurRaqax863okgjmQ56ZJlMSQxmxl5s3ejbY8AlPFicA/640?wx_fmt=png&from=appmsg#imgIndex=1)

低波动且长期向上的市场里，长期持有才是正解。

高波动的市场，做波段比长期持有更具备适应性。

很多人一看到做波段、做交易就想喷，但我觉得这些人搞错了一点：

该不该做，能不能做好，其实是两件事。

波段确实不好做，所以在A股能赚到钱的人确实也不多啊。

如果你实在不喜欢「波动」这种话术，那我换个说法：

**在 A 股投资，入场和离场时机决定了大部分收益，而「持有时间」并不是一个重要因素。**

还有一个很普遍的误会：

大家倾向于认为买债基会降低收益而且持有过程太无聊。

但上图也告诉我们了：

如果在组合里加入相当比例的债券（比如 40%），同时把一部分A股替换成美股。

你会发现，最终并没有降低多少收益，但是有效控制住了波动。

仔细看看下图中最右侧的两列，你会有很多感想：

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/M7fHtGOlzVaHkk1l1TibBuI5MZ92m0F2iapQBIPvqPCVNFqewCiccgMr8NuZrdLPnGzmrAaICHTCGSGhXs1bRpia7g/640?wx_fmt=png&from=appmsg#imgIndex=2)

下图解释了投资者在A股难受的另一个重要原因。

注意图中的灰色柱子，它代表估值变动，也是市场情绪的直接体现。

**在大多数年份，估值变动都是影响当年回报率最重要的因素。**

而且估值经常与基本面业绩相悖！

这也是基本面派在a股总是痛苦的原因，不能说失效，但解释力度确实经常性的不高。 

反而是时常被大家挂在嘴边的「投资是件逆人性的事」在A股真的特别重要。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/M7fHtGOlzVaHkk1l1TibBuI5MZ92m0F2iaqYVvwAwhnJp06bL7RD75CufrPwRiaDyj2DJwxVZaSNVUKWxasdBLBfg/640?wx_fmt=png&from=appmsg#imgIndex=3)

下图是对一些典型风格的长期回报和近期估值的统计：

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/M7fHtGOlzVaHkk1l1TibBuI5MZ92m0F2ia4D1JiboYkoPNU2VA1U31BbBv0qlfJUJgMOTOHqAuzXym0vm18GH95BQ/640?wx_fmt=png&from=appmsg#imgIndex=4)

最后我想说：人都是环境动物，浸泡在这样的市场环境里，所训练出的审美体系，确实比较畸形。

前段时间我和一位朋友录播客，她坦言觉得投资挺简单，买了拿着就能赚钱。

听完我心想：这么唠还咋录啊！

后面聊天才明白原因：

她上学时被老师安利种草，初接触投资的起手式就是买了标普 500。

这么多年下来，才有此感慨。

这边没有赚钱的配得感，那边乐观得云淡风轻。

只能说，都是惯出来的...
