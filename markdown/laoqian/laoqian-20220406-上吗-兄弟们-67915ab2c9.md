# 上吗？兄弟们

就说一个事，很多人都在盯着明天开放申购的**华夏中国交建高速REIT（508018）**。‍

简单提醒几个要点吧：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2O3iaVEwCCQhQ4qQaYhic9PNBhgH6ky9HZdm1DCrTa3rdZS82VibKgJqicvicY1NtpibobwEnz59cbDJMsg/640?wx_fmt=png#imgIndex=0)

如上图，REITs可能是2021年涨幅最好的品种之一，相比股票和债券，非常出彩。

这种诱人的回报率也让它吸引了巨大的关注度和打新流量。

但夸张的、脱离基本面的涨幅并不是什么好事。

从上图中就能看出来：

「上市至今涨幅」和「区间最大涨幅」之间有着不小的差距——

这说明每支reits都经历了相当程度的回撤。

**··· ···**

其中，「鹏华前海」是A股市场里的第一支REIT。

**理论上，注意是理论上，这支老祖宗肯定更具有参考意义。**

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2O3iaVEwCCQhQ4qQaYhic9PNBPMK2HFQCMN3yp2wujyericvllRGEoicvJn2r1FXicXG6n7njXekqTwnWw/640?wx_fmt=png#imgIndex=1)

上市至今共80个月，有61个月取得了正收益，分红再投入的年化收益**6.06%**——

毫无疑问，这是个**持有体验良好**，**收益合理的收租型资产**。

但后来的REITs由于首批打样过于优秀，赚钱效应使得这类小众资产享受了巨大的关注度和流动性溢价，其走势已经和收租资产没啥关系了。

但是，如前面所说，**如果你是个理性人的话，在预期上还是应该以鹏华前海为锚。**

**··· ···**

最后下具体的申购细节：

华夏中国交建高速REIT（508018）拟募集10亿份，其中7.5亿份已被战略配售拿走，我们散户就抢剩下的2.5亿份。

前两批REITs的配售比最高8.79%，最低1.47%。

就现在的关注度而言，我估计明天的中国交建高速REIT的配售比不会高于2%。

意味着，申购1万元，抢到200元...权当凑个热闹吧。

**以及，已上市的REITs，除了老祖宗我一个也不会碰，目前的价格肯定大幅脱离基本面的。**

以上。
