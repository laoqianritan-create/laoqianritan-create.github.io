# 选股买基，我的四个长线投资逻辑

![图片](http://mmbiz.qpic.cn/mmbiz_gif/ibw8b04QVx2M7PTAr8JHoc98wCJlkDyXxsA0LtNpBgqhicVxmxOENpDia40416PMnQfU6BgCLN0bVtwGJS9LMhIJQ/0?wx_fmt=gif#imgIndex=0)

聊聊我自己投资理财的四个大逻辑，属于基本面范畴，不会涉及具体的操作建议，但对挑选基金和股票还是有一些指导意义的。

在这四个逻辑下，去重点关注一些领域和标的，长线投资，收获时间的玫瑰。四个长线逻辑分别是：

* ***细分行业，掌握议价权的龙头***
* ***城镇化趋势下的房地产和消费升级***
* ***人口老龄化***
* ***智能化趋势***

来逐个讨论下，我就抛个砖，不一定对，欢迎大伙儿在评论区批评、讨论。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02qCgMvYKH34MxWobzPkRicErYCnJAM2HX32tJ2v7qzrH2kuNv18iaGNcQ/0?wx_fmt=png#imgIndex=1)

长线持有的第一个大逻辑，是重点关注细分行业的龙头，如果龙头还能掌握议价权就更好了。我们曾经讨论过的👉[殡葬行业的龙头股](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649608902&idx=1&sn=84b26a218aa1377f550cab73851afa00&chksm=881c161abf6b9f0cb51772a61a44b74ea57392a1b1e67f48d9e5e91345ee4f0e68f21abacd86&scene=21#wechat_redirect)就是典型的例子。

最好的商业模式就是垄断，既是裁判员又是运动员。除了垄断，还有同样效果的就是牌照管控。有多少牌照就有多少参赛选手，其它的，都得被政策和监管打死。

*牌照变得越来越值钱。以老钱所在的金融行业为例，两三年前一张基金代销牌照2千万左右，如今已经被炒到6、7千万。上海车牌也是，2001年到现在，价格涨了800多倍。*

另一大趋势就是并购，龙头会吃掉越来越多小企业。比如殡葬行业的福寿园、养猪行业的温氏股份、还有血液制品行业*（这个还没研究过）*等等。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02b6ic60tUu5mmkiaW840DDlQZbpDx6FrKZw80myPXshlIiamrskPzvYEwg/0?wx_fmt=png#imgIndex=2)

城镇化催生出了两个大逻辑—房地产和大消费。

过去十年是房地产的黄金十年，在这个逻辑下，一批地产大牛股诞生了。但现在是城镇化的中后期，一个很明显的感受是，接力棒正由地产给到大消费。

所以，消费升级绝对是一个时代级的机会，我们所处的市场，体量数倍于美国。屌丝以上，富人以下，渐富人群的消费观正在发生变化，人们更愿意为品质而非品牌买单；更愿意为优质的产品和服务付出溢价，不像从前那样，更倾向于廉价。

而这又催生出了另一逻辑，就是国货代替进口。“进口货”三个字再也不像从前那么有吸引力了。

这一现象的背后，是产业升级—人力、土地都不再是优势后，越来越多的企业走向中国质造和中国创造方向。这也是投资中应该重点关注的领域，比如医疗器械、新能源汽车等等。

腾讯科技出过一份报告叫《“分水岭”大时代》，里面说创业还有三个相对蓝海的市场，分别是：儿童、老人、农村，需要完全没有被满足。

老龄化将给一批行业和企业带来大发展，比如：养老地产、医疗保健、殡葬等等。

![图片](http://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PvblicW8Aog7Ub8lKyODhLns95Pn0LYat9kKQsGuxngUczRu9dI8AdEl9P1RQuicGibJsmzJiaRMf34A/0?wx_fmt=png#imgIndex=4)

如上图，按照13亿人口算，中国目前有将近1.9亿老年人，如此巨大的市场，且很多需求都没有被满足，机会巨大。

可以重点关注医疗保健、哪些公司生产治疗老年人常见病的药品、体外诊断医疗器械等等。

这个逻辑水比较深，因为太概念化了，而概念很容易被炒。如果不能挖掘出深度需求，长线持有的风险较大。

所以最好关注被验证过的公司，比如苹果，可以当成消费品公司来投；比如腾讯、阿里巴巴，可以当成基建公司来投；

也可以通过一揽子打包的方式，比如购买中概互联指数513050。
