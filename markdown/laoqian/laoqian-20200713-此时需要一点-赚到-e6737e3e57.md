# 此时需要一点「赚到」心态

●

讲道理，我认为现在只有两种心态可以在股市里愉快地玩耍。

一种是在车上的，还有座，死死握住把手，老子买票上来的，谁也别想轻易踹我下车。管它前方路况咋样，屁股下面是盈利，软和着呢！不怕颠。

第二种，面对将近2900点的创业板**（背后是医药+科技）**，又爱又恨，爱它的赚钱效应，恨它高处不胜寒。

**眼下的市场氛围，一句话就能解释明白：超额收益来自「风险暴露」。**

明知它危险，可也知道买它更赚钱。

这种情况怎么上车呢？

如标题所说，需要一点「赚到」的心态——

既然决定硬着头皮上高山，那就得更注意风控，有点盈利就落袋为安。

不奢望赚更多，只求用一些仓位博点收益，赚到就好，随时准备止盈。

我比较认可这种方式是因为我从今年开始一直抱着如此心态在炒港股。

港股各方面的约束条件很多：

比如出入金很麻烦，不可能补仓，我也不想把钱弄出去。所以只能有多少玩多少。

也不能做左侧死扛着一支股票，我等不起。指不定哪天就来新股了，需要立刻卖出去参与打新。

各种限制决定了我炒港股只有一个原则：赚到就行。只做绝对收益，该卖就卖。

比如上周全力打的几支热门—新股思摩尔、欧康维视、永泰生物、正荣服务都上市卖出了。

本周没有新股，资金闲置，又可以拿去炒股。

每一次买入都是新的开始，必须克服之前的价格锚定，而且随时准备卖出好参与打新。

想去追创业板的读者，不妨把这种确保赚到的心态复制到A股。

①适度的仓位风控**（大跌还可以补）**，配合②及时止盈的计划，再加上③打满下半场的预期，应该可以缓解你们的焦虑心情。

**如果不知道买什么，就还是撸指数，轻松省事，还能跑赢大部分股票和股基。**

**创业板50指数要比创业板更猛。**原因很简单，前者的行业、成分股市值、抱团情绪这几个当下牛逼哄哄的因子更集中。

如果你和我一样，还相信风格切换，单押高估值晚上睡不着觉，认为左手价值加右手成长更稳妥，那我再推荐个有代表性的标的：

这是支主动型基金，规模足够大，成立时间长，成分股也很棒——银行、保险、券商、地产龙头基本包圆了，还差个「基贱」就能集齐「低估五大惨」。

而且这支基金的机构持仓比例常年保持高位，最新数据是76%。机构如此愿意买它，也能说明一些事情。

●

心态问题特别普遍也最容易被忽视，尤其是市场好的时候，新人进场，看着买了几支票，第二天一开账户发现不是红的就开始闹心。

对绝大部分股民而言，**买啥只是短期问题，心态却是长期烦恼。**别看市场只有**涨****跌**两种情况，但就是每天这么来来回回才把很多人的心态玩崩。

我这个月看平安就特别闹心，甚至比60多块钱时还烦，就是嫌弃它弹性小呗！后来做了两个调整心情就好多了。

首先我摆正了预期——爱咋地咋地吧，只要能把我们家未来的保费赚出来就知足。当初在瑞幸咖啡上赚了点钱我也是这么劝自己的，能白喝半年咖啡，挺好！

然后我把平安单独放在了一个账户里，眼不见为净，换个账户炒。

早该这么干的！
