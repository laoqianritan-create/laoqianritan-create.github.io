# 泉州：拜拜神仙烟火

上个周末和女搬砖工去泉州玩了一趟，她上班上得有点麻了，换个环境，逛一逛，多少能缓缓。可以说过去两个月就指着这趟活着呢！

其实我也差不多，每年四季度都是一年中最忙的时候。自由职业者的重点是职业，自由不过是一种自我安慰的说辞。因此，忙里偷来的闲，效用往往最大，也最珍惜。如果一直闲，反倒索然无味了。

开元寺内的古桑树，一般桑树的年龄不会超过 400 年，但这棵古桑树树龄超过 1300 年，就像入定的老僧，最大限度地降低了自己的新陈代谢。

它长得叶子没有营养，蚕吃了会拉稀，也不吃它的桑叶。它也不结果，甚至几十上百年结出一颗桑葚，都成了大新闻。

1925年，一场雷雨把它劈成了三半，但断掉的枝干不仅没死，反而落地生根，长得更茂盛了。

闽南簪花，也叫“簪花围”，是泉州蟳埔一带特有的女性头饰文化，会把茉莉、素馨等鲜花串成花环，戴在盘好的发髻上，“头戴四季春”，这习俗从唐宋流传至今，现在不仅是非遗，也成了闽南文化的一张名片。

在蟳埔总能看到赵丽颖的巨幅照片，之前《上城士》给她拍了一组簪花主题的大片，广为流传，也带火了泉州和蟳埔。

此后蟳埔村的簪花店从不足10家激增至300余家，然后就变成了写真摄影基地... 不过总归是好事，当地经济上来了。

●最喜欢的一张照片，很有仙人之姿

藏在老城民居里的元妙观是我和女搬砖工最喜欢的一处神仙办事处，也是我俩在泉州唯一拜过的场所。

之前逛关帝庙时，女搬砖工就想找关二爷问个事，主要是这班还要不要上了？

结果整个泉州就属关帝庙香火最旺，人声鼎沸，连片跪倒，连个下脚的地方都没有，干脆就没问上。

元妙观，人少，清净，一走进来就觉得...有缘！我说咱俩就在这问吧！

净手，上香，双手覆膝，掌心向上。完了就开始念叨，我是谁，从哪来，农历生辰年月日。

然后先掷圣杯——两个半月形的木块，抛在地上，木块落地后需是一正一反，才能找仙家问话。结果我俩第一次掷，就都是一正一反，更觉与这里有缘。

然后就双手合十**祈愿**吧！不可贪多，所求之事越具体越好，还得在心中默念重复几遍。

女搬砖工问了工作的事。我啥也没问，求个平安顺遂，多涨涨粉啥的...

接着摇晃签筒，等待有缘之签自然掉落，然后拿着调出来的签去找道长解签。

在解签处等了好一会儿也不见道长，问工作人员：人呢？

对方不耐烦地回答：都下班了，三点再来！

三点我们可等不了啊！赶不上回去的飞机了！

最后俩逗逼悻悻离开了...

可再一咂摸，也许这就是答案啊！下班了～
