# 到底怎么分批买入？｜聊聊仓位管理

我特别爱在蚂蚁聚宝上看基金购买记录，因为可以回溯自己的行为。

贴一张我的蚂蚁聚宝上某只基金的截图：

![图片](http://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PbCdJiaeOhy01bSoicT6icY8GJ7ZDwWUDVs2eCV7HpCCRHIClIksiaZwHETgicnsYwtibL94lA7s4NcQjg/0?wx_fmt=png#imgIndex=2)

红点是买入点，蓝点是卖出点，这就是我在市场上的操作行为。但说实话，我也没怎么操作过。

第一个红点是我做的决定，蓝色点也是我做的决定，除此之外，根本就没管过这支基金。***如果基金没有上扬，永远不能买出，蓝色点一定要比红色点的位置高。***

这也是我为什么我每次都推荐蚂蚁聚宝的原因，这一个小小的设计，可以说是保证盈利的准则。

红色点俗称买点，也叫“踩点”，蓝色点叫卖点。踩点要踩的低，卖点要卖得高。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02b6ic60tUu5mmkiaW840DDlQZbpDx6FrKZw80myPXshlIiamrskPzvYEwg/0?wx_fmt=png#imgIndex=3)

如果想用定投的方式，中短线跟一支基金或股票，比较保险的方法就是分批买入。

举个例子，如果老钱能拿出1万元跟一支近期比较看好的基金。那么，我的总仓位就是1万元，把它分成10个仓位。

做了张图：

![图片](http://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PbCdJiaeOhy01bSoicT6icY8GicZsibfesrdgxsuPDjgJR9XOMlXPC7qce3AxmG7y2KCWbM6iabjdcTS6Q/0?wx_fmt=png#imgIndex=4)

既然是中短期，我们可以分5次购买，把牌打光。

入场顺序是：1—3—5—7—10

也可以是：2—4—6—9—10

接下来比较重要了，买入标准是什么呢？没有标准答案。

假设老钱的策略是每下跌2%买入一次，那么这支基金需要下跌10%我才会满仓（这里的下跌，指的相对买入净值而言）。

如果我点子很背，跌了10%之后，接着下跌（爆仓）怎么办呢？没办法，那就继续补仓呗。

没有只涨不跌或只跌不涨的基金。如果买了之后，基金上涨，我就没有补仓的机会了。

***你可以根据自身情况，定下每个仓位的具体金额，每次投资，都以仓位为单位出牌。***基金A没有补仓的机会，可以作为备用资金，以应对其它标的的下跌补仓。

相比无脑买入，跟风买入，这个方法，给自己的投资，增加了那么一点儿纪律性。它同样适用于股票。

怎么说呢？我估计赚不到什么大钱，但是亏损的概率，应该也很小。以稳为主，稳赚不亏，我就挺知足的。能10%止盈，我也挺知足的。太贪心，普遍没啥好结果。
