# 爆款的宿命还是没躲开

达尔文3号从618上线到今天，卖了将近2个月。

对于爆款重疾险来说，这个时间不算短。

但爆款免不了被砍的宿命，该来的总会来。

昨天收到保险公司通知：

> **达尔文3号****保至70周岁的版本****将于2020年****8月25日晚上24点下架**
>
> **后期仅保留保障至终身计划**

***1***

这一刀不算狠。

只是8月25号后不能保70岁，必须保终身。

因为**我一直推荐保终身**，所以如果按照我的建议买，那这个变动其实没啥影响。

但还是有一些朋友选择保70。

可能是想把保费做到最低；

或者之前买了其他终身重疾，再买保70的达尔文3号做高保额。

总之不管怎样，**如果你有保70岁的需求，别错过下架时间**。

比这一刀更吓人的是它带来的隐忧：

之后会不会有**第二刀、第三刀**？

第二刀会不会**把不含身故版本砍了，改成身故必选**？

如果改成身故必选，性价比就会大幅削弱。

如果近期有买重疾险的打算，还是建议尽早买达尔文3号。

这款产品除了销售区域限制严格，真挑不出啥毛病。

***2***

再简要说下达尔文3号的保障要点。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/8Xvb4dBQauAL5yEw4T0WOCYUFiaI3QrT0TtwJzS6129MiaFO1nZxDL4szh0ICZNibcgbV65vet3OEbkyLx6eVnrCg/640?wx_fmt=jpeg#imgIndex=0)

**必选责任保障全**

• **60岁前额外赠送80%重疾保额**

买30万，60岁前实际重疾保额54万；

买50万，60岁前实际90万。

买一份终身重疾，送一份定期重疾。

• **中症、轻症赔得多，高发疾病二次赔**

中症，2次×60%基本保额。

中症中的「中度脑中风」可以赔两次。

轻症，3次×45%基本保额。

轻症中的「原位癌、不典型心梗、微创冠状动脉介入、微创冠状动脉搭桥」也可以赔两次。

**最高发的5种中症和轻症都有了二次赔保障。**

这个二次赔在必选责任里面，等于白送，不用额外花钱。

**可选责任性价比高**

• **身故非必选**

身故责任可以不选，性价比高。

省下的这笔钱买份定期寿险，更划算。

• **癌症二次赔性价比高**

达尔文3号可以附加癌症二次赔保障。

**150%**基本保额。

非癌——癌，间隔180天；

癌——癌，间隔3年。

附加这项责任后，男性保费增加**9.6%**，女性增加**15.5%**，同样是目前的最好水平。

• **心脑血管二次也不错，但一般不建议选**

没有心脑血管家族遗传史的不用选。

***3***

投保建议。

• **保终身**

现在还能保70，但推荐保终身。

25号后只能保终身，那也不用再纠结。

• **保额30-55万**

一次配好，买50-55万。

预算没那么充足，或者想以后再加保，买30万。

• **必选责任+恶性肿瘤扩展保险金**

恶性肿瘤扩展保险金就是癌症二次赔。

性价比很高，建议选。

• **其他责任不选**

身故责任不建议选，省下的钱去买份定期寿险（推荐[**瑞和2020**](http://mp.weixin.qq.com/s?__biz=MzU4MDcxMDIwMQ==&mid=2247486441&idx=1&sn=fc3b663629f229fc0dfd8941f634d649&chksm=fd53f1bfca2478a9ce5f9e643d4c7a64a2028c29a4db867800ec842dc2644f266452acd347db&scene=21#wechat_redirect)）。

心脑血管二次赔，如果没有相关的家族遗传史，也没必要选。
