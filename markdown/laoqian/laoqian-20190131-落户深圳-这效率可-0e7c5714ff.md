# 落户深圳，这效率可以的

去年12月17日，我在「人生要选对」星球里写帖子建议小两口可以挑个人办理下深圳户口。

后来一想，我也办个得了。

毕竟落户北京高攀不上，户口在老家也没啥用，趁着一线城市还有口子，凑个热闹。

本来我是把这事儿当成2019年的一个目标，因为知道过程肯定比较麻烦，还劝自己认真对待，正经当个事儿来处理。

结果昨天中介告诉我，人社局的审核已经通过，入户指标卡（调令）已经顺利拿到了。

哈？这就...搞定了？太快了吧![图片](https://res.wx.qq.com/mpres/htmledition/images/icon/common/emotion_panel/emoji_wx/2_05.png#imgIndex=2)！

中介帮我走的途径是在职人才引进。

「在职」就是就业关系，即公司给我缴纳社保，社保异地目前没有联网。

人才的意思是身体健康、无犯罪记录，要提供深圳指定医院的合格体检表；

统招大专学历，35周岁以下；

统招本科以上学历，45周岁以下；

我在职那么至少也要过1.2个月试用期，才可以名正言顺的引进，否则说不过去；

因此缴纳2个月社保，再引进就是最低的要求；

在职三个月，引进一个月，即可引进深圳，拿出入户指标卡；

大概就是这样。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2OrYk01tQRV43lotIicQheu5ibeRsMa6Xzt4FWQFvhkgwpwFZhN5P7sBEdakdggBKINJlANiakAP5utw/640?wx_fmt=png#imgIndex=3)

落户有两种选择：深圳集体户口和个人家庭户口

说说区别：

集体户口和个人户口享受深圳基本福利和待遇一样，享受的社保、买房、买车待遇也一样。

小孩落户问题：集体户口小孩落户可以落在家长所在的集体户口上，办理落户需要用集体户口的首页复印件加盖公章。

小孩教育问题：小孩是集体户口同深圳个人户口小孩享受一样的教育资源（需要注意：深圳各学校在根据积分入学时有房产的孩子入学更有优势）。

集体户口相比个人户口办事要麻烦一些，每次办事需要户口材料时都需要向集体户口单位借集体户首页然后打印复印件，借取、取号、排队等等非常耽误时间。

家庭户口，不需要和那个家庭有什么实质关系，只要对方同意挂靠即可。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2OrYk01tQRV43lotIicQheu5hNt40pSniaSFj7kzUvyw5yUehsHvbcLOM2WY9ddVHQrKMibL8yicrKxOg/640?wx_fmt=png#imgIndex=4)

办理深圳户口有啥好处？

我觉得，如果没有过去买房的打算，其实也没啥好处。

当然人才补贴肯定算，但我觉得过多讨论这个没啥意思。

我办深户也有点私心，主要是我们两口子一直想去南方生活两年，感受感受，否则一直留在北京，有些小遗憾。

不过这种事儿就是想想，还没提上日程过，好折腾...

李诞有次在脱口里调侃过：一边是逃离北上广，一边是来了就是深圳人。这两个口号会不会是深圳人才引进的阴谋？

之前的文章写过，城市化后半场，抢人大战中吃相越难看，越不要脸的城市，我越看好其长期潜力。

深圳是四个一线城市里抢人条件最好的，也是最尊重、保护市场的，也是人口结构最好，老龄化问题最小的。

过去十年，深圳市户籍人口增长了202万，常驻人口增长了376万。

未来的城市战争，就是抢人战和产业战。
