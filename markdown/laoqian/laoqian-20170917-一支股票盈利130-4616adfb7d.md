# 一支股票盈利130%，分享点心得 | 财报入门

![图片](http://mmbiz.qpic.cn/mmbiz_gif/ibw8b04QVx2M7PTAr8JHoc98wCJlkDyXxsA0LtNpBgqhicVxmxOENpDia40416PMnQfU6BgCLN0bVtwGJS9LMhIJQ/0.gif#imgIndex=0)

抱歉啊，昨天出差回来倒床便睡，开了天窗。不过一般这种情况，我第二天都会补上的。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02qCgMvYKH34MxWobzPkRicErYCnJAM2HX32tJ2v7qzrH2kuNv18iaGNcQ/0.png#imgIndex=1)

今年在3个股票市场都收获颇丰。

A股市场，中签了2支新股，一些白马股收益也都不错；

美股市场，宜人贷和好未来都带来了70%+的收益；

港股市场，通过对比财报，在融创中国身上实现了人生第一支翻倍股；

今天分享买入融创的过程，主要是想科普下最简单的财报入门。

首先，关于投资房企的大背景，之前专门分析过👉[关于房子，我的几个看法](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649609324&idx=1&sn=6b1b36257d9faed28f88d509817a71ad&chksm=881c10b0bf6b99a6388f49f46bfe33d86b775edc1478e1b90e95c1c25f8bbddf7bcd88062af3&scene=21#wechat_redirect)，尤其是第3、4段，可以作为本篇文章的背景介绍。

其次要寻找标的，重点关注龙头房企。原因有二：

港股市场虽然整体估值低，但其实都是被大量尾部公司拉低的。港股愿意给头部企业很高的市盈率，腾讯就是典型例子。

其次房地产企业门槛越来越高，未来一定进入优质房企整合的大时代。

最终，我在港股市场确定了4家公司：恒大、万科、碧桂园、融创。

但我首先就排除了恒大。说实话，连它的财报我都没看。首先在寻找标的时，恒大已经有了一轮暴涨，不便宜。

其次，我特别不喜欢许家印和恒大的调性，包括一些多元化的布局，都不太看好。

但为了这篇文章，依然把恒大的财报纳入了对比。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02b6ic60tUu5mmkiaW840DDlQZbpDx6FrKZw80myPXshlIiamrskPzvYEwg/0.png#imgIndex=2)

分析房企的框架，在这篇文章👉[看房，看什么？](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649609353&idx=1&sn=e5927e305a0b18cac916412a298e6b48&chksm=881c1055bf6b99432aa9d82279d4eaf4686100792c0f70f3b5abbd38fca66d53c073a6f09a25&scene=21#wechat_redirect)中也讨论过：拿地、操盘、周转—**“买、建、卖”**这是衡量一家房企最重要的三个指标。

但，其实没看财报之前，我也不知道哪些数据能反应以上三个指标。不过没关系，带着问题，先看一家公司的，自然就能筛出指标了。

好了，那我们正式开始。

首先是去哪里找财报？回复：港交所，会自动收到港交所的财报查询页面链接。长这样：

土地储备代表拿地能力，最显眼的我用红圈画出来了，是恒大；

平均售价代表操盘能力，同样的地段，卖得就是比你贵，比你快。这个维度最牛的是融创。

再看用红线标出来的“市值”一栏：融创的市值与其它3家依然很悬殊。我买入融创是，它的市值大概是万科的1/5，碧桂园的1/3。

不错的土地储备，最好的操盘能力，还有最重要的原因，便宜！这是我买融创的理由。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02SKtRicicWjqyGd1G1CXibXVdldbmBCbPIwYRwr3etQhdBp2A37X2Nl4OQ/0.png#imgIndex=6)

以上数据，都是从各家公司财报里的利润表、资产负债表、现金流量表中找的。

财报密密麻麻的，很容易看懵。我建议带着明确的问题看，拿着笔，边看边画重点。比如这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PM1sMic0n7kos3icWoU14Ekic7wR7wiaGrCeFsVWGn8f6yUo879cl4BBGonQ7XdnDXrrQApWFpsobEPQ/0.png#imgIndex=7)

这是在算“净负债”一项时做的标记：

（流+非流）资产-（流+非流）负债=净负债

其实都是一些最简单的加减乘除，能找到数就好。

再比如：

* 现金=《资产负债表》“流动资产”中的“现金及现金等价物”+“受限制现金”；

* 有息负债=《资产负债表》“非流动性负债”中的“借贷”+“流动负债”中的“借贷”；

此外，单看一家公司的财报，很难得出结论。需要几家竞品同时比对，才能看到差异。

就像之前我们介绍”市盈率“这个估值指标时，一定要同行业横向比较，才能看出高低来。
