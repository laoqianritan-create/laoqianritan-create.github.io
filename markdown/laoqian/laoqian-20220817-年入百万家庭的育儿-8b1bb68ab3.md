# 年入百万家庭的育儿选择

知识星球球友提问：

我和老婆都是33岁，孩子马上3岁了，和父母同住，父母身体尚可。

在北京上车共有产权房，月供1.5W；

收入我70w，老婆30w，均税前，储蓄100w；

我天津户口，老婆河南户口，拿北京户口无望；

目前想到几条路：

①在北京不动，孩子上到中学，高中考虑上国际学校，走出国的道路；

②天津买房落户，老婆去天津陪孩子，我继续在北京赚钱。需要研究何时动身，是学前就去？还是三四年级再动身？

③去上海工作一年，可拿户口，买房。经济压力大，没法考虑学区了。

④居家去其它二线城市，都easy模式，但工资不确定了。

你给出出主意。

**··· ···**

北京教育资源分配我是非常厌恶的，最好的两个资源——高考、职技校都不向外地孩子开放。

你还别看不上北京的职技校，很实用的，就业率也很高。

但是不行，只面向本地（被中考淘汰）的孩子，你说这些孩子想念技校吗？肯定不想啊！

但北京技校也是全国TOP级的，同理，深圳的也很牛，这些都与地方财政和就业直接挂钩。

北京赶人的套路是：

如果你30岁还没买房，可以考虑走了。

35岁，买了房，生了娃，没户口？那也可以考虑走了。

我为啥不生？

我特么真受够了这套资源硬约束下用东方价值观不断委屈自己的游戏了。

事实上我觉得这也是中文互联网戾气的一大来源——

我都已经快卷出翔来了，怎么居民部门基本的生活需求就这么难呢？

不好意思，共情了，激动了，说回你设想的几条路子：

①走出国路子，这是一项巨大的系统工程：

K9的教育资本支出，尤其是英语，3年高中的昂贵学费，4年海外大学的学费+生活费。毛估一下，汇总后买套上海房子也够了。

你娃现在3岁，你要规划到ta至少22岁，到时你都50多岁了，不确定性太大。

中产阶级的底座是「假设一切顺利」——这是小概率事件，从风控的角度看，底裤漏风。

②天津买房落户，我觉得是可操作最高的一条，老婆+二老过去，爹妈可考虑在天津养老了。

③、④我觉得都不太现实，100W的年收入，应该多赚一年是一年，保持高储蓄，努力维持，而不是主动打破这种状态。

祝一切顺利。

最后，建议中产家庭降低对自己养老和子女教育的预期，无论投入还是回报，都要降低。
