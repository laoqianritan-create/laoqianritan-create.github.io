# 所以，房价会跌么？

标题是平时公众号评论区里最容易碰到的一个问题，跟楼市相关的任何新闻最后都会引到这个问题上。

三道红线要问，HD事件要问，XX城市限购要问。

这次就好好回答下这个被问烂了的提问。 

首先明确下，二手房每平米下跌个几千上万的情况咱就不说了。

这种下跌就是正常的市场波动，就跟交易日里的股价变化一样，没意义，却是大众最爱讨论的。 

真正值得被关心的「房价下跌」就一种情况——核心楼市**（一二线城市）**的系统性风险。 

信用违约、信心崩塌、流动性崩溃、金融机构拿不到钱。

这种才是值得关心的下跌，也是高层也担心的。

我们在这方面的储备经验也很多，因为血淋淋的先例太多了——

日本经历过，美国经历过，还有很多新兴国家都经历过，足够多的样本供你研究。 

研究来研究去，最后发现崩盘路径都是一样的： 

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2Mr9W3znjBsCNxwQxD7F6pOE4qaor2zJSROwQWcMoVz7BvKrjKTXBHKV8P71k7mE18cZD0y82kfhA/640?wx_fmt=png#imgIndex=0)

→ ①温和发展，或者说还没有被价值发现，一如房改到08年的楼市。 

→ ②积极上涨，一部分人先富起来了，发财故事变多，赚钱效应明显，一堆钱开始涌入，买到赚到，资产价格快速拉高。 

→ ③市场开始担忧了，任何资产，价格太高都是一种风险。此时多空分歧最激烈。 

→ ④最疯狂的来了，又涨了，涨到所有人心态崩溃，全信了。贪婪，健忘，不死不休。 

→ ⑤BOOM！系统性风险爆发，大家一起GO TO HELL，贪婪瞬间转为恐惧，信仰崩塌。 

①②③④⑤，系统性崩盘的演绎。 

目前一二线城市的楼市处于哪个阶段？ 

我认为就是阶段③。 

回到那个问题上：所以房价会跌么？ 

不会真跌⑤**（系统性崩盘）**。

真跌了银行第一个不干，因为它是中国楼市最大的债权人。 

高层最怕的当然也是阶段⑤，房价真跌。

因为不能让房价跌，所以不能让房价涨。

再涨，容易进入阶段④了。 

看得见的风险，那都不叫风险。因为时刻堤防着，出事也不会太大。 

怕的是所有人都已疯，看得见的手已经无法拦下市场的不理性。

看不见风险了，那才最要命。 

其实上半年深圳就有阶段④的苗头。

深圳调控升级后，我说深圳房价要跌，评论区一帮人直接不干了，那架势分明是断人财路如同杀人父母。

就是涨疯了，干红眼了，房价信仰被触碰，骂死你！

如前文所说，贪婪，健忘，不死不休，这种状态才最危险。 

在某些情况下，所谓的「市场理性人假设」完全就是狗屁。

理解了这点，再看当下，就会特别理解为何每个上涨的城市会立刻迎来调控加码。 

再重复一遍：因为不能让房价跌，所以不能让房价涨。
