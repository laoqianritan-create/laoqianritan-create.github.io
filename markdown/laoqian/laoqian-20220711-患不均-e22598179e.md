# 患不均

有感于四字弟弟考编事件激起的讨论，分享一些对于不平等的零碎想法：

**①**这次对四字弟弟和《中国新闻周刊》的讨伐在于两点：

前者是对机会不平等的厌恶；

后者对这种用一个标签就能轻易将奋斗者污名化的不满；

而以上情绪都源于「患不均」，这正是后期疫情时代舆论情绪的一大关键词。

在这种氛围下，像钟薛高这种所谓社交货币型网红产品也是批斗对象。

尽管在便利店的冰柜里，哈根达斯的价格依然吊打钟薛高，并凭借品牌溢价摄取了行业最多的净利润。

**②** 「小镇做题家们」上一次被污名化，是「凤凰男」，它来自电视时代的热播电视剧们，发明者是上海编剧，一群最善于拉踩，构建鄙视链的“文化人”。

新加坡籍华裔、新上海人编剧@六六正是这个群体的代表。当然六六女士已经彻底闭嘴了，因为一个加拿大人。

影视剧需要矛盾，编剧们塑造的矛盾核心是**「农村穷小子扎根城市，迎娶城市小资女，但男方家长和农村亲戚实在太烦人，事多素质差」。**

很多50后60后家长都被这些电视剧深刻教育过——不能找农村人，哪怕他是在城里站稳脚跟凤凰男，我也不同意，电视剧里演的多吓人啊！这又进一步影响了我国相亲市场的审美。

**「凤凰男」再上一次被污名化是「农民工」，这个直白得有些刺眼的名字仍偶见于官方文件中。**

根据第七次人口普查数据，这个群体人数多达**2.9亿**，平均月薪4千多元，他们的子女多是「小镇做题家」，其中混得好的才叫「凤凰男」。

城镇化，两代人，三个词。

**③** 我们所谓的不平等，大概有三个维度：

* **收入不平等**
* **财富不平等**
* **机会不平等**

放到30年前，收入不平等是一切的根源。

那时我国贫富差距还很小，收入不平等意味着储蓄不平等，储蓄不平等导致购买的资产不同，而这又会进一步加剧财富不平等。

随着经济发展，财富不平等已经超越了收入不平等——即存量超过增量，搬砖累死也追不上财富增值。

何为财富？

真实的财富创造需要生产商品和提供服务。

在现代经济中财富代表的是对产出的索取权，和储蓄积累不一定是对应的关系。举例：

你有7位数的银行存款，很难拿到5%以上的收益。

你有一套北京三环里的房子，凭它可以轻易拿走一个打工仔的半个月工资。

在美国，财富是股市/GDP；

在中国，财富是房地产/GDP；

**财富分布的差距远高于收入分布的差距，这句话有两句潜台词：**

**财富远比收入重要，是为财富不平等。**

**财富继承比财富创造重要，是为机会不平等。**

教育差距导致的社会分工、分配差距，则又是另一种机会不平等。

**④**我又在想，如果四字弟弟事件的主角不是明星，而是网友们挖不出的官二代、富二代，大家的情绪是否还不如此激烈？

据我观察，很多小城市的年轻铁饭碗们，其家庭也大多殷实。

我2014年毕业时是非常看不上考研、考编的。

不光我，身边很多同窗都是这个想法，那时我们向往的是互联网、媒体，虽然学校并无光环，但我们还是有信心能敲开那扇门的。

《中国新闻周刊》那篇挨骂的文章结尾也提了一个问题：

普通人考编无非是想获得一份安全感，而演员明星这个职业本该是最市场化的，但如果他们也都纷纷考编，那说明什么？
