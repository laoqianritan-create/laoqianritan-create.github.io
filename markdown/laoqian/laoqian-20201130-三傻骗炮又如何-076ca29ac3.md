# 三傻骗炮又如何

**●**

今天银地保三傻午后跳水，因为权重比较大，气势如虹的指数也跟着泄了气。

我看不少人吐槽这哥仨涨跌都不讲武德，又想拿7月份的剧本骗炮。

人家「顺周期」概念刚要冲击开跑，三傻又双叒躺地上带队伍带跑偏了。

反正我自己是对三傻充满信心的：

今年涨得好的，像新能源、半导体、创业板、医药、消费，现在让你去追，你敢么？哪怕是在那些车上的股民，涨跌他都不舒服。

反倒是三傻这种低估值的，**越涨心越齐，越跌信心越足，每一次回撤都是多拿点筹码的机会。**

而且这哥仨的中长期逻辑没那么悲观：

银行零售龙头相当于成长股；

万元美金时代和人民刚需都是保险龙头的巨大空间；

三道红线提高行业门槛，大量中小房企死掉让出份额，利好地产龙头；

目标乐观，估值择时绝对有效，过程中的波动，怕个蛋啊！

输点时间而已，又不输钱。结果总比债券强吧？

**我不觉得这是骗炮行情，而是一段美好姻缘的小波澜**，因为估值真的已经很有效**（就是便宜）**，很多细节也就没那么重要了。

从这个角度看，光伏和新能源汽车非常像——

都代表更先进的生产力，未来一定会成为主流。

都有政策引导，比如十四五对二者未来的渗透率都有很明确的规划目标。

都有政策扶植和补贴，但政策本身又是个很大的变量，给这两个行业挖过大坑，好在目前政策都在退坡，变量在减退。

都有非常大的需求量，光国内渗透率提升就意味着几倍的行业规模。

这还不算国外的需求，全球大部分的供给都在中国，如下图：

但也有不同的地方，汽车是高心理附加值的东西，大众需求千奇百怪，中高低端产品都有人买单。

而光伏是完完全全的成本导向，谁的转化效率高，份额大，成本低，谁就能提高光伏发电站的回报率。
