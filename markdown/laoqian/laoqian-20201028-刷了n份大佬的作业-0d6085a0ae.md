# 刷了N份大佬的作业

**●**

先说下基金报告怎么看。

基金和股票一样，每年也要定期发4份报告。尤其主动型基金的报告，很值得一看。它也是基金经理和基民沟通的重要渠道。

这些报告去哪找呢？

天天基金、雪球都是大家常用的工具。先在网站上搜基金名字，然后在页面里找「公告」字眼即可。

支付宝里也有，但路径藏得很深，使用体验非常差。

而且像报告这种密密麻麻的文本形式，建议还是在电脑上看网页比较好。

基金报告和公司财报一样，也是有固定格式的八股式文本。

拿到一份报告后，只需重点看以下四个部分：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PbL4K1Avskr2CM6Latwyh7Dp7Yaqp4a1GZtx3duZiaojmkZaIUWBWeMZq3fAibib69giajFokYY44icSA/640?wx_fmt=png#imgIndex=0)

基金经理会在①②部分和大家掏心掏肺地唠唠嗑——

过去一段时间市场是这样的，基于此，结合我自己的投资理念，我是这么炒股的。最近市场有啥风险，我觉得哪里有机会，对未来的宏观经济走势我是这么看的blabla...

有人会写得很用心，比如张坤在他管理的王牌产品「易方达中小盘混合」的半年报里就说了很多有关投资理念的心里话。

有些则非常敷衍，还是张坤，在三季报里就特别惜字如金，草草几百字了事。

③会披露基金在本季度的详细持仓，这部分很重要，因为平时我们只能看到基金的前十大持仓，再往后就看不到了。而基金半年报、年报会披露完整的详细持仓。

④会披露基金经理的交易记录，买入了哪些，卖出了哪些，从中也能看出他的换手率啊，对市场的真实投票等等。

毕竟是在收费管理我们托付的钱嘛，你也可以把报告当做基金经理的定期工作汇报。

拿到报告后重点看着四部分即可，其它直接忽略，没啥用。

还要提示一下:

季报的份量不如半年报、年报重要。

所以季报甚至连目录都没有，③部分也只披露前十大持仓，④部分直接略过。

最后复述下策略一哥张忆东对四季度的看法，其中有个观点蛮有意思的——

中国制造业面临天时地利人和的机遇，有利于结构转型，也值得买。

天时是指本来中国在全球供应链体系内是有压力的，逆全球化和产业转移都对我们不利。之前中国的出口份额占全球15%，贸易摩擦后下滑到13%，但是疫情我们又最先复苏，一下子干到了20.4%。

感谢疫情，本来要从中国撤出到印度、东南亚的产业现在想走都没法走，那些地方根本没法有效生产。这种情况会持续3~5年，是我们抓紧转型高端制造的窗口期。

地利是面对全球民粹浪潮和逆全球化趋势，中国的内需市场是最大的倚仗。

人和指的是供给侧改革、去杠杆让各个领域的资本开支向头部集中、注册制和科创板也给产业升级提供了制度和融资保障。

在资金层面，按住房地产的上涨预期，固收领域打破刚兑推广净值化，这些趋势都在把渴望回报的资金赶向权益市场（股市）。

张忆东在接下来的四季度看好三类机会，风险偏好由高到低依次是：

天时地利人和利好的制造业重估，包括光伏、新能源车、半导体等先进制造，长期的盈利增长和景气度都有。调整出了性价比就值得参与。

低风险偏好的，银地保三大惨里死不了的好公司，现在估值已经反映了市场过度悲观的预期，这类资产至少比债券强。

医药消费科技的行业景气度很确定，从三季报也能看出来。这些资产唯一的问题就是贵，因此一旦调整了，也有机会。
