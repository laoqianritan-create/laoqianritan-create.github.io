# 3年了，你丫也跌回来了

今天没啥事，就简单识别并记录一下新能源汽车指数估值重回低估区间，重点看下图蓝线：

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVboaZkzptNghDaCDWs61ZojqHqlXlibibPFJiagk340fB1LqnpACPMGetdnv9PjcOdvD1xslxsKvsiaRQ/640?wx_fmt=png#imgIndex=0)

新能源汽车指数PE估值一度超过200倍，今天的估值是27.7PE。

2019年至今，新能源汽车指数随时买随时爽。

2019年拉估值，2020和2021则是业绩和估值的戴维斯双击。

市场在乐观时总倾向于认为业绩增长会消化掉高企的估值，然而现实一再证明：**消化估值最高效的办法，还得是****下跌****。**

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVboaZkzptNghDaCDWs61ZojnAqkPFsZwT3iaH0HfUF7GbxXEuDia1KAAB7o6ktfAuJEUKljqjZAuZng/640?wx_fmt=png#imgIndex=1)

2019年中国新能源汽车销售渗透率只有6%左右，社会上对它充满质疑。

谁又能想到，短短3年时间，如今它的销售渗透率已经飙到25%左右。

而国家的规模目标是：2025年达到20%的渗透率。提前3年，超额完成任务。

本来还给找了好多份券商出的新能源汽车行业2023年度投资策略，想了想，还是算了...

科技、医药、新能源，这么高的学习门槛，那么多个股，得多闲多自信才有动力去研究啊！

人呐，得有自知之明。费那劲干嘛！

**低估时买点对应的指数基金，再找找能跑赢指数的主动型基金，它不香吗？**

头发还是让基金经理去掉吧...
