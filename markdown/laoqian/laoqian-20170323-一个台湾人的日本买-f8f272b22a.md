# 一个台湾人的日本买房经验和建议

![图片](http://mmbiz.qpic.cn/mmbiz_gif/ibw8b04QVx2M7PTAr8JHoc98wCJlkDyXxsA0LtNpBgqhicVxmxOENpDia40416PMnQfU6BgCLN0bVtwGJS9LMhIJQ/0?wx_fmt=gif#imgIndex=0)

L先生是L小姐的男朋友，台湾人，2015年在台湾购置了一套带土地的三层木造公寓。前几天吃饭，我请教了不少“买房经验”，又搜集了些资料。

今天聊聊日本买房。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02qCgMvYKH34MxWobzPkRicErYCnJAM2HX32tJ2v7qzrH2kuNv18iaGNcQ/0?wx_fmt=png#imgIndex=1)

日本的行政区划可以近似看成一个长方形，像这样：

![图片](http://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2Nf3CpAZBQibTkGJ5UgGZIzmW9xRdNpqSwTrPGxhHiab0dllHhER8qadGDcuPv6sYk9AkW2PTzHLa7Q/0?wx_fmt=png#imgIndex=2)

长方形东边要繁华很多，而东京城市圈则是全球最大的城市圈。广义上的东京圈由东京和三个邻县—埼玉、神奈川、千叶县组成，人口约3600万。

L先生说，除了东京，日本的其它地方他都不太看好。东京圈像一台抽水机一样，不断吸纳着全日本的人才，其人口数约占日本总人口的30%。租房市场很不错。

东京房地产市场的一大好处是—它经历过泡沫，整个市场很理性，日本目前的房产泡沫程度远低于世界上很多热门投资地区。

我选取了几个热门的投资地区：其中浅紫色线是日本。看图说话，日本的房价指数是最低的，泡沫破裂后，一路走低，后来即便上涨，幅度也相当可怜。

总的来说，这是变态狂热后极度理性的市场，房屋价格和价值偏离不大。再看其它几个国家，斜率陡峭，房价指数都要远高于破灭之前的日本...

可以看到，两张图中，日本的位置都比较低，显得很异类。

而中期来看，日本楼市最大的利好就是2020年东京奥运会。每一个举办奥运会的城市都会发生深刻而久远的改变。总的来说，城市会变得更好。

尤其是奥运会需加强基础设施建设，交通等基建的改善，能带动干线和中转站附近的地产增值。

L君认为，现在入场已经有些晚了，大家都盯上了奥运概念。最好的入场时间在2014～2016年左右，趁注意力在巴西奥运会时低调进场。

从历史规律看，举办过奥运会的城市，房价在5年内都会大幅上涨。目前来看，东京也是如此：

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02b6ic60tUu5mmkiaW840DDlQZbpDx6FrKZw80myPXshlIiamrskPzvYEwg/0?wx_fmt=png#imgIndex=7)

日本的交通极为发达，不管去哪里，一个小时的交通时间基本都可以覆盖。所以，只要房子靠近快速干道附近就好。

L君买在了板桥区，一幢木造的三层公寓，带土地。价格3600万日元。L特地强调，一定要注意合同里是有含有土地的所有权。

整个公寓三层的总面积为32平左右*（是的你没看错，而且每层都有独卫和浴缸）*，三层分别租给了三个租户，月租金19万日币，扣除掉税费，年化收益不到6%。属于平均水平。

L君说，在日本如果回报率能超过7%已经相当不容易，属于优质投资资产。

其中有很多权衡的因素—比如我买的是一栋新房，价格要比老房子贵，基本20年之内完全不用担心它。

而有些房产因为房屋价格便宜，投资回报率可以超过10％，很诱人。但风险极大，因为房屋一旦因为太老需要修缮，费用极高。而日本要求木质房屋40年需要翻修一次。

L君投资考虑的第一件事是地段，这栋公寓步行到车站的距离在15分钟以内。

第二考虑房子要租给谁：L的房子每层只有十几平米，价格也不算便宜，所以租户势必都是有正经工作的单身人士，每天回来只是睡一觉。所以房子的折旧速度很慢。

而且L明确要求中介，租约在两年以内的租客，一律拒绝掉，他宁可等。这也是考虑到自己身在国外，尽可能不被这些事打扰，尽管房租已经全权委托给中介。

每个月，中介都会给L发来当月的租金、税费报告。L特意又说了一遍房屋的价格—3600万，它想日后把这套房子抵押再贷款，接着在日本投资一套。而银行要求抵押贷款的房子，必须在3500万以上。

买房有个说法：跨省买房，战斗力打7折；出国买房，战斗力打3折。因此一定要有靠谱的中介帮忙。

尽管中介是自己的学弟，L为了买这套房子，两个月飞了三次日本，把房子所在的社区走了个遍。观察了邻居、周边的配套，体验了各种生活场景后才开始办理手续。

此外，外国人是无法在日本办理贷款的。解决办法有两种：

第一种是在国内贷款后，全款去日本买*（L就是把他在台湾老家的房子抵押贷款，再去日本买的）*；

第二种是通过日本当地的中国银行贷款，最多5成，最长15年。

L君推荐关注三个区域：世田谷区、港区、千代田区。
