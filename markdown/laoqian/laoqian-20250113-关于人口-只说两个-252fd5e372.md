# 关于人口，只说两个趋势

本来想等2024年的新生儿数据出来了再说这事儿，但最近看到两张好图，忍不住想和大家分享下。  
  
✅图3. 少子化速度对标韩国  
  
还是那句话，别劝人结婚或者生育，没用，也不是重点。  
  
真正的重点是靠社会化抚养和发钱，帮想生的人（不非得结婚）切实减轻养育负担。  
  
✅图4. 老龄化速度超过日本  
  
老龄化是个比值问题。在我国，分子端跟随60后婴儿潮变老猛烈变大，分母端跟随少子化和自然死亡率而变小。  
  
都是灰犀牛，关键是何时承认问题是问题，否则谈不上缓解。  
  
注意，是缓解，咱都没说解决。  
  
趋势无法扭转，能降低斜率，就算卓有成效了。
