# 连踩三次狗屎的男人

**●**

前两天在脉脉上看到一个帖子，是这么说的：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MzicpxNUgIicfZqPY4x6XUe2yuV88QkxZJn6tRYeYJLPgQHpaqBZXQT8WJlbejxeeYPyiaYrxNGKtBA/640?wx_fmt=png#imgIndex=0)

这位鹅厂35岁老哥可以说踩中了三次红利——

300万现金，一份好工作带来的现金流结余。

这份红利既可以说是腾讯给的，也能归功于过去十几年中国互联网的成长。

哪怕他没能进腾讯，但只要一直泡在互联网行业里，最后当个中产肯定绰绰有余。

1000万腾讯股票，肯定不是买的，而是工作的10年中包含在工资包里的股票长期增值的结果。

这是股权红利，好股票+长期持有，足够long，所以收获足够big，股票市场最普适的道理。

1000万深圳房子，相当于抓住了中国城市化浪潮的红利，而且还是浪潮之巅深圳。

当然，这其中还包括过去十几年M2增速始终高于GDP增速，货币超发，导致「资产负债表」里的债务持续贬值，而资产价格持续通胀的红利。

三次红利，让一个人的财富攀上了2300万的高度。

我不想老生常谈鼓吹**人生要选对**的重要性。

但我最近真心觉得，每个人身上都有时代性。

第一产业只能广泛提供年收入几千块的工作。

第二、三产业能广泛提供年收入几万块到十几万的工作。

只有高科技、新兴产业才能让高薪岗位越来越多。

产业才是教育最大的配套设施。

韩国年轻人挤破头想进三星。

日本年轻人挤破头想进索尼丰田日立。

台湾年轻人拼命想进台积电。

香港年轻人只想去体制内当医生警察，或者加入金融业。

中国年轻人都想进互联网大厂，或者留在本地加入体制内。

华为、中建等公司是优秀理工科院校最大的招聘方。

如果产业缺失，教育的整体回报率必然变低，这是家长再怎么努力也注定无力改变的事。

很多城市的问题是产业不兴，那么年轻人用脚投票的结果必然是：

离开本土去一二线城市卷

挤破头进入体制内混个蝇头小吏

加入当地的餐饮服务业当个小老板，彻底把自己市场化

看清洪流，才好下水摸鱼。

当然也得努力，往上爬，关关皆是窄门。
