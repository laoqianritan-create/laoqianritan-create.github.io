# 不要走进大厂人和金融人的内心

真的，金融人和大厂人的内心没必要窥探… 都太干瘪、干涸了，没啥可看的。不是羞耻感，就是恐惧感。  
  
现在和未来，我们会有越来越多的「碇真嗣」和「完治」，配不上命运赏赐的「赤名莉香」，因为大家的底色就不一样，完全是两个世界的人。  
  
一个烈火烹油，一个无欲无求。  
一个纯爱战士，一个爱哭小子。  
一个轻盈热烈，一个压力山大。  
  
昭和已逝，平成日久，告别希望的原野，挥别高增速的余晖，在漫长的季节里，\_ \_ 吧！  
  
P.S. 这种风气投射到保险上就是：  
  
尽管现在的重疾险规模相较 2018 年时几乎萎缩了 80%，但我很明显地感觉到大家对保险的接受度跟 18 年完全不一样！不抵触了，更接受了。  
  
但保险是可选消费，所以，大家来我这买的几乎一水的都是便宜的意外险、医疗险，以及趸交的年金险。
