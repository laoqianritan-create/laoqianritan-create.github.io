# 还在坚持买买买

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2OrYk01tQRV43lotIicQheu5H3kEeicrIfKPqqicroPCYxtPKcrHIGay2GdL3TpAp9ol7bF7dpTyic2ZA/640?wx_fmt=png#imgIndex=1)

今天主要是简单复盘一下「长赢计划」。

去年7月份，我开始在「且慢」上跟着「长赢计划」定投指数基金，每份1000元，计划一共投入150份，共计15万。

不少读者对这个定投计划非常熟悉，但肯定还有不少新读者不了解，我再快速介绍下：

长赢计划是由E大主理的，已经实盘运行12年的指数基金定投策略。12年共有两轮完整的退出，取得了10倍的回报。

目前正处于第三轮150份的定投周期，已经投出去114份。

我跟大多数朋友一样，也是中途上车的，目前已投出去88份。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2Mbia3YtZkpvWXuCOe87vh30niad8iajO0hiaWc9vuqpDXfWyasOl0r4t7WrDiaooHFgkmF3yflj3kZ6icg/640?wx_fmt=png#imgIndex=2)

我打心底里认可「长赢计划」，只在低估时才出手定投指数基金，这个主逻辑一点儿毛病没有。实盘运行了12年，经历过时间的考验。

而且有明确的买入卖出提醒，省心省力，是非常适合公司人的基金定投策略。

现在的收益率我也不觉得打脸，有熊市才有出手赚钱的机会，我们能做的就是耐心地、不慌不忙地默默出手，低价买入份额。

**短期看熊市赚份额，牛市才赚钱。**

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2OrYk01tQRV43lotIicQheu5ibeRsMa6Xzt4FWQFvhkgwpwFZhN5P7sBEdakdggBKINJlANiakAP5utw/640?wx_fmt=png#imgIndex=3)

最近且慢对「长赢计划」进行了一些更好的调整。

因为很多用户都和我一样，中途才上车，面对已经投出去的一百多份，不知该怎么补仓。

且慢希望大家在承担不高于长赢策略风险的前提下，收益尽可能逼近或者高于长赢。

让大家在成本不高于主理人的前提下，持仓比例尽量接近主理人持仓比例；

按照分散优先、价格差其次的原则补仓，尽量降低持仓的波动率；

具体调整如下：

> 之后的跟车卖出提醒实行定制服务。并不是主理人卖出1份，就提醒大家卖出1份，而是根据每个用户当前持仓份数和主理人卖出后的持仓份数来定。
>
> 如果一次要补齐很多份，在资金不足的情况下，且慢会优先按照价格差把每个品种的价格差最大的先补一轮，然后再依次补入第二轮。
>
> 这样不仅考虑了价格差，也可以避免补仓品种过于集中。
>
> 对于主理人已经清仓的品种和波段仓位，禁止自主买入。
>
> 大家自主买入时，且慢也会及时做出风险提示，劝你别冲动。

这个计划最大的风险就是中途退出，浪费时间浪费金钱。坚持就是胜利！
