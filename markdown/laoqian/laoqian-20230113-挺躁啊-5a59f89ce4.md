# 挺躁啊！

怎么样兄弟们，一看账户美美滴吧？

为什么每年年初大家都热衷于讨论「跨年行情」或者所谓「春季躁动」？

大概有三个原因：

第一，年初一般是信贷投放的高峰，宏观上来说，流动性充裕，不差钱儿。 

第二，1-2月有宏观数据真空期，1-4月有上市公司业绩真空期，没凭没据，瞎\_\_ \_\_炒。 

第三，新年新开始，市场对政策、经济等都有期待，大家的风险偏好会不自觉地提升，类似年初立flag。

刻舟求剑地回顾下09年至今每年的春季躁动行情：

有朋友说了，这不是刻舟求剑嘛！

没毛病，就是刻舟求剑，不涨谁也不知道哪天是底，同样地，不跌谁也不知道哪天是顶。

每一个拐点，都是事后确认的。

比如2023的春季躁动，事后总结，大概始于去年12月23号。

至于哪天结束... 我哪知道！跌了不就结束了嘛！

看起来是废话，细品还挺有道理的。

比如面对不确定性，何必去猜，靴子落地不就确定了嘛，等就完了。

历史只能参考——

你觉得2022年和2018年一个熊样，那今年就多瞅瞅2019年。

国家刺激楼市，房贷打折，那你就多看看2009年、2015年。

以上动作看起来不咋高级，但是2018年底谈股票，2014年9.30谈买房，能被大伙的吐沫星子淹死。

兄弟们，我真的怕打脸！

但更重要的是，得在关键节点留下一份公开可查、观点明确的证据。对错不论，时间验证。
