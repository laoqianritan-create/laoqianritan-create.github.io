# 公募抄底，简单道理

**●**

根据中基协数据：截至昨天晚上，至少有26家公募基金表示以固有资金及员工资金合计20.5亿元认/申购旗下公募、专户产品。

昨天我在文章里说他们一共买了不到10个亿，冤枉它了，人家买了20个亿！

还没有北向资金平时一天买的多...

不过也没办法，如果A股是个大家族，公募基金扮演的角色一直是**穷酸亲戚**。

为啥这么说，看个指标你就明白了：

这次拿出来20亿抄自己家的底，怎么也算穷亲戚摆阔请客了。

横向比较下，A股家族台柱子之一平安去年也抄了自己的底，回购自家股票，拿出来了50个亿；作为外地来的亲戚，北向资金也是每天几十上百亿的买。

机构很少买公募基金，它主要还是帮广大散户们管钱。虽然穷酸，但必须承认，人家投资能力还是有的：

说句公道话，这也不全怪人家，我们也有责任，用脚投票，追涨杀跌，高位抢着送钱，地位骂骂咧咧地割肉。比如下面这张图：

接下来说下怎么用：

**1、海量的数据**

数据这个东西很神奇，可以提前预判国内的经济情况，也可以提前预判行业的经济，同时还能提前预测企业的业绩，在萝卜投研看数据也很简单，搜索关键字就行了。比如“汽车”、“汽车行业市盈率”、“格力空调”等等。

**萝卜投研的数据主要分为三大类：**

**1）宏观数据：**比如说财政收入与支出、汇率、利率、就业与工资、证券市场、产品价格指数、工业主要经济指标、政府财政预算、国内外贸易等数据变化趋势图，研究宏观数据的主要是为了提前预测国内经济的整体经济情况。

**2）行业数据：**这个就比较多啦，A股所有的行业全部都覆盖了，搜索关键字就行，比如像汽车销量、汽车产量、汽车行业市盈率、汽车行业市净率，还有一些产品的价格数据。

比如像万华化学的主力产品TDI的价格走势图及原材料纯苯的价格走势图，通过这些行业数据就可以提前预测出来企业的净利润增长情况。

**3）企业数据：**这个主要是某个企业的产品数据，比如格力空调的销量、格力空调的平均价格等等，从这些数据的走势情况可以提前预测企业的业绩趋势。

说一个用数据预测走势的小技巧，大家都知道通过数据可以提前预测上市公司业绩，预期业绩乐观的时候股价走势就会比较好，所以股价走势和主营产品价格走势也是相关的。

**3、利用财报对比工具选优秀企业**

这是选企业的一个小技巧，比如看中某个行业的时候，肯定得选一个好的企业呀，市场上大部分产品都只有某个企业的数据化处理，但一家公司好不好，往往需要与公司所处行业内的企业进行对比，萝卜投研可以对同行业的公司根据指定的财务指标进行对比排序，这样更便于筛选好企业。
