# 信息密度很高的一张图

左边是收益率指标，右边是持有体验指标。左边是成果，右边是代价。我们都想在左边得到好成果，却对右边必然的代价没啥心理准备。

何为代价？最大回撤幅度全部超过腰斩，年度回撤超过20%更是家常便饭，这无疑会给持有人带来很不好的持有体验，又会伤害本金。
