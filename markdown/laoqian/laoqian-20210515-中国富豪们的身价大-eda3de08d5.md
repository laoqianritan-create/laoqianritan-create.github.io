# 中国富豪们的身价大爆发了

●

一年一度的《新财富500富人榜》出炉了，这个榜单主要统计上一年度中国顶级富豪们的财富变化。

榜单太长，为了不影响阅读体验，这里只附上前100富豪的财富变动情况：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PeOn1odInyGlz6txUHRxH1oibZy9Pd600AN9KibT8kwGBRx2K1ibbHVk6tOY0hQzGeJdDIjApKFLhWA/640?wx_fmt=png#imgIndex=0)

据此榜单，我们来看看能从中挖掘出哪些信息：

***1*** 《新财富500富人榜》也有快20年历史了，如果只是用它来吃有钱人的瓜，关注其排名变化，实在有些可惜。其实这种榜单背后都有更宏大的时代性。

比如福布斯全球500强公司榜，更多是在**比较经济体之间的优势产业**，它同时包含国营和民营公司，**是各国经济实力的缩影**。

而新财富500富人榜，更多是**中国民营经济的缩影**，上榜的富人就像经济T台上的模特，是各自背后产业、城市的代言人。

***2*** 富人榜的变化，也能折射出不同时代的财富主引擎。

富人领导的是国内最有竞争力的组织形式，**这些人的转型一定与中国经济结构转型亦步亦趋，同时又保持领先，可以视为经济体转型的领先指标。**

通过榜单能发现，中国的财富主引擎一直在变化，富人榜也跟着大浪淘沙、不断洗牌换血。

1978~1997年，中国以轻重工业化为主，造富主要来自于实业和政策。

1998~2006年，来自制造业的富豪们上榜最多。

2007~2015年，城市化进城加速，居民部门杠杆启动，房地产成为各行之手，跑出来一批耳熟能详的地产富人。

2016至今，新经济跃居地产之上，且每年都在增长，更多80后新贵不断挤进榜单。

差不多10年左右，富人榜就会大洗牌，8成富豪换血，TOP10富人更是全部换人。相比之下，美国TOP10富人则很稳定，和十年前的榜单重合度很高。

这一方面说明中国正经历如火如荼的产业结构转型，而且顶层富豪的转型速度领先于经济。另一方面也说明中国经济更有活力，并未出现像网上中产阶级们担忧的阶层固化，跌落攀升时常发生，通道的流动性很高，可上可下。

能出现在每年榜单上的富人，要么是上位的新钱，要么是**不断精准调整自身财富结构的老钱**。

***3*****股权是富豪最主要的财富形式**。也就说在中国你想成为富豪，必须得有能赚钱的公司，且公司必须证券化。

2021年榜单中，只有66个人旗下公司没有上市，相当于TOP500人中证券化率达到86.8%。

**靠房子只能成为富人，但绝对不会成为富豪**，因为豪宅无法吃下那么多财富。

这种财富榜单的制作方法就是根据富豪们拥有的主要企业，对其股权财富进行评估，以某个日期的收盘价为准。没上市的公司，就根据其净利润和已上市同行公司的市盈率来估算。**所以富豪的身价始终是波动的。**

***4***之前很多富豪都来自海外资本市场，但是从2018年开始，回归A港股成了富豪们整齐划一的选择。

看其来源会发现，**中小板科创板是新钱造富的宝地，但波动也很巨大，不是一劳永逸的久安之地**。A港股快节奏的IPO能带来富豪排名的快速变化，榜单不断迎来送往，每年都有新面孔。

由于身价与股市高度绑定，导致个别年份比如2009年、2012年、2018年，富豪们的身价会罕见缩水，且TOP500的入榜门槛也会跟着有所降低。

2021年富豪榜入门门槛也从去年的63亿元大涨至今年的89亿元，同比增长40%。

***5***从2003→2021年，18年间，TOP500顶豪的财富复合年化增速**23%**，城镇居民人均可支配收入增速10%，中国GDP增速13.6%，中国M2增速14.4%。

2003年，TOP500总财富约为0.5万亿。

2020年，TOP500总财富约为10万亿。

2021年，TOP500总财富约为17万亿。

前面说了，榜单主要衡量的是上一年度的财富变化，意味着中国顶豪们在2020疫情之年身价暴涨70%。

与之对应的是应对疫情开启的货币信用双宽松政策、更多的水、更低的贷款利率、中国率先全球复苏、产业链受益于国内和海外市场、核心资产抱团导致估值红利等背景。

顶豪们成了这波最大的受益者，迎来了财富盛宴，大幅跑赢美国富豪。

******6******富豪们的身价凭啥这么快？或者说贫富分化加剧凭啥这么快？有几个原因：

富豪背后是公司，这些人的判断、投资回报、资本、生产率等所有优势都可以归纳为一个指标，就是上市公司的ROE。而普通老百姓的财富增长率平均下来就是GDP。

**ROE>GDP**，就是这么简单。

另一个因素就是金融，我们知道**金融是不帮穷人的**。富豪们有资产抵押物、有信用，他们能申请到利率低、倍数高的杠杆，进一步把赚钱能力放大。

举个例子，我前几天看一个新闻感触颇深：

亚马逊账面上趴着巨额现金，然后发了一笔185亿美元规模的公司债，融资利率仅比美国国债高出零点几个百分点。借这些钱拿去干嘛呢？用于回购自家公司股票、收购其他公司。

一家科技巨头的借钱成本已经比绝大多数主权国家的融资利率还低，这笔钱便宜到近乎白送，然后公司拿它去回购自家股票，推高股价，让所有股东获利，同时让财富进一步集中。可以确定亚马逊就算闭着眼睛做资本支出，其回报率也远远超过融资利息。然后这些利润还不在美国本土计提，而是跑到爱尔兰等税收优惠国进行避税。这也太尼玛开挂了。

***7*** **地产这台经济发动力早晚会被淘汰**，从2007年到现在，一线城市的房产价格又上涨了至少5倍，甚至有郊区更收获10倍涨幅，但主要财富依托资本市场市值的地产富豪们，财富却根本没有涨多少。

2021年榜单TOP10中一个地产富豪也没有，而且今年中国地产行业的首富是左晖，其背后是贝壳，尽管股价从高点几乎腰斩，但贝壳仍是中国市值最大的地产公司。这也完美呼应了中国房地产从增量时代转入存量时代的大趋势。

持有地产股的同学，可以好好调整下自己对回报的预期。

***8***从富豪角度看中国民营经济的优势产业：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PeOn1odInyGlz6txUHRxH1dxNPpdJ2YVnibUSktMPY921SIuzvNQr1kuIPCkMJiaNFWIdD4xa8aALQ/640?wx_fmt=png#imgIndex=2)

大消费+大科技+先进制造三个概念几乎涵盖了民营经济的优势领域。再加上航天军工，**这四大领域也是未来20年中美博弈的四个聚焦点**。

***9*** 中国新经济的势能威力巨大。

中国产业链拯救了特斯拉，还买一送一把马斯克推上了世界首富的位置。因为特斯拉，中国造车新势力三剑客李斌、何小鹏、理想都在今年携手上榜。要知道李斌之前还濒临破产，被评为2019年最惨的男人，然而1年后就成了身价502亿的富豪了。

同样让人感慨的还有薇娅，2016年还是名不见经传的服装店老板娘，2021年就成了身价90亿的富豪，其财富量级与老干妈陶华碧以及提携刘强东的今日资本徐新差不多。

当然，论速度，没人比得过黄铮和张一鸣。黄铮身价排名一年提升8位，如果他不捐赠股权，本可以超过钟睒睒成为中国首富的。

***10***最后再总结一下：

吃富豪们的瓜意义不大，**富豪榜是果，背后的公司才是因**。

我们要坚定相信股市可以实现群体造富。

富豪的财富只能主要绑定在自己的公司上，而普通人则可以绑定在多家甚至一揽子优秀公司上。抱住富豪大腿，因为这一小撮人享受着全社会最高的财富增速。

过去十几年，中国普通老百姓的主要财富都体现在房地产上，大城市的房子确实也提供了丰厚回报。但高房价对消费、创新、生育、金融系统安全性都不利，股市一定是普通人下一个分享经济成长的风口，这点毫无疑问。

股票、基金、债券等金融资产占居民部门的财富占比只有11%，还有很大提升空间。
