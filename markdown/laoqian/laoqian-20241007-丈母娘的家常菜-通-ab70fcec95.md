# 丈母娘的家常菜，通杀！

其实每次回长沙就惦记两件事儿，一是能在家里吃饭，二是爬岳麓山然后湘江边上遛遛弯。

这次回来，不是下馆子就是在村里吃席，一顿饭没在家里吃上。

赶飞机之前，丈母娘火速张罗了一桌儿，总算没留遗憾！

和兄弟们显摆一下：

这是醴陵做法的小炒（驴）肉，配菜是芹菜和大蒜叶。这次太着急，平时还会加上切成丝的炸豆腐，更绝！我觉得秒杀湘菜里最常见的辣椒小炒肉做法。

醴陵菜的做法，偏好汤汤水水，方便菜汤泡饭。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/M7fHtGOlzVZyITaSSibRoIh2lGAc592hicuTjFM35quy8LLGiaN0wKpv7diaKdeRSUkrmOOR9dVtTbGApUaVRmzWRA/640?wx_fmt=jpeg&from=appmsg#imgIndex=0)

家烧鱼，又是一个方便泡饭的菜。

这边做饭，一定要略带炫耀地和你强调：这个食材可是直接从乡下里带的哟！

鱼是老家水库里的哟！鸡蛋是土鸡蛋哟！这可是本地辣椒哟！本地辣椒更辣哟！菜可是上午从地里现拔的哟！

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/M7fHtGOlzVZyITaSSibRoIh2lGAc592hicTNngtzjRWdJ2B8FgcNcn69KdkT3tia5tYLY10h64qAiapJjjLSvPicWnA/640?wx_fmt=jpeg&from=appmsg#imgIndex=1)

萝卜菜炖芋头，继续泡饭！

东北管萝卜菜叫萝卜秧子，好像会用来喂鸡。

同样用来喂鸡的还有白菜梆子，也很美味！清炒大白菜，味道清甜！

豆渣也会喂鸡，这次我也吃了炒豆渣，和辣椒、大蒜叶一起炒，嘎嘎好吃！就是着急干饭，忘了拍。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/M7fHtGOlzVZyITaSSibRoIh2lGAc592hicTHjgFbjdNbmuQcZAs5qMBmjfVQMeZ4XwcQVYXkQtcDlxrFlu7DIJzg/640?wx_fmt=jpeg&from=appmsg#imgIndex=2)

炒毛豆子，乡下带回来的，我和女搬砖工现剥的。

平时炒还会放点新鲜肉片，这次也是着急炒，就没放。还有本地辣椒确实辣！

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/M7fHtGOlzVZyITaSSibRoIh2lGAc592hicwEOnq1q5kSKQqLpfLra1vuV9MDFyyMyO4dIPYcFlu2SCeRj2Ak8Q7Q/640?wx_fmt=jpeg&from=appmsg#imgIndex=3)

这是我特意点的菜，苦瓜炒酸菜，巨好吃！

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/M7fHtGOlzVZyITaSSibRoIh2lGAc592hiccmw6MJf0uFicGPq49OCyHAicIZlXnAXrkrcEv67ic6RVjvZcSWGxHhrdw/640?wx_fmt=jpeg&from=appmsg#imgIndex=4)

最后这个是饭店菜，拍起来比较好看而已，乱入凑数的，不重要。

相比小龙虾，更推荐罗氏虾，肉多，好剥。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_jpg/M7fHtGOlzVZyITaSSibRoIh2lGAc592hicZWicqxagv2DMfiaNf0PqAQrSbM3kWPBBVvNCzlB1oluPTpoic98ibKtG2A/640?wx_fmt=jpeg&from=appmsg#imgIndex=5)

能回家吃饭一直是我们想回长沙的主要原因，没有之一。

回东北就不一样了，回东北我只想吃自助盒饭，一顿都不想在家里吃（没有说我妈做菜难吃的意思）。
