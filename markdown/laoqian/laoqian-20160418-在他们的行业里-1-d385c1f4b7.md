# 在他们的行业里，100亿是什么概念？

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Ok6L07zATib01c4drUbukJYlGvibM0XkaQPyiba94ibMbCyibZYGlauYZDvic5vJXO6JttHBSaUqCcTB9Q/0?wx_fmt=png#imgIndex=0)

如果你熟悉互联网金融这行的话，会发现越来越多资质不错的企业的交易额都陆续突破***100亿***。理所当然地，如此重要的节点自然要宣传一番。比如：

* 你猜我们何时突破100亿交易额呀？
* 100亿我们发大奖，快来参加活动呀！
* 让我告诉你，我们的百亿之路是怎么走过的！
* 你知道100亿堆起来有多高，有多重么？

这次找到老钱的金主是交易额在今天突破100亿的搜易贷—搜狐旗下的互联网金融公司。我们自然要在100亿上做文章，但是上面几种规定动作已经被好多前辈们用过了，飞机稿做起来容易，但做出来没新意。

任何互联网金融公司的品牌内涵词都是—***钱***。但围绕钱，有太多外延词可说。

我相信没人会对100亿有直观的概念，量化会让这个数字变得更加具体，但如果只是在数字上拆解，只是把100亿变成了一堆冰冷的数字，并不会引起共鸣。

钱中有欲望、梦想、贪婪、偏执、妥协、自由、自我价值...这些才是能引起共鸣的东西。

于是，我们换了一种量化思路，询问各行各业的人：

***在他们的行业里，100亿是什么概念？***
