# 一个真实的小生意样本（附详细经营流水）

![图片](http://mmbiz.qpic.cn/mmbiz_gif/ibw8b04QVx2M7PTAr8JHoc98wCJlkDyXxsA0LtNpBgqhicVxmxOENpDia40416PMnQfU6BgCLN0bVtwGJS9LMhIJQ/0?wx_fmt=gif#imgIndex=0)

题图来自我最喜欢的漫画《深夜食堂》。因为实习的原因，我从大四开始频繁往返于北京和保定，当时挺不适应的，觉得未来很迷茫。经常在火车上看这部漫画，心情会平静好多。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02qCgMvYKH34MxWobzPkRicErYCnJAM2HX32tJ2v7qzrH2kuNv18iaGNcQ/0?wx_fmt=png#imgIndex=1)

今天来说一个真实的创业开店的故事，主人公是我的前同事L君。昨晚我突然想起他，遂在微信上聊了一阵。

L君还特意给我邮件了一份商业计划书，里面有真实的经营流水和店铺成本分析。他本想靠着这个BP拿一笔融资，做直营店。

我认为这是一个很难得的案例，和大伙儿分享一下。

先介绍下L创业的原因。

L是我之前在门户网站财经频道的同事，一个身高接近一米九的大高个，内秀，做的创意短视频相当惊艳，当时在秒拍上小有名气。

有天L偶然吃了一份烤冷面，那是他第一次吃，惊为天人。他发现南方似乎从没流行过这东西，自己又特别爱研究，觉得是个机会。就这样，辞职创业了。

我们当时听说都惊呆了，但随即又觉得很难得，有趣的人永远有趣，我身边这样的人太少了。

L辞职后去了南京，开始创业。一番研究后，在南京狮子桥步行街上开了第一家烤冷面店，取名“四车巷”。

![图片](http://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2NL0Ejos0zQ7QYNcltUYvoPAk5qf7AQQsicKRH8Xgiawkq49IfAEljp7HiaIZjibuAJHwdjMTviclbMzbw/0?wx_fmt=png#imgIndex=2)

*店面实景*

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02b6ic60tUu5mmkiaW840DDlQZbpDx6FrKZw80myPXshlIiamrskPzvYEwg/0?wx_fmt=png#imgIndex=3)

线下生意最重要的是人流，光是店面就找了好久，最终把地点选在了南京有名的商业步行街—狮子桥。

L是个特别能专研的人，他仔细分析了制作烤冷面的所有材料，自己调制了酱汁，甚至连刷酱汁的刷子都挑选了好久，每刷一次的成本都算了出来。

![图片](http://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2NL0Ejos0zQ7QYNcltUYvoPEBSTvqM8s2vCslH6GwcqqdettS1LRnsuR4W8uiba2obn3LooTpjNIIw/0?wx_fmt=png#imgIndex=4)

*图片来自L的商业计划书*

“四车巷”主打三款烤冷面，L还自己设计了包装盒，相当精美。

![图片](http://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2NL0Ejos0zQ7QYNcltUYvoPm2l0q5z7iaSJ6peJOG63qtf6yE5ZjOtOBJd2icMO2OYPrF3UfH91QAJQ/0?wx_fmt=png#imgIndex=5)

*图片来自L的商业计划书*

我特别佩服L的一点是，他很有***审美自觉***，做出来的东西很好看，这点对于创业者来说太重要了。所谓品质感的塑造，有至少一半功劳来自视觉美感。

烤冷面很快就盈利了，下面是一个季度的流水：

![图片](http://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2NL0Ejos0zQ7QYNcltUYvoPotZHOZFICPZpyT3n02hwYnBavAv5UnSuYicicFCegGk9iaAI6aSSXWzTw/0?wx_fmt=png#imgIndex=6)

*时间：2015.12.1—2016.3.1*

这家店每个月能卖7000份烤冷面，平均每天200+份，周末会更多一些。每天营业12个小时算，每小时要卖接近20分，3分钟左右就出一份。

毛利率在70%～80%，净利润在17～35%。

固定的开支包括：

* 店面成本13000元；
* 2名员工成本11000元；
* 原料占总流水的25%左右；

L说，几个月的时间里就收到过几十次加盟询问，他想如果放开加盟，即便单靠加盟费也能赚一笔可观的收入。他也犹豫过这事儿，但还是觉得初期保证直营比较稳妥。

计划书里同样罗列了详细的开店成本：

* 标准面积10-25平，门面宽3米以上
* 深夜档4-10平
* 供电：房屋供电最低10千瓦250V
* 店铺装修10000-30000元／店
* 投入设备20000-50000元／店
* 首次原物材料投入10000-20000/店
* 店铺租金8000-25000元／月
* 前期投入预计10-15万

后来狮子桥开始施工改造，严重影响了人流，这家店的流水骤降，而新店选址等也是一项大工程。

L觉得，这个小生意虽然流水稳定，但也没有多大的想象空间，再加上自己这么年轻，也不甘于以一个小老板的身份一直这么干下去，遂转让了店铺，又回到了北京。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02SKtRicicWjqyGd1G1CXibXVdldbmBCbPIwYRwr3etQhdBp2A37X2Nl4OQ/0?wx_fmt=png#imgIndex=7)

近距离看了L的创业后，我也有几个感想：

首先再小的生意，其实都不容易。像这种店铺，每个月5万的流水，每天12个小时的高强度劳动。

即便按照最高的净利润比例来算，每个月落到自己口袋里的钱，也就1万5千元左右，可能还不如大城市上班族的月薪多。想扩大收入，开分店势在必行。

可是直营分店的话，选址装修，又是一笔不小的前期投入。我们之前在分析👉[如何买消费品公司的股票？](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649608824&idx=1&sn=ea327852270f42a246dac5cdf1404029&chksm=881c16a4bf6b9fb2833c28db40db4f3e17b3119d28f70f523b7e61fc56a2d3dc574ce781dedd&scene=21#wechat_redirect)中说过，线下生意扩大规模的唯一途径就是开分店。

以前看消费品公司的财报，一年开几十家分店，我会觉得，太慢了。但看了L的计划书，才真切感受到开一家分店的复杂程度。即使一年开几十家分店，也是几天一家的速度，如此看来，很快了。

之前有一些朋友留言说想做些小生意开个店，问我有什么建议。这种宽泛的问题实在不好回答，但，希望今天的文章，能让我们更深刻地思考这件事。
