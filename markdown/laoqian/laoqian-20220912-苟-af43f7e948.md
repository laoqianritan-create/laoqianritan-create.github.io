# 苟

这篇推送我特别想写好，毕竟是干自媒体的，对大众情绪的变化相对敏感，能感觉出大家心态都不太好，每当口罩抬头、股市变差**（两者本就相关）**类似的情绪就会蔓延。

大概从「把寒气传导给每一个人」，我开始阅读相关资料，期望从财务、开销、心态方面给大家提供一些**「苟住猫冬」**方面的建议。

找资料时我发现了曹德旺在2007年写给公司员工的吹风信《一叶知秋》，老一辈说话比较含蓄，具体到公司经营上，无外乎砍成本、压债务、攥紧现金流，减少开支，内部降本增效开动员会。

曹德旺写这封过冬信时，形势一片大好，福耀股价当年涨了**145%**，次年美国次贷危机爆发，福耀股价**-80%**，保守经营让福耀在危机中扛了下来，2009年股价涨幅**270%**。

我还阅读了《更富有、更睿智、更快乐》这本书，作者是一名资深记者，花了数百小时深度专访了40多位世界各地的杰出投资者，访谈的主要线索有两条：

**一是如何在市场上活下来，并取得优秀的业绩；**

**二是如何在生活中获得幸福和快乐；**

两件事单独看都已不易，要兼顾更是难如登天。

毕竟无论多勤奋、多谨慎，再出色的投资者也必然会搞砸某笔投资或者倒霉。

金融市场就是生活的缩影，它无限复杂，又难以预测。

就连投资和交易这行的祖师爷——格雷厄姆和利弗莫尔的结局都谈不上圆满。

其实对理财爱好者而言，「过冬」并不陌生，它的另一个叫法是「穿越周期」，几年一个轮回。

尤其对那些**信仰用股票或基金等权益类资产储存财富**的人而言，面对周期、穿越周期是他们一生都要面对的命题。

我建议大家投资基金，尤其在解决自有住房问题后，最好把剩下的财富配置在基金上。当然，房子的容量也足够大，毕竟一套好房子轻松上千万。

但我也要提醒大家，一旦你用股票或基金来长期锁定自己的财富，你未来的命运很大程度上会受金融市场影响甚至掌控。而且金融市场变化无常又无情，会惩罚你性格的弱点，暴露你思维的缺陷。

作者发现，为了完成好以上两大任务，他采访的接触投资者们趋同的方法，比如：

**根据概率做决策、管理自己的时间分配、构建安静的思考环境、主动选择一起闲逛遛弯的人、避免与他人打交道、防患于未然、有意识地避免受偏见和盲点的影响、从错误中吸取教训、避免重蹈覆辙、应对常态化的压力和逆境、承受痛苦的能力、思考诚实和正直、过有意义且质朴克己的生活...**

我知道以上看起来都挺假大空的，但其实都能单拎出来写出不少东西。

比如防患于未然，就有投资者常年保持较高的现金仓位，这降低了自己的β系数，对回报无益，尤其在市场火热时注定落寞。但能确保在寒冬时不会遭遇夸张的亏损、或者低价甩卖，还能抄底弥补前期的低收益。

**每每到熊市时，对现金仓位的思考和结论都很有价值。**

再比如质朴克己的生活，很多投资者都有这个习惯，我把它称为「最低功耗运行」。

事实上，直到我看了自己老妈的[《月账单》](http://mp.weixin.qq.com/s?__biz=Mzg2MDc2MjM3NA==&mid=2247495050&idx=1&sn=b696fb1a33fa6ed145fe686d06b954f3&chksm=ce23d5e3f9545cf52f9179dafc2d035bcd98b6cef45eaed916e993dc7ada22e8f99b056d933f&scene=21#wechat_redirect)，才意识到年轻人所谓的节俭生活在长辈眼中是多么弱鸡...

低功耗运行的一大要点是**刚性支出要尽可能地少**。

很多互联网人士的职场路径顺遂，丰厚的薪酬+股票package让他们不知不觉中有了很多硬支出——孩子教育支出、房子的高按揭、资产锁住了大量剩余现金流，结果失业后发现才扛了几个月，财务就不堪重负，必须卖资产了。

**现金流就像血液，平时习以为常，一旦断了才惊觉这东西能要人命。**

那么，如果你手里有一笔闲置的现金，是否要提前还贷就更要三思——

是把它留存为安全边际？还是消耗掉换取远期硬支出的减少？我的现金流有没有可能断掉？现在有没有更便宜、更具性价比的资产？

再比如承受痛苦的能力，是的，这甚至是一项技能。**坚韧是在市场和生活里获得成功的必要条件。**

财富和现金流当然能解决很多问题，但再有钱、再厉害的投资大佬也始终面对风险和痛苦——这点任何人都不例外。

研究「如何幸福」是我今年的一大输出母题，越研究越发现很多方法都非常唯心。比如：

**幸福=增长（多巴胺）/预期**

幸福感是个比值问题，相比分子端的增长依赖，**分母端的预期更加主观且可控**。如果能在主观上把预期降低，幸福感自然就上来了。

基于此，抛开外界因素不谈，幸福感很大程度上源于内部——多巴胺可以控制，预期可以调节。**反之焦虑也源于内部——自己的感知。**

当然了，财富是最重要的外界因素，**财富能带来的最奢侈的东西，是能自由自在地过真正符合兴趣的生活**——这种状态与欲望无关，却很容易被欲望毁掉。
