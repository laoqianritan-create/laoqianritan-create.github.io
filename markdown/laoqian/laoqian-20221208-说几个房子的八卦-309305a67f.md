# 说几个房子的八卦

如题，和兄弟们唠唠最近观察到的几个跟房子相关的有趣八卦，国内海外的都有。

***1***今年国内的房地产大家都有数，跟2021年相比一个天上一个地下，概括来说就是居民部门的资产负债表收缩。

几个典型：深圳均价从2021年一路跌到现在，上海豪宅也见顶回落了，北京学区房也平淡了，有新房倒挂效应的城市，倒挂幅度也都在缩窄。

至于提前还贷什么的咱们就不多说了，都不是新闻。

***2*** 信贷端，非常友好！重点城市的房贷利率加点基本都变成了减点，有的进入3.x%时代。更友好的是经营贷，我甚至看到了2.x%的20年期贷款，还有3.25%的30年期贷款，搁以前我怎么意淫也不敢想到这份上。一个字，绝！

***3*** 香港房子，今年最大的利空就是美联储加息，因为香港货币政策会紧跟美联储，所以房贷利率今年提升的特别多。但是确实没怎么跌，跌幅还不如2019年作死和2020年疫情，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVY50HVlhH9tdWzskicc4WDKdBu27AgL4quHsM3ls3tuIxmBkvGOPZMQz8XSV7ibic7cXGcicr92zlBMQg/640?wx_fmt=png#imgIndex=0)

另外香港在2019年托底楼市，总价1000万以下的房子首付最低2成，800W以下的房子首付最低1成，杠杆怼到了极致，这种状态下，面对5%+的房贷利率，今年这个跌法我是服气的，确实艺高人胆大。

***4***与香港类似，韩国房地产也能把杠杆玩到飞起，我们之前专门写文章科普过[韩国发明的炒房科技](http://mp.weixin.qq.com/s?__biz=Mzg2MDc2MjM3NA==&mid=2247493546&idx=1&sn=b3e7ab06d674af52bfad8b876141ec4f&chksm=ce23dfc3f95456d5ce0fff976cca01a6de4c1ca308770fca27e09d7e6a7d095f894eceb4a7e2&scene=21#wechat_redirect)。跟随美联储的步伐，韩国今年把利率从0.5%拉到了3.25%，房贷利率也突破了5%+，虽然疫情后涨幅相当夸张，但是今年也没怎么跌，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVY50HVlhH9tdWzskicc4WDKd0EEG7dGqfl2iaRwibhyRQgu8potDRsxjiczTJVfGP3icv3OgicWmAM3APXA/640?wx_fmt=png#imgIndex=1)

***5***日本今年坚持用货币政策刺激经济，日元严重贬值，人民币兑日元升值了40%+，相当于单算汇率日本房子就打了6、7折。根据日经新闻网的报道，来自大陆的房地产咨询量激增，尤其是东京黄金地段的超高层公寓，特别受欢迎。

***6*** 一个规律：**大通胀背景下，大部分实物资产的价格都是涨的，越稀缺越涨。**所以美国房价今年的涨幅也很高，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVY50HVlhH9tdWzskicc4WDKdv2PhIpNdYnS8rRxQXGP7YZBUbpckCnUJ4LbMUh5hsbBlSiacWiak1FuQ/640?wx_fmt=png#imgIndex=2)

看图你们会发现，其实美国房价除了08-12受次贷危机影响的四年以外都是涨的，2020年开启QE4后，房价涨幅的斜率蹭地飙起来了，房价大涨带动了房租提高，房租高企又成了今年美国大通胀最核心的支撑项目。

随着快速加息，现在美国房贷利率已经接近7%了，涨幅也隐有回落之势，说明它涨得没那么猛了，但还是在涨。

哦对了，还有一个有趣的现象：次贷危机后，美国居民部门的杠杆率并没有上涨，自有住房率甚至还降低了——这很反常识，但这个事实说明次贷危机之后，房子和很多美国人的生活已经无关了，也侧面佐证租房市场的紧俏。

***7*** 类似的，在那些高通胀的国家，房子作为实物资产都迎来了很不错的涨幅——**这是一种纯粹的货币现象**。也说明房子确实可以守住财富，至少保证你在社会中的财富顺位。

比如土耳其，80%+的通胀率，翻倍不止的房价，像这样：
