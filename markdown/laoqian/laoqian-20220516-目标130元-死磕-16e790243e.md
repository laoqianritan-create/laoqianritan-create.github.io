# 目标130元，死磕到底！

上周五偶然发现持有的「宏丰转债」猛然飙到了147元。

有点惊喜，一看规模，3个亿出头。

哈~ 瞬间懂了，感谢我游资大哥。

于是在147元卖掉，结果当日收盘涨到165元，今天收盘涨到193元。

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVZ0hNMVhP4XV0zbg5UEZZpav8GpUkFIvuH2vcyF0bvvVAG8z64fquiafsyrSaew4qkyrqyajRmiaw8g/640?wx_fmt=png#imgIndex=0)

当然我心态还好，毕竟这是打新中签得来的，本金就1000块，属于意外之喜。

在知识星球里记录了一下，有球友发来三连问：

你对可转债的打新和持有是啥思路？

中了就一直捂着吗？

如果跌下去又涨不上来咋办？

很好回答：

怎么打？无脑坚持打。

中了咋办？一直捂着。

不涨不跌咋办？死等。

一切的逻辑在于两点：

**①** **可转债价格上130元是大概率事件，****因此我们通过捂着不管押注这个大概率事件。**

我跑了下数据，2016年7月1日至今还可交易的可转债中共404支。

还没摸到过130元的只有71支。

最高价摸到过180元以上的可转债有126支。

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVZ0hNMVhP4XV0zbg5UEZZpaesGiaVxVsII6icJOUXaI1AicsxEatp6VjZXa9ZaAIDexG7aLx9N3VicLgw/640?wx_fmt=png#imgIndex=1)

**②****可转债价格下有保底，至今没有暴雷过，依然拥有制度红利。**

**因此我们会低价摊大饼，押注价格向上的概率。**

进一步地，我还把这种行为视为「耐心训练」。 

如果面对这种友好品种、这种小体量的资金，都没有足够耐心的话。

那么，中长期持有股票和基金这件事对你来说基本就是伪命题了。 

拿不住只有两个原因： 

一是心态上等不及，二是绝对金额大到受不了**（跌幅不高但亏损金额大）**。 

克服以上两种心态都需要一定的训练，而可转债还有以前的港股打新都是很棒的训练工具。

**可转债打新和持有是低风险投资爱好者必玩的品种。**

持有期间还会遇到很多小插曲，比如：

转债市场跟随股票牛市迎来一波大涨，跟随熊市遭遇大面积跌破百元票面值；

还有类似现在5亿以下小转债被游资大哥盯上乱炒一通的福利。

相比股票和基金，可转债是一个时不时就给你送波惊喜的宝藏市场，想亏钱都难。

而我们能做的，就是坚持打新→中签→持有→130以上择机卖掉。

用双低策略摊大饼，像家长一样，用看娃的心态对待手里的一堆双低可转债，静待他们长大成人，离开家门。
