# 服务业未来大有可为！

**●**

今天看到一个中国互联网公司的排位：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2NTR1z0VllX24yBoCtRib631lvJydNtejHB3OqOZ4DQqPKMbST5icxtIibn9yGia8mpBhNpnkypS8vkTA/640?wx_fmt=png#imgIndex=0)

当然这种排名千万别较真，比如百度也就剩下上古了，哪里还是巨头？为啥没有快手京东网易小米？瑞幸这种公司也能算小巨头？

说实话，我看到这个榜单还挺感慨的，因为这批互联网大小巨头每家都提供了海量的**工作岗位和赚钱效应**，社会价值太大了。

像我这公号狗就是腾讯生态里的一员，多亏了微信公众号我才能心安理得地在家吃软饭。

在北京这几年我结识了很多湖南朋友，陆续都回长沙买房生活了，做什么呢？淘宝客、公众号、拍抖音、做小红书，非常接地气。

我最近在准备教师从业资格证，科目是初中数学，备考材料来自快手，一个叫「阿柴哥数学课堂」的博主出了份初中数学知识点串讲，时长12个小时左右，只卖9块钱。我买了这个课后再也不想买好未来和新东方的股票了，学而思网校单单一个学期的数学课程就要一两千块。

说真的，我特别希望这些草根教育博主有一天能把好未来们干死！干不死也能逼着它们降价。

前阵子去常德参加婚礼，发现美团饿了么快递小哥的招聘工资远高于常德平均水平。美团甚至有自己的学院，教餐饮、外卖、美业、酒旅方面的职业技能，培训人数超过3000万人。

还有滴滴，中老年男性就业神器，只要有一辆车龄低于6年的小轿车就能做滴滴司机给家里创造收入。对他们来说，如此友好的就业岗位已经很难找到了。还有58到家这种公司，中老年女性就业神器，养着中国工资最高的一批蓝领阿姨。

在拼多多上开个人店铺，保证金只需要1000块钱，门槛远低于快手。抖音快手也极大降低了拍摄剪辑视频的门槛，成为东北轻工业支柱。

我对这些互联网公司特别有好感，高瓴资本有个著名的投资逻辑：

**社会早晚会奖励那些**不断地疯狂创造长期价值的企业。****

满足别人的需求，就是创造社会价值，然后才有商业奖励，才能赚钱。

只要你相信这个道理，就一定会利他。帮别人，有利可图。

**未来的服务业大有可为！**

我在这个公众号上写完文章、回留言陪聊也是一种效率极高的服务。

**●**

补充两个新能源汽车行业的最新消息，我持有相关基金嘛，肯定比较关注。经过三年的赌气定投，一不小心把新能源汽车基金买成了长赢以外的第二大基金持仓。

周末有关今年新能源汽车补贴是否会进一步缩水退坡的传言一直在发酵，最后工信部站出来实锤**今年补贴不会大幅下降**。利好。

你们可能对补贴没啥概念，我举个例子——2018年北汽新能源净利润1.55亿，少得可怜。但同年各种补贴、拨款合计54亿，是净利润的35倍。你们感受下...

2018年国家给这行补贴了543亿，2019年补贴313亿，今年新能源车的预期销量是160W，就看能部多少钱了。

2019年11月新能源汽车销量同比下滑43%，业绩依然很烂。**去年底到现在的这波涨幅主要是预期很热**，特斯拉这个大利好实在太激动人心。但是今年的业绩能否跟上还需要后面再看。

说实话我觉得补贴还不如彻底退坡呢，这样最大的不确定因素就被干死了。未来业绩可能会差，但极健康。现在行业天天靠兴奋剂吊着，谁也不知道光凭体力究竟能跑多快。

比亚迪今天涨停了，原因是取得了重大技术突破，开发出了「刀片电池」，这种电池体积更小，安全性更高，成本更低。注意这不是炒概念哈，是实打实地创新。

我之前在研报里看到过一组数据：过去5年，全球电池成本每年下降了16%。

**原材料成本降低是行业普及阶段的必要条件。**特斯拉这波爆吹的一大原因也是零件国产化后综合成本进一步降低，一辆model3只需要20来万。
