# 俩娃高贷家庭

看到特别写故事的「每日人物」写了俩娃高贷家庭的困境：

由于同时承担育儿和月供压力，原来的中产生活难以为继，变成了「穷中产」，有钱，却苦逼。收入的波动，对未来的不确定，贷款和育儿的负担——这就是中产生活的脆弱基座。

我身边也有一些类似的案例：双职工俩娃高贷家庭、双创业三娃高贷家庭。

我也属于这个群体：一职一创丁克高贷家庭。

虽然我一直以个体户自居，而且正在提前还贷。

说说我的观察——

在一线和二线城市，俩娃必高贷！ 

为啥？ 

每增加一个家庭成员**（人或宠物）**，都会新增对更大居住面积的刚需。

再考虑到未来孩子空间以及父母过来照顾，俩娃家庭通畅三居起步。这意味着你至少要有一次置换，随之而来的就是大房子带来的高贷。

如果还愿意为学区房支付溢价，那负债就更高了。

俩娃，意味着6岁前的精力和时间投入，6岁以后的教育资本支出**（再次感谢双减）**。 

而对于一个中产家庭而言，其支出公式是这样的： 

**可选消费=劳动收入+资产收入-月供-保费-必要开支**

另一方面，中产阶级又需要用可选消费来完成身份认同，但你从上面公式找找，留给可选消费的，也就那仨瓜俩枣了，这帮人当然要上网哔哔赖赖。 

这还没完！

大城市中产家庭大多晚婚晚育，尤其是那些自己爬上来的、外地的，前期都忙着资本原始积累了，谁有空生娃？ 

等这些人到了俩娃高贷的阶段，再过几年，爹妈又要过来索要精力了，钱倒好说，身体开始出小毛病了。

对未来的担忧感会进一步袭来。 

我还没说家庭经济支柱所要面临的行业波动和经济周期呢~ 

双职工家庭的职场天花板、年龄、失业风险；

双创家庭的经营风险、债务风险... 

算了算了，不给大家添堵了。

总之：

**向60后学习低功耗运行，多规划多未雨绸缪，好好调整预期。**

当然了，大城市、结婚、买房、生娃，你放弃其中任何一样，人生都会容易许多。

**都有代价，要能自洽。**
