# 下坠的缩影

这两天被媒体广泛报道的姑娘，已经有点「缩影」的味道了...   
  
经历过14~21年的我们，都很容易高估了自己的理性α，也轻视了过去的运气β。   
  
而很多95后没经历过这段好时光，这又成了一种代沟，人们很难切身感受到他没经历过的事，也就不容易与亲历者共情——你们这帮老登儿，老跟那追忆个什么劲呢？哪来的底气乐观呢？  
  
时代周期一粒灰，个体命运喜与悲。
