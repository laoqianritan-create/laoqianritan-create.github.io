# 不碰商铺，不碰商住

如题，不碰的原因是，明明有更好的选择。

老朋友都知道，我们反对简单的定性结论，推崇定量分析。

那就来分析一下：

如果你是刚需自住，我觉得对错意义不大，可奢可简。买大四居都可以，只要你喜欢。

对刚需来说，可能地段和户型更重要一些，因为这关系到日常居住的幸福感。

但从投资角度看，房子是商品啊，得考虑谁来接手的。

那我当然希望，投资的房子向主流人群，主流户型靠拢。

因为**主流意味着**更好的流动性、**更高的关注度和交易量、更高的溢价可能—供需决定价格。**

谁是买房的主流，谁是租房的主流？人群画像是这样的：

所以，你懂我意思了吧？

40年产权，最低50%首付（据我所知北京要求全款），更高的交易成本、租售比虽然高，但也有空置期等不确定性来拉低。最要命的是，涨幅也一般！

请你告诉我，为啥还要投资商铺和公寓？

同样的钱，去买一套刚需户型不好么？好租好卖。

![图片](https://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02b6ic60tUu5mmkiaW840DDlQZbpDx6FrKZw80myPXshlIiamrskPzvYEwg/640#imgIndex=4)

还有一些很普遍的问题，比如：

***1*** 买房的话，多背几十万贷款，没问题。租房的话，多付几百块房租，我得考虑考虑。

站在租房者的角度，一居室是最理想的户型：不用合租，绝对私密；非常适合一个人或者小两口，哪怕有了宝宝，也能将就一下。

站在刚需买房者的角度，只要首付还能凑，都想买个两居室：万一有了孩子，爸妈朋友过来住几天呢？

***2***买卖时，房子的所有缺点都会被介意、被定价；出租时，房子的所有缺点都会被装修弥补；

让一套房子好卖不容易，让一套房子好租很容易。

***3***什么是刚需？

其实我的刚需是三居室，但我连两居室的首付都没有。

刚需不是你想住什么样的房子，是你买得起什么样的房子。

三居室当然是很多人的刚需，但显然这些人没有想买一居、二居的人多。

在一线城市，最典型的主流户型就是老破小，所以它才流通性这么好。虽然又老又小，但是它地段好啊。

**房产交易的因素，除了房屋本身，还有附加在房子周边的各种资源。**

***4***理解了上面这句话，就不难理解商铺了。

本质上，商铺的价值由人流量决定。人流量大，几平米的周黑鸭也能创造月流水30万的业绩。

住宅周围的资源都是静态的，学校、地铁站、医院它不会跑。

但对商铺来说，人一直在流动，这是最可怕的。商铺有太多不可控因素了，就拿我上班附近的朝外soho举例：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2Nnbl0m3DcvFiciav84fwRSbIAmwb8pNXPYYCicIEUhfTrdu8bahKC9OcbElEyKtUic6ByibW9IckLceNg/640?wx_fmt=png#imgIndex=5)

右侧商铺的人流量会数倍于左侧红框里的商铺，原因在于，左侧的楼梯挤压了走路空间。

太多因素都可以改变人流走向—这些细节，拿着位置图和户型图是根本看不出来的。

以上种种，都不如投资一套刚需户型来得踏实容易。
