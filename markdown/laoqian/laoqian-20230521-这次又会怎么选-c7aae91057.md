# 这次又会怎么选？

***1*** 每次面对下面这张图时，我都会好奇：

**究竟是什么样的人会在1996年以前买这种复利8%以上的保险呢？**

这帮人怎么就这么聪明呢？

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVaQSdszzDwTETaj2icDp6WoKXymLHKQL1PK97mtqf4cRKYpu6YaACAc2XzMMFicS9IlQ6yEQZlKpC9A/640?wx_fmt=png#imgIndex=0)

于是我又去找了些资料，补充了这方面的颗粒度。

当时之所以能把利率定得这么高，是因为我们连续经历了两场非常严重的大通胀：

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/M7fHtGOlzVbXxibM78nVicchDHd5wYAyCzS4l9I9hLuRo1d0oLApnG9icj7dM0icKpuJFHsbRuzajFDUs5YFY60kOA/640?wx_fmt=jpeg#imgIndex=1)

尤其是1992~1994年期间，当时的人们形象地将这段经济过热总结为——

**四热：**房地产热、开发区热、集资热、股票热；

**四高：**高投资膨胀、高工业增长、高货币发行和信贷投放、高物价上涨；

**四紧：**交通运输紧张、能源紧张、重要原材料紧张、资金紧张；

**一乱：**经济秩序特别是金融秩序混乱；

为了平抑通胀、稳定物价、给经济降温，人行大幅加息，于是才有了存银行1年利息超过10%的历史奇观，以及保险行业的这段高复利奇迹。

***2*** 那我就忍不住意淫了：

**假如我活在1996年，会不会去买复利8%以上的保险？**

咱们这不是爽文剧情，得尊重基本现实：

根据国家统计局的数据，1996年我国城镇职工的平均年薪酬收入为6210元/年，一个月在五百多块左右——这就是我的收入。

活在1996年的我，刚经历了人生中第二场大通胀，2年前的通胀率是24%，去年是17%，今年也足有8%。

什么都在涨价，生活成本大幅提高，过日子都有压力。

而且我身边很多国企工友都在下岗，我自己所在的厂子效益也不咋地。

那时候我国还没有加入WTO，说实话，也没有什么所谓的自信，对未来肯定谈不上乐观。

如果我当时有2万元的存款，银行1年期存款的利息大概9%，每年光利息就有1800元，快赶上4个月工资了。

结果有人让我买保险，说什么复利8.8%，收益可吓人了，但是要几十年后才能拿到钱。

我会买吗？扪心自问，我应该不会买。

**因为1996年的我无法预测接下来的20多年全球化会突飞猛进，不知道1999年存银行1年期利率只有2.25%，不敢想未来全球都会进入低利率时代，无法预料钞票会变毛，更不知道现在的保险收益全托了高通胀的福，未来不会再有...**

我唯一能想到的买入理由，就是亲戚朋友逼着我买的...

我查了资料，那时候卖保险可比现在野蛮多了，是真的贴身销售，不买轻易不放你走。

***3*** 再看看开头那张图中的第四个红点——

现在保险行业的预定利率又迎来了重大变动节点，将从3.5%的水平进一步降低。

现在的你，有了更多的理财知识，能看到更多的历史参考样本和经济规律，又会做出什么样的决策？

我整理了几款代表性产品，都很能打，至于何时停止入单，完全看监管要求。

真诚建议大家：**如果你确定自己现在或者未来一两年有买保险的需求，真的不如趁着现在预定利率还未调整，在这一两个月完成投保，因为同样的价格能买到更高的保额或收益。**

这次不是单个产品停止录单，而是所有按照3.5%预定利率来定价的产品都要逐渐退出历史舞台。

另外，严肃提醒大家一定要确定自己真的有对重疾或增额寿险的需求。自己的钱真的能满足增额寿或年金险的长期锁定——这两类保险的优势都在远期而非现在。

如果您持有大额存单、5年定期存款、长期国债等长期储蓄类产品，真的可以考虑往这种储蓄类保险上搬家，它们可以长期锁定高利率，越往后越有优势。
