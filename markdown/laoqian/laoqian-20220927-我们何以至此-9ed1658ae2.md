# 我们何以至此？

***1***值此逆全球化轰轰烈烈之际，让我们回望昨日的世界，看看来时路。历史学即是未来学，回顾过去，有助于更好地预测未来。

本文力求用最凝练的信息从头复盘全球化的历史进程，其实也是资本主义全球扩张的明线。

***2*** **16世纪末~一战**

地理大发现→欧洲开始全球殖民扩张→输出贫困人口→占有资源品→资本原始积累→瓜分殖民地冲突→英法老牌打压德日新秀→一战 

欧洲在海外复制希腊罗马的奴隶制，对内“自由平等民主博爱”。

***3*****一战~二战后民族国家独立运动和产业跨国转移**

二战后，民族国家在美苏冷战的背景下纷纷开始自主独立。

先发国家为了降低劳工成本，缓解阶级矛盾，环保压力等，开始向民族国家转移低端制造业，以低成本获得发展中国家的低廉劳动力和自然资源，把劳工矛盾、环境代价转嫁给发展中国家。 

先发国家继续掌握核心技术，国际货币金融、贸易制度的主导权。 

这个阶段也是一种发展中国家的时代背景，其中东亚模式最为成功。

***4*****苏联解体~2017年**

全球化进入新高度，中欧俄美四边嵌套，经贸深度纠缠。 

核心国家的资本跨越了地缘和意识形态壁垒，在发展中国家赚取了巨额利润。

利润回流又客观上促使资本主义核心地区加速金融深化，并多次催生出各种资产泡沫，不断引发金融危机。 

日本发明QE，美国将其发扬光大，借美元的国际储备货币地位，用4轮量化宽松来缓解危机，发展中国家承担金融无序和财富大规模流出的风险。

***5*** **特朗普上台至今**

全球化开始逐渐脱钩，美国和欧洲试图把中国和俄罗斯踢出四边嵌套的全球化体系。 

美国开始退群，贸易战，科技卡脖子，新一轮加息周期向外输出通胀危机

***6***三种力量的碰撞和重塑——

**政治力量**，内循环，自主可控，保护主义，民粹抬头，地缘冲突。

**经济力量**，虚拟化金融扩张，金融资本过剩，贫富差距扩大，债务高企。
