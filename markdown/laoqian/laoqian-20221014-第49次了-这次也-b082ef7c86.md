# 第49次了！这次也一样

今天的几个想法：

***1***不要预测！不要预测！不要预测！**随机波动是中短期唯一的神。**

***2*** A股第49次收复了3000点失地，这次用时3个交易日。像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVZs8NL8mOkuTysboTltOnxJO11C8w5B0ORAMVjMibRp7Hf2rcR6tbTJ627HXGwDWxRX7BEy93wHicMw/640?wx_fmt=png#imgIndex=0)

每次3000点的背景、叙事都不一样，每次都有新担忧。

但价格只有一个维度，要么上要么下，要么买要么抛，每次都一样。

当然了，下手标的也可以每次都不一样。

***3***每次3000点买入主动型基金，即便下次回到3000点，还是赚钱的。像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVYoquEvxnJQUiaXc3rrj0oyBtLwiaTSfG0k1J6kgG3kn4OqBqHnAH2vhAz2fXtqUbyibunzy1bMzbHIA/640?wx_fmt=png#imgIndex=1)

***4***我们看不到且可能发生的才叫风险@香港楼市@英国养老金危机

全市场都在讨论的、有预期的那些，都叫**风险被引爆**。

***5*** 错过暴涨的那几天，长期复合年化回报一定是平庸的。

**1%****的暴击交易日可以贡献总收益的****60%****以上。**

错过暴击，几乎白玩！今天就是暴击的一天。
