# 那个日子到了

***1***从5月份传言至今，保险行业都在等的窗口期终于定了。

根据财联社的报道：

**「监管窗口指导险企7.31前下架定价利率大于3.0%的保险产品，包括——增额寿、年金险、重疾险、保底2%以上的万能险等。」**

经过近三个月的狂轰滥炸，相信大家对此事已经不陌生了。

**调整预定利率的核心重点其实就在年金+增额寿+重疾险上。**

其中成人重疾的预计涨幅**10%**，少儿的新品看下来涨幅也就100-200左右，其他的涨价的幅度也相对小。

受影响最大的就是增额寿和年金险，因为收益是实打实的从3.5%变成了3%以内，现金价值长期差了**20%**左右。

***2*** 我在这两个月已经写了不下10篇稿子来介绍，其实也说不出啥增量内容了，本文最后**给大家提供三个看待****储蓄险****和****健康险****的框架**，这些内容你大概率在其它地方看不到。

**框架一：**

**人生全阶段现金流框架**

增额寿本质是自动复利的持续增值**账户**

年金险本质是自动复利持续释放的**现金流**

未来我会专门再写一篇文章来解释上图，现在大家只需要明确一个概念：

**过日子就是让现金流支撑我们走过人生的每个阶段。**

**框架二：**

**保险在家庭财富中的位置**

同样的，我用红框在下图中标注了保险的位置，像这样：

左侧的「保险账户」对应增额寿+年金等储蓄险

右侧的「风险」对应医疗+意外+重疾+定期寿等健康险

**框架三：**

**健康险保护的到底是什么？**

它分别保护了我们的**人力资本**和**金融资产****（家庭财富）**，像这样：

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/M7fHtGOlzVb8He3j35UpHtM4ibNclofrh1AkIFP9EzicKaAibYcnQhTZG6WkWCSexgibFgc2IcZLQCiagW9yj0HJBDQ/640?wx_fmt=png#imgIndex=2)

为什么要保护这两个要素？

因为从整个生命周期来看，**一个人所拥有的总财富=手里的现有资产+未来的收入**

这里还有明确一个原则：

**人力资本>金融资产**

**健康险的优先级>储蓄险**

**所以，如果目前收入有限，应该把有限的资源优先分配给健康险。**

储蓄险虽好，但如果需求和产品不匹配，体验会很糟糕。

它主要适合三类人：

👴 为养老做准备，给自己攒一笔用来养老的钱。

👶 为孩子攒一笔钱，具体用途不明，但可以极大拉长久期。

💰每年都有定期存钱的习惯，拿增额寿当一个长锁定期无风险的理财产品，把超额储蓄往储蓄险中搬家。
