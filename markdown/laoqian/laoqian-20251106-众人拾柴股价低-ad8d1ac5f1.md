# 众人拾柴股价低...

随便找了几家知名公司，看了下股价和股东人数的互动关系。  
  
结论一目了然：就是股价和股东人数呈现出肉眼可见的负相关性。  
  
老话讲「众人拾柴火焰高」，但到了股市里则变成了人越多越坏事儿。  
  
从筹码分布的角度也好理解，人一多，心容易散，队伍不好带了。  
  
为啥心容易散？  
  
配图明明白白告诉我们了：  
  
股东人数大涨往往发生在股价从阶段性高点回撤之后。  
  
说人话，我A股民整体是喜欢抄底的，牛股一回撤必有人冲，每次倒车都能接上人。  
  
上车之后继续跌，然后产生套牢盘，一套牢就装死，一回本就想卖，一上涨就心虚，进而加剧抛压。  
  
所以，牛股更像是少数人的共谋，而不是很多人的共识——  
  
三根K线改变信仰，任何超级大牛股的日度涨跌分布都是相当随机的，且涨跌天数基本对半开。  
  
价格信号的随机游走本身就会瓦解队伍，难有很一致的共识。  
  
这让我想Nick之前在播客图8里提到的一段投资(机)四问，其实就是在追问筹码的分布情况。  
  
我把这四个问题问题放上来，大家以后再想干一票时，可以在心里过一遍，自己打打分。  
  
1️⃣面对这次投资你是否觉得非常紧急？  
a.非常紧急，一天都不能等  
b.紧急  
c.不紧急  
d.有点没底  
e.内心慌得一批  
a-2, b-1, c+0, d+1, e+2  
  
2️⃣这项资产的量价近期的真实趋势如何？  
a.大涨到破圈  
b.在涨  
c.平稳  
d.在跌  
e.大跌到破圈  
a-1, b+1, c+0, d-1, e+1  
  
3️⃣你身边的朋友或者社会上的人是怎么看你要做的这笔投资的？  
a.别人没怎么想过，不理解  
b.一致不看好  
c.倾向于不看好  
d.无所谓  
e.倾向于看好  
f.一致看好，想问你代码  
a+2, b+1, c+0, d+0, e-1, f-2  
  
4️⃣这样的资产你身边持有的人多不多？  
a.大家都持有  
b.越来越多的人在买入持有  
c.持有者很少但大家都想要  
d.持有者少，关注者也少  
e.没讲过什么持有者  
a-2, b-1, c+0, d+1, e+2  
  
得分越高，是好机会的概率越高。  
  
其实何止是股票，好多“点子”都可以用这四个问题评判一下：  
  
比如以后我要不要当个博主？  
比如我要不要去卖香港保险？  
比如现在是股票牛市吗？
