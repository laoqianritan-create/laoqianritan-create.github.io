# 记人生首次和零零后说话

朋友们，我约了一位零零后来《面基》录了期播客，这是我第一次和活的零零后说话。

欢迎大家收听：

👇👇👇

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/M7fHtGOlzVZdpib7hL9qRxYA9hDhKIvnPiaiasBsGicWllcbeFlc9H1jaOoDVnV3wOGzxd3ayIBqHZn5Y4KnFxicOpw/640?wx_fmt=png#imgIndex=0)

平时我一直都觉得自己是个年轻小伙儿，但面对下个代际时，感觉自己就是“老哔登”了，而且非常不敢给**（自以为是的）**建议，不敢表达。

于是我试着问了自己几个问题：

**零零后的22/25岁~40岁面对的是什么样的经济增速平台？**

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/M7fHtGOlzVZdpib7hL9qRxYA9hDhKIvnPdInObj1Nh2xQvIDrITG0TcMtNOLscA5iaKQYuWy4Lfe9RhDy77u9ejA/640?wx_fmt=png#imgIndex=1)

**能否有更多像互联网、新能源汽车这样的优势产业崛起从而提供大量优质岗位？**

我希望如此。

**能否还有更多的类似B抖快红这样的流量红利提供一些另辟蹊径的机会？**

这里既拼天赋又拼运气，而且流量红利来得快，去得也快。

**年轻人的三座大山——就业、住房、婚恋会怎么样？**

我知道，但我不想说。

**以学历通胀为主的同辈竞争会缓解吗？**

如果没有增量，内卷是徒劳的。

最后，人类社会的循环，其实也是人状态的循环。

社会：好时光**→**蠢人**→**坏时光**→**伟人

人：好状态**→**做蠢事**→**坏状态**→**做对的事

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/M7fHtGOlzVZdpib7hL9qRxYA9hDhKIvnPGjPLsNdYCD3PtcXj4g1EYtoHjltTYAgq8juaoxQbUXB7cp3WAichv3A/640?wx_fmt=png#imgIndex=2)

所以，人在糟糕的日子里，不好的状态里做什么，比在好日子里做的事更重要。

我坚信个体奋斗是可以决定人的下限的，当然，是社会和运气赠予了你上限。
