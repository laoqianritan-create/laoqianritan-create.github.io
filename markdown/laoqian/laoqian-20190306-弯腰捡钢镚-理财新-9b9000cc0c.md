# 弯腰捡钢镚：理财新人的另一条上手路径

![图片](https://mmbiz.qpic.cn/mmbiz_gif/ibw8b04QVx2M7PTAr8JHoc98wCJlkDyXxsA0LtNpBgqhicVxmxOENpDia40416PMnQfU6BgCLN0bVtwGJS9LMhIJQ/640#imgIndex=0)

对于刚接触投资理财的读者，我之前推荐过一条很普适的路径：

**固定收益产品—指数基金—股票组合**

大概思路是这样的：

通过固收上来就感受赚钱的滋味，树立信心。

通过指数基金感受择时、长期持有、亏损。

通过股票感受公司分析和更大的波动。

写得久了，我认为另一条路径也很不错。

我把它形象地比喻为：**弯腰捡钢镚**。

最典型的标的比如「可转债打新」、「港股打新」。

特点是胜利比较高、本金比较少、单次盈亏的绝对金额不大，偶尔还能碰上亏损。

需要勤关注，勤操作，其实非常适合刚接触投资理财的新人。

为什么呢？理由有四：

***1*** 门槛低，上手容易。

港股打新一两万港币足矣，可转债打新中签普遍也是十张二十张左右，一两千块的事儿。

***2***低成本试错，感受交易。

比如港股打新，单只新股的入场费最贵也才5千多港币，亏损10%也就500多块，完全可以承受。

但是我们却能通过它充分感受交易，很多老手也会因为贪恋收益或亏损而卖飞。

***3***能让新手摆正预期。

知道投资一定有亏损，「高胜率」也不等于「包赚钱」，但可以在高胜率标的上通过多次尝试，赚到概率的钱。

新人买固定收益产品，上手就赚钱，现在看来，有些害人。

因为新人很难在固定收益产品上认识到风险，也没尝过亏损的滋味儿，想的都是怎么拼尽全力把收益再提高一些，以后可能栽大跟头。

***4***一年下来，回报也不错。

虽然单次盈亏的绝对金额不大，但是两种标的都需要频繁操作，集腋成裘。

尤其是港股打新，一年中能遇上一两次翻倍股，本金翻倍都有可能。

这两种标的的回报，可以看成是对新人遵守纪律，有执行力的奖励。
