# 当抠门省钱变成一种美学

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2OpdyNkSs1AXAqpWawpibm6OicQ8ib0zmVVVQibNVYOShgI2h8sjYl1w6OGh2ibeyOvxe9axJUd1SiaAmdg/0?wx_fmt=png#imgIndex=0)

老钱现在是互联网金融这行的广告狗，平时总会找些与钱有关的广告来看。今天分享一组印象最深的，广告主是台湾全联超市，创意执行方是台湾奥美。

去超市采购这种行为更多是会过日子的中年人的标签，很难于年轻人产生关系。但奥美的聪明之处在于，把这种精打细算的态度上升到了生活美学的高度。这次活动的主题是 ***#****全联经济美学 #***。

最主要的传播媒介是印有“全联福利中心”的购物袋—你看，全联很聪明地把自己符号化了，且所有的用户都变成了一种媒体，不断通过这个符号去传达一种生活理念。年轻人很可能排斥***“精打细算 ”***这种标签，但又天然地向***“有态度 ”***等符号靠拢。老钱认为，这正是全联与奥美的高明之处—也验证了一个说法：洞见是广告最有效的切入方式。

另，都说台湾是文案的天堂，真的如此。
