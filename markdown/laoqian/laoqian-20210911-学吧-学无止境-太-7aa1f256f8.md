# 学吧，学无止境，太深了

今天逛公园，突然想明白一个事。

就是如果加入「时间」维度，「风险」的性质会有很大变化。

论风险程度，我们一般会默认为：

股票>债券>现金。

如果看中短期的话，这个结论当然成立。

但长期呢？谁的风险最大？

我想排序应该是这样的：

现金>债券>股票

什么意思呢？

讨论短期风险，我们关注的是波动，隐含意思是**亏损的可能性**。

但长期风险的隐含意思则变成了**购买力的降低****（M2）**。

比如现在买入，拿3年，沪深300指数和现金，二选一，你选哪个？

不用想也知道哪个预期回报率更高。

**现金的中短期风险最低，但长期风险反倒是最大的。**

它不是没风险，只是不体现为账面亏损。

润物无声，很难感受到。

股票**（指数）**的中短期不确定性最高，但长期风险反而最小。

像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2Mtj8ib5YsBJJz1fibLT6gtwYn2qAvoAfzf0oB5VS35xXxnCZ0HSsd4Yib7dy23BzbPaCPX7rVw3BXDA/640?wx_fmt=png#imgIndex=0)

这提醒我们在现实生活中**不要因为过度恐惧风险而过度长期持有低收益率的资产**。

这种行为本质上是刚出狼窝，又入虎穴。

同时也提醒我们，在投资中引入时间维度的好处：

**它会改变我们对风险的理解，增加对确定性的把握。**

有的人吧，接受不了任何波动，买个银行理财都瞻前顾后，比如妈妈。

还有的人吧，接受不了自己只是个无法战胜市场的普通人，每天不拍单子做交易浑身难受，专挑风险和刺激的干，比如爸爸。

不管是谁，只要你带资入场了，就必须花时间去思考很多充满哲思的深刻命题，比如：

如何认识自己？如何应对不确定性？如何消除自己的妄念？

怎么定义速度？多快算快？多慢算慢？什么样的速度是合理的？

如何搜集信息？如何在有限的信息里做选择？

如何看待竞争？哪些是线性的？哪些是失控的？哪些是稀缺的？

还有哪些，欢迎大家在评论区说说。

投资理财就是这么好玩，很多老生常谈的话题，你细品品，还挺有回味的。
