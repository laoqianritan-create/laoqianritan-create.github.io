# 芒格说他恐惧

● 

今天开始，大A股第一个指数「上证指数」正式启用新的编制方法。

具体影响我在[《股市天花板已被掀飞》](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649615489&idx=1&sn=a7c68b4013b74212f75a59a85830f402&chksm=881c285dbf6ba14bb32412258e465c947d49af9a0edc84104395e74a9cc7e9450a7ced023100&scene=21#wechat_redirect)中分析过，不再赘述。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MPPbU9hBDPukUGBOQJficWribVkpMf3gUSVicLTRVC4O3M02sGLuTuCicOxSuTdYo68AszoLog7PCUkg/640?wx_fmt=png#imgIndex=0)

虽然上证指数没啥实际作用，但它已经成为灯塔一样的符号，对大部分股民而言，A股=上证指数。像什么3000、6124、5178，你一说，大家都知道啥意思。不用否认，在股民心中牛市也是和上涨指数点位直接挂钩的。

从上图你们也能看出来，上证指数的底一直在提升，加上使用新编制方法后，上证指数还想再回到3000点以下还真的挺费劲了。

另一方面，上证灯塔更像一个信心和情绪指标。真正有参考价值的是横跨沪深两市的沪深300指数，举个最直观的例子，大部分基金的业绩基准都是和沪深300PK。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MPPbU9hBDPukUGBOQJficWrYbJe2TKoicqL6aicp0QTRiaASiampUbiaHXUW7Jhia7x6ZG0k5BPUqpDzHag/640?wx_fmt=png#imgIndex=1)

如上图，2015年的大顶是18PE，今天收盘是13.8PE。

贵了贱了的，你们自己衡量下。

明天科创板50指数（000688）将正式发布实时行情，成分股名单如下：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MPPbU9hBDPukUGBOQJficWrZKhcybYg6xEl4JHMesF72dywkqTH3KuibLyhaV4Bge1LJUzNQ5GRYFQ/640?wx_fmt=png#imgIndex=2)

至于跟踪这个指数的基金，华夏是第一个申报的，不出意外第一个批下来的也是它。

后期还会有纯科创主题的主动型基金——80%的仓位都要买科创板股票。

根据历史经验，像科技、医药这种高投研门槛的行业，优秀的主动型基金可以大幅跑赢行业指数基金。这方面买医药基金的读者应该深有感触。

至于解禁潮，不是说卖就能卖，想套现还得发公告，估计未来一个月会看到一批解禁公告。所以，就看是科创接盘基金募资块，还是大股东们跑得快了。

● 

美方要求要求关领馆的事，个人感觉情绪大于实质，相比制裁和列清单，这事没啥实际影响。

懂王想鱼和熊掌兼得——鱼是中美第一阶段协议赶紧落实，根据协议，中国得从老美手里买农货买能源。熊掌就争面子问题，比如香港问题、南海问题、加清单等等。

鱼和熊掌兼得的最终目标就是拿下大选。不顾疫情坚持复工也是为了大选，毕竟懂王现在的全国支持率低于拜登。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MPPbU9hBDPukUGBOQJficWrNicKZ4wl1KqX6UrXic2Bv4OLQXa1bsOLh4m7FTS9D9rMeu2e58jK6WZg/640?wx_fmt=png#imgIndex=3)

当然，不管谁赢，对华态度强硬都有利于选票。所以硬是毫无悬念的，不确定的是能有多硬...

除此之外，另一大外部风险因素就是美股。我举两个例子你们感受下：

30年前，东京的房地产可以买下整个美国土地。

30年后，纳指4位带头大哥——苹果+微软+亚马逊+谷歌的市值总和可以买下整个日本股市。

第二个例子，最近有一场芒格出席的对话。主持人向芒格问了那个经典问题，2020年你是恐惧还是贪婪。

芒格说：我现在不考虑这个问题了。因为当一个傻瓜无论做什么都能赚钱的时候，这个问题失效了，现在就是这个样子。市场上确实有很多愚蠢和错误的行为，那些不谨慎的人永远会面临最大的风险。

翻译一下：我恐惧。

横向比较，中国今年的基本面之好全球公认。因为外部风险因素导致的下跌都是很好的上车机会。
