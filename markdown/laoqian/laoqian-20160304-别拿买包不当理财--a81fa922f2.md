# 别拿买包不当理财 真正会买的都赚了

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2OpdyNkSs1AXAqpWawpibm6OicQ8ib0zmVVVQibNVYOShgI2h8sjYl1w6OGh2ibeyOvxe9axJUd1SiaAmdg/0?wx_fmt=png#imgIndex=0)

总有人问，为什么女生喜欢买包包？因为***包治百病***！

很多人都觉得包包是消耗品，没有人会去想到投资。但一款包其实每年都会升值的。

升值渠道有两种。

一种是：***通过购买限量版、有年代意义的版本的奢侈品包***——但这需要许多的专业积累。

法国时尚专家Penelope说：***大牌设计师设计的包正在以平均每年8%的增值速度增长。***

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2OpdyNkSs1AXAqpWawpibm6OfewnyzBFrq8QQ6mtLE5NA3w6YQQxuM3SKeiclHsaXax5qq0a0bf9ZBA/0?wx_fmt=png#imgIndex=1)

爱马仕的这款Birkin Bag柏金包据说***永不跌价***，在2011年美国Heritage拍卖行举办拍卖会上，这款Hermès的红色鳄鱼皮Birkin手袋以20.3万美元(约合人民币125.8万元)的成交价，创下了当时该品牌手袋拍卖最高成交纪录。

之所以拍卖到这么高的价位，因为它是***限量定制款***，就是说，你有钱也未必排得上号。一个包包的制作周期在半年到一年，从基本款到稀有皮质，价位从5万到30万不等。

如果你买回来不用，没有任何损伤，就可以坐等升值了；如果是用过二手的，就要看包包的损伤程度，一般售出在6—7折，但不会低于3折，这就是大牌的好处。

女人对奢侈包包的执着就像男人对运动鞋的喜爱，是身份的象征，我就喜欢看你讨厌我炫耀又干不掉我的样子。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2OpdyNkSs1AXAqpWawpibm6O7BgcHbdFtVoCShuSaZM7iaGzpyIvc4hicJglCHS1E00TIs1uY87MUxWw/0?wx_fmt=gif#imgIndex=2)

另一种升值原因可能更大众——***包的逐年定价会走高***。不过随着物价膨胀，走高不会使你在二手奢侈品市场赚多少钱。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2OpdyNkSs1AXAqpWawpibm6ODjgHlqaBjaxEAbOUs4NKYobJ3KWiaYWGO02Xic640c7gP629hYbs3BzQ/0?wx_fmt=png#imgIndex=3)

这款包包是不是很眼熟，某宝上39.9包邮。它出自香奈儿2.55手包系列，2007年黑色小号牛皮售价17600人民币，近几年售价已达36000人民币。

对女人来讲，打折的东西和不花钱是一个道理，同样，我买的包包比你买的包包价格低了一倍，那就是赚了。

但问题是，买个包绝对是必需品，买快销包，或者是买时尚品牌类包，随着使用变成二手是会贬值的。

 而投资奢侈品包，如果保养得当，卖到二手市场，没准还会持平当时的购买价格。

所以如果把包当做必需品，***投资一款奢侈品包确实要比随便买一款时尚快销包要更值得***。

当然，***投资lv***，***不如投资lvmh（股票）***。因为市场流动渠道更完善。

男人们在给女人买包的时候，记住一条就行：

***只选最贵的，不选最美的！***
