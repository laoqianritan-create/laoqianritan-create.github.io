# 又一轮猪周期开始了

废话不多说，我们先来回顾下过去几轮猪周期的情况：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MtM74M3tBOiaj11J4QJWaUVd5RmlMqsj8LNMJnMqoEPY2iatupK9da6W3sPhvZHIISyt4f3vCSSJVQ/640?wx_fmt=png#imgIndex=0)

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MtM74M3tBOiaj11J4QJWaUVYPMiaq6DTQtZjCI19oyz7rug3BzRQ4xEjHHSFS9h182gd3EjPicmDCLQ/640?wx_fmt=png#imgIndex=1)

从上面两张图可知，2006年至今，我们一共经历了4轮猪周期，平均每轮4年左右。

目前我们正处于第四轮猪周期的尾部，根据历史经验，可能还得持续小半年左右，到今年年中结束，然后开启第5轮。

按理说，等今年年中猪价底部确认，猪周期明确结束时再写这篇文章更合适。

但是，像这种时间节奏几乎都是明牌的事件，你猜市场会交易预期还是交易现实？它会按部就班地等吗？

看看猪肉股近期的表现就知道了，在过往的猪周期中，股价一直领先于猪价，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MtM74M3tBOiaj11J4QJWaUVAaxbWhkNnjRKaVx6O1EOwONUG7YicVuovhtiazkhcURfQiaIklwoAicibFQ/640?wx_fmt=png#imgIndex=2)

不难预见猪企的2021四季报和今年的一季报、半年报都会非常难看。

但这不妨碍股价已经开始对第五轮猪周期的开启做出反应了。

没别的意思，这篇文章作为日后的备忘记录。
