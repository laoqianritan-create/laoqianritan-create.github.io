# 男方婚前全款买房，婚后让我出装修钱？

‍‍

‍‍知乎网友的问题：

2019年公公婆婆全款购置一套期房，我和老公2020年11月登记结婚，2021年1月初房子交付，2021年6月孩子出生。

现在准备装修房子，让我出钱装修。

我提出在房产证上加上我的名字，我愿意全款装修。但是老公不同意，说是他爸妈买的房子不能加我名字，我该不该出装修钱？

回答：

其实大家心知肚明。

房子是婚前财产，放在公婆名下就是跟儿媳妇进行资产隔离的手段。

理论上，房子跟男方也无关，你俩都拿到了使用权而已。

装修钱是婚后支出，那就大家共同承担。

还是打个马虎眼，这事别放心上，就让它过去吧。

**丈母娘经济学**的诉求是：本次公司重组，我们双方各给新公司注入多少资产呢？

**婆婆经济学**的诉求是：婚姻并不会创造增量财富，一家所得既是另一家所失。

当你用这两种对立的思维去对待婚姻，必然会拿金钱考验人性，双方都有被算计的感觉——这滋味并不好受。

就像男女不该对立一样，夫妻必须也是一种合作合伙的关系。

**家人就是要彼此付出。**

**其中，彼此和付出同样重要。**

更何况，夫妻账本来就是也应该是一本糊涂账。

只有伴侣才能陪你走完一生，连亲生子女都不能。

所以我的建议是，充分沟通，不加名字，共同承担装修成本，向对方展示出合作的态度，此事翻篇，坚决不把争议扩大化。

要是非得像各种律师课教的那样，谁都不能吃亏，占到赚到。继续用丈母娘和婆婆经济学的思维继续掰扯下去...

放心！肯定还会有更多矛盾在前面等着。
