# 交易降息，咋还跌了呢？

美股在降息时的表现，一目了然。  
  
可能（市场预期）分子端下降的速度比分母端更快吧！  
  
进一步（瞎）推论：  
  
如果分子端能稳住，分母端又下降——啊这，好像是港股最爱的宏观组合诶！  
  
如果分子端稳住的信心不足，债券也直接受益于降息诶。  
  
如果美联储降息也为我们打开了降息空间，央妈跟进，进一步进入低利率环境的话，高股息的红利是否更像小甜甜一些了？
