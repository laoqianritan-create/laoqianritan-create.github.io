# 如果非要给定投加上个期限，我希望是20个月

老说定投止盈不止损，但何时止盈呢？我们曾在👉[基金定投心法—养基必备](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649608583&idx=1&sn=b7c5ab988452c21392e64e6c672bb1d8&chksm=881c155bbf6b9c4dde0072bb8ff06e43d46e2b4319dd9dfa7a259a70f2ad821ed92106c01b0a&scene=21#wechat_redirect)中讨论过。***结论是：***要看你买入的起点在哪。起点和卖点的相对位置很重要，当起点<卖点时，已经成功了一半；

这个结论有它的不足之处—只给出了条件：卖点>起点，但还是没有明确的时间，when？

今天尝试下回答这个问题。如果非要给定投加上个期限，我希望是20个月*（星爷脸）*。

注意，这里说的不是20个月就该止盈，而是定投了20个月时，我们应该好好审视下自己的定投效果，看看是否要改变策略。

why？为什么是20个月？

依然是一道算术题：假设每个月定投1000元，20个月的本金就是20000元。第21个月的1000元，仅仅相当于本金的5%。新增资金对整个盘子肯定是有影响的，但意义不大了，因为本金只增加了5%。

尤其是这种情况：

![图片](http://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2Nibt8Aopkxg9NvVryWDU5CoDsPicdq3ZmibSAuMhstv8Zu7ozia3XtQy3AgqPmneSHjibSjibBSzuYzWWA/0?wx_fmt=png#imgIndex=2)

假设前20次定投曲线如上图，第21次的买入点对整体收益的改善，杯水车薪。此时我们就需要改变策略，有以下几种：

* 每次定投金额＝目前亏损金额；
* 逢跌大规模补仓；

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02b6ic60tUu5mmkiaW840DDlQZbpDx6FrKZw80myPXshlIiamrskPzvYEwg/0?wx_fmt=png#imgIndex=3)

再来举两个例子，解释下定投的盈利杠杆：

![图片](http://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MzBdVWSUZNcuYboOicxorU9Tbib8nKMCndW6HUd2OLt3DZagfbZ8zLTcGvFmt73o38PEkf2QQgvIoQ/0?wx_fmt=png#imgIndex=4)

如上图，假设老钱在A点一次性买入1000元的基金，接着这只基下跌了50%，一路赶跌到了B点， 然后从B点又涨到了C点。但这其中的幅度完全不一样：

A点—B点：跌幅50%

B点—C点：涨幅100%

A—B—C，难度根本不在一个量级上。放到现实的投资中，又哪个标的能实现100%的回报呢？

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02SKtRicicWjqyGd1G1CXibXVdldbmBCbPIwYRwr3etQhdBp2A37X2Nl4OQ/0?wx_fmt=png#imgIndex=5)

定投的本质就是多次买入，最后的资金池由每一次单笔投资加总而成。那么只要每一次投资的终点>起点，最终的收益就一定为正。我想说的是，***定投是自带盈利杠杆的***。

![图片](http://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MzBdVWSUZNcuYboOicxorU9Wy33Wfqlic0AKYX2NBNiaoWibBecQIViaPxBLbMiaDOzX4aYkqUh2HqQ81A/0?wx_fmt=png#imgIndex=6)

如上图，坚持定投的话，只需要小幅的反弹，前期坚持积累的筹码就能撬动收益，迅速反弹。在这种情况下，卖点<起点依然可以盈利。

投资中的很多时候，都需要我们做出不舒服的决定，比如越跌越买，涨了却要卖。但这才是正确的。
