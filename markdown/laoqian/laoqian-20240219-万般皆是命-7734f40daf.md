# 万般皆是命

去年底，家附近新开了一条地铁线。

我和女搬砖工怀着复杂的心情去感受了一把。

开心的是，房子配套更好了，算上正在施工的12号线，以后更方便。

无奈的是，房价不涨反跌。

我们2018年上车至今，浮盈几乎都被抹去。

地铁里，我给女搬砖工看了张图，长这样：

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/M7fHtGOlzVY5OW5Sz19I3x4Eibf4DWcIxtG17nXP6vJ0I1l5NJibPyWlrZpzckSHDmSicdjozD3nhaumvRow1shqA/640?wx_fmt=png&from=appmsg#imgIndex=0)

我指了指2018年的北京说：

**「你看，我们是在这年上车的，之后就没咋涨。」**

2018年我还折腾了一件事，把户口迁到了深圳，成了一名深圳人。

当时还拉着不耐烦的她在深圳踩了几个盘，JYD中介也都有现成的。

那时女搬砖工觉得我被房子搞得有些魔怔了，而且她对高额月供非常抵触，觉得压力太大。

对此我印象非常深刻，因为当初能上车的一个盘之后几年涨幅可观，我耿耿于怀。后来随着21年深圳调控，这个盘的挂牌价接近腰斩，心有余悸。

地铁里，女搬砖工盯着上图看了会儿，又指了指2016年的北京说：

**「要是我们在这一年上车，那就好了！」**

那一年，是一线楼市前无古人后无来者的大牛市，而且刚需房的涨幅相当领先。

也是在那年，我在公司厕所里魔怔一样给我妈电话，态度强硬地让她赶去重庆订套房子。

我妈真去了，预算有限，挑的地方也一般，交了6万块订了套房子。后来我自己又跑去重庆交了10万，把首付补齐。这套房子至今没卖，涨了一倍左右。如果换成现在的我，大概率会买法拍房。

还是那一年，我开始了基金定投。

地铁里，我又指了指图片里2014的北京，无奈地说：

**「怎么可能，我2014年毕业，你2015年毕业，咱那点钱咋买得起...再说咱也没资格啊！」**

时间来到2017年，她跳槽到了一家互联网大厂上班。

我给她起了个外号，叫「搬砖工」，一直叫到现在，等她毕业那天，我打算换个叫法。

女搬砖工入职后，立刻加入了「北京工作居住证」的申请队伍中，排队！

对北漂而言，这证可是个宝贝。没它，有钱都不能在北京买房。

2018年，女搬砖工只排了小半年，证书就下来了——放到如今，这速度想都不敢想。

下证时，我们房子都签约了，没资格，找了个有买房资格的朋友过来签的字。后来我们又签了个买卖变更协议。

2018年底，此时基金已经连续定投3年，我亏得像个傻\_\_。

2019年，我们住进了装修好的房子。装修风格家徒四壁风，家里至今都没有电视。

女搬砖工对我说：

**「这房子是你一个字一个字码出来的。」**

我苦笑回道：

**「月供你可记得还啊！」**

过去我一直认为，普通家庭的孩子，来大城市打拼，白手起家，靠自己的努力在大城市落地生根，成家立业——这是过去这么多年，我所见过的最美好的事之一。

现在，人到中年的我觉得，其实个人奋斗也没多重要...万般皆是命。

啥是命？

下图带🏠的年份意为房价大涨，带🐂的年份有股票牛市，带🌊的年份有货币宽松。虚实红圈意味着代际进入社会开始赚钱。

![图片](https://mmbiz.qpic.cn/sz_mmbiz_png/M7fHtGOlzVY5OW5Sz19I3x4Eibf4DWcIxmecfpX6LQ7BGepEqBOZOBnsLFKOFsE8smHib4QhBYyOmlPoFcheNc3w/640?wx_fmt=png&from=appmsg#imgIndex=1)

上图是中国加入全球化分工体系以来的黄金20多年，电梯上行，GDP中高增速，发财机会分布于点状的城市群和产业链之中。

命就是：能够较早地介入到这场财富创造的浪潮之中。

至于能拿到何种结果，看个人运气、能力、学历、所在城市、行业、公司、长相、关系、眼界、收入、结余、家底...

时代不欠谁的。

但不可否认的是：

黄金窗口期，发财要趁早。

以前英雄不问出处，后来研究生文凭也只是敲门砖。

怎么着也得22~25岁毕业以后，有收入有结余了，才有财富能动性。

另一方面，再看看上面两张图，增长斜率和资产牛市会塑造年轻人的财富观。

2016年~2018年的我确实对房子魔怔。

2023年的我，提前还贷，对未来预期很低，可内心仍对股票基金充满期待——谁知道呢！

每个人都用自己的姿势与时代相遇，每个人身上都有时代印记。

现在还有心折腾，是种难得的珍贵品质，但也别太魔怔，也不用对个人奋斗自我感动，成败都少往自己身上归因。

其实都那么回事儿，万般皆是命，边干边等就行。

**时代性β+主观能动性α+命运的随机性=人生**

与大家共勉。
