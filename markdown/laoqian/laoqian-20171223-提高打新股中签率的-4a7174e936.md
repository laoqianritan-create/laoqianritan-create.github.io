# 提高打新股中签率的小窍门

![图片](http://mmbiz.qpic.cn/mmbiz_gif/ibw8b04QVx2M7PTAr8JHoc98wCJlkDyXxsA0LtNpBgqhicVxmxOENpDia40416PMnQfU6BgCLN0bVtwGJS9LMhIJQ/0.gif#imgIndex=0)

回家呆两天，在沈阳和大伙儿问好。

一回家就犯懒，简单写写如何从概率上提高打新股的中签率。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02qCgMvYKH34MxWobzPkRicErYCnJAM2HX32tJ2v7qzrH2kuNv18iaGNcQ/0.png#imgIndex=1)

首先声明，打新股完全是概率问题，总的来说，还是拼人品和运气。我们能做的，就是根据自身情况，尽量提高中签概率。

未来上市新股的配售情况如何？我们不得而知。

有人通过历史数据测算过不同市值和持仓，对应的打新股收益：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2OMzwe0SXmxxFYicqPCzOh4PrqLict04aPRcib31MRAZsTsmlricTIOIG6OCvnX3AOupLFFdmAeJVA5jA/0?wx_fmt=png#imgIndex=2)

这张表汇总了不同的打新市值，应该如何分配沪深两个市场的仓位，以及打新收益。

注意，表格并不准确，因为没有统计中签概率。但仍能带来很多启发：

***1***10万以内小市值的话，深市场持仓多一些，比较有优势。

因为深市的新股发行数量会多一些。而且，深市每5000市值就给配一签。

***2***资金量越大，沪市的持仓就要占比越多一些。因为深市以小票为主，可能会出现可用市值封顶的情况，造成资金浪费。

**提升中签概率最有效的方法，就是增加不同身份证的账户。**

这点我们在👉[家人支持的重要性](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649609754&idx=1&sn=6469e19909064e890ef5158fd1c5d685&chksm=881c12c6bf6b9bd0c5da1e26f3e92cf157d0725a9f487d14d11375760d1e9374f3f75953ac2a&scene=21#wechat_redirect)这篇讨论过。

一般持仓市值22万左右，打新的效率是最高的。如果能配4～6个账户，中签几乎是一定的事。

其次，错开高峰期，多账户同时打新，能够有效避开配号重合的问题。一定程度上，也能提高中签概率。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02b6ic60tUu5mmkiaW840DDlQZbpDx6FrKZw80myPXshlIiamrskPzvYEwg/0.png#imgIndex=3)

再啰嗦几句打新门票的事儿。

沪市打新门票，我主推银行股轮动策略。好处是安全边际很高，预期收益虽然不大，但也很稳定。

具体操作，详见👉[银行股轮动策略](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649609374&idx=1&sn=8e121c6e00c318146684c3b756d635f3&chksm=881c1042bf6b9954a95c098f0c9ffca154e702713ee32c444c6eb323719067e4fb3c8e044866&scene=21#wechat_redirect)

深市的打新门票，不妨参考深红利的成分股，比如从159905的前十大持仓中挑选。
