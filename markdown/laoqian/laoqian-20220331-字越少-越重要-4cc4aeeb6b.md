# 字越少，越重要

写一个短小精炼的小科普哈，很重要，我们来研究下：养基到底怎么赚钱？

我选取的时间是5年左右，覆盖了牛熊市。

大家简单记一个结论：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PjyYLbLzssTIkY32X2W3G3Vatt0VAcxjVYiaHmrcaPA8Rnky01JneicK1hS9VWDFeEdBpFWIibt23bw/640?wx_fmt=png#imgIndex=0)

论回报的话：

**主动股基>偏股基金>沪深300**

究其原因，一是股票仓位的不同，二来单一指数确实不如基金经理们管理的主动型基金，这也侧面说明在A股生态内，基金经理确实能跑赢指数取得超额收益。

既然「主动股基」的中长期回报最好，我们就以它为例，接着深挖。

假设，你在2017年买了这个指数死拿，到现在可以获得69.7%的累计收益，年化回报率21%。

非常不错！

那么，持有期间的具体感受如何？

大部分时间都会极其无聊！像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PjyYLbLzssTIkY32X2W3G3zicGfTIOQAddl77t2uXcWqcvVvb1zjt6dXIGjnq0Kb9n4zX5RsWjh1g/640?wx_fmt=png#imgIndex=1)

持有1196个交易日，其中751天的日内波动小于1%，400天小于0.5%。

淡出个鸟来，连账户都懒得看。

但是！

个别交易日里也会遭遇刺激的暴击，这是真正考验投资者情绪的时刻，是市场给我们出的一道题。

像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PjyYLbLzssTIkY32X2W3G3p6slczZYo0icKhkNUFSmnaVzm3z3KA5kbOpCib3XhrfVd66KzmT9fpqg/640?wx_fmt=png#imgIndex=2)

持有基金的最大好处是它很难像股票那样动则单日10cm、20cm的暴动。

波动被平抑后，如果基金的日内振幅超过3%就算非常刺激了。

所以普通投资者买基金确实可以有效避免情绪波动。

持有期间，有24个交易日下跌超过**3%**，13个交易日上涨超过**3%**。

至此，结论已经非常清楚：

你买到一个好标的，持有1196天，其中751天百无聊赖地苦等，有24天跌得痛苦，有13天涨得很爽。

其中暴涨的13天贡献了46.79%的收益，占总收益的67%。

**再说一遍：1%的交易日贡献了67%的回报。**

而一旦你在苦等中失去耐心，或者在24天极端下跌的日子里恐慌割肉，终将失去可观的回报。

最后，我们再来总结一下养基赚钱的逻辑：

→找到一个逻辑通畅的资产/标的

→长期陪跑持有

→百无聊赖地苦等

→扛过令人恐慌的大跌

→收获至关重要的暴涨

这就是养基赚钱的奥义。它真的不难，与大家共勉。
