# 连上市公司都在买买买

![图片](https://mmbiz.qpic.cn/mmbiz_gif/ibw8b04QVx2M7PTAr8JHoc98wCJlkDyXxsA0LtNpBgqhicVxmxOENpDia40416PMnQfU6BgCLN0bVtwGJS9LMhIJQ/640#imgIndex=0)

乔布斯曾经给巴菲特打过一个电话，原因是苹果公司账面上的现金太多了，想问问巴菲特应该怎么处理？

巴菲特给了乔布斯四个建议：回购股份、现金分红、收购、存银行。并嘱咐说回购股份是最有用的。

但乔布斯没听。

我们都知道，巴菲特投资苹果，已经是库克时代的事了。

如果你手里有市值100块公司A的股票，想赚钱只有这几种方式：

***1*** 业绩增长。公司A今年的利润增长了10%，相对应的，这支股票的合理价值应该是110元。

***2***估值抬升。有人愿意出110元买你手里的股票。不管什么原因，反正就是有人愿意出这么多钱。

业绩和估值结合起来，俗称戴维斯双击或双杀。

******3******回购股份。上市公司自己出钱在市场上买入自己家的股票，再注销。

如此一来市场上公司的股票数量就变少了，而公司市值又没有变化，则每股的含金量就会增加。

蛋糕还是那么大，但切法变了，每个人拿到的会更多。

***4***分红。就是上市公司自己手里有钱，资本支出总有个合理的比例，多出来的确实不知道怎么花，干脆拿出来和股东们分分。

分红是一种态度，反映出公司是否想回报投资人。

好公司不一定是好股票，好股票的两大特质就是公司会主动回购股份以及分红。

前两天阿里除了宣布马云退休，还宣布了未来2年计划回购60亿美金的股票；

同样的，腾讯最近也连续多天在市场上回购自家股票，虽然回购数量和其账上现金比起来九牛一毛，但拿真金白银来提升股东价值的态度总是好的。

看看美股市场在「回购」这件事上发生了什么。

要说回购的力度和规模，美股比A股厉害得多。

阿里要回购60亿美元，而Apple今年5月份的时候宣布了1000亿美元的股票回购承诺。

上面这张图是美股2009年低谷之后的买家比例情况。

下面三根线分别是美国境外投资者、家庭投资者和机构投资者。09年之后，这三者的比例基本是在下降。家庭、机构的比例甚至已经是负数，说明这两类投资者净出售了不少股票。

最上面那根红线代表的是非金融企业。从09年之后，这类投资者所占的比例越来越高。

非金融企业怎么买到越来越多的股票？就是通过「回购」。

美股一个很大的买家就是上市公司自己。
