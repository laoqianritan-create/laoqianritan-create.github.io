# 三个速度决定赚钱的快慢

![图片](http://mmbiz.qpic.cn/mmbiz_gif/ibw8b04QVx2M7PTAr8JHoc98wCJlkDyXxsA0LtNpBgqhicVxmxOENpDia40416PMnQfU6BgCLN0bVtwGJS9LMhIJQ/0?wx_fmt=gif#imgIndex=0)

似乎每到周末，都想写财商改造系列。

工作日太忙，经常早上六点多爬起来，先写一部分。下班之后，再把剩下的补上。因为时间分散又紧张，普遍写的都是实操类文章。

但周末不一样。周末的时间完整，又不着急，可以躺在懒人沙发上慢慢地码字。适合讲道理。

上个周末，老钱写了我们[赚钱的意义—往上爬](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649608516&idx=1&sn=943d6f9f8fb8cd705c8b3e12cac27b73&chksm=881c1598bf6b9c8eebc9dc1f2834afa979b858fffd348eba292367cb32cef704b83e88350e45&scene=21#wechat_redirect)。今天想聊聊爬的速度。

我想尝试着给出速度的定义：

***速度＝个人速度＋环境速度＋投资速度***

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02qCgMvYKH34MxWobzPkRicErYCnJAM2HX32tJ2v7qzrH2kuNv18iaGNcQ/0?wx_fmt=png#imgIndex=1)

定义个人速度，借用一张很火的网络鸡汤图片刚好合适：

![图片](http://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2NqibYrvzsjajQksg3rQKqhgJLA16KGXBzEMFN6hgYykHxDQgSm2QEUPEqu6icEPK2c9lFs93I3AyzQ/0?wx_fmt=png#imgIndex=2)

标题完美概括了这张图片的含义—慢慢来，比较快！慢不要紧，关键在于可持续，每天都有新认知*（学习）*和新尝试*（跳出舒适区）*。

当然，图片只是个完美的模型，现实中往往会更快—日积月累的“靠谱＋情商”可以慢慢把人脉变现。变现又分两种：

被动变现—别人介绍的突如其来的机会，可以直接把你的职位或收入提高一个台阶；主动变现—你通过整合人脉资源，获得更多收入；（详见👉[开源方法大全的第三种](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649608412&idx=1&sn=516444e36d50afe324ed444fdf5d780e&chksm=881c1400bf6b9d167b5d8221471216496cf8fa024a5a1f2c3900606bda437ca9b90d41e0eee0&scene=21#wechat_redirect)）

以上，就是个人成长速度的关键。

但现实中，像老钱这种年轻人的速度普遍没多快。这个问题我想了很久，发现大家的问题很一致，主要是三种：

* 眼高手低，图快不踏实。基本功不踏实的，往往结果都不好。*以投资为例，假设直接给一个年轻人100万，保证5年平均10%以上的年化收益率，他大概率是做不到的。操盘1万的和100万的难度根本不在一个量级。*

* 不知道[目录](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649608516&idx=1&sn=943d6f9f8fb8cd705c8b3e12cac27b73&chksm=881c1598bf6b9c8eebc9dc1f2834afa979b858fffd348eba292367cb32cef704b83e88350e45&scene=21#wechat_redirect)和难度，随便定目标，发现根本实现不了后，被挫败感笼罩，要么影响效率，要么干脆放弃；比如，[轻松从P5爬到了P7](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649608516&idx=1&sn=943d6f9f8fb8cd705c8b3e12cac27b73&chksm=881c1598bf6b9c8eebc9dc1f2834afa979b858fffd348eba292367cb32cef704b83e88350e45&scene=21#wechat_redirect)，自认为再往上还会这么快...结果被牢牢锁死在P7一栏；

* 年轻人现金流普遍不好，特别在意当下消费和短期利益，错过了攒雪球的最佳时期，在P5、P6停留过久，最后放弃；

回到公式。

什么是环境速度？简单说，就是上对车—如果职场就跟坐火车一样，有的行业是高铁，有的行业是动车，还有一些悲催的行业是k字头的。

上错了车，就算在k字头里跑得再快，车速的差距永远也逾越不了。反之，上对了车，即便你进步不大，也可以享受到行业的发展速度，靠工作年限变现。

目力所及，哪些车比较快？

***北上广深。***对于没资源没背景的年轻人来说，这里似乎是最快的车了。首先起薪高，毕业就找到一份6千元的工作并不困难；机会要远多于二三线城市；

***互联网行业。***不断有新的业态产生，几个月的时间就可以完成试错，几年的时间就可以完成渗透和下沉；微信，今日头条都是例子，没有哪个行业的速度和范围可以跟互联网相比；

***自媒体。***近几年才有的新高铁，门槛之低令人发指。这是手艺人变现的最好时代，内容生产者的春天。自媒体并不只是微信订阅号，事实上，现在来说，微信的门槛很高了。真正的红利在今日头条们的算法推荐，连粉丝积累的过程都省掉了，只需生产内容就好了。*今日头条、喜马拉雅、得到、映客、在行、干聊等APP们都在用各自流量把你的文字、音频、视频甚至经验变现。*免费时代的终结，版权时代的崛起。

关于投资的速度，怎样才能更快？

理财有个说法是：***投资的秘诀就在于找到湿的雪和长的坡***。说白了就是找到高收益的投资渠道，并尽可能的持续下去。

在这个指导思想下，哪些资产是适合的呢？对于普通人来说，肯定不是股票，股票确实是足够湿的雪，但它不是雪坡，悬崖太多了。

老钱觉得，最合适上班族和普通人的，还是固收产品。因为这些投资渠道一旦投入，几乎不需要时间打理，定期跟踪一下就即可。省心省力，收益还有保障。*在过去的十几年里，固收就意味着刚兑。尽管不合理，但对投资人来说无疑是好事儿。不好的消息是，现在所有机构都在去刚兑。*

老钱个人很大比例的资产放在了固收渠道上。迈入P6，我做的第一件事就是买房。（详见👉[在泰国买了套小公寓，聊聊我的经历和感想](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649608198&idx=1&sn=5a463abe770d3c6ba69161e508a4310c&scene=21#wechat_redirect)）

此外，投资的另一大原则是***规模化***。

从这个角度看，股票照样被淘汰。除了疯子，没人敢拿全部身家在股票市场上刀口舔血，而且一搏还是十几年。我们只会拿出一部分钱来炒股，而且大部分时间也不会全仓猛干。

股票既高风险，又无法规模化，且不可持续。固收风险低，收益低但可持续可规模化；房产本身就足够规模化—加杠杆all in，过去16年，收益一直很高且持续；

综上，个人速度、环境速度、投资速度，我们只需要做好选择，长期坚持即可。剩下的，交给时间。
