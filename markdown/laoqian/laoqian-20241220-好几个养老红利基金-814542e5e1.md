# 好几个养老红利基金，咋选呢？

自从大量指数基金被纳入个人养老金账户，很多人觉得，红利的风险收益特征特别适合养老配置。   
  
我也盘了下纳入个养账户的几只红利基金近3年的「年化收益」和「年化波动」，如上图。   
  
横轴是收益率，纵轴是波动率。   
  
直接说我个人的结论：   
  
第一，注意看纵轴的刻度，其实几只红利基金的年化波动率相差并不多，都落在了15%~16%区间内。   
  
唯一的例外，是沪深300红利低波，年化13.5%的波动率，也并没有突出太多。   
  
其实还有一组数据我并未在图中展示，几支基金的最大回撤也都落在了-12%~15%的区间内，同样差异不大。   
  
第二，收益方面，差异较大。   
  
具体来说，红利低波类跑赢中证红利类。   
  
其中，跟踪中证红利的基金，又基本都跑输了指数本身。   
  
最拉胯的就是红利增强，收着最高的管理费，增强了个寂寞...   
  
P.S. 红利的宽度有限，又十分看重基本面，做增强的难度很高。   
  
想做增强，相对中证红利偏离了，反而就跑输了。

异类同志并无冒犯之意，只是如今顶格买个养就像当年买锤子手机——只要敢露头，就会被质疑甚至嘲笑。  
  
当了小白鼠，还没咋赚钱，挺不容易的。
