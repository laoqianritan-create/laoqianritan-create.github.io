# 给这位丈母娘跪了！

**●**

最近抖音上有个相亲段子很火，主角是大妈中的战斗机，闻名全国的上海丈母娘。

这位阿姨替女儿征婚，条件没的说，31岁的央企高管，年薪50万还自带两套无贷三居。

丈母娘知道自己想要什么样的女婿，硬性门槛非常明确——3年以上投资经验。理财组合***（注意哦！是组合！）***年化10%以上。

至于三无屌丝，只要收益率符合条件，也能给个机会。

有路人看不过去，替自己儿子打抱不平，怼道：我儿子月薪好几万呢，会理财了不起啊！

阿姨神回复：

> ***你儿子上班只能决定下限！会理财才能决定上限。我要看到他十年后能捞到多少钱，这才真正重要。***

**●**

站在阿姨的角度，我来试着分析下她的选婿思路：

金融资产价格上天的时代，**年轻人靠流量财富翻身已经很难，把存量财富守好才是王道。**

大门大户的女婿太难找，高薪潜力股也不好遇，就算碰上了，我家也不差钱，锦上添花而已，差点意思。

农村剩男，城市剩女。上海高帅富的供给侧实在有限，需求端更是汪洋大海，纵使有房有车的富裕阶层，也只能猫在人民公园的角落里苦钓金龟婿。

所以与其在高估值抱团板块中搏杀，不如放宽标准，去估值很低，但自身增速不错群体中找。这个思路类似用低PEG指标选股。

阿姨仅有的两个要求中，明确规定男方的理财组合收益要做到年化10%以上。

潜台词是：股神请靠边站，你的资产管理能力再牛逼我也不要，过日子不能高波动。

**我要找的是财富管理高手**，给女儿稳稳的幸福。

会理财的男生，基本都有自律、延迟享受、放眼未来的优点，本身也是一道过滤器。

**●**

阿姨牛逼！给跪了！

上海丈母娘比较直接，最有名的一句话就是：侬房子买好了伐？

「丈母娘经济学」的本质是：婚姻并不会创造额外财富。所以，亲家母，本次重组***（结婚）***，我们两家各注入多少资产？

然而本文的阿姨已经能接受技术入股了。理念再次领跑全国！

这个故事告诉我们什么道理？

多看「老钱说钱」！房产固收股票基金保险知识储备起来！

总有一天，上海内环线大平层的大门，也能向你敞开！
