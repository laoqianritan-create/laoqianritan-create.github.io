# 中产阶级要躲的三个大坑

**第一大坑：****幸存者偏差**

每个中产阶级都羞于承认自己是中产阶级——别乱说！我不是！很普通！其实内心中都高估了个人的努力，低估了时代的运气。

**第三大坑：现金流难以穿越周期**

在穿越经济周期、产业周期、年龄阶段的同时，平衡好现金流、财富积累、对家庭的财务责任，对每个中产而言都不容易。
