# 存钱这事儿吧，还是挺值得说的

![图片](http://mmbiz.qpic.cn/mmbiz_gif/ibw8b04QVx2M7PTAr8JHoc98wCJlkDyXxsA0LtNpBgqhicVxmxOENpDia40416PMnQfU6BgCLN0bVtwGJS9LMhIJQ/0.gif#imgIndex=0)

今日更新了1本书。在菜单栏—💡财商—【📚杂书单】可以找到。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02qCgMvYKH34MxWobzPkRicErYCnJAM2HX32tJ2v7qzrH2kuNv18iaGNcQ/0.png#imgIndex=1)

前两天有读者问一款储蓄型保险值不值得买。介绍写得花里胡哨的，我做了简化，来一起看下：

假设老钱有个1岁的宝宝，可以给她买款储蓄型保险。每年存103632元，存5年。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2ME4fCBeERvLpz8icXNSwcCZDsVUnmMic9I4SKq2SeHlP7jsk2uy87vrC6xfrfwTCic2ibMySAFl3GlPg/0?wx_fmt=png#imgIndex=2)

看着挺诱人，于是我想用XIRR计算下真实的年化收益。

|  |  |  |
| --- | --- | --- |
| 买入日期 | 买入金额 | 实际年化 |
| 2017/1/1 | -103632 | 2.05% |
| 2018/1/1 | -103632 |  |
| 2019/1/1 | -103632 |  |
| 2020/1/1 | -103632 |  |
| 2021/1/1 | -103632 |  |
| **2027/1/1** | **610000** | **到期** |

好吧，如果孩子10岁时取出来，年化收益只有2.05%；18岁时取，实际年化3.36%；

越后期取，年化收益越高，85岁时取，实际年化收益4.34%。快赶上余额宝了...

还需解释下，为什么我没用之前介绍过的👉[IRR](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649609642&idx=1&sn=f432d9908747549904b5f763aa8925d7&chksm=881c1176bf6b98602a621fdbef7f1b327ec5a628330a896bd143074536429ca53d305e28a52f&scene=21#wechat_redirect)算法来计算。

因为IRR一般用来计算有规律的投资、借款的实际利率。而这个案例中，取出时间时随机，这种情况下，用XIRR更合适。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02b6ic60tUu5mmkiaW840DDlQZbpDx6FrKZw80myPXshlIiamrskPzvYEwg/0.png#imgIndex=3)

上面这个案例，你会觉得，保险公司都是骗子，这么低的收益，买了就是个坑。

如果发现得早，想退保，还是亏本的，因为折算成现金价值，还没有本金多。

其实，我们从这个案例中，能得到很多结论，甚至颠覆你以前的认知。

来聊聊：

***1***储蓄型保险，是典型的“长期复利模型”—初期收益很差，微乎其微，但越后期收益越明显。

关于复利模型，也有很多经典案例，我强烈建议看下这篇旧文👉[哪怕1%也要斤斤计较！](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649608465&idx=1&sn=8febd3a36a371fc81753eb420a35c408&chksm=881c15cdbf6b9cdbacfb7c415c9d963df7684b084a60ba27a8e7034800b8eb1e817884fa73a2&scene=21#wechat_redirect)

***2***我一直说，对普通投资者而言，**保险最核心的功能，是规避风险。**保险是保险，投资是投资。

如果你想投资赚钱，别买保险。如果买了保险，别以获利的眼光看待它。

***3***任何资产都有三个属性：安全性、流动性、收益率。三者是[“不可能三角”](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649609300&idx=1&sn=9c73e5f89464bbdc563f49ba6d495aae&chksm=881c1088bf6b999ebc4d750a9e810e39e335b577ebade5926e166c1cd4e7f0f498c26356d9ba&scene=21#wechat_redirect)，绝不可能实现同时完美。

现金是流动性好的资产、保险是安全性好的资产、P2P的年标是收益率好的资产、房子是安全性好的资产...

***4***从财富管理的角度看，“确定的财务目标”都要靠稳妥的投资方式实现。也就是说，要配置“安全性”最佳的资产。

刚性需求的钱，比如孩子的教育金、自己的养老金，少点儿没关系，但是不能没有！

***5***财富管理并不寻找最优解，而是帮客户实现合理的财务目标和生活目标。

回到开头的这款储蓄型保险，你会觉得，并不划算。大部分情况下，确实如此。

但是，换个情况呢？

假如老钱离婚了，孩子1岁和妈妈过。除了抚养费，我还想留给孩子一笔钱。

但是这笔钱，不可能直接给一个1岁的孩子啊。即便他长大了一些，乱花怎么办？

这种情况下，这款储蓄型保险的优势就特别明显了。

我作为这款保险的投保人，享有这笔保险的控制权和所有权。

孩子作为被保险人，有权享受这个保险未来释放的现金流。

至于什么时候释放，我说了算。

***6***从财富传承的角度来看，房子、保险都是很不错的媒介。

房子不多解释，香港保险的分红要高于内地保险。

一个储蓄型保险，居然扯出来这么多🥚。
