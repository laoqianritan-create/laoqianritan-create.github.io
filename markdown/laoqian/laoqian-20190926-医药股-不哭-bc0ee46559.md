# 医药股，不哭

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MtYY6DwPeUXqfqgXDKoQRQeA9lxVSd9HTSxerpf9Kfab3NIHynuD1vvdRfyy5R85thF4htRUm9uw/640?wx_fmt=png#imgIndex=0)

借着最近很火的带量采购说说医药行业的基础知识，以及我买了快三年医药类基金的投资体会。

医药行业有个特点：

一般来说，绝大部份商品都是谁需要，谁付费，天经地义。

但医药行业不是这样，老百姓是**「需求端」**，人们生活水平越来越好，需求肯定越来越强，这没啥好说的。

但医药行业的**「支付端」**却涉及很多方面：政府、医保、个人、商业保险。

看病买药的钱不全是老百姓出，而且所有利益方的压力都在慢慢变大。

现在医药行业最大的变数就出在支付端上，老百姓看病贵，商业保险也越来越贵。

不光我们觉得贵，政府和社保也觉得贵，他们也要买单啊！所以才有了带量采购杀价格。

中标的公司，惨！比如前天的新一轮集中采购招标会，拟定采购的60个品种的药品价格比2018年的最低采购价平均降幅接近60%。

没中标的，更惨！连量都没了。

而**「供给端」**就是各种医药机构，它们又细分为很多种：

有做创新药的、仿制药的、中药的、做生物制药和疫苗的、专门做研发外包的、专门卖药的、还有做医疗服务的、器械的、医美的、把带有保健功能的药品做成日销品的、专科医院、综合医院等等...

供给端最好的好处就是确定性强，面对老龄化趋势带来的巨大需求，医+药作为稀缺资源长期供不应求。**医药成为A股中十年十倍股产生最多的行业。**

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2NGdX9ABia74ZP9iaeeAV812EZgHfhgHB8IPg5S2RpPSMhjXj6Lr1XbjicY4OeTnSwmteTZpicCqrff2w/640?wx_fmt=png#imgIndex=1)

带量采购给医药行业带来的最大改变就是**利好龙头药企**——政府通过降价有意压缩仿制药的利润空间，创新药处于保护期则受此影响小，而有能力大规模投入研发的只有大型药企。

可以说，每一家大型药企一定程度上都是华为，必须重金投入研发。

**... ...**

对于我们普通投资者来说，想投资医药股可不容易，因为它太专业也太庞杂了。

按照惯例，最好的方式就是买指数基金。

我当时也是这么想的，问题来了，正因为这行庞杂又专业，光医药指数就有好多个，比如：

中证医药卫生指数、中证精准医疗指数、中证中药指数、中证互联网医药指数、沪深300医药指数、中证医药100指数、中证全指医药卫生指数...

完全懵圈了，真的整不明白！所以17年我想定投一支医药指数时根本不知道选哪个。

后来一想，算了，既然指数基金不会买，我去买**医药主题的「主动型基金」**，专业的事交给专业的人。

但是买主动型基金有个非常非常重要的原则就是主动型基金一定要跑赢对标的指数，说白了就是要有超额收益。

这也算一个很诚恳的建议吧：

如果大家想买一支主动型基金，一定找一支指数来对比下长期业绩。如果主动型基金无法长期跑赢指数，完全没必要买。以为指数基金的费率更便宜，稳定性更好，不怕更换基金经理。

所以当时就选了一个成立不久的医药主题的主动型基金，基金经理叫葛兰，是美国医学博士，这个履历在基金经理中还是挺少见的，看起来很专业。

就冲着这点，我开始了定投。合计先投一年试试，如果跑不赢指数就换成「300医药」或者「医药100」这种指数。

结果就一直定投到了现在，确实长期跑赢了指数：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2NGdX9ABia74ZP9iaeeAV812EebBa71sIInHQ8sp22PlfC3IQxqzsMgRgZRReBOZCCASfXMyxBl2Ficw/640?wx_fmt=png#imgIndex=2)

「中欧医疗健康混合」净值走势图

嗯，中间还止盈过一次，但没停止定投。

**想借这支基金告诉大家，想投资需要专业性的细分行业，主动型基金未必不好。**

并不是推荐这支基金哈， 只是我基金亲身定投过，体会比较深而已。像同样有医药专业背景的于洋管理的「富国医疗保健混合」，还有博时医疗保健行业混合等主动型医药基金都有很不错的长期收益。
