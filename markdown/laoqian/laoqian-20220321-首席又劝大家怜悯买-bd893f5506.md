# 首席又劝大家怜悯买入了

有一种底，是专属于兴业证券张忆东首席的「怜悯底」。

讲道理，张首席很会拿捏投资者的心态。

所以每次在底部做心理按摩时，不劝大家勇敢，而是借坡下驴——

> **大家快看！A股都这德行了，你们就怀着怜悯的心买点儿吧...**

成功激发了股民们的同情心。

可问题是，受伤最深的是股民啊！

可没人怜悯这些人，大家只能关灯舔舐伤口，然后又一次**选择原谅**。

我们来回顾下张首席的怜悯史——

**2015年8月**劝大家怀着怜悯的心逢低布局 

**2018年10月**劝大家怀着怜悯的心逢低布局 

**2020年7月**劝大家怀着怜悯的心配置一些金融地产

**2022年3月**劝大家怀着怜悯的心逢低布局 

不得不说，择时还是很准的，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PYRMNqLbIYiaibXmPibTmMBb8zqXJAfIFy2xfq2ibUkkeh3QyZU6SXstLiaiayTNVhZ7Q6u4N3IhvibWJ3w/640?wx_fmt=png#imgIndex=0)

最新一次怜悯是这么说的：

> **现在的重点工作不是去猜指数能够反弹到哪个位置，现在要淡化指数，精选个股，****怀着怜悯的心****去逢低布局中国的优质资产。**

此时**信心**跟**火种**都很重要，大家可以有节奏地怜悯起来了。

**··· ···**

之前答应你们的，统计完[主动型基金经理的回撤幅度](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649620063&idx=1&sn=8b221753620c488b556f86c3ab9c9037&chksm=881c3a83bf6bb395b14afc1ce0fde24ff4688aa3a77e9420cdfcbe2586382d4f9196fdb98fb2&scene=21#wechat_redirect)后，再来看下主流指数的估值，它来了：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PYRMNqLbIYiaibXmPibTmMBb8XSchco6uSt30ibCmzeVqEsAsgNnRjICfjJGY6mtk7bSJ0hcLxZTCBXA/640?wx_fmt=png#imgIndex=1)

上图从估值「百分位」的角度统计了比较热门的宽基指数和行业指数目前的估值，并且和2018年和2020年的两次阶段性大底做了比较。

我觉得梳理得比较全了——

几大宽基该有的都有，属于做多中国的概念。

便宜的医药，死贵的食品饮料，全看疫情脸色的旅游**（年初已经凸凸一波）**，成长方向的5G、芯片、创成长，碳中和和新能源汽车...

大家当然可以继续等大底，但我需要提醒几点：

第一，确实还有一些靴子没落地。

第二，**市场年年巨变，别太一厢情愿。**

第三，结构性行情有涨有跌。

第四，2021年报和2022一季报已经开始密集披露了，**多看看景气在哪里**。
