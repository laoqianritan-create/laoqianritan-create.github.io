# 年薪50万定律

✅图1.是在群里看到的，应该是某网友发在脉脉的上帖子，非常真实：  
  
「任何单位，做任何职业，只要工资年入超过50万，基本上都要牺牲个人生活。  
  
无论医生还是教师，金融还是互联网，央企还是民企，只要工资收入超50万，除了极个别销售类岗位，都要牺牲个人生活，只是多少而已。  
  
体制内也一样，好的企业随便混混5点下班大概能有25-35，但只要想工资收入超过50，要么疯狂做业务，要么当领导，都要身心都扑上去个人生活也非常受影响。」  
  
年薪是面子，时薪是里子。赚多少钱，操多少心，就这还是理想情况。  
  
✅图2.是我做的体制内岗位收入的DCF图，也揭示了一个真相：  
  
收入增速一定会下降甚至倒退的！  
  
如果能保持稳态增长，退休前的收入绝对值会高到离谱。  
  
而现实是，我国人力资本的高峰来得很早，达峰后便会跟着年龄下降。  
  
✅图3.是「面基」最近反响不错的一期节目，里面也有一个关于职场收入的真相。  
  
女搬砖工看完后表示：很治愈！已释然！  
  
这个真相是：  
  
职场收入高到一定程度后，这个收入的稳定性就与个人能力完全无关了。  
  
注意！是稳定性与个人能力无关，而不是可获得性与个人能力无关。  
  
优秀的人获得高收入天经地义。  
  
但这份高收入能维持多久，更多由公司人力资本开支意愿、你的可替代成本、行业发展阶段和竞争烈度，甚至是宏观经济周期决定。  
  
所以，老天爷赏饭，就把盘子舔干净，至于人家啥时候收碗，看开点儿吧~  
  
当然，很多人在不稳定的高收入时期，给自己背上了稳定的房贷，那就是另一个中产故事了...
