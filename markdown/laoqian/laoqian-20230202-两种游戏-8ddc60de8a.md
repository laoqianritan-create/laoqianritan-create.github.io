# 两种游戏

上一篇推送[《A股你啥时候才能长牛》](http://mp.weixin.qq.com/s?__biz=Mzg2MDc2MjM3NA==&mid=2247496287&idx=1&sn=8422c49e2e80daef485e441ab0d08529&chksm=ce23ca36f95443205a06a034b116c33cad661a0db193803223f411f170732921f2152099ba33&scene=21#wechat_redirect)，我们探讨了美股「高波动阶段」和「长牛慢牛阶段」的经济背景。

望岳投资的朋友看到后提醒我说：

美股指数的上限明确，下限未知；

A股指数的下限明确，上限未知；

事实确实如此，我们找数据来佐证下：

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVY03wicsjHgf1RFJ2X64N3OpZ3vqp7CygHuYAUFYmlvHdFLaJXas2AH1NvYNOouicCTpyYbAZMSOmjw/640?wx_fmt=png#imgIndex=0)

**美联储放水和收水动作对投资具有高度的指导意义。**

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVY03wicsjHgf1RFJ2X64N3Opdg80t5jOB0uXxw7Z6unsI3z9oUN0TtkGhEZHX9bUOovYMM7gBHU5PQ/640?wx_fmt=png#imgIndex=1)

A股则专业磨底二十余年...

从上面两张图可知，A股和美股是两个很不一样的市场。

虽然最终收益率差不多，事实上A股还要更好些，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVY03wicsjHgf1RFJ2X64N3OpUaKFcbvmRdNy3eebwPWfFGzJwQC62qicaZlLjxSSjicGG2hSmN4d4wYg/640?wx_fmt=png#imgIndex=2)

但是毫无疑问，美股的持有体验**更好**，买入难度**更低**，群众获利的概率**更高**。

而A股呢？因为周期性的高波动，所以在这获得超额收益的概率**更高**，群众亏损的概率**更高**，买入难度也**更高**。

无论做投资还是做生意，很重要的一项工作就是对我们所处环境的识别，认识市场及其客观规律。

「有知有行」最近也做了一项研究——在中美两个市场怎么买更聪明？

在美股玩，买入并长期持有就挺好：

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVY03wicsjHgf1RFJ2X64N3OpXVoeftCRMqWI3onCFDCictEbGgiauhZT8xJ7OGVCr5DD3JfdDsD0Xv8A/640?wx_fmt=png#imgIndex=3)

但是在A股玩，必须在买入和卖出上**做大周期级别的择时**才能取得理想回报，买贵了会毁掉一切：

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVY03wicsjHgf1RFJ2X64N3OpWn0VFicZ8cj9NoFBHrlVppYm9JQTuqCsbaoNwvWsib0o5kHEibibSa8NGQ/640?wx_fmt=png#imgIndex=4)

也因为这两个市场的特点，买美股更应该去研究**顶部区域**的特征，关注如何逃顶。买A股更应该去研究**底部区域**的特征，关注如何抄底。
