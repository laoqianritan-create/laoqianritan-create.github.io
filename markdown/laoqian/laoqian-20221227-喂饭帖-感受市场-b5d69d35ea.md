# 喂饭帖：感受市场

***1***本文旨在和大家分享我自己观察市场的一个小方法，以及这个方法背后的逻辑。

首先，我们需要在行情软件的「自选股」里新建两个分组，分别取名**「风格」**和**「行业」**。

接着，要在两个分组里加入一长串代码，这步有点麻烦，但很值得，因为**一劳永逸**。

行业分组里，我们要关注一堆场内ETF代码。因为涉及的代码太多，本文就不一一列举了，公众号底部对话框回复：**场内** 能收到我整理的一份列表，照着挨个关注即可。

***2***我们做以上工作的目的，就是想从「风格」和「行业」两个角度去感受市场每天的内部肌理，比如使用涨跌幅排序功能，不同行业谁强势谁弱势，一目了然。

以上工作也说明一个真理：**预测市场是徒劳的，能准确描述市场都已殊为不易。**

***3*** 进一步地，我们还要厘清「风格」和「行业」这两个概念。

如果从宏观到微观一层层地把股市拆开，它可以分为以下几层：

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVb3VtXjmfoqwULmpOHm8riaPibVs53U0kW9iahsPmMjwt38Oq0iaNZCdY7JqQTzxfHc9qQ0icbGmXY627w/640?wx_fmt=png#imgIndex=1)

最外层市场，是所有力量博弈后输出的最终结果，太笼统。最内层个股，又太过微观随机。

我们选择通过中间两层来感受市场的运行。注意！只是感受，至于如何理解、预测，因人而异，并无标准答案。

***4*** 再来解释行业。

A股有很多行业，往小了说，申万二级行业的颗粒度已经足够细了。我选择的抓手是关注各种场内ETF，它的好处是既能用股票账户一网打尽，又能随时出击，立刻买卖，所以它非常好用。

根据深交所的报告，目前A股市场上兼具较强认知度且交易活跃度的行业主题类ETF就有**106**支，已经非常细分了。场内ETF持有时间中位数是**11**天，平均每**14**天就会交易一次。你们感受下。

往大了说，28个申万一级行业又可以大体分成四种风格——**周期****、****消费****、****科技****、****金融**，每个行业风格都有自己的特点和投研方法论。

***5*** 再说市场风格，这是个有点虚的概念。

从上图可知，风格是介于市场和行业之间，所以风格是超越行业的。某些行业和个股又同时受到相同的规律**（变量）**影响，从而表现出高相关性——人们把它们归纳为「风格」。

***6*** 大概在2010年以前，A股里的个股数量有限，制造业和三驾马车中的投资主导驱动经济。在这样的背景下，行业、个股相关性很高，**大家同涨同跌**，所以最重要的是**猜涨跌****（高级点说法叫大势研判、判断市场方向、自上而下、择时）**。

在这个阶段，风格是很没用的概念，都没啥人提，因为大家在方向上几乎统一，只有幅度的差异。

***7*** 2010年以后，随着A股股票数量越来越多，经济结构转型，机构投资者影响力增强，**分化成了A股的主旋律**，大家言必称「结构性行情」——市场看起来波澜不惊，但内部泾渭分明，不同风格、行业在大量时间里都涨跌不同步。在这两个维度一旦选错，也就错过了行情。

比如今年，全A指数**-14.9%**，大盘成长**-27.5%**，大盘价值**-12.4%**，差异巨大。

所以这些年，对风格、行业这种中观维度的判断就成了股市研究的重点之一。尤其对指数基金爱好者来说，他们无需研究个股，重点就是对行业进行挑选和择时。

***8*** 比较烦人的是，风格极容易和投资理念混淆。

比如价值风格和价值投资啥关系？

比如一个人说**「我看好成长股」**是不是在说废话？

比如人们习惯性认为大盘股没有成长性，那茅台宁德时代的业绩增速怎么解释？

比如一个人说**「我的投资策略是选择真正具有成长性的个股」「我的投资策略是选择业绩高增速且估值合理的个股」**，这两句都是挑不出毛病的废话，没办法用风格去套它，也不容易指导具体实操。

***9*** 总体来说，A股的风格可以分为以下几类：

**市值维度**——大盘、中盘、小盘

**估值维度**——高估值**（成长）**、低估值**（价值）**

P.S. 本文第一张图就是前两个维度的组合

**景气维度**——高景气、低景气

**价格维度**——高价股、低价股

**行业维度**——周期、科技、消费、金融

需要注意的是，风格是超越行业的，一个行业内部可以同时存在大中小盘、成长价值、高低景气的个股。

实操一下，民生金工团队总结了今年公募基金的四招胜负手——

**①**偏向超小市值风格 **②**偏向低估值风格 **③**偏向煤炭医药有色等行业 **④**偏向低仓位

其中**①②③**都是在说市场风格，**④**是大势研判。

***10***为什么不同年份会跑出不同的强势风格？

原因还是我们多次重复过的一个结论：**市场年年巨变，谁适应得好，谁收益高。**

**经济环境、流动性的变化都会影响不同的风格**，举几个例子：

* **流动性宽松****→**利好中小盘风格；
* **经济景气度好、社融增速提高****→**利好大盘风格、价值风格；
* **利率下降****→**利好高估值风格；

***11*** 最后，无论大势研判，还是风格行业的中观判断，其思路都是自上而下。

如果你的思路是**「我就要深度陪跑我看得懂的公司一起穿越周期」**，那就是典型的自下而上，什么风格策略都是浮云。

两个思路并无优劣之分。

茅指数、宁组合当道时，自下而上一骑绝尘。但是遇到今年这种宏观巨变的环境，大家又开始对自上而下进行补课了。

还是那句话，市场年年巨变是真理，一代版本一代神。
