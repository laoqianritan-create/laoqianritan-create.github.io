# 几个北漂的生活被全国网友围观

**●**

北京顺义昨天有几例新增确诊患者，因为防疫需要，这几个人的日常行程轨迹被公布了出来：

40岁北漂，在北京当滴滴司机，最狠的一天从早上6点开到半夜23点。

32岁北漂女生，白天上班，下班看病，晚上10点到半夜2点在顺丰兼职。

家住燕郊，每天驱车100公里去望京上班的北漂。

31岁北漂，白天上班，晚上兼职，还要去医院陪护妻子。

34岁北漂，有娃，老人过来照顾，4口人住在70平的顺义房子里，还在准备清华的考研。

我相信谁看完了都挺感慨，**不容易是真的，但绝对没有网友们说得那么惨。**

选择城市就是选择人生：

都知道二三线城市的生活性价比更高。

主题只有一个：搞钱搞钱搞钱！

说惨的网友，可能实在没啥生活经验。

如果这都需要悲天悯人，那绝大多数一辈子平均月薪几千块，工作到退休也攒不下200W的广大群众过的是什么日子呢？

**中文互联网的一大特色就是总喜欢把一小撮中产阶级的生活当成主流。**

**●**

从11月蚂蚁IPO上市被叫停开始，阿里巴巴连续大跌，从高点回撤30%。

明年反垄断是重点工作之一，阿里又被拿出来杀鸡儆猴。

现在市场对它比较悲观——监管风险倒不必过分演绎，毕竟这是中国最优秀的几家上市公司，肯定要管要改，但绝不会上升到网上那些阴谋论的高度。

其次是业务方面的担忧，大文娱集体失利，用户数被拼多多超越指日可待，投资方面很多决策失误，社区团购军备竞赛布局落后等等。

当然，想象力也还在，阿里依然是中国最好的，最有toB基因的互联网公司——钉钉、云计算、物流**（菜鸟）**、金融**（蚂蚁）**。

其实我觉得现在的阿里和2018年的腾讯很像，见下图绿色区域：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2NCiaR48DBfiboB6ruVdeSY6snRX0YxUV6At8ZsibW44XyVVh8nMsfdPgZV8lIp2kgRIWG9sjMId32bA/640?wx_fmt=png#imgIndex=2)

那时的腾讯也被市场质疑基本盘动摇，社交领域微信无人能敌，但用户使用时间被短视频抄了后门——目前这种趋势还在加强。

占利润一大半的游戏业务被版号限制，也出现了很大的政策风险，而且有业绩实锤。

再加上2018年股灾，最终砸出了股价黄金坑，估值一度摸到罕见的25PE。

而现在的阿里巴巴是这样的：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2NCiaR48DBfiboB6ruVdeSY6sAnXCjnzPpFnZUuVqggZoia7W8xvtyUiarYlm3fmK1f1NqYbqDCH8U4kQ/640?wx_fmt=png#imgIndex=3)

年初就砸出了黄金坑，其它巨头在流动性泛滥行情里大涨时它一直没动，直到后来借着蚂蚁上市才把市值顶起来。

真想抄底的，我觉得可以再等等，因为现在还没有业绩实锤，具体的调查结果也还没出来。没准以后这能砸个年初那样的黄金坑来。

但对阿里我还是长期看好的，**好公司就是这样，很多时候你得相信，才能遇见。**
