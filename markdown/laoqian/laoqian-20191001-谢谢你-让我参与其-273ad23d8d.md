# 谢谢你，让我参与其中

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2Mia1sjjnPkia1ZLmXyJMIYvS7JibFkejT4y8YJKX8XjAc8M1Ch9qnSvNJmjls9hgibBFOjC8HGBMBPnw/640?wx_fmt=png#imgIndex=0)

下面这个视频应该很多人都看过，它统计了1968年-2016年主要经济体GDP排名的变化。

以几十年的跨度审视过去，这些变化仍显得有些不可思议。

5年前我拖着两个行李箱挤上开往北京的火车，很幸运地涌入这洪流之中，亲眼目睹了很多，更亲身参与了一些。

尽管我现在的日子看起来平淡无奇，但回望5年前的生活，改变之大仍然难以想象。

尽管当下正经历着一些波动甚至是下行周期，但远眺5年后甚至更远的未来，我坚信这仍然是一条上扬的曲线。

谢谢你带来的发展、变化。

谢谢你让这么多人都能参与其中。

一切刚刚开始，这只是预告片。

生日快乐！
