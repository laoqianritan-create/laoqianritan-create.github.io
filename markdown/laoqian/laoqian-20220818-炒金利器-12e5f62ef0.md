# 炒金利器

今天看到丁昶老师在书里说如果大佬看好黄金，不会买金条或者黄金ETF，也不怎么使用期货来放杠杆，而是买入金矿股。

我一下来了兴趣，跑了下数据，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVbOHN7gD52bVHu0ibZu5XtVA8FQtD7TMmSQHXb2mCkGwmib75cO9vGw3r0ibNdkic9Qfk5d6VLW5wiaZnA/640?wx_fmt=png#imgIndex=0)

2016年至今，金价涨了大概50%，紫金矿业股价涨了**250%**。

再看涨幅最猛的阶段——

2020年受益于美联储的QE4和降息，作为信用货币的反面，黄金最高涨了20%+，同期紫金矿业最高涨了**370%+**。

有点意思哦！

**··· ···**

为啥会这样？

因为作为一家正常经营的企业，**金矿公司自动带有好几重杠杆**。

一是毛利率杠杆。

比如现在的金价是每盎司1700美元，矿山开采的成本是1000美元，那么生产一盎司黄金的毛利就是700美元。

当金价从1700美元涨到1800美元的时候，它的毛利就会从700美元涨到800美元。

金价的涨幅只是5.8%，金矿公司的利润涨幅却是14.3%。这就是2.5倍杠杆了。

二是财务杠杆。

金价上涨，金矿价值提高，公司可以借入更多的债务来支持经营，省下钱来用于分红或者回购。

三是矿石品位的杠杆。

因为在不同的金价下，开采品位的下限是不一样的。

比如在金价800美元时只能扔掉的低品质尾矿。

而当金价突破2000美元时，又有重新提炼的价值了。

所以随着金价上涨，有些矿山反而越生产储量越高了。

****··· ···****

本文并无荐股之意，也没能力预测金价未来的短中长期走势，不过以后大家再想参与黄金相关的交易时，或许有些新工具。
