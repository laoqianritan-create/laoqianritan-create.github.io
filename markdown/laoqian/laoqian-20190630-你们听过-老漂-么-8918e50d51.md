# 你们听过「老漂」么？

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2NMNibQZuicwEq6hySCo0X4rPMMk1jY2icH5aicAprgEibHVngYhhv152MwmIE3wOAYn4317lsv2N1IfdA/640?wx_fmt=png#imgIndex=0)

读者@Echo提问：

可以谈谈父母养老问题吗？ 

例如需要预留多少资金给父母养老，以及老年人如何度过自己的退休生活。 

我爸妈目前53岁，退休在家，没有退休金，相当于0收入，有医保，配置了意外险和医疗险，不打算配置重疾险了，上周刚做完体检，目前身体没有太大的风险。 

因为不想让爸妈太辛苦，所以让他们不要工作了，但是目前还未探索出赋闲在家可以干什么打发时间，按83岁的寿命计算，我想说需要留多少钱给爸妈养老才可以？ 

我目前想到的思路就是：基本生活开销、每年体检医疗支出、重大疾病备用金、保险费。这个算比较省的，还不包括旅游娱乐费等等。

---

真是应景的提问啊，正好我最近学到个新词叫**「老漂」**——

指已经退休的父母，在还有很强自理能力的养老蜜月期，去子女所在的城市发挥余热，照顾工作的儿女和年幼的孙辈。

老漂当然不好当，要切断老家的亲戚朋友、社会关系、远离家乡来到别的城市，住进子女家的次卧，几乎没有任何朋友。

母亲们只能去小广场上和同龄人跳跳舞，有的父亲在白天还会开着孩子闲置的小轿车跑跑滴滴。

我老娘来北京住了一个星期就再也不想来了——整天没事儿，无聊得要拖几遍地，出门也不知道去哪儿，不能去健身房练瑜伽，没劲透了。

我以前觉得养老不是什么难事儿——老有所居、钱够花、健康生活就完了。

现在越来越觉得这是一个宏大命题，黑发50年，白发三五十年，如何终身自立地优雅老去？这题好难。

回到你的问题，我觉得想得已经很全面了。

但50多岁就彻底脱离社会赋闲在家有待商议。

如果身体条件允许的话，还是要发挥余热，老人自己也够呛能闲得住。

帮他们找到兴趣爱好或者继续工作的方式，确实蛮重要。

关于保险可以参考下图，不多说了。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2O1fccwjWKIg7P49jvXGJpJJLHmxib5CGqjy0CVkhVGfheOQEK0C53AdHGVj9V1Iyl93MZ2RpS8cuA/640?wx_fmt=png#imgIndex=1)

有一定的现金储备——我一直觉得这点很重要，因为真的说不好家庭成员会遇到什么意外。

反正只要是突发情况，能救命的只有现金和朋友帮忙。

子女在本地买房，都可以尽量离父母近一些。

随着父母越来越老，电梯房／低楼层的楼梯房对他们来说也是一种刚需。

另，虽然一直反对投资公寓和商铺，但以解决家庭闲置劳动力为目的购买商铺，我是认可的。

关于到底需要多少钱养老？从身边的例子看，只要不用负担房租，靠退休金解决日常开支问题不大。

这里不得不再提一次「延迟享受」。

**其实延迟享受的本质不是「抑制消费」，而是平移现金流，削峰填谷。**

我们一生的收入曲线两头低，中间高。

支出曲线大概35岁左右迎来高峰，但不是一次性花出去，而是以信贷形式支出，再递延到之后的现金流中。

最典型的就是房贷、生娃、养老，每年要为此支付的现金流损耗完全可以预见。

**所以延迟享受的本质是用现在的结余去支持日后的支出。**

退休是非常重要的拐点，**我们会在退休前后彻底进入「零债务」状态**——还清30年的房贷、子女不再需要我们的金钱支持、保费支出也到此结束。

这本该是个轻松的时刻，但紧接着就会进入退休阶段，不再产生价值，完全消耗积攒的财富。

**一个理性的人，应该将自己一生的财富平均分配到每一天消费，才能得到幸福最大值。**
