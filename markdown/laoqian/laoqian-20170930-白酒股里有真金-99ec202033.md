# 白酒股里有真金

前两天聊了聊[👉A股里最赚钱的公司都是做什么的？](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649609634&idx=1&sn=44abbbc2212958bcb8d1a3fa51afd08a&chksm=881c117ebf6b98685dc5e05adcbd2465fd6c086aef16bb286f42121c486f11f97d00bddd8bf3&scene=21#wechat_redirect)发现白酒股过去10年都是盈利方面的常胜将军。

我挖了个坑，一定好好说说白酒股。这两天略忙，但空闲时间都在研究它。

总结了白酒股的几大特点，和大伙儿分享一下。

***1***白酒行业是真正的暴利行业，利润高得吓人。

以老大茅台为例，毛利率高达90％以上，令人发指！五粮液，毛利率70%＋；洋河股份，毛利率60%＋；

基本上如果净利率不超过30%，都好意思说自己是卖白酒的。

再和其他行业对比，你们感受下卖白酒有多赚钱：

谷歌、facebook、微软、苹果、腾讯这种近似垄断、特别赚钱的公司，净利润没有一家超过25%的。

为什么白酒这么赚钱呢？

其实之前在[👉](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649609634&idx=1&sn=44abbbc2212958bcb8d1a3fa51afd08a&chksm=881c117ebf6b98685dc5e05adcbd2465fd6c086aef16bb286f42121c486f11f97d00bddd8bf3&scene=21#wechat_redirect)[买茅台的新思路，稳赚](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649609223&idx=1&sn=b893eefb4defbcfda0b62ef6d521d0b5&chksm=881c10dbbf6b99cdd7e7fd1ddf6b00d647f5557b6165f4e70b39eba06e1a256cbac517615cd5&scene=21#wechat_redirect)就分析过：

首先制作白酒的成本很低，粮食、原酒都不贵；

其次，生产白酒也不需要太高精尖的设备、更不需要产品创新，只需保持口味不变；

历史也是白酒行业真正的护城河。没有几个亿，根本咋不出新产品来。我近几年唯一有印象的就是“江小白”。

此外，对于消费品行业来说，库存是魔鬼。但白酒行业恰恰相反，库存越压越值钱，甚至还要补库存。

比如这一波白酒股上涨的最大逻辑，就是涨价和补库存周期；

最后，白酒行业的品牌溢价空间特别大，有定价权。完美符合消费品股票上涨的最根本逻辑—量价齐升。

***2***白酒行业的地域性极强，所以但凡是能做到全国化的品牌，我都比较看好。

比如茅台，不用说，贵州的；洋河的大本营是江苏；四川名酒比较多：五粮液、泸州老窖、水井坊、沱牌；河北老白干；我老家东北，似乎老龙口和老村长比较主流；

***3***还有第三点，不是明确的结论，只是我个人的感觉，不一定对。

我觉得白酒行业正在酝酿一场长周期的消费升级—如何通过产品定位讨好年轻人，或者说开发年轻、商务化新产品。

举2个比较成功的例子：

比如江小白，定位就是给我们90后撸串时喝的；

再比如洋河海之蓝，定位就是一款年轻化的，喝了不上头的商务酒。特别适合商务应酬；
