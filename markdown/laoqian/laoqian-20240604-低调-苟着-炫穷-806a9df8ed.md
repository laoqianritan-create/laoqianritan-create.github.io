# 低调，苟着，炫穷

今天刷到「人物」公众号推送的炫富网红集体消失，巧了，正好在看席勒的《叙事经济学》讲节俭与炫耀性消费一章。  
  
美国人也有过爱存钱的时候。  
  
以及，再次感慨：  
  
历史不会重复，但它自然成韵。  
  
当下炫穷才具有正当性，成功学和奋斗叙事都成了某种魔怔，一个简单的「卷」字能消解所有的努力。那就别吭声了，过好自己的日子。  
  
另外，兄弟们，本周我就不更新了哈，老丈人突然高血压飙到207，直接住院了。  
  
我去长沙陪护一下，表现的时候到了。  
  
白天也没啥事，我准备在医院里也挂号瞎看看，验验血验验尿啥的，反正也是干呆着，当溜达了，自己找乐呗~

 北京,2024年6月4日 15:01,
