# 中国老铁集散地—快手要上市了

这两年多热闹啊，一个个的都冲击上市了。

新东方刚回来，好未来也传出要二次上市。

字节跳动刚传出要登陆港股，快手就递交了招股书。

我周末扫了一遍，和大家分享几个亮点：

****①****快手和抖音到底有什么不同？

这是很多人最关心的一个问题。

其实答案很简单：

如果你想看心中向往的，被略微粉饰过的生活，那就去看「抖音」。

它的slogan是**「记录美好生活」**。

如果你想看的是更贴近真实的生活，哪怕它有些平凡甚至残酷，那就去看「快手」。

它的slogan更提倡**「拥抱每一种生活」**。

**②** 在招股书中，快手强调了自己的四大价值观——**美好**只排在第三位，**真实**被放在了第一位，其次是**多元**，最后是**有益**。

这种对真实和多元的坚持也深刻影响了快手。

在算法分发方面，快手会刻意调整大家的注意力，避免贫富差距过大，给普通用户更多被看到的机会。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PibOjXM8ecDNQyVDDrOicZ0D6tExqXrbVCuvBNible4nXcJZDWGPwLQFk1GV6wBvCjcpYuZ1iaglRfZQ/640?wx_fmt=png#imgIndex=0)

这种普惠倾斜又会反哺用户黏性——快手的点赞评论比、直播打赏、卖货、创作比例等指标均好于抖音。

**③** 快手关键数据一览：

****④**** 快手的主要赚钱来源有三个：

直播打赏分成是大头、广告次之、最后是电商和星星点点的知识付费、游戏收入。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PibOjXM8ecDNQyVDDrOicZ0DZcEcnHn8djk1w4rUM06EusRTeMImib9q4jMqCickydhoUyN1E3yNI7hw/640?wx_fmt=png#imgIndex=2)

2019年快手营收391亿，其中直播分成314亿，广告74亿，电商成交佣金26亿。

今年上半年快手营收253亿，广告**（28.3%）**和电商**（3.2%）**的收入都有大幅增长，使得直播收入占比进一步降低**（见上图）**，未来这种趋势还会继续。

上半年快手毛利率34.3%，净利润为负，上半年净亏损63个亿。但这种亏损并非业务问题，而是期内**有巨额资本支出用于拓展市场份额和研发。**

快手在电商领域很有想象力，上半年GMV1096亿——根据艾瑞咨询的测算，这个体量排名全球第二。第一是谁没说，但谁都知道肯定是淘宝。

**⑤** 估值方面，快手本次IPO的估值在***400~500******亿***美金区间。

而媒体报道字节跳动的IPO估值大概是***1800亿***美金，打包了抖音、今日头条、西瓜视频等一系列产品。

**⑥** 短视频崛起背后是大家用手机的行为发生了巨变——

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PibOjXM8ecDNQyVDDrOicZ0Dic7CUdLTia41Rz8Piaeamob6sHwOk6ozINq82rSkJjorPFGQp3RZT1HjA/640?wx_fmt=png#imgIndex=3)

2015年，最占用大家手机时间的事有3个：聊天、看长视频、打游戏。

2019年，这3件事变成了：聊天、刷短视频和直播、看长视频。

艾瑞咨询认为到了2025年，短视频会进一步挤占大家聊天和看长视频的时间，成为手机用户的时间黑洞。

如果预测成真，我怎么看都觉得腾讯是最大的赢家——

**·**快手的第一大股东

**·**微信QQ就等于中文世界的即时通讯

**·**腾讯视频是长视频领域的头部玩家

**·**世界第一大游戏公司

移动互联网的时间争夺战，企鹅跑在了最前面。

总结：A股啥都利好茅台，港股啥都利好腾讯！![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2PibOjXM8ecDNQyVDDrOicZ0D4QrszVzeYPsUXicMXRGXI3O850Hodr1P3WRHS9l0qGEyrrRVQfMTcdg/640?wx_fmt=png#imgIndex=4)
