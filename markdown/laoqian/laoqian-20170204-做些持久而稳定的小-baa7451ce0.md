# 做些持久而稳定的小生意，挺好！

![图片](http://mmbiz.qpic.cn/mmbiz_gif/ibw8b04QVx2M7PTAr8JHoc98wCJlkDyXxsA0LtNpBgqhicVxmxOENpDia40416PMnQfU6BgCLN0bVtwGJS9LMhIJQ/0?wx_fmt=gif#imgIndex=0)

归人终究是过客，昨天回了北京，今天调整一下，明天上班。

沈阳是一座没什么特色的城市，连有名的小吃都没有。如果你们去那边旅游，我推荐三个吃食：顶好快餐、老四季抻面，大富鸡架；这三样东西，我每次回沈阳一定要吃一样，再喝上一瓶“闷倒驴”*（老雪花啤酒）*，不然就是白回来了。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02qCgMvYKH34MxWobzPkRicErYCnJAM2HX32tJ2v7qzrH2kuNv18iaGNcQ/0?wx_fmt=png#imgIndex=1)

老钱小时候有次发烧输液，老妈给我买了一份顶好快餐的鸡腿。那是我第一次吃，从此再也忘不掉那个味道了。当时我问老妈，这饭多少钱？老妈说14，我心想，好贵。

16年过去了，顶好的鸡腿饭25元一份，堪称良心。这个涨幅绝对跑输真实的通货膨胀，甚至还要低于CPI的涨幅。想必，背后的成本控制做到了极致。味道、搭配、菜单没有哪怕一点儿改变。

东北经济素来不好，体现到实体小微企业，许多店面的租户一换再换。而我知道的两处顶好快餐店面，每一个都有15年以上的历史，堪称奇迹。

那天等餐时，和服务员聊天。我问生意好么？她答，好着呢，比以前还好，外卖订单特别多，中午都忙不过来。多好的一门生意啊～

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02b6ic60tUu5mmkiaW840DDlQZbpDx6FrKZw80myPXshlIiamrskPzvYEwg/0?wx_fmt=png#imgIndex=2)

再说大富鸡架，店面在一个老小区里。每天中午开卖烤鸡架，300个售完为止，基本上几个小时就被抢购一空，排的队能拐好几个弯儿。剩下的时间卖麻辣烫。

老有人调侃东北女孩是“穿貂儿小妹儿”，给身边的金链子大哥扒蒜。这种场景我没少见过，就在大富鸡架的店里。

还有我前面说的老四季抻面。一碗抻面闻名全市，搭配的是煮鸡架*（嗯...我们东北人民对鸡架有着特殊的感情）*。我小学时，一碗面才2块钱，现在5块。据说加盟费跟肯德基差不多。

我上次和老妈去吃，一个老爷爷穿着住院服，自己吃了两碗面，把我看得目瞪口呆。当时我想，这种店它倒不了，已经成为几代人的城市记忆了。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02SKtRicicWjqyGd1G1CXibXVdldbmBCbPIwYRwr3etQhdBp2A37X2Nl4OQ/0?wx_fmt=png#imgIndex=3)

现在回想起这些，暖心暖胃。每次我在店里吃饭都觉得心里踏实极了，那感觉跟在公司楼下的星巴克里太不一样。

互联网工作是青春饭，它让你一上来就开始收割职场红利。有时候，我想，如果我过了40岁，还不是个高层，有脸在公司里呆下去么？同事里连94年的小朋友都有了，我却熬个夜都得难受半天。

所以，老钱有个感受就是，我的职业生涯大概率会在传统行业里落脚。这是[老妈退休教给我的道理](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649608177&idx=1&sn=0d35df8c844a751bb4a81bdb2bf8147d&scene=21#wechat_redirect)。

老妈一朋友的儿子，念书不好，成绩勉强上个三本。问我怎么办，我说不如不念大学了，去社会上打拼几年。要是最后能做成个小生意，小心翼翼地积累自己的口碑。虽然幸苦，但一定会过得不错。比上班强。

老钱小时候家里条件不好。上了重点初中，我们那届比较特殊，可以跨过中考，直接念重点高中。但是六年学费总计需要一次缴齐，四万八千元。就这钱，还问人借了一部分。我高三第二次模拟考试前几天，爸妈离了婚。

这么多年，老妈教给我最大的道理就是，***生活从不会亏待那些认真生活的人***。我们后来过得越来越好。

似乎经营个小生意，也是这个道理。
