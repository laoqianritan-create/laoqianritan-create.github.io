# 亏钱不愁，俺会定投！

如果兄弟们遇上了像2022年这样的熊市，或者买入既亏的瘟基，定投是最好的应对策略。

以比较渣男的新能源车ETF为例：

一种是年初一次性买入，另一种是固定每月定投，两种策略在2022年跑一遍，结果如下：

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVY958vRYo0Cic8Ho0jmPAsIDpyhLoNFGnGuBVC0veDia0IwZb9gbNOUvFcb1DxgybFhzsuoW9AxbbzA/640?wx_fmt=png#imgIndex=0)

截至昨天，每月定投的收益是**-10.8%**，年初一次性买入的收益是**-23.8%**。

在渣男行情里，坚持定投跑赢13%。

当然，我不是鼓励大家无脑定投，它也有适用条件：

下跌行情里，定投无疑是个更好的选择；

上涨行情里，定投会不断拉高买入成本，最终收益跑输一次性买入；

最关键的是，行情涨还是跌，无法预测，只能应对。

因此，我们可以给正确定投增加几个必要的限定条件：

**①**如果你持有的标的**亏损了**，可以考虑开始定投。

**②**定投请注意**节奏**、注意**仓位**，不宜过频、过重，万一遇上中概呢？

**③**定投请确保**有稳定不断的现金流**，典型如工资结余。

**④**定投请**对最坏结果有个预期**，去查一下标的的历史最大回撤、历史最低估值、熊市年份的净值走势等指标。

**⑤**定投请**坚持**，面对跌跌不休的市场，我们内心都不够强大，扛不住了，可以选择场外基金自动定投。

**⑥**对指数基金来说，估值是决策最好的伙伴；对主动型基金来说，如果已经盈利，定投请**适可而止**，让净值飞一会儿。

**⑦**当净值>所有历史买点，就是卖出的及格线。亏损卖出，负分滚粗！

最后，股市周期永存，恐贪情绪的钟摆永动。

识别周期、对抗周期注定是个体行为，绝不会形成多强大的共识，上升为群体行为。

如果周期是一台精密运转的市场机器，群体的恐贪情绪就是机器内部的核心齿轮，没了它们，周期也就消失了。

所以穿越周期只能求诸己。
