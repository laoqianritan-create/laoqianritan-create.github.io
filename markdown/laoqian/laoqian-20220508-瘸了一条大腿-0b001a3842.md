# 瘸了一条大腿

一切都发生得太快了，财政的两条大腿，今年快速瘸了一条。

地方政府和体制内岗位可能都要坐稳扶好。 

除了北京，几乎所有地区的一季度卖地收入都相较去年大幅减少，见下图黄线： 

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVZs36icxDjZYWgC7ZB6CJABsFiciaSRbNRXo3BWDicicTCIvcmp4MnaCZyhQL87E6veeGGuMDxrzmnpsIQ/640?wx_fmt=png#imgIndex=0)

对地方财政来说，税收收入+土地出让金是最大的两项收入来源。 

一方面，疫情和减税让利会减少税收收入。 

另一方面，楼市遇冷、开发商摇摇欲坠又会极大减少拿地热情，影响土地出让金。 

我一直好奇东北、山东这种非常崇尚体制内的地区未来会怎样？

唇亡齿寒，可能最后大家日子都不太好过吧～

开个脑洞：

我国最杰出最聪明的年轻人——211/985/C9毕业生们最愿意流向的行业，也基本预示着该行业红利即将见顶。 

从外企、互联网大厂，到K12教育，到公务员事业编...

这两年，体制内是热衷追求「当下局部最优解」的优秀毕业生们最爱的方向。
