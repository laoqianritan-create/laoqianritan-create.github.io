# 盘点今年逆势上涨的基金

‍

‍中金做了一个回测，看看开年以来哪些主动权益基金在大盘下跌的环境下逆势做出了阿尔法收益。

结果如下：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MHvZW0ib0DTVDgJUGqlcBwkDFYjwsvicnTxU3ydJap4NE0maDxgKgVUJsNwEskG3WqVMiatkIVtsyew/640?wx_fmt=png#imgIndex=0)

点击图片可看大图

今年的行情给人感觉是：

流动性有限**（外资和公募的新增很差）**的约束下，市场风格轮动。

今天涨的好的板块，明天可能就领跌了。

从上图可知，开年至今，金融地产、周期主题基金的业绩相对领先。

市场对灵活配置风格、低估均值回归风格比较友好。

而过去两年则对单一风格更友好**（茅指数→宁组合）**。

之前我们得出过一个重要结论：

市场就像一个生态环境，每年都会巨变，每个物种都要努力在这种变化中活下来。

同时市场会用「高回报率」奖励最能适应当下环境的物种，但这种高度的匹配又会市场再次巨变时变成一种诅咒。
