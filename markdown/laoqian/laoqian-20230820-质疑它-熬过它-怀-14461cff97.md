# 质疑它，熬过它，怀念它

燕翔老师新发了一篇报告叫《A股磨底往事》，复盘了2008、2012、2018三轮底部的诸多细节。

我认真学习了一遍，不禁感慨太阳底下无新事，很多事情哪怕经历过多次，依然在重复...

你们注意看下面三张图的灰色区域：

经历过去年和当下才知道，现实世界里的底部绝非图片中这般简洁。

灰色区域往往混杂着不断释放的刺激政策、吐槽段子、小作文。

今天「赔半就是最长情的告白」，明天「A股就是缅北，老胡给你打电话了吗？」

**磨底，除了磨估值，磨的何尝不是人心？**

每一轮下跌都有大型利好政策来确认「市场底」。

然后市场的反应是：

完全不信，非常无感，情绪丝毫没好转。

反弹之路，势能不足，坎坎坷坷。

**「政策底」之后确实还有一个更黑暗的「市场底」。**

究其原因，是从政策频出到预期扭转之间，需要一定的落地和传导时间。 

这个过程绝非一蹴而就，市场会在经济数据短期偏弱与政策提振中期预期中来回摇摆，资金用脚投票，波动不断。

你也可以说，政策底+市场底组合在一起，就是所谓的「底部区域」。

它并非某个时点，而是一段区间。

这个区域内，看短期，无人知晓。

看长期，方向明确。

回顾过去10年，每一轮向上行情都需要——

**基本面+流动性+政策+海外环境**

这四大条件中至少两个亮绿灯来支撑。

这些不确定性只能通过等待，靴子落地，把确定性等出来。

如今我们正处于新一轮底部区域，政策底已经由7.24会议确认，接下来就是磨。

历数2008、2012、2018、2022和2023，每一轮的矛盾、细节、节奏、转机都不一样，却又无本质差别。

**就像经历每一轮的人，大家总是质疑底部，熬过底部，最后怀念底部。**
