# 挑战一个月只花3千块，结果...

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MtYY6DwPeUXqfqgXDKoQRQeA9lxVSd9HTSxerpf9Kfab3NIHynuD1vvdRfyy5R85thF4htRUm9uw/640?wx_fmt=png#imgIndex=0)

7月8号我参加了一个朋友圈自发组织的打卡活动，挑战一个月只花3000块，进群后每天晚上po账单。

抠门如我，当然想都没想就加入了。

群主把这场消费实验定性为「抵抗消费主义」，敌人太强大，想赢有代价。

我问钱嫂：你愿意跟哥过苦日子么？她吃着外卖，没接茬儿...

这是一场注定失败的挑战，我知道。只是没想到，才10天就输了。

以下是我的失败经验：

群主说了，房租水电不算在3千块额度里，只需要控制好日常吃喝消费。

也就是说每天100块封顶，坚持30天就行。

我还有个优势，作为一名减肥中的无业游民，出门基本靠走是每天最大的运动量。去再远一些地方，小蓝单车月卡才10元。

所以单出行这块我就能省下一笔巨资。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2OqfzHrkibpqvu9RWEGQc0BlviaDCdNibjcjg81vNVDdLF8Zl2WXquSoglOUtGjD3xuyd8tmLCE0mq1Q/640?wx_fmt=png#imgIndex=1)

打卡第一天，因为减肥还去Wagas吃草，晚上一看账单，痛定思痛，改成买便利蜂的夜场打折三明治。

打卡第二天，花了102.5元，超标了，居然有负罪感！（P.S.打车是因为下雨还要见人）

第三天和人吃饭谈事儿，买完单发现花了428...

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2OqfzHrkibpqvu9RWEGQc0BlK117Q6YX9niaNIvAtZbA1icia9zejQFwDOlFFqOFVolxzBibQf8eUm3K2w/640?wx_fmt=png#imgIndex=2)

此时我的心态已经彻底崩了，真的，只想破罐破摔，想吃啥吃啥吧！

而且贴上「省钱」标签后在群里晒大额消费居然有种炫富的感脚...

吃饭也很节省，有时会自己做，点外卖也很少超过30元。为了省钱还买了「饿了么」会员。

这几天我还学会了做「大阪烧」，一个洋生菜就能做好几次。

但是水果真的费钱！比如这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2OqfzHrkibpqvu9RWEGQc0Blib5mEA7xxkLicgKpfb5tSpAObk6bJ9q0VwrOm6ibO5wicNV2GIicZFEcNBg/640?wx_fmt=png#imgIndex=3)

我昨天买了1/8个西瓜+2个水蜜桃花了22块，知识星球里发牢骚：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2OqfzHrkibpqvu9RWEGQc0BlZmS3ewjVDFLxOu1PRHRnK6v1WybmtBVWx9Y9wkhIQzf6M8e2OV5X3Q/640?wx_fmt=png#imgIndex=4)

以前还能喝点儿瑞幸和星爸爸，打卡以后一律改成便利蜂的免费咖啡（超级会员的权益）。

哦对了，我还有个固定消费就是「缴多巴胺税」——每天下午都无可抗拒地想吃东西，咖啡、茶、水果、面包、酸奶...而完成收税工作的就是家楼下的便利店。

为此我非常有仪式感地跑了趟很久没去过的超市，一次囤了不少东西，省钱还省事儿！

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2OqfzHrkibpqvu9RWEGQc0BlyV7Xia1KvhAYr9jvOpYgZOLcK1CR9MkWeaJHvjnibI3ak9UYUWiaNr6pA/640?wx_fmt=png#imgIndex=5)

然而真相是，4天以后这些东西就都被我吃光了，比之前还费钱！

上个周末和钱嫂去做了盲人按摩---120元

去快手美食账号推荐的馆子吃饭---206元

逛超市---86元

请保洁阿姨---80元

我实在没有心情再去记账，没能及时打卡报账，被踢出群了...

身残志坚的我本想独自继续挑战，直到前天晚上刷淘宝看到人体工学椅的那一刻，所有情绪都爆发了——

算了，早晚都得买，早买早享福，向消费主义低头吧。老子不玩了！

坐在2800块的人体工学椅上写这篇稿子时，突然想起刚来北京的第一个月，实习工资刚好也是3千块（150/天），那时居然能有结余。

当然这10天还是有收获的：

比如我做了好几顿早饭，再也不会懒得逛超市，更有动力把花钱买的书看完，以及...人体工学椅真的很舒服。

之前晒过身边几个朋友的月账单，你们感兴趣可以去看看👉[《晒几个账单》](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649610235&idx=1&sn=ddb9f8ce378e45b1f8d062b79d517bc5&chksm=881c1327bf6b9a310d330bea8cf66755ce25d2a7ca7a11e4625d749104d82f9f280c09308906&scene=21#wechat_redirect)。

今天市场传闻陆金所计划退出P2P业务。

陆金所也回应了：正在配合监管「三降」要求，网贷业务正常运营，存量产品与客户权益不受影响。

陆金所的所有P2P业务都放到了「陆金服」平台里，待收984亿。

备案迟迟不落地，老大哥都不玩了，可见这行的变数之大，还是建议大家到期后撤出P2P，不论平台。

中信建投统计了1600多家公司的中报披露情况。

按行业划分，最好的是农林牧渔、通信、综合、机械设备和建筑材料；

最差的是汽车、建筑装饰、有色金属、轻工业制造和钢铁。可以看出来多少都和进出口有关。

另外正和日本贸易摩擦的韩国今天宣布降息，这些影响都还有限，重头戏是月底美是否会降，市场都在等。

美联储7月31号会开「议息会议」（FOMC），现在市场的预期是百分百降息25个bp（0.25%）。

一般美联储的降息窗口会有两个先行指标：

**制造业PMI会先于「降息」跌破50枯荣线；**

**失业率会拐点会先于「降息」到来，且失业率不会很低；**

现在的问题是，这两个指标都没恶化，当前PMI51.6，失业率3.7%在历史上也是很低的水平。

然而现在美股和国债又已经充分吸收了降息的预期。大概就是这么个情况。
