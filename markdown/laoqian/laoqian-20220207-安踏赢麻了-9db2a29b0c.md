# 安踏赢麻了

冬奥会成了羽绒服品牌展销大会。

中国国家队在开幕式和比赛中穿的都是安踏的衣服，借着这个热点，给大家补充一些背后的信息。

**··· ···**

服装行业一直充斥着资本收购。

2009年安踏从百丽集团**（后被高瓴私有化）**手里接手了严重亏损的意大利品牌FILA，希望借此冲击高端市场——此时安踏李宁等国产品牌的定位都是中低端。

在安踏的运营下，定位运动休闲的FILA越做越好，2020年营收超过主品牌安踏，毛利率达到惊人的70%。

2018年安踏又联合腾讯等资本联手收购了AMER公司，这家公司旗下全是细分领域的顶级高端品牌，包括始祖鸟、萨洛蒙、Wilson、Precor、Atomic等等...

这些在国际上知名度颇高，在国内却只在小圈子里流行——一是太贵了，二来国内的销售渠道也非常有限。

从2020年开始，户外、露营、滑雪等活动的声量在小红书、抖音的推动一下子就起来了。

其中声量最大的就是始祖鸟，一个顶级户外品牌，被大家称为「鸟家」。

在羽绒服鄙视链里，鸟家是加拿大鹅之上的存在。

户外圈或者熟悉始祖鸟的都会觉得加拿大鹅是垃圾，这种鄙视不是品牌之间的互相攀比，而是那种理工男思维的瞧不上——你丫参数不行！

始祖鸟的灵魂产品还不是羽绒服，而是冲锋衣。这么说吧，在一部分男人眼中，一件上万元鸟家旗舰冲锋衣的诱惑不亚于LV包之于女生。

最好的鸟家冲锋衣会使用goretex-pro面料——这东西耐磨、耐脏、防暴雨、防风、透气，里面搭配一件排汗棉服或摇粒绒，基本可以应付整个冬天。

其实每次我收到广告费都想冲动消费买一件鸟的冲锋衣，但一直不舍得，真的太肉疼了，程度仅次于冒绿光的股票基金账户。

**··· ···**

李宁之前也尝试过跟安踏一样的收购扩张之路，但最终没成功。

08年北京奥运会点火仪式成了李宁和李宁公司的高光时刻，随后公司开始疯狂开店**（超过5000店）**，最终因为设计缺位、销售不利，在2012年爆发了极其严重的**库存危机**。

这期间李宁也在走多品牌战略，买了LOTTO、Kappa、KASON、红双喜、Z-do等品牌。

但主品牌都深陷危机，更别提其它品牌的孵化了，最后这些品牌大多都因为财务压力而砍掉。

在安踏收购AMER正式走上多品牌之路的同一年，李宁走了一条新路——

重视设计和年轻人，推出了国潮路线的子品牌「中国李宁」。

后来的事你们都知道了，中国李‍宁的市场认可度很高，并逐渐成为李宁的另一条大腿。

> **P.S. 个别缺心眼的营销号会炒李宁的CEO是个日本人... 好吧，我告诉你，李宁之前的CEO还有美国人。可能拿这种事做文章的人根本不懂职业经理人吧...**

**··· ···**

安踏外延收购其他品牌，李宁内部孵化新品牌——这两条路阿迪耐克都走过。

比如耐克孵化了Air Jordan，收购了Converse等诸多品牌。

阿迪则孵化了三叶草，收购了Reebok等品牌。

不能低估深耕某一细分运动的小品牌，这里可能长出Lululemon、Under Amer这样的巨头。
