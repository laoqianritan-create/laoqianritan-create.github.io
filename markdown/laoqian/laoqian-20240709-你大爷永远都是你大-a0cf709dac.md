# 你大爷永远都是你大爷

✅图1、2，同一组数据的两种展现形式：  
  
30、40后，1.7亿人，八九十岁的人了，80、90后的祖辈，养老院主流客户。  
   
50后，1.6亿人，退休有段日子了，身体毛病越来越多，医药消费大户。   
  
60后，2.2亿人，史上最猛退休潮，未来平均每天退休八、九万人，每天！正处于养老蜜月期，有机会多出去玩玩，越往后成本越大。前面几个群体也是骗子们的主要目标！  
  
70后，体量和60后一样，还在工作，等退休。没啥资本开支，高储蓄率，趁着还能干，努力给家里的00后多捞点儿。   
  
80后、90后，体量也都差不多，社会中流砥柱，扛起了居民部门杠杆的大鼎，见过经济高速增增长期的余晖。目前正承受来自资产负债表和现金流表的阵痛，并且将痛苦线性外推。   
  
00后，人数上比90后减少了近5千万人。考公、考研、留学、陆续进入社会。  
  
✅图3~6，财富的代际分布，在未来将是越来越重要的命题。  
  
我说句心里话，消费行业，还惦记年轻人兜里那仨瓜俩枣儿，性价比不高了。财富管理行业早就看清趋势了，钱在谁手里，这是根本问题。  
  
✅图7，这是我今天看到的最震撼的一张图！  
  
这大爷，这阿姨，这要溢出屏幕的老年性张力，简直双杀！谁看不迷糊啊！一看一个不吱声儿！  
  
有时候想想，自己写养老，探访养老院，金融机构拍养老视频，各种保险、红利产品努力往养老身上蹭，有用吗？在这两位老年模特面前，一文不值。  
  
只有老年人才能说服老年人，你大爷永远都是你大爷。  
  
我搜了下图7.中视频号的注册主体才明白过来：大爷永远是大爷，但真正厉害的还是大哥。
