# 倒霉到家的前首富

●

AMC是今年美股市场的一支大妖股，堪称YOLO小旋风。具体有多妖呢？像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2OE0icicLauONwUaVrcSO5kLYicGFez7tEpwNdibKSMlWacWdzzpvWBLvNbSTfAQn3vnRYXW9ibwwDlKjA/640?wx_fmt=png#imgIndex=0)

半年30倍涨幅，市值300亿美元，放到A股也算2000亿大白马了。

这家院线公司本来是老王的。2012年万达花了7亿美元完全收购了AMC，并推动其上市，从2017年开始AMC股价一路阴跌。

2018年老王开始各种甩卖国内外资产变现，其中也包括AMC，总之就是一路减持，终于在今年5月份基本清仓了AMC的股权，彻底退出公司董事会，仅保留了少数股票，累计变现了14.76亿美元。

7亿美元买的，套现近15亿退出，虽然没亏，但是估计老王心情跟吃了屎一样，因为公司现在值300亿美元，万达在底部持续割肉，在股价黎明前彻底清仓。

就在万达5月23日发布公告说AMC已经退出后，AMC股价7个交易日涨了4倍。

当然，AMC股价显然是被美国散户炒起来的，公司能否扛过今年都难说，但至少这轮泡沫老王是一点没捞着。

而A股的纯种院线股、拥有中国最多荧幕数的「万达电影」股价也连跌6年，市值378亿，约等于1/6个AMC。

这种点背程度不亚于老王在万达商业地产上的操作。

2014年万达商业在港交所上市，成为当年最大IPO公司。

2016年老王觉得万达在港股不受待见，估值被严重低估，实在没法忍了，直接私有化，去A股圈钱得了，这边估值给得高。

结果A股素来不欢迎房地产企业来上市，什么恒大万达一律不给面子，老王这排队了6年还是没等来审批。

最气人的是2020年物业股在香港市场超级被看好，市盈率甚至愿意给到100倍以上。

万达又完美错过，只好灰溜溜撤销了A股的IPO申请，又跑回港股排队上市。

时来天地皆同力，远去英雄不自由。这点子真是背到家了。

●

说个打肿脸事件给大家开心下。

之前我太年轻，不懂事，为了亲身给大家示范在最乐观、最高估时追高瞎买的后果有多惨，我在去年12月21日中证白酒指数55PE，估值百分位100%**（历史新高）**时追高买入。

因为知道这是一场中短期必亏的投资，没必要浪费钱，我就只买了10块钱的，坐等它跌！结果你们应该都能猜到：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2OE0icicLauONwUaVrcSO5kLYe5sCOOHvFGmls3b0BjVIWmeiaLgx9lwGWk3e4IPeiay1IQLibPdFttqlw/640?wx_fmt=png#imgIndex=1)

算上今天的涨幅，目前盈利21%。

在此宣布本次实验到此结束，不玩了。如前面所说，是我太年轻，惹了不该惹的大哥，现在趴在地上唱《征服》，以及后悔当初为啥不在份额那一栏多按几个零。

本人在中证白酒身上第二次犯傻是2019年7月停止了3年的定投并赎回，像个小丑。

以后再也不和大哥对着干了，但30PE以上不定投买入是我最后的倔强。

仅剩的10份份额我会一直留着当做纪念，时刻提醒自己别瞎折腾，没什么用。
