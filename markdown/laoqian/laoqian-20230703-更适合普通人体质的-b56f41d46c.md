# 更适合普通人体质的“宝典”

很想给兄弟们推荐《金钱心理学》这本书，它比去年很火的《纳瓦尔宝典》更适合普通人。

这本书的厉害之处在于——

很多理财投资中的朴素道理，大家听完可能相当无感，那不过是一堆“正确的废话”罢了。

但这本书的说服效果却很好，旁征博引，一发入魂。

面对投资理财，我们都太过重视「正确」了，却忽视了自己的感受。如果自己都不舒服，又怎能期待长期的好结果呢？

**投资体系不仅涉及「策略」层面，更需要有稳固的「三观」作为支撑。**

本书有助于帮我们慢慢塑造出一套适合自己的「金钱观」。

这期节目2小时，可以带大家省流地过一遍《金钱心理学》。

希望对兄弟们们有益，更推荐大家去阅读原书。
