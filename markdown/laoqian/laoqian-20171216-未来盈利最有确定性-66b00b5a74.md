# 未来盈利最有确定性的行业—医药

最近看了林园在雪球嘉年华的演讲，讲的一般，但是有个观点深以为然：长周期来看，未来有个行业一定赚钱—医药行业，人们会为保命花钱。

人口老龄化、消费升级等宏观层面的机会无需多言。

今年美股研究领域有个论调特别火—**房地产、教育、时间，是新时代阶级博弈的三个战场。**按照顺序，维度从低到高。

这个逻辑我是服气的。

何为时间战场？一是活得更高效，二是续命。前者依靠人工智能、后者则是医疗。

投资最重要的一点就是👉[需要确定性](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649609377&idx=1&sn=9d39b5822bb380cc8865d9d8a74e7a8b&chksm=881c107dbf6b996bb07276a271fb3bbb4aa9715f25c1cdc2a7167386b36e51ad92f2b3c1ab70&scene=21#wechat_redirect)，如标题所说，医药行业绝对是确定性极大的行业之一。盈利能力也不错：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2OAROq4I8QcVdrGZ7WQJZ8ua59qahvajibib66Mu41D8bOfBG1BcnvlHaCWbopR5sY6R1Pialn2M7h2g/0?wx_fmt=png#imgIndex=2)

今天聊聊医药行业，包括行业趋势、标的和投资机会。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02b6ic60tUu5mmkiaW840DDlQZbpDx6FrKZw80myPXshlIiamrskPzvYEwg/0.png#imgIndex=3)

医药行业是个特别宽泛的概念，可以细分为几个具体领域：

* 医药制造
* 医疗服务
* 医疗机械
* 医疗美容
* 医药流通
* 保健品

每个领域的盘子都很大，目前巨头多集中于医药制造领域，这个后面会有具体标的介绍。

先来聊聊国内医药行业的问题：

***1***大家都不便宜，行业整体市盈率（PE）30多倍。这意味着什么呢？如果整个行业不增长的话，这个估值下，你每年的回报率也就3个多点。

这不光是我们的问题，国外市场的医药行业估值也都这个水平。

可能大家都知道医药行业需求稳定，盈利预期明确，才给了它如此高的估值吧。

***2***虽然行业需求稳定，但国内医药企业的波动真的不小！不同年份的净利润可以相差20倍。如下图：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2NYeMC42U8yejpAF52p9aJGmOicdokKqfibfzZlalTr7Ym2sm9NibquUxeWkicOROXRTneedLzmGU3XBg/0?wx_fmt=png#imgIndex=4)

红线为利润曲线

造成这种波动的主要原因是政府对药价的限制，一般有管制的年份，利润都不咋地，直接影响业绩和股价。

***3***国内的医药行业，真的有些不思进取。

对于做原研药的企业，以及真正的巨头公司，有个财务指标特别关键—研发投入。因为只要研发出好产品，绝对大赚特赚，钱景无限。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2NYeMC42U8yejpAF52p9aJGlibVhnSDlibpJol4icl2dCpIXVano467btBQKq4ZyuooMLr0PSfYIwMiaQ/0?wx_fmt=png#imgIndex=5)

美国新药研发周期

上面这张图是我根据网上资料做的，美国新药研发周期。

你们感受一下新药的研发成本和难度。不管是大病小病，只要研发出了有效的药物，长期赚钱根本不用愁。

**可是从数据上看，国内的制药企业，把太多钱花在了打广告上。**

假设医药行业每年赚100块，大部分企业的做法是：拿3块钱研发新药，拿20块去打广告。

目前医药行业的研发投入占比中位数是3%，销售费用占比中位数是20%。

当然了，如果是以仿制药为主营业务的药企，在营销方面多花钱还是很合理的。

![图片](http://mmbiz.qpic.cn/mmbiz/ibw8b04QVx2Mic6PGWVNqAFHDdX4tZUk02SKtRicicWjqyGd1G1CXibXVdldbmBCbPIwYRwr3etQhdBp2A37X2Nl4OQ/0.png#imgIndex=6)

除了新药研制成功，医药行业未来最大的投资机会，莫过于行业整合，提高集中度。最终结果就是产生巨头。

目前港股医药巨头是石药集团，市值不到千亿。A股最大的医药集团，市值不到2千亿。而美股的医药巨头强生、辉瑞全部万亿市值。

港股最大的医药股石药集团，就是典型的通过并购整合一跃成为龙头企业。一款明星产品恩必普，就贡献了超过十个亿的利润。

国家也在引导推进行业整合，典型的政策就是“两票制”。药品的生产—销售流程如下：

生产企业—流通企业—医院/药店

两票制压缩了流通企业层层加价的环节，流通环节利润减少，就会进入整合并购阶段。这种时候，资本实力雄厚的龙头企业强者恒强。

这种杀估值的情况说明什么呢？

我们知道，PE的计算方法可以简单理解为：市值/赚钱能力。

所以指数涨了，PE却一直降，说明指数成分股的盈利增速，快于指数的增长。

512010前10大龙头股的持仓占比超过70%，而其他基金前十持仓占比最高40%。目前易方达的这支也是所有医药指数基金中业绩最好的。
