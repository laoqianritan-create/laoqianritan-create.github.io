# 美股惊魂一夜vs港股惊魂一日

**●**

流动性退潮啥样？

看看昨晚美股开盘后的表现就知道了，浓浓的股灾味儿，一片惨跌！

几大知名权重股集体重挫，纳指最高跌近4%，中概股全部杀跌。

市场如此恐慌的原因主要是涨得多，估值高，以铜和油为代表的大宗商品价格通胀抬头，美债收益率大幅走高，经济复苏...

总之诸多因素吧，**大家担心美联储提前收水加息**。

好在，那个最关键的男人及时发声救市，稳住了人心。

美联储主席鲍威尔再次明确：将保持当前的超低利率和QE购债，知道经济复苏有实质性进展为止。

关键女人耶伦的1.9万亿财政刺激计划也板上钉钉。

总结来说就是水还是大大的有，但势头稍微不对的话，昨晚美股也给大家预演过了。

**●**

港股惊魂一日，主要是被「提高印花税」这个黑天鹅给吓到了。

2018看北水，2021看南水。今天的南水长这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2O6ickx1CZ1uZcZUibia52aGnDVN2FRvHicZh6t8FCST66mlsLa8ib2wic0ibwfuBic2OvQmvEIIQy9rfyWzg/640?wx_fmt=png#imgIndex=0)

开年以来首次净流出，买买买了两个月，今天脚底抹油跑了129个亿。

提高印花税的大背景是港府财政赤字，缺钱。

这里既有天灾也有人祸——

从中美Eileen贸易摩擦、红空、疫情封关，过去一年多香港和港人的日子都不好过，港府为了纾解民困只能不断地砸财政支出。

花钱的地方太多，就得开源节流，楼市不敢动，这两年港股大热，只能薅股市的羊毛了。

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/ibw8b04QVx2O6ickx1CZ1uZcZUibia52aGnDxpAbkV6TDzqtXicQkaMXa02TRUN9O18RvUHKX8NtzgN6ZBbPW03Woiag/640?wx_fmt=jpeg#imgIndex=1)

印花税提高三成，每天多赚半个亿，股民每一次买卖，都在为香港做贡献。

然而流动性不足恰恰是港股最大的痛，在香港上市的股票相对A股或美股普遍大幅折价。现在印花税提高再一次打压了成交量。

这两年受益于香港市场地位提高的港交所对此也表示无奈又失望，「但是理解政府的做法」。

按理说，交易成本与公司质地没有任何关系，但流动性的折溢价从来都是股票价格的一部分，所以这个政策对所有港股还是长期利空的。

哦对了，本次提高印花税主要影响的是来买港股的南水。对北水没有任何影响，北水要交A股的印花税。

另外，因为估值问题和一些个人原因，我上午把定投了近两年的「恒生指数」和「恒生国企指数」给清仓了。

两个指数基金从2019年红空期间开始定投，卖出时恒生盈利20%+，恒生国企8%。

因为波动很小，真心没意思，如果不是去年三月份多买了一些恒生，收益率会更差。

以后除非极度便宜，否则不会再碰这种波动小的指数。

还不如定投科创50或者恒生科技这种高波动指数来得刺激。
