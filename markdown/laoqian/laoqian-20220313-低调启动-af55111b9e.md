# 低调启动

‍‍

‍‍本文是对[《28个核心城市买房的β收益》](http://mp.weixin.qq.com/s?__biz=MzA5MDg0NjY0Mw==&mid=2649619983&idx=1&sn=ada447495cc51ed27acb096f071acc5c&chksm=881c3ad3bf6bb3c5662da2001e54929102395b5264850616ce45e32c072d733c9cebbd9a7c19&scene=21#wechat_redirect)的补充。

我用**「月度同比」**这个指标，尝试勾勒出一二线楼市的**周期感**和**波幅**。

另外有几个城市的数据没查到，比如苏州、东莞、佛山、珠海。我去国家统计局找了半天，确实没有。当然也可能是我水平不行，有懂行的读者可以留言指点一下。

下面的图，你仔细看的话就会发现**不同城市的周期时间和幅度还是有一些差别的。**

众所周知，今年楼市放松的迹象非常明显——

银行系统的贷款额度放松、利率加点降低、甚至降息也是可期的，还有限购的放松，贷款的友好，首付比例降低，限价的放松...

一切为了稳增长。

因为不同城市因城施策，各种密密麻麻的新闻也不好总结。

但是我想提醒大家**（尤其是有买房打算的读者）**：

**重视这个信号，多关注本地的政策变动，多看房。**
