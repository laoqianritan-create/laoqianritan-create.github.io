# 短短3个交易日，埋了8万亿

9.30、10.8、10.9三个交易日，大概埋了8万亿资金。✅图1.  
  
8 万亿什么概念？大概占 A 股总市值的 8%。  
  
这告诉我们什么道理？  
  
这8万亿资金中，大部分都是奔着等雷击的预期来的，但雷击时刻只占极少数。✅图2.（点击图片看完整版）  
  
预期打满时，稍有回撤都会陷入（边际减弱式）失落，比如10月8日。  
  
普通投资者的买卖动作和情绪是对价格的被动反应。  
  
整体情绪只有贪婪和恐惧，并不存在中间态。  
  
人得为自己的决策承担后果。  
  
以上现象和规律都same as ever.
