# 被泼了一盆冷水

***1***兄弟们，事情是这样的：

昨天的推送，很多读者都在评论区表达了对个人养老金账户的质疑。

说实话，大部分我都没当回事，不过点赞最多的那条评论确实提了个醒：

![图片](https://mmbiz.qpic.cn/mmbiz_jpg/M7fHtGOlzVbCruMuFJTz9Yd0IwzzVd97c9XxrMQw4Aa0LnGib5StXhWy4Xzel0oPfwVjQqrJ8odm3R2C9VicaywQ/640?wx_fmt=jpeg#imgIndex=0)

这事我有点吃不准，上午再三确认，读者说的没毛病！

个人养老金，确实要到法定退休年龄后才能领取。

**如果延退落地，那个人养老金账户的提现时间确实也得相应地延后...**

***2***诶... 真的好有挫败感。

而且仔细琢磨，也有点儿不合理。 

虽然延迟退休大概率不会一次性延后5年，还是不同年龄的人按年甚至按月逐次延退。

但对个人养老金账户的投资者来说，买的时候默认的预期普遍是60岁可以领，现在意识到未来极有可能还要再延长几年，这确实是违背预期了。 

尤其85后延退到65岁几乎板上钉钉，不爽也很正常。

这...有点语塞。

尽管如此，我还是会坚持顶格投资个人养老金，**主要是想做一场超长期投资的实证**，看看最后结果如何。

不过也严肃提醒大家，**一定确保投进去的钱能匹配上个人养老金账户的锁定期！**

***3***用一张图片给大家演示下「延迟退休」：

我国养老金现状是这样的：参保人数10.5亿人，其中大约2.89亿人正在领取养老金。 

说白了就是仍在工作的7.61亿劳动力在缴纳养老金，体系再通过「现收现付」的方式把这些钱及时转移给退休老人。 

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVbCruMuFJTz9Yd0IwzzVd97nnyJOv4icIWzTutsRd9cxVMLQibwzlHO9WBpiaNdpk1Fqd0cg9t8vIs1w/640?wx_fmt=png#imgIndex=1)

目前我国法定男性领取养老金年龄为60岁，女干部55岁，女工人50岁。 

养老金是一直领取到死亡的。 

我国男性预期寿命为75.3岁，平均领取15.3年。 

我国女性预期寿命为80.5岁，平均领取25.5~30.5年。 

延迟退休在做什么呢？

就是逐年把领取养老金的年龄往右移。

老龄化最严重的日本，已经把领取养老金的年龄逐渐右移到了70岁。

**P.S. 日本男性的平均预期寿命为81.4岁，女性为87.5岁。**

***4***怎么评价呢？Well, this is life.

感性地讲，是个人都希望早退休，最好一边领退休金，一边返聘再就业，赚双份收入。

但退休制度只能从整体考量，比如人均寿命一直在提高，而现在的退休年龄其实是1951年制定的。

再比如，养老金体系涉及代际公平，越早退休，还在职的劳动群体要承担的社保压力越大，代际矛盾也就越激烈。

以上矛盾，都需要延退来缓解。
