# 美股再次草木皆兵

**●**

五一假期港美股是正常交易的，几个主要指数自周一（5.3）以来的表现如下：

恒生指数**-1.07%**

恒生科技指数**-2.48%**

标普500指数**-0.4%**

纳斯达克指数**-2.36%**

截至发文时，美股还没开盘，所以两个美股指数统计的是5月3、4两日的表现。

美股和港股表现不好，主要是前美联储主席，现美国财政部长耶伦昨天给「加息」吹了风，原话大意是：

> **受大规模财政支出影响，为了防止经济过热需要适当加息来抑制通胀。**

一语惊人，纳指和中概股迅速大跌。见势头不对，几小时后，耶伦又站出来澄清说自己并没有预测或建议加息。毕竟我也不是美联储主席了，我很欣赏美联储的独立性。

当然这种情况也不是第一次了。

从2月底开始，因为担心美联储收水加息，美股自己吓自己把心态干崩溃了。最后还是鲍威尔出来发声说利率还会这么低，QE购债不会停，这才把市场稳住。

所以算上这次，美股对加息和流动性退潮已经提前彩排过两回了，就等摔杯为号。

哪怕鲍威尔在4月28日的美联储议息会议上鸽声嘹亮，可只要有点风吹草动，那必定草木皆兵。

美联储有两大政策目标：

一是保住就业率，越充分越好。

二是控制通胀，尽量稳定在2%左右。

只有这两个目标都取得实质性进展，经济复苏乐观时，才会真正开始收水加息。

对于就业率，盯着高频的非农数据即可。

而通胀，不用怀疑，目前就是通胀。

主要大宗商品价格都在大涨价，像紫金矿业等周期股这两天在港股市场都涨得非常好。

包括美国房价，也在快速大涨，不断创新高。

现在的市场氛围打个比方就是：

大家都知道音乐早晚会停止演奏，但只要曲子没停，又都得跳舞。而且很多人在边跳边往出口那边挪。

**●**

美国那边货币政策把市场吓得摔了个跟头，我们这边的货币政策也在4月30号的政治局会议上吹了风，我看了多家券商对此的解读，大同小异，大家普遍认为：

第一，今年完成6%的经济增长目标毫无压力，定性为「稳增长压力较小的窗口期」，所以要趁机做好各种调结构的工作，包括地方债去杠杆、布局碳中和、科技赋能、耕地保护、**反垄断**、**房住不炒**等等。

第二，货币政策不会收紧，不会急转弯，仍然围绕紧信用+宽货币的政策节奏。

但广发郭磊团队也提了个醒——对资产定价更有利的阶段一般是财政货币双宽的**稳增长阶段**，而**调结构阶段**往往压力较大。

总体来说，今年**货币政策不松不紧**，**企业盈利向上**，都是利好。

一方面有利于消化估值；

另一方面，受到外部冲击**（美国加息或印度疫情超预期）**跟着跌，但基本面并没有变差，那么下跌就意味着机会。
