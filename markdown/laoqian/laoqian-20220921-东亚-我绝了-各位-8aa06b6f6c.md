# 东亚：我绝了，各位随意！

***1*** 不知道大家发现没，这两天有关我国老龄化的报道和讨论又多了起来。原因就是前几天国家卫健委提醒2035年左右我国60岁以上老人将突破4亿。

老龄少子化是个灰犀牛问题，大家都知道，都装看不见，非得媒体点一下，大家焦虑几天，然后继续视而不见，直到问题避无可避。

社科院的测算是，到了2035年我国会耗光「养老保障基金」的全部结余，如果考虑到延退，那时候差不多第一批70后开始退休。

***2***关于养老，我们写过很多文章，比如：

[《当年轻人工资和父母退休金倒挂》](http://mp.weixin.qq.com/s?__biz=Mzg2MDc2MjM3NA==&mid=2247494931&idx=1&sn=e6ea37767b46c83e39f0f751cb546145&chksm=ce23d57af9545c6c57010f5f7d65e1778c575dc96f864c13e391932749b47aa6793af9bbd1be&scene=21#wechat_redirect)分析了我国养老金的现状和问题；

[《丁克劝退神书》](http://mp.weixin.qq.com/s?__biz=Mzg2MDc2MjM3NA==&mid=2247493823&idx=1&sn=c1b35c79fb78f5eb06e587848fe37bdf&chksm=ce23d0d6f95459c0335aa5e79c8c6a20a713959a402a5ac390be2e244ee7ced836ecd59403b0&scene=21#wechat_redirect)是我看《老后破产》的读后感，里面写了日本的整体情况，以及几位窘迫老人的每月收支账单，细节满满。

***3***在养老方面，日本这块石头至少证明了几件事：

第一，在一个人均GDP超过4万美元，财政支出中「社会保障」占比高到让年轻人愤怒的经济体，完全依赖养老金仍然很难过上体面的晚年。

第二，健康问题和医疗消费，无房和房租、无子女、有债务、存款少是老年悲剧的几大源头。

第三，延迟退休是必然的，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/M7fHtGOlzVa6E4tVibCjg0SQP28Eibv0GrQ1Xy8cMtNuRibCpXr3d89J6mlI1hwiazs6HwjosZL8tV6dicibR4Y52iabg/640?wx_fmt=png#imgIndex=0)

另一个触目惊心的数据是，日本65岁及以上老人的犯罪率超过20%，就业率超过25%。老后就业，老后进监狱，都是为了更好地活着。

***4***给大家梳理下中日韩三个东亚经济体的人口问题脉络。

东亚模式有几个共性——

①集中力量办大事

②人口红利→人口负担，婴儿潮60年后就是退休潮

③人均资源有限的硬约束下崇尚奋斗文化

④承接西方产业转移，作为制造国纳入全球分工体系，迎来阶段性经济腾飞

***5***最后一个共性是都经历过外力影响下的经济危机。

日本：日美贸易战，主动削减优势产业，《广场协议》拖累出口，为保增长主动加杠杆投资，泡沫破裂。

韩国：外债在经济波动和加息周期下扛不住，亚洲金融危机后，被迫金融自由化，引入外资允许控股，财阀和外资结合。

中国：参考温铁军教授的《八次危机》，城市危机转嫁给农村，农村优势资源转移给城市，年轻劳动力进城，社会保障覆盖农村老人的力度有限。

***6***中日韩解决人口问题的三种思路

日本模式：安倍三支箭包装下的扩张性财政和货币政策。发明了量化宽松，首创央行干预资本市场。政府加杠杆成了治标不治本的特效药，药不能停，负债支持「公共福利支出」的高占比，进而帮企业和居民稳杠杆。死气沉沉，但一切稳定，长期高就业率。

韩国模式：「社会保障支出」占财政预算的比例很低。亚洲金融危机后进入的外资和本土财阀结合，要喂饱。居民部门杠杆率世界排名靠前，全民变态，好赌，自杀率高，房价高，生活水平低。

中国模式：在发展中解决问题，2001-2011经济高增速平台运行，2011-2019经济中等增速平台运行。农村供养城市并承接发展代价，房地产转化为财政收入，地方政府有一定杠杆率（藏于企业杠杆里）。

P.S. 横向比较下几个经济体的「社会保障」占财政支出的比例：欧洲福利国家都很高，法国最高31%，美国18.7%，加拿大18%，日本22.3%，中国13.7%，韩国12.2%，墨西哥7.5%。

***7***总结：

老龄少子化是工业化和城市化的伴生现象，说实话，各国没看到啥有效解决思路，稳住不恶化就是胜利。

内部比烂的话，日本好于中国好于韩国。

经济增长做大蛋糕是帕累托改进。共同富裕，调节分配是动存量蛋糕。财政支出是硬约束，厚此就要薄彼，一定有人承担代价。

中国的解题思路：三座大山，政策来搬。从分配入手，共同富裕。以经济建设为中心，趁着窗口期，努力调结构，做蛋糕。养老体系缓慢改进，但似乎窗口期不多了。农村咋办？呵呵，我就问问。

日本的解题思路：调节货币和财政政策，由政府加杠杆来维持社会保障支出，日本国债/GDP冠绝全球。居民和企业得以稳杠杆，优势产业没能抢下来，都躺平了，人均GDP从5万美元掉到4万美元。

韩国模式：想调整但力不从心了，优先喂饱财阀和外资，居民加杠杆，只要薅不死，就往死里薅；
