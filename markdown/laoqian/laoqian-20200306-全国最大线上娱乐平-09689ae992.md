# 全国最大线上娱乐平台，血赚

今天的标题，要是再来点儿背景音乐，估计很多男读者已经嘿嘿嘿地笑了。

打住！车确实是开往幼儿园的。全国最大线上娱乐平台说的当然是我大A股。整个2月份大部人都停工宅家，谁闲着没事儿还不去A股爽两把，券商的生意自然好。

券商和保险行业很像，每个月都会披露经营数据。目前看，已经公布的27家券商2月份净赚102个亿，环比增加41.3%，同比增加19.3%。

正好借着这事聊聊券商行业什么时候值得配置？

盯紧四方面足矣：

一是**市场流动性**，很好判断。

包括货币政策，比如现在的基调就是稳健的货币政策更加灵活适度。还有市场交易量，单日破万亿是标志。流动性好了能给券商行业带来弹性。

历史上的宽松拐点还包括08年、14年底。相信你们也能感觉到，市场流动性最好的时候，并非经济最好。

二是**证券行业的监管政策**，也很好判断，大体思路就是**由强监管转向鼓励创新**。

比如去年下半年至今的科创板试点注册制、并购重组、证券法修订、再融资新规等等都是信号。比如下图：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2O5vdEF82ebeRqSPYvSjlQmicV0hq3bBIXz7tDextqnfuqoC3jFFhiblBJSQeZYc05VcanfMpVMXYicw/640?wx_fmt=png#imgIndex=0)

从上图能看出来，**券商历次大涨都是流通性+政策同时利好共振的结果。**

三是**基本面**。一和二算先行指标，反映到基本面上会有一定滞后。但证券行业不一样，每个月都会披露经营情况，通过这些数据也能基本感受个大概。

券商是典型的周期性行业，大部分时间平淡无奇，一旦牛市行情来了，立马会所嫩模。比如下图：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2O5vdEF82ebeRqSPYvSjlQmrqjP1MXF4vanON6iankLDoocibewTuVmSRAnnXslMT9zO0jRc1gkV2ww/640?wx_fmt=png#imgIndex=1)

牛市来了，ROE能直接拉到20%。

熊市来了，ROE可怜到只有5%。

四是**估值，**从上图能看出来券商的PB估值和ROE高度一致。

大部分时间券商都是不温不火的**波段行情**，在1.5-2PB估值区间晃荡，也就是下图的三个绿色区域。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2O5vdEF82ebeRqSPYvSjlQmNNhTDzBqUL9jeiaDn3YmCXZs4J1RwghwE4yibFKpojZd3Ur8ok9yGhug/640?wx_fmt=png#imgIndex=2)

15年牛市最高飙到5左右，18年股票质押风险暴露让券商行业的估值中枢掉到了1-1.5PB区间，最惨的时候一度破净，我觉得这两段都不正常。

下图的绿色区域（1.5-2PB）属于合理的日常估值区间：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2O5vdEF82ebeRqSPYvSjlQmbaoH937MoLGur3R9d3AjujhuckbFia51Dy2gLhWe0g25icDqYsAjBDicA/640?wx_fmt=png#imgIndex=3)

证券ETF目前的PB大约是1.9倍。

如果你认为今年仍是波段行情，现在肯定偏贵。

如果觉得今年要刺激经济，还有这么多股市宽松政策，乐观估计能涨到3300-3500点，那么券商跑赢指数肯定是没问题的。反正万一牛市真来了，券商一定不会缺席。

至于具体券商股，中信、华泰应该归类到平时说的券商航母一类；

中信建投、中金公司的特点是投行业务优势明显，打科创板、香港新股的朋友应该能经常看到他俩的身影。

东方财富、同花顺属于经纪、两融业务做得最好的，弹性很高。

以上算是证券行业的入门介绍吧！

周五了，不写那么多。
