# 核保大放水，带病体千万别错过！

[图片]

弘康、复星、复保这3家公司今年搞了个「开门红」活动。

活动内容是大大放宽了核保条件，之前买不了，或者需要加费买、除外买的疾病，现在都可以标准体承保。

标准体承保，省钱不说，能买上比什么都强，并且还不会在保险公司留下「除外、加费」这样的附加条件记录。

带病的朋友，一定要多...
