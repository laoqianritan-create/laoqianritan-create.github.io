# 给大家看点儿恐怖的

日本给人的普遍印象有几个：

垃圾分类，流行断舍离，有收纳整理师，家里非常干净，老龄化严重，养老经验丰富等等...

今天给大家介绍另一个职业——特殊清扫。

其实还是收拾屋子，但客户比较特殊，订单可以分为两类：

一种叫垃圾房，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2NJ1icuMpUsXdUEiaybmZBkXl6DRAZ9VSELGp4YKaXEWC7D09Vbb1PffRFvD2CeDD9lr18lO5vlqfzg/640?wx_fmt=png#imgIndex=0)

上图房子的主人是一个单身中年人，平时打两份工很辛苦，基本顾不上家里。 

日本垃圾分类必须定天、定时、定点处理。

房主因为工作经常错开，日常垃圾只能在家里越堆越多，破罐破摔。 

最后扛不住了，找特殊清扫来处理。 

结果就这二十几平米的房间，8个保洁员愣是收拾了5小时。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2NJ1icuMpUsXdUEiaybmZBkXlNM1R7vmC1vNiblibkVJB09n9rPgxEUygtTAFdr1PNYXmBR0c6fn56RNA/640?wx_fmt=png#imgIndex=1)

因为必须把所有垃圾全部分类处理才能扔。

结束后叫来足足5辆车才运走，还用了5瓶杀虫剂来应付满屋子的蟑螂。

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2NJ1icuMpUsXdUEiaybmZBkXl5hMhQEnuYR881Fdibic9jtnAq9UaGo2OEPia7bOLEZLQ2zl6S4HjDjcug/640?wx_fmt=png#imgIndex=2)

最后收费两万多人民币，也挺恐怖了。

但其实这种订单还算好的，无非虫子多，味道不好而已。

第二类订单既恐怖又常见，叫孤独死，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2NJ1icuMpUsXdUEiaybmZBkXl1B4AicmFQlco6MnhaztUtRz6Wm2w6ciaueNQ1P8TSa7tLzIiaRv3xjbEA/640?wx_fmt=png#imgIndex=3)

就这一张，不多放了，容易引起不适。

日本常年独居的老人很多，而且水电费都直接绑定银行卡，不会断缴。

所以经常走了很久都没人发现...

很多都是亲朋联系不上或者邻居闻到臭味了才知道。 

这种情况的处理流程是一般是先报警，把人运走，然后叫来特殊清扫善后——

收拾、消毒、祛味，把房间恢复，可能还得让不动产管理公司重新装修下。

此外很多老人因为腿脚不利索，下不了楼，相当一部人平时也生活在垃圾房里。 

处理这种单子要穿防疫服，戴护目镜，袖口都要封死，还是有些危险系数的。

如果是租的房子，摊上这事，房东心情也可想而知了，所以也不愿把房子租给老人。 

我看完觉得挺震撼的，一股悲凉。

很多问题也不是人均可支配收入提高就能解决的...
