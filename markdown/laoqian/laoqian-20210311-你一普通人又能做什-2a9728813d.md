# 你一普通人又能做什么呢？

**●**

看了眼被市场当做救命稻草一样的1.9万亿美元财政刺激方案的具体内容，这里面有1万亿投向了「个人救济」。

每一轮灾难都有最受伤的领域。

比如08年次贷危机最惨的是承受了大量违约的金融机构和大量背了房贷的中产。

而本次疫情最受伤的是那些依靠中小企业、服务业谋生的底层老百姓。这些人收入差，信用差，储蓄差，又没了工作，情况非常惨。

很多人从去年开始都一路靠政府救济才活下来的，这并非危言耸听，美国一共进行了三轮财政刺激，核心内容就是给大量老百姓发钱，像这样：

![图片](https://mmbiz.qpic.cn/mmbiz_png/ibw8b04QVx2MqLuMF47qd8UsKGgZJ2LBlCbiaXlJ4ReMlSibJPp1PXgagD46AZ3zb40UBuibb4ibSiccYaKbyF9F5yxw/640?wx_fmt=png#imgIndex=0)

给一张大额支票，如果没工作，每周还有300美元的救济金，还包括帮那些租不起房的人延长租约，对有娃家庭税收减免等等。

有一些脑子里灌屎的恨国党把这理解为幸福，得多没同理心才会有如此离谱的想法。

说这么多就是想提醒大家多关注下现实生活，**不要以为股票或者指数涨了就岁月静好，世界从来不会围着股市赚。**

一个经济体的股票市场从来都只是货币流动性的外溢。

**经济增长（GDP）代表大部人的平均水平，金融资产只是少部分人的身价，两者并非亦步亦趋，甚至可以脱钩。**

**●**

每次应对危机的惯用操作都是凭空印钱**（发债）**，再把贷款成本**（利率）**压得很低。

08年次贷危机让很多中产一蹶不振，20年新冠疫情让大量普通人的生活雪上加霜。

**每一次降低利率（降息）都会拉大贫富差距。**

货币政策和穷人没啥关系，富人却能不断从中受益，核心差异在于**「现金流」**和**「抵押物」**上这两大要素。

每每谈到低利率总会收到两类天真问题：

①我们普通人应该怎么做呢？

②国外利率那么低，外国人为啥不借钱投资呢？

很简单。

穷人去银行加杠杆——

你月收入多少？哦，我因为疫情失业了。

你有房子作为抵押物吗？哦，我租房呢。

请问这杠杆怎么加？

银行不傻的，你日入斗金时，它求你贷款。

你惨淡经营时，它随时准备抽贷。

富人呢？有现金流，有更高的收入增速，有资产**（抵押物）**，还有银行送的杠杆。

贫富差距能不大吗？

这种问题是货币政策能解决的吗？

金融帮过穷人吗？

很显然，答案都是否定的。

相反，高利率是有利于穷人的。

**因为利率真正的锚是经济增长。利率高，说明经济增长快，居民收入增长快。**

不好意思，我只是来指出这种现象的，没解决办法。

俺也只是洪流里的一滴水。

这两天和关哥在准备一期播客节目，聊什么样的养老算及格的？

聊来聊去，发现说白了就三样东西：

人-还是亲生的最放心

钱-得有现金流支撑每月支出

房-电梯房是刚需

所以，你一普通人能做什么呢？

就那点儿事呗，搞钱，造人。
