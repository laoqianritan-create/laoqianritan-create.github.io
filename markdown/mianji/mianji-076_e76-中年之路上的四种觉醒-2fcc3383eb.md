# 076_E76.中年之路上的四种觉醒

[厚望] 面基的很多节目,首先是我自己感兴趣,需要投入时间去研究的课题,然后才能成为分享给大家的选题。投资理财,幸福,养老,这些都是我自己要长期关注的母题,当然中年也是。《第二座山》那期节目发布以后,我又看到了两本书,一本叫《中年觉醒》,其实这本书的英文名更贴合作者想表达的主题。它的英文名叫《从一种力量到另一种力量》,第二本书叫《中年之路》,它用戎格派的理论去解释人在中年时期,内心中所发生的这些变化究竟源自哪里。它告诉我们,中年时期所经历的各种内心中的痛苦的体验,其实是我们人格的第二次成型。就像我们在青春期的时候,早上起来膝盖会痛一样,我记得那时候每次膝盖痛我都很开心,因为我知道自己在长个儿,那如果能用这种心态去看待中年时期的种种欲结,它就又有了不同的意味。

[厚望] 我特别喜欢《中年之路》这本书《妖风》上的一句话,它说,中年是一段从痛苦到异议的旅程。其实稍微翻看这两本书的时候,我就意识到,之前发布《第二座山》那期节目还远远不够,所以趁着中秋假期,我就开始着手准备本期节目,和大家分享一下,这两本书中我印象深刻的内容,也算给《第二座山》那期节目打个补丁。本期节目会以《中年觉醒》这本书的内容和结构为主,因为《第二本》《中年之路》这本书,它的内容实在有些违心,而且表达过于书面化,所以我会把它穿插进节目的各个角落。但我尤其想和大家分享的是《中年之路》这本书的阅读体验。中秋假期我回了沈阳老家,这几天经常带着狗子在小区里面读这本书,周围有草坪,树木,却没有蚊子打扰。我靠在椅子上或者席地而坐,狗子就在脚边趴着,我妈在家里做饭,

[厚望] 我已经好久没有过这么舒服的时光了,希望这期节目能给大家带来一些看待和走过中年这段人生必经路的新角度以及新思路。另外还要感谢家庭清洁机器人品牌云晶对本期节目的赞助支持,在所有的内容形式中,播客是占用人体器官最少的,它解放了双眼,双手,双脚,因此我一直认为,一期节目最完美的收听体验一定是需要一个搭子的,正如面积在节目详情里鼓励的那样,大家在听节目时可以找一件更有意义的事做,比如逛公园,骑行,洗大澡,还有做家务。做家务是难得的个人解压时刻,也会给房间,这个不可避免陷入伤增的封闭系统引入一些负伤,其实家务活和我们平时接收到的各种信息,当然听播客也算,他们都是负伤,负伤会形成伤减,伤减就意味着秩序和干净。

[厚望] 当然了,嘴甜,眼里有活,更是中年男人的幸福秘诀之一。云京已经开启了新产品,云京智能洗涤机ISR Island光辉版的预售,这款产品攻克了洗涤机行业自清洁不干净,滚刷干不透,毛发缠绕,洗涤机有异味等等难点和痛点,首创了自清洁灵动岛,全面革新了自清洁体验,而且它低重心,轻量化,一操控,用它洗涤时手部负重仅0.8千克,而且没有跌缘线,足够轻盈,科学洗涤从自清洁开始,否则就是二次污染。云京是大湾区走出的国产品牌,也是家用清洁机器人行业的领航者,是连续四年登榜胡润全球独角兽的科技企业,目前已经服务全球超过300万用户,连续五年稳坐行业踏破万宝座。OK,接下来我们就进入正题,欢迎大家收听本期节目。我们将分别讨论在中年之路上跋涉时会经历的四种觉醒,

[厚望] 第一种是智慧觉醒。人生的上破路固然辛苦,但快乐,下破路虽然容易,但它痛苦。两条路,最核心的区别是,邪律究竟是向上还是向下,哪怕再功成名就的人,也难逃邪律向下的宿命。1831年,22岁的达尔文硬要参加贝格尔号环球旅行,借此他进行了长达五年的科学考察,期间搜集了各种珍稀动植物标本,然后把它们送回英国。他所寄回的这些宝贵资料引起了科学界和普罗大众的极大兴趣,也让达尔文声名确起。我们今天再看达尔文,当然取得了泰斗般的科学成就,但是回到他所处的大航海时代,其实能先别人一步去看世界,本身就已经十分不凡且幸运了,这些难道不应该归因于时代和运气吗?环球旅行五年以后,27岁的达尔文返回英国,他所提出的物竞天择理论彻底点燃了知识节,

[厚望] 达尔文享受了一段高邪律的漫长岁月,足足有30年,他构建了自己的理论体系,出版了著作、发表论文,声望与日俱增。1859年,达尔文50岁的时候,被后人铭记的《乌荣起源》出版了,这是他人生的高光时刻,但人生的真相是高峰难跃,邪律难知。此后的岁月里,达尔文遭遇了中年危机,当然那个时候距离中年危机这个词被真正的发明出来还很遥远。达尔文的中年危机是,痛苦于自己的创造性停滞不前,研究进入了平静期,尽管他后来又出版了不少著作,但这些作品显有新意和创建性。达尔文痛苦于雄孔雀美丽的伪评为什么那么无用?因为按照物尽天则太弱留强的理论,这种美丽而无用的东西压根就不应该存在啊。尽管后来有一位叫梦德尔的杰克修士发现了遗传学理论,

[厚望] 这是达尔文进一步展开研究所需要的理论。但是这份研究被发表在了一份不知名的德国学术期刊上,达尔文一生都未曾读到过它。我喜欢把那些让人快乐到上瘾的阶段统称为高邪律。同比增速为正不是爽,真正的爽其实是环比增速为正。这意味着下一秒要比上一秒更爽。贪婪的多巴胺其实耗的是这口,而一旦当环比增速下降的时候,哪怕同比仍在增长,大脑已经觉得索然无味了。进入中年危机的达尔文痛苦于自己的往日荣光,他几乎拥有了一切值得幸福和满足的东西,但他厌倦了自己的生活。他就像一个原来壮高薪却被优化掉的大厂员工,事业不如下行期,音乐停止,宴席结束,但是,不甘心啊,非要想办法做IP,卖保险,当陪跑教练,教人家做所谓的增长,硬撑着让宴席不散场,

[厚望] 结果越努力越悲伤。其实这些大厂员工和晚年的达尔文并无本质上的不同。你当然可以说,少年得志,晚年抑郁,这并非是人生常态,但真的是这样吗?《觉醒》这本书的第一章就在讨论说,职业下行时期就是常态,而且它比你想象中要来得更快,对此我完全同意。真相是,几乎所有从事高技能型职业的人呢,在30多岁到50多岁之间的某个时间点,都会开始进入下行通道,有可能是因为个人原因,也有可能是行业或者宏观因素的原因。下句话更可怕,一个人在事业巅峰期所做出的成就越高,那么他在下星期的表现往往也就越差。如果你觉得这一切太过残忍,可以想象运动员,他们退役之后干什么?可以说这是每个运动员都躲不掉的命题。当然我也极其佩服,比如勒布朗詹姆斯或者科比这样伟大的运动员,

[厚望] 用极致的科技以及各种科学手段,去尽可能地拉长自己运动生涯的97,后面我们也会谈到如何拉长自己的牛马生涯。不是,那个,执商97,我说错了。可是看看赞姆斯,他今年也在39岁,但是幸福是比较出来的。可能对詹黄来说,尽管他的竞技水平与日俱下,但至少他还能keep on the court,对吗?不相可比。类似的《觉醒》这本书说,统计数据发现,科学家们常常在自己30多岁时做出了伟大的发现,但是在40多岁,50多岁,60多岁这几个时间段里面,有重大突破的可能性就急剧下降。一个人在70岁时做出重大创新的概率和20岁时差不多的,都几乎为零。对科学家们学术高峰年龄的统计结果还显示,从1985年以来,物理学家的世界巅峰依然是50岁,

[厚望] 化学家的学术巅峰大概是46岁,药学家的巅峰大概是45岁。一旦过了巅峰年龄,这些研究人员的创新能力就会急剧下降。其他知识领域也在遵循类似的基本模式,作家步入事业下行通道的时间大概在40到55岁之间,金融从业者最好的投资业绩的时间段,普遍也在36到46岁之间。医生往往在30多岁时达到职业巅峰,他的技能水平会下降,甚至做手术的失误率都会更高,这些都有数据来支撑。甚至连创业这件事,人到中年创业的能力都会急剧下降。所以既然这是一种相当普遍的规律,它一定是有原因的,对吗?一个比较好的解释是,是我们大脑的前额叶皮质的性能,会随着时间而发生变化。前额叶皮质是我们童年时期,大脑发育最晚的一部分,但成年以后它又是最早开始衰退的习惯。

[厚望] 它主要负责工作技艺,执行能力,还有屏蔽与手头任务无关的信息。只有它足够强大,我们才能集中注意力去提高自己的核心技能。所以一个容量大且强健的前额叶皮质,可以让我们在自己的专业领域上游刃有余,无论是处理法律案件,做手术,还是开公交车。但是人到中年,前额叶皮质的工作效率就是会降低。这意味着我们的快速分析和创新创造能力都会下降。其次,它还意味着一些曾经很容易上手的技能,比如多任务处理,也开始变得不再得心应手。也就是说,年纪越大的人干活的时候就容易分心。直到这儿我突然想起来,我高中的时候可以一边听结论的歌,一边做地理习题,但是如今我写博客竹子稿就只能听轻音乐了,旋律还不能太激烈,手机也得塞进抽屉里面,锁上,

[厚望] 为了防止自己看到别人发来的微信,还得把写作的页面最大化。前额叶皮质负责的另一项技能是记忆能力。随着年龄的增长,我们大脑里的信息就像一座图书馆那么多,但是你的图书管理员他年事已高,行动缓慢,容易分心。比如年纪大了以后,你让这位管理员帮你回忆起某个人的名字,可能他得先花一分钟站起来,喝口咖啡,再和管理期刊的负责人聊会天,然后拎着包就要下班了,他完全忘记了你的指令。而当你为自己的记忆力大不如前感到自责的时候,这个老头拎着包又回来了,他说哦,我想起来了,你刚刚问的那个人他名字叫老六。不如职业下行期还有一个定律,说出来也许能让很多人平衡一些,这个定律很简单,就是你飞得越高就跌得越痛。一个人在中年时期的失落感和他之前取得的成绩,

[厚望] 以及对过往念念不忘的程度是高度正相关的。如果一个人本来就对自己没有什么期待,日常语境中我们喜欢管这种人叫没有上进心,但是你还别说人家可能就是过得比你快乐,但偏偏是那些人上人爱好者,奋斗和增长成因者们的下坡路,呵呵,你看着吧。现在我们可以总结一下人生下坡路要面临的几重可能的打击。第一重是,我们会不自觉地渴望更大的成功,用更高的二阶岛增速来避免一难平,但这不太可能,正如你炒股票不可能把K线拉直了转一样,高增速的好时光往往就那么一段。第二重打击是,随着年龄的增长,我们真的很难维持现有的水平。第三重打击就是,当我们过分执着于更大的成功,还有职业技能下降这些关系的时候,很容易最终会陷入成瘾模式,比如变成工作狂。

[厚望] 这会让那些奋发向上者,或者说奋斗逼们,陷入一种很不健康的关系,就是他以牺牲自己的健康,与配偶,孩子,朋友们的深层关系为代价。这也是中年那期播客的第二部分,老男想提醒我们的,就是把自己与家庭,与身边人的关系搞搞好。而且你知道最惨的是什么吗?就是没有人会共情你,大部分人都只会觉得你矫情,尤其是那些曾经做出过成绩,在世俗眼光中他们过得还不错,有点成功的那些人。大家并不会为你的遭遇和苦闷而感到遗憾,他们只会觉得你太矫情,身在福中不知福,他们甚至乐得看到你难受。一个生活无忧的奋斗逼的所谓的挣扎,只会让人觉得在无病呻吟,很不真诚,虽然你确实在挣扎,那怎么办呢?《觉醒》这本书说,在你面前有三道门。一号门,你可以拒绝接受这一切,

[厚望] 否认现实,不甘平凡,愤怒地,固执地对抗下行,但可能会陷入不断的沮丧和失望当中。二号门,你可以耸耸肩接受这一切,任命躺平,然后将人生的下坡路视为一场宿命般的不可避免的悲剧。三号门,你还是得接受现实,那些曾经令你清云直上,功成名就的职业技能,确实都成了过眼云烟,一切都归于平淡了,但是你可以带着自己的好奇心,重新找点新乐子,学点新事。这会让我想起周乐华老师在时间游戏里说的,终身学习并不是一个空洞的鸡汤式的口号,而是不管我们是否愿意,我们一生中总会经历几次集体游戏的切换,每次换游戏的根本原因是为了解决新的问题。为此,新的游戏会鼓励一些新技能,鼓励的方式就是给予掌握这项技能的人更高的估值,让这些人的社会地位上升,

[厚望] 所以学习新技能是为了适应新游戏,仅此而已。我又想起面积的一位60后嘉宾季老师,季老师之前和我说过,他这么多年有四个最能拿得出手的技能,第一是编程,他老程序员了学过不下十种编程语言,第二是天文,当年被随机性推了一把,不知不觉地走上了这条路,但是干一行爱一行,做到了教授。第三是投资理财,出于朴素的,要解决自己养老和子女教育的目标,季老师开始学习理财,他规避了股票,研究基金,然后把自己的学习心得体会发在了论坛上,成为了我国第一代的基金大V,直接间接地影响过很多人的投资理财观念,甚至是他们的人生道路。第四个技能是留学咨询,这是当年他在民办大学里面当老师,为了学生能多挑出路,开始研究留学,在这个过程中熟悉了英美澳东南亚等等地区的留学情况,

[厚望] 很多他身边朋友的子女留学的问题都是找他做的咨询,其实这四种能力背后是季老师的四段人生经历,这些经历需要不同的技能。之前有听过季老师的节目,说他是典型的强者思维,对此我不否认,但每每想到他我都很受鼓舞,或者说每当我真的需要学点什么的时候,我更有好奇心了,而不是更有勇气了。这种心态的切换是我最大的收获,尽管最终的行为都是学习新技能,但是我相信好奇心会比勇气更好使,就是这两位前辈给我的智慧。周乐华老师教会我要去看天外天,要去学习新技能,杰老师教会我要乐观,出来混的第一步是出来,先干再说,所以我想面对所谓的中年转型,以上种种同样适用,注意不是痛苦的无奈的被迫转型,而是找点心乐,乐呵乐呵。生命都有周期,人生由绚烂归于平淡本身就是应有之意,
